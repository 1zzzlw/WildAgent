# WildAgent RAG 文档模板

先从 `metadata-schema.md` 复制 frontmatter，再按文档类型选择模板。删除空章节，不为了统一外观保留无内容标题。

## WILD Schema / 蓝图规范

```md
# WILD `<type>` 规范

## `<type>` 定义与能力边界

## `<type>` 最小字段集合

## `<type>` 字段说明

## `<type>` 坐标与引用规则

## `<type>` 约束与校验

## `<type>` 最小有效 JSON

## `<type>` 常见错误

## `<type>` 与其他构件的关系
```

字段表、坐标规则、正确示例和错误示例回答不同问题；内容较长时使用独立真实标题，不放进同一个超长章节。

## 构件族

```md
# `<构件族>` 分类与组装规则

## `<构件族>` 定义

## `<构件族>` 当前引擎能力边界

## `<构件族>` 组装主题

### `<风格或功能分组>`

#### `<具体变体>`

<!-- rag-meta
entity_type: <canonical type>
entity_name: <canonical entity id>
topic: assembly
status: supported
authority: engine
keywords: <中文名>, <英文名>, <WILD 字段>
-->

##### `<具体变体>` 定义与适用场景

##### `<具体变体>` 所需 WILD 构件

##### `<具体变体>` 参数与空间约束

##### `<具体变体>` 最小有效 JSON

##### `<具体变体>` 常见错误
```

每个具体变体使用真实标题，并在变体标题后提供 `rag-meta`。多个变体不得依靠粗体编号区分；没有内容的中间分组标题应删除。

## 建筑类型

```md

## `<建筑类型>` 默认语义

## `<建筑类型>` 默认完整构成

### `<建筑类型>` 默认完整构成合同

- 识别特征：
- 空间与体量：
- 主体骨架：
- 外围护：
- 开口组件：
- 交通组件：
- 附属组件：
- 重复与模数：
- 组装与依附：
- 降级映射：

## `<建筑类型>` 推荐尺寸与比例

## `<建筑类型>` 构件组合顺序

## `<建筑类型>` 风格变体

## `<建筑类型>` 最少可行回退

### `<建筑类型>` 回退触发条件

### `<建筑类型>` 回退保留与简化项

## `<建筑类型>` 最少可行蓝图示例

## `<建筑类型>` 必须校验的约束

## `<建筑类型>` 不支持或需要降级的能力
```

详细建筑文件的默认完整构成使用 `topic: composition`，最少可行回退使用 `topic: fallback`。两者不得合并成一个“最小构件”段落。构成合同中的每个系统注明 `required / characteristic / conditional / optional`；来源未提供的类别写“来源未提供”，不要猜测。

catalog 版本保持简短，只保存默认语义、检索关键词和 fallback 入口；详细建筑文件可以为每个风格变体增加实体级 `rag-meta`。多建筑文件中，每个建筑实体都必须有自己的构成合同，不能只在文件开头放一份总表。

多建筑实体推荐结构：

```md
## `<建筑类型>`

-->

<使用上述十项合同或“系统角色/WILD 映射/优先级/条件/省略后果”表。>

### `<建筑类型>` 关键组装关系

### `<建筑类型>` 最少可行回退

<!-- rag-meta
topic: fallback
-->
```

## Pattern / 已确认案例

```md
# `<模式名称>`

## `<模式名称>` 用户目标

## `<模式名称>` 可复用决策

## `<模式名称>` 蓝图摘要

## `<模式名称>` 不应泛化的内容

## `<模式名称>` 已验证结果
```

Pattern 必须能够追踪到用户确认或已验证项目，不得把单次偶然参数包装成通用规则。

## JSON 示例

有效示例使用：

````md
### `<实体>` 最小有效 JSON

以下是 `geometry.elements` 片段，不是完整 `.wild` 文件。

```json
{
  "id": "example",
  "type": "supported_type"
}
```
````

错误示例放在单独标题和代码块中，并在代码块前明确说明错误原因。若需要展示非严格 JSON 的注释说明，代码语言使用 `text`，不得标成 `json`。
