## 修复 LangGraph 启动失败：`cannot import name 'web' from 'app.agent'`

**现象**：`langgraph dev` 加载 `./langsmith_tools/studio_graph.py` 报
`ImportError: cannot import name 'web' from 'app.agent' (unknown location)`，服务启动即退出。

**根因**：提交 `a22336f`（更新了一下目录结构）把 `app/agent/web/` 整体移到
`app/agent/knowledge/web/`，但 `app/agent/nodes/web_research_node.py:23` 的
`from app.agent import web as _web_api` 漏改；`app.agent` 是隐式命名空间包（无
`__init__.py`），所以报错信息里出现 "(unknown location)"。

**修复**：`web_research_node.py:23` 改为 `import app.agent.knowledge.web as _web_api`。
测试对 `app.agent.knowledge.web.create_search_client` 打补丁，别名指向同一模块对象，仍生效。

**验证**：
- `python -c "from app.agent.graph import build_generation_graph"` OK
- 按 langgraph 方式 `spec_from_file_location` 载入 `studio_graph.py`，图编译成功
- `pytest tests/agent` → 85 passed
- 全量导入扫描 `pkgutil.walk_packages(app.__path__)` → 112 模块 0 失败

**注意（约定）**：`app/agent/` 根目录**故意不放 `__init__.py`**，
`tests/agent/test_agent_module_boundaries.py` 断言根目录只有
`graph.py / routing.py / runtime.py / state.py`。加 `__init__.py` 会让该测试失败。
副作用：`pkgutil.walk_packages(app.__path__)` 不会下钻 `app.agent`，
需单独用 `app.agent.__path__` 扫描。
