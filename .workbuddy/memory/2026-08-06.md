# 2026-08-06 工作日志

## 生成建筑「错位/偏移/重叠」根因诊断（用户要求全面复查）

结论：**不是渲染引擎 bug，也不是单纯提示词问题，而是管线设计缺陷**——LangGraph 各节点自由生成坐标，但缺少介于 merge 与渲染器之间的「确定性蓝图归一化/修复层」（schema 合规 + 几何坐标不变量强制）。

证据（115 个 .wild 批量扫描，`scripts/analyze-batch.mjs`）：
- 重建错误 = 0（渲染器稳健）
- 解析失败 = 29（25%，schema 不合规，整图报废；含旧 schema 残留 parentFloor / 旧枚举）
- 开口墙角 = 12（墙端点不共享）
- 双墙/重叠墙 = 2（z-fighting）
- 同墙真实组件重叠 = 12（门窗同高重叠）
- 组件编译错误 = 3（个别构件被静默丢弃）
- 手绘参考 `generated_modern_villa.wild` 验证为 0 问题（基线）

失败模式映射缺失的守护环节：schema 修复门、墙角 snap、墙体去重、同墙开口排布/间距校验、竖向连续性对齐、from[2]≈0 归一。

修复建议：新增 `blueprint_normalizer`（merge/final_validate 后调用），严格回滚不静默。

产出文档：`docs-dev/生成建筑错位重叠根因诊断.md`

注：此前修的 design_brief/component_quota 只管「数量」，没管「坐标位置」，所以重叠/错位仍在。
