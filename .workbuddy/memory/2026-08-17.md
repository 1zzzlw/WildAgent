## roof 几何错位根因 —— 知识库 roof 章节事实偏差（非 skill 设计问题）

用户用 `.codex/skills/wild-knowledge-ingest`（知识入库 skill）维护 RAG 知识库
`wild-server/storage/knowledge_base/`（42 个 md）。RAG 检索源就是它（`collect_markdown_paths(_KB)`）。

**结论**：skill 设计本身严谨（事实优先级「渲染引擎源码 > 规范 > 样例 > AI 推断」、
交叉验证、真实分片预览），不是 skill 的问题；问题在**知识库文档 `BLUEPRINT-SPEC-FULL.md`
的 roof 章节（约 303–334 行）与渲染器 `wild-web/src/wild-core/src/primitive/geometry/roof.ts`
有 3 处事实偏差**：

1. `position` 写成「位置（自动计算时可省略）」——渲染器实为 `pos = params.position ?? [0,0,0]`，
   省略即默认原点，**不会自动算中心**。
2. 没写 flat 屋顶**忽略 height**（`buildFlat` 只接收 span/depth/thickness）；height 却标「✓ 必需」，
   模型就给平屋顶填墙高 4.5。
3. 没写「L 形 / 退台 / 多翼要按翼拆多片 roof、各自对齐该翼中心与支承标高」，
   退台别墅生成了 span=12 的单片大屋顶盖住只有一层的侧翼 → 悬空 3.2m。

**渲染器 roof 语义（已验证，供后续修正知识库用）**：
- `hw = span/2`（X 向）、`hd = depth/2`（Z 向）、`position` = 底面中心世界坐标；
- flat 屋顶 `position.y` = 支承标高（墙顶），实体从 y 向上增厚 `thickness`；
- `height` 仅坡顶/穹顶/曲面屋顶使用，flat 忽略。
