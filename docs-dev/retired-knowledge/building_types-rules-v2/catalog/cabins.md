- 适用条件：用户或已批准方案明确采用木屋；名称本身不决定全部构件。
- 类型特征：木构或木饰面的居住体量；前廊、烟囱与坡顶都是条件选择。
- 条件关系：选定前廊后安排板、柱梁与屋盖；烟囱按真实屋面定位，门窗绑定围护墙。
- WILD 映射与边界：wood 是材质角色而非结构验算；chimney 不自动穿透屋顶。
- 自由变量：层数、体量轮廓、开间、屋顶形式与材质由本次需求和方案确定。
