# 凉亭：类型特征与条件关系

> 来源：本文件旧版资料的语义审查；旧稿逐节保存在 docs-dev/knowledge-before-rules-v2。仅保留有用的类型差异，示例尺寸、默认配色和整栋蓝图不参与生成。共性字段以 components/ 与 BLUEPRINT-SPEC-FULL.md 为准。

- 适用条件：用户或已批准方案明确采用凉亭；名称本身不决定全部构件。
- 类型特征：开放停留空间与遮蔽屋盖的联系。
- 条件关系：柱数由平面、跨度及选定屋顶决定；开放边界不强制围墙或门窗。
- WILD 映射与边界：column/beam/roof 与平台 floor 表达；中式、四角或八角由需求触发。
- 自由变量：层数、体量轮廓、开间、屋顶形式与材质由本次需求和方案确定。

## 现代廊架

- 适用条件：用户或已批准方案明确采用现代廊架；名称本身不决定全部构件。
- 类型特征：开放空间与重复遮蔽构件的联系。
- 条件关系：遮蔽杆件按所选支撑和节奏重复；不强制增加封闭屋面。
- WILD 映射与边界：beam/primitive 表达杆件，column 表达支撑；网架和膜结构没有自动生成字段。
- 自由变量：层数、体量轮廓、开间、屋顶形式与材质由本次需求和方案确定。
