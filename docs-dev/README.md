# WildAgent 历史文档归档

本目录保存开发过程中的方案、阶段总结、Bug 复盘和旧版项目文档。内容未被删除，但可能与当前代码不一致，不应作为实现依据。

当前权威文档统一位于 [`docs/`](../docs/README.md)。

## 目录约定

| 目录 | 内容 |
|---|---|
| `docs/` | 原 `docs/` 中的专项方案和阶段材料 |
| `root/` | 原仓库根目录中的思路与项目文档 |
| `wild-server/` | 原后端目录中的修复、测试和实施总结 |
| `wild-web/` | 原前端目录中的修复报告和专项说明 |
| `former-docs-2026-08-08/` | 本次文档治理前仍被当作正式文档的完整快照 |

## 使用规则

- 查当前架构、开发方式和路线时，只阅读 `docs/`。
- 需要追溯设计动机或历史 Bug 时，再按原目录进入本归档。
- 历史内容如要重新成为正式结论，必须先与源码和测试核对，再合并到 `docs/`，不要直接搬回。
- 新的临时分析和实施记录可继续写入本目录，并在文件名中包含主题或日期。

本次整理只移动和归档了旧文档，没有永久删除；根 README 的旧版本也保存在 `former-docs-2026-08-08/root/README-before-cleanup.md`。
