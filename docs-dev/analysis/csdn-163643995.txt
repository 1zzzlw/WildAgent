TITLE: 阿里云百炼向量模型踩坑：一次最多传20条，超过就报400错误


阿里云百炼向量模型踩坑&#xff1a;一次最多传20条&#xff0c;超过就报400错误** 
在使用阿里云百炼&#xff08;DashScope&#xff09;的向量模型时&#xff0c;发现文档切分后如果一次上传超过20条&#xff0c;就会报 400 错误。本文记录问题原因和解决方案。 
一、问题描述 
 在使用 LangChain &#43; 阿里云百炼做 RAG 应用时&#xff0c;将文档切分成多个 chunk 后&#xff0c;调用 embedding 模型生成向量&#xff1a; 
 from langchain_community . embeddings import DashScopeEmbeddings
embeddings &#61; DashScopeEmbeddings ( model &#61; &#34;text-embedding-v3&#34; ) 
# 假设切分出了 50 个 chunk 
texts &#61; [ chunk1 , chunk2 , . . . , chunk50 ] 
# 一次性传入所有 chunk 
vectors &#61; embeddings . embed_documents ( texts ) # ❌ 报错&#xff01; 
错误信息 
 dashscope.common.error.InvalidParameter: 
HTTP code 400, {&#34;code&#34;:&#34;InvalidParameter&#34;,&#34;message&#34;:&#34;The input is invalid...&#34;,&#34;request_id&#34;:&#34;xxx&#34;}
或者&#xff1a; 
 openai.BadRequestError: Error code: 400 - {'error': {'code': 'InvalidParameter', 'message': 'The input is invalid...'}}
二、原因分析 
 2.1 官方文档的限制 
 查阅阿里云百炼官方文档&#xff0c;发现 text-embedding-v3 模型有以下限制&#xff1a; 
 限制项 限制值 单次请求最多输入条数 20 条 单条文本最大 Token 数 8192 总 Token 数&#xff08;单次请求&#xff09; 约 32000 
 关键点 &#xff1a;一次请求最多只能传入 20 条文本 &#xff0c;超过就会报 400 错误&#xff01; 
 2.2 LangChain 默认行为 
 LangChain 的 embed_documents() 方法 默认会一次性传入所有文本 &#xff0c;不会自动分批。所以当你的文档切分超过 20 个 chunk 时&#xff0c;就会触发限制。 
三、解决方案 
 方案一&#xff1a;手动分批处理&#xff08;推荐&#xff09;

六、常见问题 
 Q1&#xff1a;为什么阿里云要限制 20 条&#xff1f; 
 主要是为了&#xff1a; 
 控制单次请求的计算量 &#xff0c;避免超时 保证服务质量 &#xff0c;防止单个用户占用过多资源 降低出错概率 &#xff0c;小批量更容易定位问题 
 Q2&#xff1a;batch_size 设置成多少合适&#xff1f; 
 推荐值 &#xff1a;20&#xff08;官方限制&#xff09; 保守值 &#xff1a;10-15&#xff08;留点余量&#xff09; 不推荐 &#xff1a;超过 20&#xff08;会报错&#xff09;
