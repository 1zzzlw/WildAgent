## 1. 类型定义与特征

### 1.1 类型学界定

现代简约别墅是低层（1–3 层）独栋居住建筑，以**几何纯粹的体量、简洁屋面（平顶为主，双坡为变体）、大面玻璃与实墙的虚实对比、克制的色彩**为标志。与相近类型的区分：

| 对比类型 | 区别要点 |
|---|---|
| 坡顶小住宅（通用协议 F1） | 本类型**以平顶 + 女儿墙为原型**；双坡仅作 §7.4 变体（山墙朝主立面，无中式举架曲线） |
| 中式宅院（F2/F3） | 无坡瓦、无柱廊；木色仅作点缀不做结构表达 |
| 玻璃幕墙公建（F5） | 玻璃是**开洞窗**（宿主墙 + window 组件），不做整片幕墙 |
| 多层公寓（F6） | 层数 ≤3、体量错落而非规则柱网重复 |

### 1.2 五大类型特征（生成时的"气质校验"）

1. **体量语汇——错动的盒子**：2–3 个几何纯粹的体块咬合，禁止每层同轮廓的"叠方盒"。惯用手法：底层满铺基座、上层退让出露台、翼体延伸、局部悬挑（≤1.2m）。
2. **虚实对比**：每个主要立面同时存在"实"（白墙）与"虚"（大玻璃），虚实比约 6:4～7:3；南向（主立面）虚面最大。
3. **材质体系——三色律**：全楼外墙**统一一种材质**（默认暖白），配深灰金属框与木色点缀；全楼可见材质 ≤4 种；**严禁各层异色**。
4. **开口逻辑——水平长窗 + 四分格**：窗以水平向为主（宽 ≥1.5m），统一 `frameWidth 0.09` 深灰框 + 四分格/竖梃；同一立面同轴同型号。
5. **屋面即第五立面**：平顶时退台处全部升格为可到达露台（floor_terrace + 女儿墙 + 可达门窗）；双坡时山墙三角面作为主立面构图要素，坡下空间不设露台。

### 1.3 默认设计参数表 P（未指定时全部采用，并向用户标注假设）

| 参数 | 默认值 | 参数 | 默认值 |
|---|---|---|---|
| 层数 | 3 | 外墙厚 / 内墙厚 | 0.24 / 0.12 |
| 轴网开间 | 5.0 × 3 跨（总长 15） | 地坪厚 / 楼板厚 | 0.20 / 0.20（休息平台 0.15） |
| 轴网进深 | 5.0 × 2 跨（总深 10） | 女儿墙 | **高 0.90–1.20 / 厚=墙厚 0.24**；对齐墙边；底=板顶 |
| 层高 | L1 3.6 / 上层 3.0 | 楼梯 | 双跑，梯宽 1.2，步高 0.15–0.18，步深 0.24 |
| 主入口 | 南面，1.2×2.2 单扇 + 雨棚 + 两级台阶 | 阳台 | 南向 ×2（上层卧室），3.6×1.5 |

**板的级配（与层数联动，见 §5.4）**：N 层 → **1 组地坪（仅一层，轮廓=一层外轮廓）+ N−1 组层间楼板（每组并集=下层外轮廓，板顶=上层地板）**；顶层顶板由屋面系统承担，不另写楼板。

### 1.4 类型文字描述（智能体可直接引用的"标准话术"）

**总体描述（代参数版）**：

这是一栋[层数]层的现代简约风格独栋别墅，平面呈[轴网总长]米 × [轴网总深]米的矩形基座，总建筑面积约[Σ层面积]平方米。建筑整体由[2–3]个几何纯粹的体块咬合而成：首层作为完整基座满铺场地，二层向西收拢为[主块尺寸]的主体、向东伸出[翼体尺寸]的翼体，顶层再度收为[顶层尺寸]，两次退让在东侧和东北角分别造就了高出室外[标高1]米与[标高2]米的屋顶露台，使建筑剖面呈清晰的阶梯状退台。立面以暖白色涂料实墙为底，穿插深灰色金属框的水平长窗与整面落地玻璃，虚实相间；[平屋顶以深灰色女儿墙收边 / 双坡屋顶以深灰屋面覆盖，山墙三角面正对南向主立面]，与白墙形成两色对比，木色仅在门扇与室内地板处作点缀。入口位于南面中央，两级混凝土台阶与深灰雨棚界定了谦和而明确的进门序列。

**气质描述（固定话术）**：

建筑的语言是克制的：没有线脚、没有装饰构件，全部表现力来自体量本身的错落、玻璃与实墙的比例关系，以及三种颜色（暖白、深灰、木色）之间的克制搭配。水平向的长窗强化了低层建筑的舒展感，露台把"屋顶"变成可居住的第五立面，楼梯间借助外墙高窗获得垂直贯通的自然光——白天整栋建筑像一组被阳光切割的白色盒子，夜晚室内灯光则透过分格玻璃透出安静的网格。

### 1.5 基本形式特征描述（分维度）

**① 体量特征**：由 2–3 个长方体盒子错动咬合，几何纯粹、边角锐利；禁止曲线与装饰性体块。层间至少一处退让或悬挑，形成"基座—主体—退台"三段式剖面；悬挑 ≤1.2m，悬挑下方即灰空间或入口。

**② 立面特征**：构图逻辑是**实墙与玻璃的面积对比**（约 6:4～7:3），每个主立面同时有"实"与"虚"。窗全部为矩形水平窗，以 1.5–1.8m 标准窗为基本单元、4m 级横向大玻璃为客厅主角色；深灰细框四分格或竖梃，窗台统一 0.9m（客厅大玻璃 0.3m），同轴同型号逐层对位。上层卧室常带 1.5m 出深的南向阳台，栏板为细金属杆。

**③ 屋面特征**：平顶 + **0.90–1.20m 女儿墙（厚=墙厚，对齐墙边）** 为原型，退台暴露屋面全部升格为露台；**双坡变体**（§7.4）山墙三角面朝主立面，坡角 25°–35°，无中式举架曲线。屋面不是覆盖物而是构图与活动面。**无墙的屋顶/露台边缘必须做女儿墙**（通用硬性）。

**④ 材质与色彩特征**：三色律——暖白涂料（主调，≥70% 可见面积）、深灰金属（框料/栏杆/压顶）、木色（门扇/室内地板点缀）；全部哑光，无镜面高反射；玻璃为淡蓝透明（transmission 0.92）。

**⑤ 比例与尺度特征**：开间 4–5m、层高 3.0–3.6m，窗高普遍 ≥1.5m，建筑总高（3 层）≈10m——总体**横向舒展**；南立面窗带与实墙交替周期约 5m，与轴网同构。

**⑥ 入口与序列特征**：主入口位于南面轴线附近，雨棚 + 两级台阶构成过渡空间；L1 公共区（客厅/餐厨）居南向采光面，上层私密区（卧室），动静分层、洁污分区。

**⑦ 竖向交通特征**：双跑楼梯藏于角部楼梯间（默认西北角），借外墙高窗采光，梯井垂直贯通——楼梯间在外立面上表现为一列上下对位的竖向窗带，是唯一暴露"垂直性"的元素，与水平长窗形成方向对比。

**⑧ 场地关系特征**：**±0.000 = 室外地面**，建筑抬升 **0.45m 室内外高差**（首层室内地坪顶 = +0.45），以**三级 0.15 台阶**消化，整栋坐落于**实心地基（勒脚，顶 +0.45 / 底 −0.02 / 四面出挑 0.06）**之上；不设院墙时以 L1 满铺体量的檐下阴影定义边界；露台朝东南开口取日照。

## 3. 引擎关键语义速查（完整版见书写说明 §1.4）

> 以下 5 条是**设计决策时必须提前预判**的引擎行为；字段级写法与模板一律查书写说明。

| # | 语义 | 对设计决策的影响 |
|---|---|---|
| ① | `floor.from[1]` = **板顶**，板向下延伸 | **板顶 = 下层墙顶 = 上层墙底（与墙体顶面同一平面）**；「下层屋顶楼板≡上层地板」只写一次；地坪仅一层 |
| ② | 墙 `from/to` 为**轴线中线**，厚度法向对称 | 外轮廓尺寸按**轴网**定，不要按外皮定 |
| ③ | 门窗构件 `from` = [左边缘沿墙距离, **世界 Y**, 0] | 上层构件坐标含累计层高（L2 门写 3.6 起） |
| ④ | 楼梯升高 = `stepHeight × stepCount`（与 from/to 的 Y 无关） | **层高必须先定**，步数×步高 = 半层高 |
| ⑤ | 屋顶**必须显式定位**（position），否则会被扩展到全楼包围盒 | 多体块建筑：屋顶只盖顶部体块，露台不设屋顶 |

**摆放顺序提示**：元素在 JSON 中的排列顺序不影响渲染，但建议按"楼板 → 墙 → 楼梯 → 屋顶 → primitives → components"书写以便自检。

## 4. 体块构成规则（防"叠方盒"——本类型的灵魂）

### 4.1 轮廓错落律
相邻两层实体外轮廓**至少一处退让或悬挑**，禁止完全重合。推荐三段式：**L1 满铺基座 → L2 主体 + 翼体 → L3 主体 + 露台**。

### 4.2 支承约束律
缩进/悬挑的上层墙体必须有同轮廓的下层楼板托底。生成时**自上而下检查**：L3 轮廓 ⊆ L2 楼板，L2 轮廓 ⊆ L1 楼板（→ 书写说明 §5.6）。悬挑 ≤1.2m 且在设计说明中显式声明。

### 4.3 露台升格律
上层退让暴露的下层屋面**必须升格为露台**：floor_terrace 面 + 女儿墙 + 至少一樘可达门窗。禁止留裸楼板。

### 4.4 翼体收头律
L 形/T 形平面中，翼体尽端设满长女儿墙或高墙压边，与主体墙外皮精确对齐（**角部按 §6.4 三层总律：端点重合、引擎斜接，90° 阳角零缺口**），不留缺口。

### 4.5 两个已验证体块（可直接套用）

**实例 A（三层平顶，轴网 15×10）**：

| 层 | 轮廓 | 说明 |
|---|---|---|
| L1 | 15×10 满铺 | 完整基座，客厅大玻璃朝南 |
| L2 | L 形：主块 10×10（X 0–10）+ 东翼体 5×6.5（X 10–15, Z 0–6.5） | 主块正好托住 L3；东北角退让 |
| L2 露台 | 5×3.5（X 10–15 × Z 6.5–10） | L1 屋面升格，+3.8m |
| L3 | 10×10（X 0–10） | 书房 + 主卧 |
| L3 露台 | 5×6.5（X 10–15 × Z 0–6.5） | 坐在翼体屋顶上，+6.8m |

**实例 B（两层双坡，轴网 11×9）**：

| 层 | 轮廓 | 说明 |
|---|---|---|
| L1 | 11×9 满铺 | 基座 3.6m 层高 |
| L2 | 9×7（东退 2m + 北退 2m） | 山墙朝南的主立面构图 |

## 5. 平面与轴网规则

### 5.1 轴网
南立面沿 X 展开；开间默认 5.0×3 跨、进深 5.0×2 跨（实例 B 为 5.0×2 跨 × 4.5×2 跨）。门窗、隔墙、楼梯**全部以轴线定位**，立面每个开口都能追溯到轴网。

### 5.2 房间表（范例，可按需求改）

| 层 | 功能 |
|---|---|
| L1 | 客厅（南向开敞，大玻璃）、餐厨（侧翼）、玄关（南中）、楼梯间（角部） |
| L2 | 卧室 ×2（带南阳台）、家庭厅/书房（中部）、露台可达房间 |
| L3（三层时） | 书房（南）、主卧（北），开门通露台 |

### 5.3 隔墙
内墙 0.12；位置避让北立面窗洞（隔墙端头不得落在窗洞内）；每樘内门 0.9×2.1。

### 5.4 水平板分层：地坪、楼板、露台面、休息平台

**术语定义（本类型的水平板只有四类，各司其职）**：

| 名称 | 定义 | 顶面标高 | 归属 | 轮廓算法 | 数量规律 |
|---|---|---|---|---|---|
| **地坪** | 首层落地板（slab-on-grade） | ±0.000 = 一层墙底 | **仅一层** | **= 一层整个外建筑轮廓**（带厚度；非矩形可拼块） | **全楼恒 1 组** |
| **楼板** | 某层的**屋顶楼板**，同时是上一层的**地板** | 上一层地面 = 上一层墙底 | **下层**（它封顶的那一层） | **= 下层整个外建筑轮廓**（不是上层轮廓） | N 层建筑 **N−1 组** |
| **露台面** | 楼板**暴露在上层轮廓外**的部分（其上无墙体） | 同该层楼板 | 该层楼板 | 楼板分块/分材质；**并集仍=下层外轮廓** | 随退台 |
| **休息平台** | 双跑楼梯半层高处的转台板 | 半层高 | — | 梯井旁矩形 | 每层 1 块 |
| **屋面** | 顶层顶板 | 顶层墙顶 | roof 构件 | **= 顶层外轮廓 + 2h**（外沿齐女儿墙外皮，§6.4b）；顶层不写 floor | 1 |

**核心理解——同一块板有两个身份，轮廓取下层**：

```
地坪 ground（仅一层）         轮廓 = 一层外建筑轮廓
一层屋顶楼板 ≡ 二层地板       轮廓 = 一层外轮廓（不是二层！）
二层屋顶楼板 ≡ 三层地板       轮廓 = 二层外轮廓（不是三层！）
顶层顶板 = 屋面 roof          轮廓 = 顶层外轮廓 + 2h（外沿齐女儿墙外皮；不另写 floor）

首层地面 ≠ 楼板，叫「地坪」；其下没有楼层，是落地板。
因此"一层地板"只指地坪；凡说"某层楼板"，指该层顶部、轮廓=该层外轮廓的那块板。
```

**平面构成**：每组层间楼板**并集 = 下层外轮廓**；室内（上层投影下）可用 `floor_wood`，暴露部分用 `floor_terrace` 分块——**分块不改变轮廓算法**。楼梯间拆板留洞后，剩余并集仍须托住上层全部墙底。

**开洞**：楼梯间拆板留洞；拆板边界优先藏入墙厚带（→ 书写说明 §5.5）。

**禁止**：二层/三层另写地坪；层间楼板缩成上层更小轮廓；用全楼外包大矩形多铺楼外板；顶层再写 floor 与屋面重叠。

**命名约定（蓝图 id）**：`ground` / `ground_<凸出>` / `slab_l<上层号>[_in|_sw|_s|_e…]` / `terrace_*`（仅材质分块）/ `landing_*`。

**修改联动**：改第 k 层外墙轮廓 → 重算以该层为下层的楼板（及一层时的 ground）；退台暴露分块随之增减。

## 6. 立面规则（虚实对比的算术）

### 6.1 门窗对齐公式

```
沿墙距离 s = 起点累加 + 开间内偏移        （一律以轴线对称布置）
from[0] = s − width/2                    （= 洞口左边缘，相对墙起点）
from[1] = 本层地面世界Y（门）/ 地面Y+0.9（窗台）
```
硬校验：同墙开口不重叠；`from[1]+height ≤ 墙顶`；相邻开口净距 ≥0.4；距墙端 ≥0.24。
**墙 `from/to` = 轴线端点**（四角严格重合，§6.4）；因引擎两端各外延 `h`，**组件局部原点 = 实际渲染起点 = 轴线起点 − h** ⇒ `from[0] = 中心 − 宽/2 + h`。

### 6.3 立面韵律律
同一立面同轴同型号（尺寸、窗台、分格全同），逐层上下对位；北立面为服务面，可统一 1.5×1.5@0.9 四分格；楼梯间开窗占北墙轴线位并逐层对位。

### 6.4 转角完整性「三层总律」（一切转角必完整、零缺口；**禁手工派坐标**）

> **★★★ 三层总律（本类型强制，与 v2.0 §0.4 一致）**：蓝图中**任何**两段**正交相会**的实体，角部**必须完整**——**外角块满实、外侧 90° 阳角、零缺口**。**不分层级**：**① 构件**（`wall`/`roof`/`floor`）、**② 组件**（`railing`/`balcony`/`stair`/门窗…作为整体）、**③ 组件内部构件**（组件展开出的子几何）**一律适用**。
>
> **为何分三层**：引擎自动斜接**只覆盖"元素级 `wall`"**（`resolveWallJoints()` 筛选 `filter(e => e.type === 'wall')`）。组件被展开（`wild-compiler/components/*.ts`）后生成的子几何多为 `beam`/`primitive`/`cylinder`/`profile_sweep`，**全部不在斜接范围**（`buildBeam` 实测：仅按 `from→to` 生成一段盒/柱，**零转角处理**）。

**① 构件级（`wall`）**：任两段正交相会的沿轴实体（外墙 / 女儿墙 / **屋面侧板** / 勒脚 / 腰线 / 栏板 / 环带）在角部必须：**① 外角块满实、外侧 90° 阳角（零缺口）；② 两段体积重叠恰为理论下界 `t×h`**（`t`=厚度、`h=t/2`；0.24 厚 ⇒ **288 cm² × 段高**）。

- **写法（唯一）**：**两端点严格重合于同一点**，交给引擎 —— `resolver.ts → adjustWallJoint()` 判端点距 `< 0.01` 且正交后，**两墙各沿其轴向对方外延 `对方厚度/2`**（`_jointExtensions`）⇒ 实体各达对方外皮 ⇒ 外角天然 90° 阳角、零缺口。
- **环写法**：四段端点严格重合于轴线矩形四角——`[0,0]→[轴长,0]`、`[轴长,0]→[轴长,轴深]`、`[轴长,轴深]→[0,轴深]`、`[0,轴深]→[0,0]`；女儿墙同法。
- **★ 禁：手工书写"满长端 / 内缩端"坐标**。① 内缩端令两端点相距 `h`（0.24 墙 ⇒ 0.12）**远超 0.01 容差** ⇒ 引擎配不上 ⇒ **不外延 ⇒ 外角缺口**；② 手工超长端会被引擎**再叠加一次 `+h`** ⇒ 端点落到对方轴线 ⇒ 缺口照旧。
- **组件连带**：外墙两端各外延 `h` ⇒ 组件局部原点 = **实际渲染起点 = 轴线起点 − h** ⇒ `from[0] = 中心 − 宽/2 + h`（漏算 = 门窗整体偏 0.12）。
- 自检（双通道）：生成器断言 + 校验器各一条——**引擎斜接后并集**对每角 `t×t` 外角块**覆盖 ≥ 99.9%**。**审计锚点须取"外尖点"（环外接矩形角 ± h）再向内采样**。

**② 组件级**（组件整体与宿主 / 相邻组件的转角）
- 转角处两段**共用同一个世界坐标点**，并由**转角柱（立杆恰落于该点）**收头——**禁两段各自缩回、中间留空档**（典型：四面栏杆在露台四角相会）。
- 挂载定位按"**世界坐标重合**"复算（组件局部原点 = 宿主实际渲染起点 = 轴线起点 − `h`），**禁各按轴线端点各写一半**。
- **`path` 布局型组件（`railing`）**：**折点即转角** ⇒ 折点位置须显式为路径顶点且有**立杆落点**，两段横杆端点同抵该立杆。

**③ 组件内部构件级**（组件展开出的子几何）
- **同轴折线分段**（栏杆横杆沿 `path` 分段）：**折点由竖向构件（立杆）覆盖**，两端点同抵该立杆（端面被吞没 ≤ 自身截面尺寸）⇒ 外角无缺口、无三角空档。
- **十字 / 丁字交接**（窗框竖梃×横档、井干式叠木纵横交替）：**一者通长、一者内缩至其外皮**（缩进 = 对方截面半宽）⇒ 角部外皮交汇成直角；**禁双缩进（缺角）、禁双通长（超叠 ≥ `t×t`）**。
- **楼梯**：转向平台处**上下跑踏步边线对齐**、梯段斜板与平台板共面收头。

**三层统一判据**：① 外角块（取**外尖点**再向内采样）被参与构件并集覆盖 **≥ 99.9%**；② 正交两段体积重叠**恰为 `t×h`**（< `t×h` = 缺口；≥ `t×t` = 超叠）；③ 转角处相邻两段（含组件与组件）**共用同一世界点**。生成器断言 + 独立校验器各一条。

### 6.4b 屋面 / 露台板边缘（**护板必写为 `wall` 环：面归板、角归墙**）

角部完整、外侧 90° 阳角这条律**不限墙体与屋顶**，但**机制只有一条**：**端点重合 · 交给引擎斜接**（`adjustWallJoint()` 只处理 `type === 'wall'`）⇒ 凡承担"角"的构件**必须是 `wall`**。（**组件级 / 组件内部构件级的转角**见 §6.4 三层总律 ② / ③。）

- **① 沿轴实体**（`wall`：外墙 / 女儿墙 / 栏板 / 勒脚 / 腰线 / 环带；坡屋顶的**屋檐封边 / 山墙三角 / 戗脊收头**）⇒ 走 §6.4「**端点重合 · 引擎斜接**」。
- **② 屋面 / 露台的一圈"边缘护板" ⇒ 显式写成 4 段 `wall` 环**（**不要**把护板职责留在 `roof`/`floor` 盒侧面上）：
  - **屋面板（内衬顶面）**：`roof/flat`，`span = BX + 2h − 2(TE+δ)`、`depth = BY + 2h − 2(TE+δ)`、`position = [轴线中心 x, 所坐墙顶, 轴线中心 z]`（`δ = 0.03` 不可见量）⇒ 退到女儿墙**内皮内侧**，与任何外皮都不共面。
  - **护板环（4 段 `wall`）**：轴线 = 女儿墙环轴线**整体内移 `EMB = 0.03`**（`X[EMB, BX−EMB] × Z[EMB, BY−EMB]`），`thickness = TE`（与女儿墙同厚 ⇒ 斜接外延量一致），下沿 = 屋面板顶、顶 = 屋面板顶 + 护板高，**端点严格重合**。
  - 例（`BX 9 / BY 7 / TE 0.24`）：屋面板 `span 8.70 / depth 6.70 / position [4.5, 6.6, 3.5]`；护板环轴 `X[0.03,8.97]×Z[0.03,6.97]` ⇒ 外皮 `X[−0.09,9.09]×Z[−0.09,7.09]` = 女儿墙外皮 ∓ `EMB`。
  - **★ 三条都治不好**：① 外沿 == 女儿墙外皮 ⇒ **共面**（渲染器无 `polygonOffset` ⇒ 掠射角 z-fight / 发丝缝）；② 「轴线 + 固定出檐 0.6」⇒ **悬挑凸唇**；③ 只改 `roof` 的 `span/depth` ⇒ 箱体四角**不斜接**、与女儿墙环**不同源**。**修法 = 整圈换语言为 4 段 `wall` 环**。
  - 自检（双通道）：① 环 4 段且 `type === 'wall'`；② 环轴端点重合 < 0.01 + 相邻段 `|dot| ≤ sin5°`；③ 环外皮 = 女儿墙外皮 ∓ `EMB`；④ 四角外角块被环并集**满覆盖**。

### 6.5 楼板边缘藏带律
楼板 from/to 取**外墙中线包络**，板边藏进墙厚带不可见；**严禁板边与外墙皮齐平**（±0.12）——会产生全周长共面灰缝。

## 7. 屋面、露台与附属

### 7.1 平屋顶（原型）
`roofType:"flat"`，`position` = **顶层墙顶中心**（屋面与墙顶共面），`height` 按构造；**`span/depth` 必须 = 轴线长/深 + 2h**（`h`=外墙半厚），使**屋面外沿与女儿墙环外皮逐边共面**（收头唯一，见 §6.4b）；**禁「轴线 + 固定出檐 0.6」**（四角悬挑凸唇）。**多体块必然分块设屋顶**；露台区域不设屋顶。

### 7.2 女儿墙（硬性 · 只布一圈 · 端点齐平）

**本质**：女儿墙是在**原有墙体顶上**再加的一段矮墙，书写同 `wall`，仅高度与材质不同。

| 参数 | 规则 |
|---|---|
| **位置** | **只**在当层屋顶/露台板的**最外边缘轮廓**（一圈） |
| **中间** | **禁止**：同层露台共边、退台内凹分界、室内板边 |
| type | **`wall`**；通长段 from/to 与下层外墙一致 |
| 厚/高 | 厚=墙厚；高 **0.90–1.20** |
| 底 | = 本层墙顶 = 板顶/屋面 |
| **端点** | 按 §6.4：**端点严格重合**、引擎斜接（各外延对方半厚）——**外角 90° 阳角、零缺口、重叠恒为 `t×h`**；**禁手工写满长/内缩坐标**、禁止嵌入墙身 |

最外一圈上若有常规墙继续升高 → 该边**该段不写**女儿墙（**同层级·遇全高墙即平齐**）。禁止 primitive box；禁止中间线段；阳台不写女儿墙。

> **★ 女儿墙转角 = 与外墙同法（§6.4 三层总律 ①）**：女儿墙环**端点严格重合**、引擎斜接，**外角 90° 阳角、零缺口**。**该律不限墙体与屋顶**——屋面侧板、勒脚、腰线、栏板、环带等**一切沿轴实体**的角落搭接均不得出现缺口、外侧必须为 90° 阳角；**组件级、组件内部构件级的转角**另按 §6.4 三层总律 ② / ③。

> **★ 退台女儿墙「同层级·遇全高墙即平齐」铁律（硬性）**：**女儿墙与普通全高墙同层级，不得嵌套**。外圈某边上**已有本层全高外墙**（退台上层外墙共线）时，该边女儿墙**只写『暴露段』**——把该边按"被全高墙覆盖段"切开，**只保留暴露段**，端点取**全高墙外皮面**（齐平、不重叠、不留缝）。
> - **判据**：同平面两段墙的「沿轴区间 × Y 区间」不得双重叠（重叠 = 女儿墙穿进全高墙）。
> - **示例（L1 11×9 → L2 9×7，东退2+北退2）**：南边女儿墙只写 **X[9.12,11]**、西边只写 **Z[8.88,7.12]**、东边（X=11）与北边（Z=9）全暴露；**各段端点与 L2 外墙端点同点 ⇒ 引擎斜接**。
> - **不这么写的后果**：女儿墙（底=板顶、顶=板顶+0.6）与全高外墙在 Y[板顶,板顶+0.6] 重叠 ⇒ **挂墙的落地门窗下部 0.6m 被吞没（门窗"嵌进墙里"）**。

### 7.3 台阶（门口）+ 台基（勒脚）
无台阶类型，primitive box 叠加：每级高 0.15、深 0.4–0.6，宽 ≈ 门洞总宽 + 0.6。

**★ 标高口径（住宅，v2.0 §2.3 / §3.13 要素 1）**：**±0.000 = 室外地面**（渲染场地锁 y=0）、**首层室内地坪顶 = +0.45 = 首层墙底**，以**三级 0.15 台阶**消化 0.45 室内外高差。整栋坐落于**整块实心地基（勒脚）**之上：`primitive box`，顶 = +0.45（= 首层墙底）、底 = −0.02（没入渲染地面）、四面出挑 0.06、南面出挑至 −0.18（兜住南外墙外皮 −0.12，使入口台阶贴墙侧有实体可倚）。**禁**只写一块 0.2 厚地坪板——y 0→0.45 悬空 => 整栋楼飘着、台阶背后无倚靠。

**★★★ 台阶朝向铁律（高的一侧贴建筑墙）**：台阶的**存在目的 = 消化「建筑标高 > 室外地面」的高差**，因此**台阶必须"越高越靠近建筑墙"**——**末级（最高一级）踏面紧贴建筑墙、其标高 = 该处室内地坪顶（首层 = 首层墙底 = 门洞底标高 = +0.45）**，向**远离建筑**的方向**逐级下降**至室外地坪（±0.000 = 0）。

- **唯一判据**：`末级踏面标高 == 室内地坪顶（门洞底 = 首层墙底）` 且 `外端一级底面 == 室外地面（0）`；中间各级单调递减、相邻级 z 区间连续无缝。
- **通式（南入口，沿 −Z 向外）**：设墙外皮 `z_w`、级数 `n`、步深 `d`、步高 `h`、室内地坪 `Y_in` ⇒
  - 第 `i` 级（`i = 1…n` 自外向内；`i = n` 最贴墙）**踏面标高** `y_i = Y_in − (n − i)·h`、**实体占 `[y_i − h, y_i]`**（`i` 级盒顶面 = `y_i`）；
  - 沿 z 区间 `[z_w − (n − i + 1)·d, z_w − (n − i)·d]` ⇒ **`i = n` 的盒最贴近墙（`z` 最大端 = `z_w`）、其踏面标高最高**；
  - `n·h == Y_in`（三级 0.15 ⇒ `Y_in = 0.45`）。**实例（本类型正典 `两层现代别墅.wild`）**：`z_w = −0.12`、`n = 3`、`h = 0.15`、`d = 0.6` ⇒ `step_1` 踏面 0.15 z[−1.92,−1.32] / `step_2` 踏面 0.30 z[−1.32,−0.72] / `step_3` 踏面 **0.45** z[−0.72,**−0.12**]（末级端面恰抵墙外皮）。
- **★ 反例（台阶反向）**：把最高一级放在**远离建筑端** ⇒ 越靠近房子越矮 ⇒ 台阶与门洞之间**悬空一大段高差**、读作"台阶与建筑脱离 / 台阶砌反"。**判据**：`最靠近墙的踏面标高 < 最远端踏面标高` 即反向。
- **与门洞的关系**：主入口门 `from[1]` = **室内地坪世界 Y（= +0.45）**（= 最高一级踏面 = 墙底），**不是 0**；台阶末级踏面与之**同标高**、**端面恰抵墙外皮**（贴接、不穿插、不留缝）。
- **护栏**：台阶宽度内、**临空侧**（无侧墙遮挡一侧）须按"有梯必有栏"设扶手；贴建筑墙一侧由墙身围护可不设。
- **★ 双跑中分（配落地方柱门廊时）**：门前台阶若与**门廊落地柱**共存 ⇒ 台阶须**中部留空**、分作**东西两跑**（镜像对称、同级同高、同 z 行程），**中央走道净宽 ≥ 门洞宽 + 1.2** 且**正对门洞投影**；**判据** = 两跑关于门廊中心对称、中央走道区间 ⊇ 门洞投影、**柱底与任一踏步『零正体积穿插』**。单跑会与柱底投影打架（穿模）⇒ **禁**。本类型正典：`step_1..3`（西跑）+ `step_1E..3E`（东跑），中央走道净宽 4.0。

### 7.3b 入口门廊（落地方柱直板雨棚）—— 形制 · 尺度链 · 四件套

> **形制（正典范式）**：现代别墅门廊六类常见形制（①对称双柱平顶直板 ②整体悬挑无立柱 ③叠檐 ④格栅顶 ⑤单坡 ⑥拱廊）中，本类型取**第 ① 类「对称双柱平顶直板门廊」**——两柱对称、柱间过梁、梁上平直棚板、棚板自墙面外挑。理由：无弧度、无雕饰，与**两层平顶体块**同族。

**三条硬性比例**：**棚底净挑高**（棚板底 − 室内地坪顶）**≥ 2.35**，且**高于门洞顶 ≥ 0.30**；**棚板外挑进深** **1.5–2.2**（自南墙外皮量至棚板南端面）；**方柱截面** **0.24–0.40**（400–500mm 缩尺），**禁细支杆**。

**★ 尺度链（统一「净挑高 = 棚板底」口径，全部由柱位反解）**：

```
落地柱柱底 = 台基顶 = 室内地坪顶            （★ 落地，不得悬空）
柱高        = POR_CLR（净挑高）
柱顶        = Y_SUP_TOP = 室内地坪顶 + POR_CLR   ← 与棚板底同一条口径
过梁 mount  = Y_SUP_TOP                          ← 引擎口径：beam.from[1] = 梁顶（自梁顶向下挂 height）
过梁底      = Y_SUP_TOP − POR_BEAM_H             ← 落在柱头之内
棚板底      = Y_SUP_TOP                          ← 与柱顶、梁顶三点重合
棚板顶      = Y_SUP_TOP + 棚板厚
```

> **★ 陷阱（必检）**：若柱顶按「`Y0 + POR_CLR`」、而过梁顶按「柱顶 + 梁高」**两套口径混写**，柱顶与梁底之间会凭空多出**一个梁高的悬空缝**，读作"**柱子没有升到棚底 / 没过梁**"。**判据**：`柱顶 == 棚板底 == 梁顶`（偏移恒 0，容差 ≤ 2e-3）。

**★ 四件套（禁用 `canopy` 组件；直写 4 个元素）**：有落地柱的门廊**禁**用 `canopy` 组件——其支柱由 `compileCanopy` 生成、**截面仅 0.06（细杆）**、且高度依附宿主墙，读作"细支杆"而非柱（用户观感 = "柱子没有落地"）。改直写：

| 件 | 类型 | 关键量 |
| --- | --- | --- |
| **落地方柱 ×2** | `primitive` `box` | 柱底 = 台基顶、柱顶 = `Y_SUP_TOP`；截面 `POR_COL`；沿墙向贴门廊两端 `门廊中心 ± POR_W/2` |
| **柱头过梁** | `beam` `rect` | `from/to[1]` = **梁顶** = `Y_SUP_TOP`；`height = POR_BEAM_H`；**跨两柱外皮**（端面与柱外皮齐平） |
| **直板雨棚** | `primitive` `box` | 板底 = `Y_SUP_TOP`；宽 = **柱外皮跨**（`POR_W + POR_COL`）；后缘嵌墙 `EMB` ≥ 0.03；进深 = 外挑进深 |
| **台基南带** | `primitive` `box`（整块 `foundation`） | 台基**南皮 = 棚板南端面**（兜住南墙外皮 + 门廊柱柱底 + 台阶起点） |

**四条通式（防「柱子悬空 / 不落地 / 穿出棚外 / 与台阶打架」）**：
1. **立柱落地**：`柱底 == 所立足实体顶面`（台基顶），**且柱底竖直投影内必有台基实体** ⇒ 台基南皮外扩到**棚板南端面**（同时兜住南外墙外皮）。
2. **柱位由棚板派生**：`柱中心 z = 棚板南端面 + 柱外皮半径` ⇒ 柱外皮恰贴棚板南端面、**柱在棚板投影内又不探出棚外**；柱外皮与**棚板端面齐平**。
3. **柱头过梁 = 梁入柱头**：`梁顶 == 棚板底`、`梁底 = 棚板底 − 梁高`，重叠段 = **柱截面 × 梁高**（属**有意嵌套**、为唯一豁免；v2.0 §7.4 四段连续）。
4. **柱底避挡台阶**：柱平面落在**台基南挑带**内 ⇒ 台阶**中部留空**（双跑分列、中央走道正对门洞），**禁落在梯段上穿模**。

**本类型正典实值**（`两层现代别墅.wild`）：门廊净宽 `POR_W = 3.0`、柱截面 0.30、净挑高 2.50（棚底 = 台基顶 0.45 + 2.50 = **2.95**）、过梁高 0.28（梁底 2.67，入柱头 0.28）、棚板 3.30×0.12×1.66（板底 2.95、顶 3.07）、外挑进深 1.60；两柱中心 X = 4.0 / 7.0、z = −1.57（柱外皮贴棚板南端面 −1.72）；台基南皮 = 棚板南端面 = **−1.72**。

### 7.3c 无框玻璃栏板 & 悬挑雨棚带（**直写薄板，不用组件**）

> **适用**：现代 / 新中式**退台、露台、平屋面**的临空护栏与**无柱入口雨棚**（形制表第 ② 类「整体悬挑无立柱」）。

**① 无框玻璃栏板**：`railing` 是**杆件型**（立柱 + 横杆）、读感太"栏杆"；退台要的是**通片透明玻璃**（见玻璃、不见柱）⇒ 直写 `primitive` `box`：

| 件 | 类型 / 材质 | 关键量 |
| --- | --- | --- |
| 玻璃面板 | `primitive` `box` / `glass`（`materialClass:"glass"`、`transmission ≥ 0.9`） | 厚 **0.05**、高 1.05–1.10；**底 = 所在板顶**（落地不悬空） |
| 金属压顶扶手 | `primitive` `box` / `frame_dark` | 截面 0.08×0.05；**底 = 玻璃顶**（`position[1] = 板顶 + GB_H + 0.025`）；同路径通长 |

**★ 角部「通长—内缩」（v2.0 §3.7 ①）**：取**南片通长**（跨满东西两角）、**东西片内缩**且端面恰抵南片北侧面 ⇒ 四角玻璃外皮拼成**连续直角**、无缺口无叠出。

```
南片长 = WBX − 2×(bi − 0.06)      // 盖满两转角，两端外皮与露台外皮齐平
东西片北端 = 南片北侧面            // 端面贴接（重叠 0、缝 0）
```
判据：`|南片长 − 目标| ≤ 2e-3`。

**② 悬挑雨棚带**（形制第 ② 类，**无立柱**）：仅一块厚挑板、靠**后缘嵌墙**支承（**禁** `canopy` 带支柱：支柱 0.06 = 细杆）。

| 项 | 取值 |
| --- | --- |
| 棚底净挑高（棚板底 − 室内地坪顶） | **≥ 2.35** 且**高于门洞顶 ≥ 0.30**（`棚板底 ≥ 室内地坪顶 + max(2.35, 门洞高 + 0.30)`） |
| 棚板外挑进深（自南墙外皮量至棚板南端面） | **1.5 – 2.2** |
| 后缘嵌入量 `EMB` | **≥ 0.03**（异材质不可见插入量；入墙不穿透、可见外沿齐平） |
| 棚板厚度 | 0.15 – 0.20 |

```
后缘 z1 = −(南墙外皮) + EMB      前缘 z0 = −(南墙外皮) − (进深 − EMB)
棚板底  = max(室内地坪顶 + 净挑高, 门洞顶 + 0.30)
```
> **★ 联动铁律（v2.0 §0.3 铁律二）**：`净挑高` 与 `门洞高` 耦合——**改门洞高必须同步抬棚底**；设门洞顶 = `室内地坪顶 + DM_H`，则棚底 ≥ `室内地坪顶 + max(2.35, DM_H + 0.30)`。**反例**：`DM_H = 2.40` 而棚底仅 `+2.50` ⇒ 高出仅 **0.10** ⇒ 读作"**棚板压在门楣上**"（门洞上部无收头）。
> **形制互斥**：**有落地柱 ⇒ §7.3b 四件套；无柱 ⇒ 本条挑板**。二者不可并存。

**本类型正典实值**（`三层退台现代别墅.wild`）：玻璃栏板厚 0.05、高 **1.10**、南片长 **9.88**（= `WBX 10 − 2×(0.12 − 0.06)`）、中心 z = +0.085（内皮内 0.06）；金属压顶 0.05×0.08、底 = 玻璃顶；悬挑雨棚带 **4.50×0.15×1.44**、后缘嵌墙 **0.06**、棚底 = 0.45 + 2.50 = **2.95**、净挑高 **2.50**、门洞顶 2.85（`DM_H 2.40`）⇒ **高出 0.10**（本例门洞偏低、属紧凑读法；正式交付宜按联动铁律抬棚底至 ≥ 3.15）。

### 7.3d 平顶逐级退台露台律 & 单件平顶挑檐板（平顶收头）

**A. 退台露台坐接律**（适用平顶 + 南向逐级退台的现代别墅）：

- 每南退一级 ⇒ 上一级露台面 = **被退台层顶板的外露段**：露台板顶 **= 承托墙顶**（= 该层顶板顶，贴接坐于本层外圈墙顶、偏移 0）；露台板南缘轴线 = **承托墙轴线**（z 区间 = [下一级南墙轴线, 本级南墙轴线]）；
- **禁**把露台板写在无承托墙的标高（悬空板）或与同层室内板体积重叠——露台段与室内段**按 z 切分瓦片**（露台片 `floor_terrace` 材质、室内片 `floor_wood`），切缝**严格共面贴接**；
- 逐级退台 ⇒ 逐级一块露台板 + 一道无框玻璃栏板（§7.3c）+ 一条深色檐口条（贴露台板南外皮、嵌 0.01）。

**B. 单件平顶挑檐板**（平屋顶收头，坡屋顶不合用时）：

- **一个体块 = 一件 `primitive box` 檐板**：底 = 该体块最高墙顶（贴接，偏移 0）；平面尺寸 = 体块外包 + 四向出挑（0.5–0.7）；厚 0.15–0.20；深色材质与玻璃栏板同族；
- **单件矩形板天然无角部缺口**，无需四段拼合；相邻体块顶檐错落时**各写一件**（底 = 各自墙顶），高低差即形制签名；
- **封顶唯一**：挑檐板**本身即屋面封顶件**（底面 = 墙顶、面域完全覆盖块体外包）。**禁**再写「屋面内衬板」——内衬 `floor` 顶面必与墙顶严格共面且实体全埋墙内 ⇒ 引擎渲染出**橙色共面**（z-fighting，材质与结构位皆正常却仍出现）⇒ 属**冗余构件、应删除**。判据：屋顶标高处**禁**任何 `roof_dark` 材质 `floor`（室内楼板 `floor_wood` 顶 = 墙顶属正常楼层结构，不受此限）。

**本类型正典实值**（`三层平顶挑檐现代别墅.wild`）：轴网 14×10（左块 X[0,9] + 右块 X[9,14]）；层高 3.3/3.3/3.0（右块顶层 3.3 ⇒ 顶檐错落 0.30）；L2 南墙 z=1.5、L3 南墙 z=3.0 ⇒ **T2@3.75 z[0,1.5]、T3@7.05 z[1.5,3.0]**；挑檐板左块出挑 0.70 / 右块 0.50、厚 0.18；层高 3.3 ⇒ 半层 1.65 = **11 步 × 0.15**（梯井 X[0.12,2.52]×Z[3.24,7.20]）。

### 7.3e 北 / 西 / 东三面窗「上下对齐 · 均匀分布」（世界坐标网格）

> **适用**：多层现代别墅的**背面（北）与两山墙（东西）**——这三面通常**同一竖向墙面的各层分属不同体块 / 不同长度墙段**（退台、分界墙）⇒ **禁按各自父墙的"沿墙距离"写**（父墙方向不同 ⇒ 同一 `from[0]` 落不同世界位置 ⇒ 上下错位）。

- **统一世界网格**：先定该面的**世界坐标中心集**，再按各父墙方向反解 `from[0]`：
  - 墙方向 **+轴**：`from[0] = 中心 − 宽/2`；墙方向 **−轴**：`from[0] = 墙起点坐标 − 中心 − 宽/2`
- **分段均布**：体块分界（L 形）处**按段分别均布**（段内等距、单窗居中）；**跨段"全宽等距"不适用**。
- **可行性**：网格点须落在**每道父墙的实际段内**（退台墙比 L1 短 ⇒ 逐层核 `from[0] + width ≤ 墙长`）。
- **判据**：① 各层同面洞口**世界坐标中心排序后逐元素相等**（容差 0）；② 段内 gap 等距；③ 逐件 `from[0]+width ≤ 墙长`。

**本类型正典实值**（`三层平顶挑檐现代别墅.wild`，每面每层各 2 窗、北面左块 2 + 右块 1）：
- **北面**（z=10）：世界 x 网格 **{3.0, 6.0, 11.5}**（左块 0–9 取 3/6；右块 9–14 取 11.5）——L1 三窗、L2/L3 各 3 窗，**三层全部同 x**
- **西面**（x=0）：世界 z 网格 **{4.0, 7.0}**——L1/L2/L3 各 2 窗，**三层全部同 z**（L3 西墙仅到 z=3，故网格点须 > 3.75）
- **东面**（x=14）：世界 z 网格 **{4.0, 7.0}**——L1/L2/L3 各 2 窗，**三层全部同 z**

### 7.4 双坡屋顶变体（引擎实测语义）
- **引擎语义**：屋脊**沿 Z（进深方向）**，山墙三角面朝南北（±Z），坡面朝东西降落；`buildGable` 输出封闭棱柱（`thickness` 不参与）。要"山墙朝主立面"，让体块长边沿 Z；
- **定位**：`position` 必须显式写（引擎扩张陷阱，§3 语义⑤）；`depth` = 体块进深（山墙与墙外皮贴合），`span` = 体块宽度 + 2×0.4（东西出檐）；`height` = 1/4–1/3 × span（范例 span 9.8 取 2.6，坡角 ≈28°）；屋脊标高 = position[1] + height；
- **与露台关系**：坡屋顶覆盖的体块上方不设露台；相邻退台仍按 §4.3 升格，坡檐可悬于露台上方形成半遮蔽。

## 8. 竖向交通（双跑楼梯间）

### 8.1 布局
楼梯间占角部，**借两面外墙采光**，另两面以 0.12 内墙围合；每层一樘 0.9×2.1 楼梯间门；门洞必须落在**到达板**范围内。完整数组配方（含拆板与栏杆）→ 书写说明 §5.5。

### 8.2 双跑构成（每层四件套）

| 构件 | 实例 A（15×10，层高 3.6/3.0） | 实例 B（11×9，层高 3.6） |
|---|---|---|
| 上行第一跑 | from (1.2, 0, 9.4) → to (3.6, 1.8, 9.4)，宽 1.2，10×0.18 | from (0.72, 0, 2.34) → to (0.72, 1.8, 4.74)，10×0.18 |
| 休息平台 | floor (3.6, 1.8, 7.6)→(4.8, 1.8, 10)，顶 1.8 | floor (0.12, 1.8, 4.62)→(2.52, 1.8, 6.06)，顶 1.8 |
| 上行第二跑（到层） | from (3.6, 1.8, 8.2) → to (1.2, 3.6, 8.2) | from (1.92, 1.8, 4.62) → to (1.92, 3.6, 2.22) |
| 洞口（两跑+平台投影） | X[1.32,4.8] × Z[7.6,10] | X[0.12,2.52] × Z[2.34,6.06] |

### 8.3 硬校验
- 每跑 `stepHeight × stepCount` = 半层高；两跑之和 = 层高；
- 平台板顶 = 半层高；**门洞 ⊂ 到达板**；**到达边 = 末步边缘**（无踏空、无共面）；其余洞边藏墙厚带；临空边设 railing（1.05）。

## 10. 材质方案库（三色律锁定）

**方案 A（默认）**——10 种：`wall_white`（全楼外墙）、`floor_stone`（地坪）、`floor_wood`（楼板 / 室内地面）、`floor_terrace`（露台面 / 休息平台）、`roof_dark`、`frame_dark`（metallic 0.8）、`glass`（**materialClass:"glass" + transmission 0.92 + ior 1.5 + side:"double"**）、`door_wood`、`railing_metal`、`concrete_step`。完整可复制字段块 → 书写说明 §6.4。

> **命名空间提示**：材质 id 与元素 id 相互独立。材质沿用 `floor_*` 前缀（`floor_stone`/`floor_wood`/`floor_terrace`），元素 id 用 §5.4 的 `ground`/`slab_l*`/`terrace_l*`——两者同名不算冲突，但引用时必须分清（`"material": "floor_terrace"` 引用的是材质，不是板）。

**方案 B（深色体量变体）**：翼体或入口体块外墙换 `wall_dark [0.25,0.26,0.28]` 作 accent volume——仅用户明示时启用，仍须保证"同层同材质"。

## 12. 修改协议（对话式增量修改）

### 12.1 话术映射
| 用户说 | 设计层动作 | 书写层动作 |
|---|---|---|
| "把窗改大" | 查立面韵律是否破坏 | 改 width/height，重算 from[0] 保中心 |
| "南墙加窗" | 检查槽位与韵律（§6.3） | add window，查同墙无重叠 |
| "加一层" | 复查体块规则（§4） | 全构件 Y 平移 + 新墙/板/楼梯延伸 |
| "要个露台" | 上层退让 + 升格（§4.3） | 加 floor_terrace + 女儿墙 + 门 |
| "改成坡屋顶" | 按 §7.4 定山墙朝向与坡高 | 改 roofType/span/depth/height/position |
| "东墙没门窗" | — | 先查洞口-框对齐（书写说明 §8.1），多为墙角/引擎角度问题 |
| "外墙退让/改轮廓" | 体块与房间随外墙变 | **外墙 + 该层全部内墙 + 依附组件**一起改 |

### 12.1b 外墙轮廓修改 → 内墙联动（硬性）

改任一层外墙（退让、凸出、共线）时：

1. **必须同步改该层全部内墙**（含梯井），禁止只动外墙+门窗/阳台；
2. 内墙只依附外墙；端点=外墙**内皮**（南 z=zc+th/2，北 z=zc−th/2，西 x=xc+th/2，东 x=xc−th/2）；
3. 端点不得超出外墙内皮区间；不得悬空、穿墙、伸到室外；
4. 组件 from 随父墙/父内墙重算；
5. 重推：外墙轮廓 → 内皮 → 内墙端点 → 组件 from → 自检。

### 12.2 修改门禁
每次修改后三级校验归零（书写说明 §8.1）；**同文件修改必须串行**；改外墙必过 §12.1b。

### 12.3 修改闭环 SOP（三交付）
1. 修蓝图 + 校验；2. 部署预览确认；3. **问题→根因→规则写回对应层文档**（设计问题回本文，书写/引擎问题回书写说明）。缺一不可。

## 14. 设计层自检清单

> 书写级自检（JSON 格式、字段、坐标、材质）→ 书写说明 §9（13 项）。本清单只列**设计层**必须自检的项：

1. [ ] **体块**：相邻层轮廓错落；L3 ⊆ L2 ⊆ L1 支承；悬挑 ≤1.2m
2. [ ] **水平板分层 + 标高口径**：**±0.000 = 室外地面**、**首层室内地坪顶 = +0.45 = 首层墙底（`ground` 顶）**；**地坪仅一层**；**层间楼板并集=下层外轮廓**；**板顶=下层墙顶=上层墙底（与墙体顶面同一平面）**；顶层无 floor；**整栋坐落于实心地基 `foundation`（顶 +0.45 / 底 −0.02 / 四面出挑 0.06）之上、全楼最低点 ≥ −0.3**
3. [ ] **露台/女儿墙**：退让暴露屋面已升格；**无墙的屋顶/露台边缘均有女儿墙**（厚=墙厚，高 0.9–1.2，坐本层墙顶，底=板顶）；阳台未重复设；**★ 转角完整性三层（§6.4）**：① 女儿墙/护板环端点严格重合、引擎斜接、外角 90° 阳角、零缺口、重叠 ≤ `t×h`；② 四面栏杆 / 阳台栏杆在露台角部**共用世界点 + 转角柱**；③ 组件内部构件（栏杆横杆折点有立杆、门窗框梃横档一者通长一者内缩）；**★ 女儿墙遇本层全高墙即平齐截断（分段书写、无同平面嵌套）**
   - **入口台阶（§7.3）**：主入口**三级台阶外低内高**——末级（最高）踏面紧贴建筑墙外皮、标高 = 室内地坪顶（= 门洞底 = 首层墙底 = +0.45），沿远离建筑方向逐级降至室外地面（0）；末级端面恰抵墙外皮（贴接不留缝）、相邻级连续无缝；**判据 = 最贴墙一级踏面 > 最外一级**；台阶**临空侧**按"有梯必有栏"设扶手（贴墙侧由墙身围护可不设）；台阶宽度 ≈ 门洞两侧各外扩 0.3
4. [ ] **★ 阳台通行**：每个 `balcony` 后台墙已配**落地推拉门 / 落地窗**（跨内重叠、底=阳台板顶、净高 ≥2.0），阳台可达、非封闭凸台（书写说明 §4.3 通行铁律）
5. [ ] **轴网一致性**：立面每个开口、每道隔墙都能追溯到轴网
6. [ ] **内墙联动**：改外墙后该层内墙已同步；端点=外墙内皮；无悬空/无超出外墙
7. [ ] **立面韵律**：同立面同轴同型号逐层对位；主立面虚实比 6:4～7:3
8. [ ] **材质三色律**：全楼外墙单一材质；可见材质 ≤4 种
9. [ ] **竖向交通**：双跑构成完整（两跑+平台+洞口+围合+门+栏杆）；层高与步数×步高吻合
10. [ ] **参数表 P 完整**：轴网/层高/墙厚/板厚/女儿墙/门窗规格全部有值，缺失项已标注假设
11. [ ] **故事线完整**：入口序列（台阶→雨棚→门厅）与公共/私密分层成立
12. [ ] **类型文字描述**（§1.4）已按最终参数替换方括号内容，可直接交付用户

## 15. 常见问题速查（设计层）

| 现象 | 设计层成因 | 规则 |
|---|---|---|
| 建筑像"叠方盒"，立面单调 | 每层同轮廓 | §4.1 |
| 把"一层楼板"和"二层地板"写成两块板 | 未理解板的双身份 | §5.4 |
| 首层地面误当楼板标高往上叠 | 地坪与楼板混淆 | §5.4 |
| 顶层多写一块楼板 / 屋面与楼板重叠 | 顶层顶板应由屋面承担 | §5.4、§7.1 |
| 三层颜色不一 | 各层材质未统一 | §10 |
| 立面杂乱、无韵律 | 同立面混用不同型号窗 | §6.3 |
| 上层墙体悬空/露台无支承 | 未自上而下检查轮廓包含关系 | §4.2 |
| 退台处留裸楼板 | 未升格为露台 | §4.3 |
| 楼梯与层高对不上 | 层高晚定或步数×步高 ≠ 半层高 | §8.3 |
| 露台无法到达 | 未设可达门窗 | §4.3 |
| **阳台无法进入（三面栏杆一面实墙）** | `balcony` 不产洞口，后台墙未补门/落地窗 | §4.3 阳台通行铁律（书写说明 §4.3） |
| **落地门窗下部嵌进墙里 / 退台女儿墙穿全高墙** | 女儿墙沿整条外轮廓通铺、穿进本层全高外墙（同平面体积重叠） | 女儿墙遇全高墙即平齐截断、只写暴露段（§7.2 同层级铁律） |
| **入口台阶"砌反了"（越靠近建筑越矮、与门洞悬空一段高差）** | 台阶朝向写反：最高一级在远离建筑端 | **入口台阶外低内高**——末级（最高）踏面贴建筑墙、标高 = 室内地坪顶（门洞底），向远离建筑方向逐级降至室外地面（§7.3） |
| **★ 入口雨棚"柱子没落地 / 棚下细支杆"** | 用 `canopy` 组件做落地门廊——其支柱截面 0.06（细杆）、依附宿主墙，非落地柱 | **§7.3b**：改用**四件套**（2 落地方柱 + 过梁 + 直板雨棚），柱底 = 台基顶（落地）、柱截面 ≥ 0.24 |
| **★ 门廊"柱顶与棚板间一段悬空缝 / 柱没过梁"** | **两套标高口径混写**（柱顶按 `Y0+CLR`、过梁按 `柱顶+梁高`） | **§7.3b 尺度链**：`柱顶 == 棚板底 == 梁顶` 绑定同标高；`beam.from[1]` = **梁顶**（引擎自梁顶向下挂 height） |
| **整栋楼"飘"着 / 台阶贴墙侧背后无实体可倚** | 只写一块 0.2 厚地坪板（板底 +0.25）⇒ y 0→0.45 悬空；或未写台基 | **住宅标高口径**：`foundation` 整块实心地基（顶 +0.45 = 首层墙底 / 底 −0.02 / 四面出挑 0.06 / 南面出挑至 −0.18）；`ground` 顶 = +0.45（§7.3、v2.0 §2.3 / §3.13-1） |
| **台基下部或台阶被渲染地面吞没** | 构件最低点 < −0.3 | 台基底 = −0.02、全楼最低点 ≥ −0.3（v2.0 §2.3） |
| **墙角 / 屋顶边缘侧板 / 女儿墙角部缺口（外角非 90°）** | 两端点**未重合**（相距 `h`）⇒ 引擎 `joinXZ` 配不上 ⇒ 不外延 ⇒ 缺口；`wall`×`profile_sweep` 交角尤易发生（外延只对 `wall` 生效）；**或"边缘护板"被留在 `roof/flat` 盒上**（板不被斜接 / 与外皮共面 z-fight ⇒ 四角读作缺口） | **§6.4 三层总律 ①**：**端点严格重合**、交给引擎斜接；**禁手工写满长/内缩坐标**；**沿轴实体皆适用**；**屋面 / 露台的边缘护板须按 §6.4b 改写为 4 段 `wall` 环**（面归板、角归墙） |
| **组件转角缺口（四面栏杆 / 阳台栏杆在露台角部空一格）** | **§6.4 三层总律 ②**：两段组件各自缩回、中间无**转角柱**收头；或组件定位按各自轴线端点**各写一半** | 转角处**两段共用同一世界点 + 转角柱**；`path` 折点即转角、折点必有立杆落点；挂载定位按"世界坐标重合"复算 |
| **组件内部构件转角缺口（栏杆横杆折点三角空档 / 窗框梃横档缺角 / 楼梯转向踏步错位）** | **§6.4 三层总律 ③**：引擎**不斜接组件展开出的子几何**（`buildBeam` 仅按 `from→to` 生成、零转角处理）⇒ 同轴折线分段各止折点留三角空档；或十字/丁字交接**双缩进（缺角）/ 双通长（超叠）** | 同轴折线段**折点由立杆覆盖**；十字/丁字**一者通长、一者内缩至对方外皮**（缩进 = 对方截面半宽）；**禁双缩进、禁双通长** |

> 引擎/书写类问题（地板与墙分离、墙角缺口、共面灰缝、有洞无门窗、屋顶被扩张、门窗偏移、预览卡顿等 12 项）→ **书写说明 §10 错误速查**。
