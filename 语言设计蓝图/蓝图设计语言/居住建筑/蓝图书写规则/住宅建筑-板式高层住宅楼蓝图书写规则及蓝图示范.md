## 0. 定位与适用范围

| 项 | 内容 |
|---|---|
| 适用 | 城市住区**高层住宅楼**（单元式，多户共用楼梯电梯），含板式 / 塔式 / 板塔结合三型 |
| 不适用 | 低层独立住宅（用《新中式别墅》规则）、宿舍、公寓（酒店式）、商住综合楼 |
| 本文示范 | **板式高层住宅（一梯两户 · 15 层 · 南北通透）**，其余两型给出参数替换表 |
| 单位/坐标 | 米；原点 = 建筑**西南角外墙角点**；北 = +Z、东 = +X；主立面朝南，主入口在南墙 |

**住宅与公共建筑的三条本质差别（决定书写方式）**：
1. **标准层重复**：2 层以上平面完全一致——一切构件必须由**层号循环参数化生成**，禁止逐层手写（手写必错，且改一处漏十处）；
2. **竖向交通核集中**：楼梯 + 电梯 + 消防前室集中在**核心筒**，是全楼唯一不重复的房间组，也是竖向贯通的剪力墙群；
3. **立面尺度靠产品而非装饰**：住宅立面的韵律来自**窗带 + 阳台 + 层间线**的重复节奏，不用任何线脚/柱式；"三段式"只是**材质与构件的分段**（基座石材 / 标准层涂料 / 顶部收头）。

## 1. 形制总表（先定高度，再定平面）

| 建筑高度 H | 规范类别 | 常见层数（层高 3.0） | 消防硬线（影响蓝图构件） |
|---|---|---|---|
| H ≤ 27.0m | 多层住宅 | 1–9 | 7 层及以上**必须设电梯**（≥1 台）、封闭楼梯间 |
| 27.0 < H ≤ 54.0m | **二类高层住宅** | 10–18 | 封闭/防烟楼梯间；H>32m 应设**消防电梯**；宜 2 台电梯 |
| 54.0 < H ≤ 100.0m | 一类高层住宅 | 19–33 | 须 ≥2 部疏散楼梯（剪刀梯或两部梯）+ 消防电梯 + 消防前室 |
| H > 100.0m | 超高层住宅 | ≥34 | 须设**避难层**（每 50m 一处） |

> **为什么不写 19 层以上**：18 层 / 54m 是住宅设计的"性价比台阶"（超过则疏散楼梯与电梯配置翻倍、保温材料升为 A 级）。示范取 **15 层 / 46.95m**：稳居二类高层、体系完整、构件量可控。
> **H 的计算口径**：本规则取 **室外地面 → 顶层屋面（含出屋面机房不计）** 为建筑高度，写入 `editor.params.totalH`。

**三型平面形制（选型对照）**：

| 型 | 平面特征 | 梯户比 | 户型品质 | 蓝图要点 |
|---|---|---|---|---|
| **板式（板楼）** | 长 > 宽（本例 16.8 × 12.6，比 1.33）；一梯 2–3 户 | 1:2 | 南北通透、全明、公摊小 | 核心筒嵌于北带中部，两户分居东西 |
| 塔式（点式/蝶式） | 长 ≈ 宽；四向布置户 | 1:4–1:8 | 朝向杂、易暗厨暗卫 | 核心筒居中，外围户按方位角阵列 |
| 板塔结合 | 两端塔、中间板 | 1:4–1:6 | 中间套板式、边套塔式 | 两端轮廓换向，需分块书写 |

## 2. 形制决策链（书写第一步）

```
① 选型（板式/塔式/板塔）→ ② 定单元面宽与进深（循模）→ ③ 定核心筒尺寸与位置
→ ④ 定层数与层高 → ⑤ 定分户线与户内分区 → ⑥ 定立面三段与构件谱
```

**②单元面宽与进深**
- 每户面宽 = 南向主要开间之和（客厅 + 主卧）：**7.8–8.4m** 为舒适值（客厅 4.2–4.5 + 主卧 3.6–3.9）；
- 单元面宽 = 户面宽 × 户数 + 核心筒宽；
- 单元进深 = 南向房间深 + 中部深 + 北向房间深，**总量 ≤ 14m**（超过则中部成"灰色空间"，采光通风失效）；示范 4.2 + 2.4 + 6.0 = 12.6m。

**③核心筒尺寸与位置**
- 内容物：**电梯井 + 双跑（或剪刀）楼梯 + 消防前室（兼电梯厅） + 管道井**；
- 位置：板式置于**北带的平面中部**（核心筒嵌进两户之间，两户分居东西，避免中部出现无法使用的空腔）；
- 尺寸反推：`核心筒宽 = 楼梯间宽 + 电梯井带宽`，`核心筒深 = 前室深 + 井道深`；
  - 楼梯间轴线宽 ≥ **2.7m**（净宽 2.46 → 两跑各 1.18 ≥ 1.10 规范下限）；
  - 井道深 = 步深 × 步数 + 平台深（示范 0.28 × 10 + 1.4 = 4.2m）；
  - 前室深 ≥ 1.8m（消防前室；兼电梯厅时 1.8–2.4m）；
  - 示范核心筒 4.8（宽）× 6.0（深）＝ 28.8㎡，服务 2 户 15 层。

**④层数与层高**
- 层高一律 **3.0m**（10M，循模；住宅规范"层高宜 2.80m"）；首层设门厅时用 **4.5m**（15M）——门厅层高若与标准层相同，入口空间读不出"基座"。
- 标高链：`首层地面 = +0.45`（室内外高差，见 §3），`第 n 层地面 = 0.45 + 4.5 + (n−2) × 3.0`。

**⑤分户线与户内分区**（以示范西户为例，东户按 X → W − x 镜像）

| 分区 | 范围 | 尺寸 | 循模 |
|---|---|---|---|
| 南向房间带 | Z 0 → 4.2 | 客厅 4.5 × 4.2、主卧 3.9 × 4.2 | 15M / 14M / 13M |
| 中部带 | Z 4.2 → 6.6 | 客餐厅一体 + 卫生间 1.8 × 2.4 | 8M |
| 北向房间带 | Z 6.6 → 12.6 | 次卧 3.6 × 4.2、厨房 2.4 × 4.2、过道深 1.8 | 12M / 8M / 6M |
| 分户线 | 南带 + 中部 X = 8.4（= W/2） | 分户墙 0.24 | — |

> 分户线在**北带让位于核心筒**：北带西户仅占 X 0 → 6.0，东户 X 10.8 → 16.8，中间 6.0 → 10.8 是核心筒。**分户墙只写到核心筒南墙为止**（示范 Z 0 → 6.6），北带的分隔由核心筒侧墙兼任。

**⑥立面三段（比例来自形体，不是装饰）**

| 段 | 高度占比 | 示范取值 | 材质与构件 |
|---|---|---|---|
| 基座 | 总高 1/8–1/6，2–3 层 | 首层 4.5m | 石材 `ws`；雨棚 + 台阶 3 级 + 无障碍坡道 |
| 主体（标准层） | 60–70% | 2–15 层 | 涂料 `wp` + 窗带 + 阳台 + 层间线（用阳台板/楼板边出挑表达） |
| 顶部 | 1/10–1/8 | 女儿墙 1.2 + 机房 2.4 + 飘板 0.3 | 女儿墙一圈 + 出屋面楼梯间/机房 + 水箱 + 四面出挑 0.35 飘板收头 |

## 3. 坐标、标高与模数（住宅专属口径）

### 3.1 ±0.000 与室内外高差（**本规则核心口径**）

住宅入口必有 **0.30–0.45m 室内外高差**（防雨水倒灌、防潮）。渲染场地的地面**固定锁在 y = 0**，因此：

> **住宅类统一取 ±0.000 = 室外地面**；首层室内地坪顶 = **+0.45**（= 3 级台阶 × 0.15，循半模），首层墙底 = +0.45；**整栋坐落于地基（台基 / 勒脚）之上**——地基顶面 = +0.45（= 首层墙底），底面埋入渲染地面 **−0.02**，四面出挑 **0.06**（详见 §4.9）。

这条口径与《设计语言》§2.3 的"大台基"条款同源（台基高于 0.9 时的口径），住宅把它**推广为常规做法**：高差用 `primitive box` 实体台阶填平，不用"把整栋楼沉到负标高"的写法（沉下去会与渲染地面打架）。

```
完成面标高谱（示范 15 层）
+49.35 ─ 机房顶板（46.95 + 2.4）
+48.45 ─ 顶部飘板顶（女儿墙顶 + 0.3）
+48.15 ─ 女儿墙顶（46.95 + 1.2）
+46.95 ─ 顶层屋面 roof flat（轮廓 = 女儿墙外皮内缘）─ 顶层不写 floor
  ⋮        （标准层 × 13，层高 3.0）
+ 4.95 ─ 首层墙顶（= 二层楼板顶 = 二层墙底）
+ 0.45 ─ 地基 / 台基顶面（= 首层地坪顶 = 首层墙底）
±0.000 ─ 室外地面（台阶/坡道落地，渲染地面）
− 0.02 ─ 地基底面（没入渲染地面 0.02，唯一的负标高构件）
```

### 3.2 模数

- **基础模数 M = 0.3**，半模 M/2 = 0.15；
- 循模：面宽/进深、开间、核心筒尺寸、层高、女儿墙高、阳台凸出、台阶踏步深；
- **半模**：台阶踏步高 0.15、楼梯步高 0.15、门窗洞高与窗台高（0.9 = 3M 其实循模）；
- **不循模（构造与人体尺度，例外）**：外墙/剪力墙 0.24、户内墙 0.12、楼板 0.20、休息平台 0.15、窗框 0.09、**楼梯步深 0.26–0.28**、梯段净宽 1.10–1.20、**地基（勒脚）出挑 0.06 与埋深 0.02**。
- **验收口径**：`楼梯步深 ∈ [0.26, 0.28]`、`梯段净宽 ≥ 1.10`、`休息平台深 ≥ 梯段净宽` 三条比"是否 0.3 的倍数"更重要，写进自检（参见 §8 D 组）。

### 3.3 轴网与墙定位

- **南北外墙（长向）**满长：`from.x = −0.12`、`to.x = W + 0.12`（满外皮长）；
- **东西外墙（短向）**内缩：`from.z = 0.12`、`to.z = D − 0.12`；
- 分户墙、核心筒侧墙（南北向）都**内缩 0.12 藏进北外墙**（`to.z = D − 0.12`）；
- 户内隔墙（东西向）**内缩 0.06**（半厚）藏进相交墙轴线；
- 内墙端点落在**相交墙轴线**上（埋入墙体，不可见），禁停在墙面外侧留缝。

## 4. 构件书写规则

### 4.1 墙体谱（住宅必备 5 类）

| 类 | id 约定 | 厚 | 材质 | 范围/要点 |
|---|---|---|---|---|
| 外墙 | `wS/wN/wW/wE + 层号` | 0.24 | 基座层 `ws`、标准层 `wp` | 首层石材、2 层以上涂料（三段式） |
| 核心筒剪力墙 | `cw/ce/cs/cm/ct/cg + 层号` | 0.24 | `cp` | 竖向贯通全楼；`cw/ce` 兼入户门洞宿主 |
| 分户墙 | `pp + 层号` | 0.24 | `wi` | 仅南带 + 中部（Z 0 → 6.6），北带由核心筒分隔 |
| 户内隔墙 | `i* + 层号`（西户）/ `j*`（东户） | 0.12 | `wi` | 每户 5 道：客厅\|主卧、南带\|中部、中部\|北带、次卧\|厨房、过道\|北带 |
| 女儿墙 | `prS/prN/prW/prE` | 0.24 | `wp` 或 `ws` | **全楼仅屋顶一圈 4 道** |

**核心筒 6 道墙的固定职责**（缺一不可）：
`cw` 西侧墙（含西户入户门）/ `ce` 东侧墙（含东户入户门）/ `cs` 前室南墙 / `cm` 前室北墙（井道隔墙，含电梯门）/ `ct` 楼梯间\|电梯井分隔 / `cg` 电梯井\|管道井分隔。

### 4.2 楼板与井道留洞（住宅竖向贯通的书写关键）

- 板顶 = **本层墙底**（硬语义①）；标准层板顶 = 下层墙顶；
- 板轮廓取**本层外墙中线包络**（`−0.12 → W+0.12` / `−0.12 → D+0.12`），板边藏进墙厚带；
- **井道留洞**：核心筒北段（`X 核心筒 → 楼梯间与电梯井带`，`Z 前室北缘 → D`）**必须留空**——该区域无楼板，是楼梯井与电梯井的垂直贯通空间；
- 留洞后板拆为 **3 块**：
  - `slA + 层号`：`[−0.12, y, −0.12] → [W+0.12, y, 前室北缘]`（通长整块，也是**楼梯到达板**）；
  - `slB + 层号`：`[−0.12, y, 前室北缘] → [核心筒西缘, y, D+0.12]`；
  - `slC + 层号`：`[核心筒东缘, y, 前室北缘] → [W+0.12, y, D+0.12]`；
- **首层不另写地坪板**：首层地面由**地基 / 台基顶面**（§4.9）承担，全楼 floor 只数标准层 `slA/slB/slC` + 休息平台 + 机房顶板；**顶层不写 floor**，屋面由 `roof flat` 承担。

> ⚠️ 常见错误：把核心筒区域整片铺满楼板（电梯井被堵死、楼梯无井）；或把 `slB/slC` 写成覆盖核心筒宽度（板伸进井道）。

### 4.3 双跑楼梯配方（住宅通用写法）

**参数反推链**（**禁止照抄**，逐项算）：

```
半层高差 h = 层高 / 2                                    （3.0 → 1.5m）
步高 sh：0.15（半模）→ 步数 n = h / sh 须为整数            （1.5 / 0.15 = 10 步）
步深 sd：0.26–0.28 取值                                   （取 0.28）
第一跑水平投影 = n × sd                                   （10 × 0.28 = 2.8m）
平台深 landD ≥ 梯段净宽                                   （1.4 ≥ 1.18 ✓）
井道深 = 投影 + 平台深                                    （2.8 + 1.4 = 4.2m ← 决定楼梯间进深）
梯段净宽 runW ≥ 1.10；楼梯间轴线宽 ≥ 2 × runW + 井缝 0.1  （2 × 1.18 + 0.1 = 2.46 → 轴线 2.7m）
```

**四件套写法**（自前室北缘起，向北升 → 平台 → 折回向南到达）：

```json
{ "type": "stair", "id": "st102", "from": [6.71, 4.95, 8.4], "to": [6.71, 6.45, 11.2],
  "width": 1.18, "stepCount": 10, "stepDepth": 0.28, "stepHeight": 0.15, "material": "fw" }
{ "type": "floor", "id": "land02", "from": [6.12, 6.45, 11.2], "to": [8.58, 6.45, 12.6],
  "thickness": 0.15, "material": "fw" }
{ "type": "stair", "id": "st202", "from": [7.99, 6.45, 11.2], "to": [7.99, 7.95, 8.4],
  "width": 1.18, "stepCount": 10, "stepDepth": 0.28, "stepHeight": 0.15, "material": "fw" }
```

- **跑A 起步 z = 井道南缘**（前室北缘 8.4 → 11.2）；**跑B 到达 z = 井道南缘**（到达板 = `slA`）；
- 两跑沿 X 的中心距 = `runW + 井缝`（示范 1.28），写入自检防重叠；
- 平台板顶 = 半层标高（`楼面 + 1.5`），厚 0.15；
- **护栏**：楼梯被井道墙四面包围，无需另加栏杆（硬语义⑨的"有梯必有栏"由**楼梯间墙体**满足）；**开敞式楼梯（无墙）必须补栏杆**。

> 19 层以上（一类高层）用**剪刀楼梯**（两部梯段交错、共用井道），写法为在井道 X 向并列两组（跑A/跑B）并对调上下层到达边；本规则示范不展开。

### 4.4 窗（住宅窗谱与窗墙比）

| 位置 | 洞宽 × 洞高 | 窗台高（世界 Y） | 竖梃 | 说明 |
|---|---|---|---|---|
| 客厅阳台联窗 | 3.0 × 2.4 | 楼面 + 0.15 | 2 | 落地推拉门联窗，通阳台 |
| 主卧窗 | 1.8 × 1.5 | 楼面 + 0.9 | 1 | 标准卧室窗 |
| 次卧窗 | 1.8 × 1.5 | 楼面 + 0.9 | 1 | 同上 |
| 厨房窗 | 1.2 × 1.5 | 楼面 + 0.9 | 0 | 暗厨不受欢迎，必须开窗 |
| 卫生间窗 | 0.9 × 1.5 | 楼面 + 1.2 | 0 | 暗卫可省（示范从简未设） |

- `from[0] = 洞口左边缘 X − 墙起点 X`（南/北外墙起点 X = −0.12 → `from[0] = X + 0.12`）；
- `from[1]` = **窗台世界标高**（= 本层地面 + 窗台高），**不是层内相对值**；
- 同墙窗带自检：不重叠、净距 ≥ 0.4、距墙端 ≥ 0.24、`from[0] + width ≤ 墙长`；
- **窗墙比**：南向宜 0.35–0.45、北向 0.25–0.30（节能与采光平衡）；上表窗谱的南向窗墙比 ≈ 0.40 ✓。

### 4.5 阳台（住宅立面的第一特征构件）

- 用 `balcony` 组件（**自动生成挑板 + 栏杆**，禁止再补栏杆几何）；
- 尺寸：宽 **3.6**（客厅开间 4.5 内居中偏外）、凸出 **1.5**（悬挑上限 1.2–1.5）、板厚 0.15、栏杆高 1.1、立柱间距 0.9；
- 宿主 = **南向外墙**，与阳台门联窗同轴（联窗居阳台正中）；
- 每户 **1 个**（客厅阳台）；主卧用飘窗（`bay_window`，凸出 0.4–0.6）或平窗——**不要每间都挑阳台**，立面会碎。
- 写法：`from = [阳台左缘 X + 0.12, 本层楼面标高, 0]`、`width 3.6`、`depth 1.5`（+Z 为墙内侧，凸出朝 −Z）。

### 4.8 台阶与坡道（硬语义⑨，住宅必备三件）

| 构件 | 写法 | 要点 |
|---|---|---|
| 入口台阶 | `primitive box` 逐级，**每级自室外地面 y=0 直砌到踏面顶**（实体），3 级 × 0.15 = 0.45 | 级 i 顶面 = i × 0.15；末级顶 = 首层地坪（+0.45）；宽 = 门洞 + 1.2（示范 3.6 = 12M）；**西缘必须对接坡道顶端**；**北端（z = 0）须深没入地基（§4.9）——背后要有实体可倚靠** |
| 台阶护栏 | `primitive box` **1 道（仅临空侧）**，**随坡斜置**：`rotation[0] = −atan2(rise, run)`（负角使 +Z 端上抬） | 临空侧 = 台阶**东缘**（示范 X 10.2）；西侧紧邻坡道顶面（同高 0.45、无临空）不设；长 = √(run² + rise²)、高 0.5、厚 0.06 |
| 无障碍坡道 | `ramp` 组件，**贴墙布置**：路径 `z = 墙面外皮 − width/2`，使**贴墙侧边缘与外墙外皮齐平**；`railingSides: "left"` → **仅外侧设栏杆** | 坡度 1:12（落差 0.45 → 水平投影 5.4）；**顶端与台阶西缘同 X 对接**（无缝、不留空档）；贴墙侧不设栏杆（用户口径，见下）；**贴墙侧须压进地基 0.06（§4.9）** |

> ⚠️ **坡道贴墙布置与"贴墙侧无护栏"（用户定案）**
> ① **贴墙齐平**：`ramp.width` 是以**路径线为中心**的带宽（编译器 `offsetStraightPath` 按 ±width/2 生成挡台与栏杆），因此要让贴墙侧边缘压在外墙外皮上，路径线必须取 `z = 外墙外皮 − width/2`（示范：外皮 −0.12、宽 1.5 → 路径 z = **−0.87**，坡道占 z ∈ [−1.62, −0.12]）。写 `z = −1.2` 会让坡道离墙 0.33m 悬空一道缝。
> ② **贴墙侧不设护栏**：符合硬语义⑨的"**除用户特殊要求**"例外——墙面自身即围护，人行侧不需二次栏杆。**`railingSides` 的左右口径**（引擎实测，`wild-compiler/components/attachedToPath.ts`：`normal = (−dz/L, dx/L)`；`left` = +normal、`right` = −normal）：路径取**高→低**（示范 +X → −X，dx = −5.4、dz = 0 → normal = (0, −1)），则 **`left` = −Z 外侧（人行侧，要栏杆）**、**`right` = +Z 贴墙侧（不设）** → 写 **`railingSides: "left"`**。若把路径反过来写（低→高），则须改用 `"right"`——**左右随路径方向翻转，换向必须同步换值**。
> ③ **顶端对接台阶**：坡道顶端与台阶**西缘同 X**（示范均为 6.6），二者在 X 向只接触不重叠；台阶宽因此由 3.0 调为 **3.6**，把坡道顶端正好包进来。若台阶仍留 3.0（西缘 6.9），坡道顶（6.6）与台阶之间会留下 0.6m 无面层的空档（0.45m 深的坑）。
> ④ **台阶只需临空侧一道栏板**：西侧被坡道顶端（y = 0.45 的近似平台面）占据，无临空面，故不设——这是"贴墙坡道 + 台阶并排"布局的正常结论，不是漏设。

### 4.9 地基 / 台基（勒脚）——住宅体量落地的唯一写法（rev3 新增）

**为什么必须有**：首层墙底在 **+0.45**，而渲染地面锁在 **y = 0**。若只写一块 0.2 厚的"地坪板"（板底 +0.25），则 **y 0 → 0.45 之间是空的**——整栋楼看起来飘着，且**入口台阶与坡道的贴墙侧背后没有任何实体可倚靠**（这是 rev2 被退回的直接原因）。做法是：把"地坪 + 勒脚"合并为**一块实心砌体（地基 / 台基）**。

| 项 | 取值 | 依据 |
|---|---|---|
| 元素类型 | `primitive` + `shape: "box"`（**实心体**，不是 `floor` 板） | 地基是实体砌筑，不是薄板 |
| 顶面标高 | **+0.45**（= 首层地坪顶 = 首层墙底） | 与首层墙底对齐，无缝 |
| 底面标高 | **−0.02**（没入渲染地面 0.02） | 不许悬空；埋深取构造小值，唯一允许的负标高 |
| 高度 | 0.47（= 0.45 + 0.02） | — |
| 平面轮廓 | 外墙外皮**四面出挑 0.06** → `X −0.18 → W+0.18`、`Z −0.18 → D+0.18` | 出挑 = 勒脚（防潮、护墙脚、立面基座收头） |
| 材质 | 基座石材 `ws`（与首层外墙、台阶、坡道同材） | 三段式的"基座"由此起算 |
| 最小尺寸校验 | **地基南面 z ≤ −0.12**（须兜住南外墙外皮） | 否则台阶 / 坡道背后仍无倚靠 |

**写法（示范，参数由 `PLINTH: { out: 0.06, sink: 0.02 }` 反推）**：

```json
{ "type": "primitive", "id": "plinth", "shape": "box",
  "position": [8.4, 0.215, 6.3], "dimensions": [17.16, 0.47, 12.96], "material": "ws" }
```

- `position` = 体块**中心**：`[(−0.18+16.98)/2, (−0.02+0.45)/2, (−0.18+12.78)/2] = [8.4, 0.215, 6.3]`；
- `dimensions` = `[17.16, 0.47, 12.96]`（= `W+0.12×2+0.06×2` × `0.47` × `D+0.12×2+0.06×2`）；
- **整栋唯一的地基**，全楼 1 块（id 固定 `plinth`），不得按层复制。

**台阶 / 坡道与地基的关系（用户验收口径）**：

```
        ▲ 北（墙内侧）
   ┌──────────────────────────────┐
   │  首层墙底 +0.45              │  ← 南外墙 wS01（外皮 z = −0.12）
   ├──────────────────────────────┤ +0.45  地基顶
   │   地  基  plinth             │
   │  （实心砌体，z ≥ −0.18）      │
   └──────────────────────────────┘ −0.02
     ↑ 地基南面 z = −0.18（出挑 0.06，兜住外墙外皮 −0.12）
     ┃ 台阶北端 z = 0 深没入地基 ─ 背后有实体 ✓
     ┃ 坡道贴墙侧边缘 z = −0.12 落在地基内（重叠 0.06）─ 抵靠 ✓
   ────────────────────────────────  ±0.000 室外地面
```

> ⚠️ **两条不可省**：① 地基**底面必须下探到 ≤ 0**（示范 −0.02），底面停在 +0.25 就是悬空；② 地基**南面必须出挑到 ≤ 外墙外皮**（示范 −0.18），与外墙齐平（−0.12）不够——台阶与坡道的贴墙侧需要压进地基 0.06 才算"抵靠"，齐平会读作"两块东西贴在一起"。

## 6. 参数化生成（住宅强制项）

元件数 > 300 的住宅蓝图**必须**用生成脚本（Node `.cjs`）产出，四条住宅专属强化：

1. **参数表置顶**：`N`（层数）、`H1`/`HS`（层高）、`W`/`D`（轴网）、`CORE`（核心筒）、`ST`（楼梯参数组）、`BAL`（阳台）、`PAR`/`MR`/`TANK`（屋顶）、`STEP`/`RAMP`/`CANY`（入口）集中为 `const P = {...}`——**任何尺寸不得散落在构件定义里**；
2. **层号循环是唯一生成方式**：`for (let n = 2; n <= P.N; n++)` 一次产出该层全部构件，id 用 `前缀 + pad(层号)`（两位，`padStart(2,"0")`）；
3. **标高一律走 `P.Y(n)` 函数**，禁止手写 `4.95`、`7.95` 这类派生值——改层高/层数时全楼自动重排；
4. **东户一律镜像函数**：`X_east = P.W − X_west`（示范 `inner("ja"+s, P.W-4.5, ...)`），禁止复制一份再手改坐标（改了西户忘改东户是住宅蓝图最高频缺陷）。

**自检必须用两条通道**：生成器内部自检（§8）+ 独立校验脚本（重新读 `.wild` 做 JSON 解析与交叉核对，`verify_highrise.cjs`）。内部自检只能证明"生成逻辑自洽"，独立校验才能发现"写出去了但结构关系错"。

## 10. 常见错误速查（住宅）

| # | 错误写法 | 后果 | 正确写法 |
|---|---|---|---|
| 1 | 逐层手写墙/窗坐标 | 改一处漏十处；层间错位 | 层号循环 + `P.Y(n)` 标高函数 |
| 2 | 东户复制西户后手改坐标 | 东西户不对称、门窗错位 | 镜像函数 `X → W − X` |
| 3 | 核心筒区域铺满楼板 | 电梯井/楼梯井被堵死 | 井道处板断开（`slB/slC`） |
| 4 | 楼板缩到本层轮廓 | 下层屋顶缺板 | 板轮廓 = 本层外墙中线包络 |
| 5 | 顶层再写一块 floor | 屋面双板闪面 | 顶层不写 floor，用 `roof flat` |
| 6 | 把 ±0.000 定在室内地坪 | 台阶/坡道落到负标高，与渲染地面打架 | ±0.000 = 室外地面，室内地坪 = +0.45 |
| 7 | 台阶用悬挑薄板 | 读作"飘浮的板" | 每级自室外地面直砌到踏面顶（实体） |
| 7b | **整栋只写一块 0.2 厚"地坪板"**（板底 +0.25） | 地面 y=0 至首层墙底 y=+0.45 之间是空的：整栋**悬空**，且**入口台阶与坡道背后无实体可倚靠**（rev2 被退回的直接原因） | 改写**实心地基 / 台基**：顶 +0.45、底 −0.02、四面出挑 0.06（§4.9） |
| 7c | 地基底面停在 ±0.000 以上（如 +0.25） | 楼"浮"在地面上，与渲染地面之间留缝 | 地基底面下探到 **−0.02**（没入渲染地面） |
| 7d | 地基与外墙**齐平**（出挑 0） | 台阶 / 坡道与地基只"贴"不"靠"，读作两块分离物 | 勒脚四面出挑 **0.06**，台阶北端 / 坡道贴墙侧压进地基 0.06 |
| 8 | 台阶/坡道不设护栏 | 违反硬语义⑨ | 台阶两侧随坡栏板 + 坡道 `railingSides:"both"` |
| 9 | 坡道离墙面留出一道架空缝 | 路径 z 未按"外皮 − width/2"取（带宽是以路径线为中心的） | 路径 z = 外墙外皮 − width/2（示范 −0.12 − 0.75 = −0.87） |
| 9b | **贴墙侧多出一道护栏**（用户会退回） | `railingSides` 写了 `"both"`，或左右写反 | 贴墙侧不设 → 路径取"高→低"时写 `"left"`（外侧）；路径反向则改 `"right"` |
| 9c | 坡道顶端与台阶之间留 0.6m 空档（0.45m 深的坑） | 台阶宽仍为 3.0、坡道顶未落在台阶西缘 | 台阶加宽到 `2 × (坡道顶 X − 门中轴)` 使两缘同 X；示范宽 3.6、交界 X = 6.6 |
| 9d | 台阶两侧都设栏板，其中一道挡住轮椅进出 | 未按"临空侧设、坡道侧不设"取舍 | 只设临空侧 1 道（示范东缘 10.2） |
| 9e | 蓝图里出现 `6.6000000000000005` 这类坐标 | 组件 `from/to` 未过取整函数（元素查了、组件漏查） | 精度自检**元素 + 组件双查**，组件坐标一律经 `R()` |
| 10 | 楼梯步数照抄 3.6m 层高的 10×0.18 | `步高 × 步数 ≠ 半层高差`，梯段悬空/穿板 | 按 §4.3 反推链重算，自检恒等式 |
| 11 | 入户门 `from[0] = 0` | 门开在核心筒墙角，进出前室错位 | 门洞必须落在前室 Z 区间内 |
| 12 | 窗 `from[1]` 写层内相对值 | 上层窗整体下沉一层高 | `from[1]` 写**世界标高** |
| 13 | 每间房都挑阳台 | 立面碎、无主次 | 每户仅客厅 1 个阳台 |
| 14 | 女儿墙每层都画 | 立面横线过密、读作"多层塔楼" | 女儿墙**只在屋顶一圈** |
| 15 | 住宅窗用幕墙玻璃 | 立面变"办公楼"，室内全黑 | 用 `gl`（透明窗玻璃，transmission 0.92） |
| 16 | 电梯井/机房脱离核心筒随意放 | 竖向不对位，屋面构架悬空 | 机房严格落在核心筒正上方 |
| 17 | 首层与标准层用同一层高 | 入口读不出"基座" | 首层 4.5m（15M） |
| 18 | 单元进深做到 15m 以上 | 中部灰色空间，功能失效 | 进深 ≤ 14m |
