# 欧式建筑：欧式别墅（新古典三段式）蓝图书写规则及蓝图示范

> **依据**：《WILD蓝图设计语言 v2.0》（下称"总协议"）第 2 章坐标/标高、第 3 章元素、第 4 章组件、第 6 章公式。
> **实例**：`三层欧式别墅.wild`（澜庭）——144 元素 + 47 组件，31.3KB；真实编译器展开 452 元素、**0 diagnostics**。
> **定位**：实例级书写规则字典。在总协议通用规则之上，给出**欧式别墅的全部专项规则、公式与实值**。与总协议冲突处以总协议为准。
> **核心抽象**：①**欧式别墅 = 法式三段式对称立面 + 罗马柱门廊 + 宝瓶栏杆挑阳台 + 三角山花 + 拱形主门 + 四坡屋顶 + 老虎窗/烟囱**；②**三段式既是平面语法也是立面语法**——纵墙一次贯通三层（不逐层重排），段宽 4.2 / 4.8 / 4.2 同时决定开窗节奏与屋顶配重；③**门廊柱顶 = 阳台挑板支座**，檐口→挑板→宝瓶栏杆构成一条**严格共面的竖向搭接链**（§4.3 / §4.7）；④**屋面一律引擎原生 `roof/hip`**，老虎窗/山花等小截面构件才用 `profile_sweep`。

## 1. 形制与总体参数

### 1.1 风格签名（判定是否"欧式别墅"的第一标准，逐条可判）

| 编号 | 签名 | 判据（可量化） | 缺失后果 |
|---|---|---|---|
| E1 | **三段式对称立面** | 平面沿短轴分三跨、中跨 ≥ 侧跨；立面左右镜像（同层同轴位洞口成对） | 读作普通民居/现代别墅 |
| E2 | **基座—主体—檐口 竖向三段** | 台基（出挑 0.30–0.45）+ 石材勒脚；层间腰线 ×2；顶檐口线脚（凸 ≥0.30） | 立面"平"，无古典比例感 |
| E3 | **罗马柱门廊 + 额枋** | 中轴 ≥2 根 `column`（`style:"corinthian"`、径比 h/9–h/10）+ 柱础 + 柱头 + 通长额枋 | 入口读作洞口，非门廊 |
| E4 | **宝瓶栏杆挑阳台** | 二层中轴挑板 + 三面 `primitive cylinder` 宝瓶阵列（间距 0.30） | 中央跨读作墙体 |
| E5 | **三角山花（fronton）** | ≥1 处 `profile_sweep` 三棱柱，坐落于门/窗头檐口之上，半跨 : 高 ≈ 2 : 1 | 缺少欧式"立面冠石" |
| E6 | **拱形主门** | `openingStyle:"arched"` + `doorStyle:"double"`，洞宽 1.8、起拱线 = 洞底 + (洞高 − 洞宽/2) | 入口读作矩形门洞 |
| E7 | **四坡屋顶 + 老虎窗/烟囱** | 一条 `roof/hip`（脊 ∥ 体块长轴）+ 前坡老虎窗 ×2 + **靠西侧坡面烟囱 ×1** | 读作中式/棚屋 |

> **正典构图法**：**中轴 → 门廊（柱+额枋）→ 挑阳台（宝瓶）→ 上层中央窗（山花）** 四个元素必须**同轴**（本例均为 x = 6.6）；两翼窗跨层同轴（本例 x = 2.1 / 11.1）。**中轴线一旦错位，风格即失**。

## 2. 坐标与标高体系

- 原点 = 台基西南角投影；**X 沿开间（三段 4.2 / 4.8 / 4.2），Z 沿进深（10.2）**；南立面在 **z = −0.12**（外墙外皮），北立面 z = 10.32。
- 竖三段轴线：**X1 = 4.2、X2 = 9.0**（纵墙轴）；中跨 CX = 6.6、进深中 CZ = 5.1。
- 标高链（**先锁此链，再推一切构件**）：`0（室外地面）= ±0.000` → `0.45`（台基顶 = 首层墙底 = 首层室内地坪）→ `4.05` → `7.35` → `10.35`（檐口平面 = 屋顶 `position[1]`）→ `13.95`（脊顶 = 檐口 + 3.6）。

### 2.5 标高口径（住宅通用，硬规则）

**欧式别墅属住宅类，一律 ±0.000 = 室外地面**（总协议 §2.3 / §3.13 要素 1）；首层室内地坪顶 = **+0.45**（3 级 × 0.15 台阶高差），**首层墙底 = +0.45**。

| 步 | 规则 | 本例实值 |
|---|---|---|
| 1 | 场地地面锁 y = 0；**禁止**把 ±0.000 定在室内地坪 | 0.000 = 室外地面 |
| 2 | **整块实心地基（台基）兜住首层墙底以下**：`primitive box`，顶 = 首层墙底、底 = −0.02（没入渲染地面）、四面出挑、全楼唯一、最低点 ≥ −0.3 | `podium` 顶 0.45 / 底 −0.02 / 出挑 0.45；`podium_porch` 南延至 z = −2.1 |
| 3 | 室内地坪即台基顶（不再另铺薄板，否则出现 0.45 空腔） | `ground` 板顶 = 0.45 |
| 4 | 台阶自室外地坪**直砌**，末级踏面 = 首层地坪；大体积室外台阶为**实体砌筑**（每级从地面直砌到踏面顶，禁悬挑薄板） | `step_a` y 0–0.45、`step_b` 0–0.30、`step_c` 0–0.15 |
| 5 | 台阶**两侧临空必须配栏杆**（硬语义⑨） | `rail_step_w/e` 高 1.05，path 由 (+0.45) 斜下至 (−0.00) |

> ⚠️ **台基出挑量**：别墅"石基座"取 **0.30–0.45**（越大越显基座感）；出挑区含门廊时，台基南缘 = 门廊前沿 − 0.3（留踏步起步带）。**勒脚带（`stone_base` 贴墙薄带）高度取 0.60、位于 0.45–1.05**，与台基同材质形成连续基座。

## 3. 主体骨架规则（继承总协议，列欧式专属要点）

### 3.1 满长—内缩配对（公式二）

| 墙 | 走向 | `from` → `to` | 长度 |
|---|---|---|---|
| 南墙 `wall_s{n}` | +X | `[-0.12, yb, 0] → [13.32, yt, 0]` | 13.44（满外皮） |
| 北墙 `wall_n{n}` | −X | `[13.32, yb, 10.2] → [-0.12, yt, 10.2]` | 13.44 |
| 东墙 `wall_e{n}` | +Z | `[13.2, yb, 0.12] → [13.2, yt, 10.08]` | 9.96（内缩） |
| 西墙 `wall_w{n}` | −Z | `[0, yb, 10.08] → [0, yt, 0.12]` | 9.96 |

> **起点方向决定 `from[0]` 换算式**（§6.1）——**写洞口前必须先看该墙的 `from` 端在哪**。南北墙满长（±0.12），东西墙内缩到南北墙内皮（0.12 / 10.08），两者端点**藏带 0.01**（不与其他墙面共面）。

### 3.2 三段式纵墙贯通（欧式别墅的骨架特征）

**纵墙 2 道（`i1_l{n}` @ x = 4.2、`i2_l{n}` @ x = 9.0）三层同轴原位贯通、逐层重建**——这是"三段式"落到平面的写法：**纵墙一次定位，三层不改**，开窗节奏由它决定。

- 内墙端点**只依附外墙内皮**（南 `z = 0.12`、北 `z = 10.08`），不得伸到室外；
- 梯间封墙 `i3/i4`（x = 5.4 / 7.8）+ `i5`（z = 5.82）围合梯井，**端点落在纵墙轴线 / 外墙内皮**（端头埋入，不留缝、不共面）；
- 房间横切墙 `i6/i7`（z = 5.1，分别从 x = 9.06→13.08 与 0.12→4.14）**东/西端埋入外墙内皮、内侧端落在纵墙内**。

### 3.3 楼板与梯井（公式四 / 六c）

1. **板顶 = 本层墙顶 = 上层墙底**，板体向下 0.20；轮廓 = **下层外轮廓**；地坪仅一层。
2. 梯井投影 = 两跑 + 平台并集，**拆成 4 块矩形**：`x[0,5.5]`、`x[7.7,13.2]`、`x[5.5,7.7]×z[0,6.06]`、`x[5.5,7.7]×z[9.9,10.2]`。
3. **板边收进墙厚带**（不可见）；例外：梯井到达边、露台临空边须与踏步/女儿墙**精确对齐**并设栏杆。
4. 休息平台 `landing_l1` @ 2.25（L1→L2）、`landing_l2` @ 5.70（L2→L3），板厚 0.15，落在梯井北端。

### 3.4 双跑楼梯（公式五 / 五b）

| 层间 | 半层高差 | 步高 × 步数 | 步深 | 第一跑水平投影 | 到达标高 |
|---|---|---|---|---|---|
| L1 → L2 | 1.80 | **0.18 × 10** | 0.24 | 2.40 | 2.25（平台）→ 4.05 |
| L2 → L3 | 1.65 | **0.15 × 11** | 0.24 | 2.64 | 5.70（平台）→ 7.35 |

> **校验恒等式**：`stepHeight × stepCount = 半层高差` 且 `stepDepth × stepCount = 第一跑水平投影`。层高不同**必须重推**（3.3 层高若照抄 10 × 0.18 = 1.8 ≠ 1.65 ⇒ 楼梯与楼板差 0.15）。
> 梯井临空边用 `railing` 组件 L 形围合（`rail_well_l2/l3`，高 1.05，path 沿洞边）。

## 4. 外立面装饰构件组合规则（欧式专属，自下而上链）

> **总链**：台基 → 台阶/护栏 → 勒脚带 → 门廊（柱础→柱身→柱头→额枋→檐口顶板）→ 挑阳台（挑板→地栿→宝瓶→扶手）→ 腰线 ×2 → 窗台线脚 → 三角山花 → 檐口线脚 → 屋顶。**任一环变更，上方各环标高必须重推**。

### 4.1 台基与石材勒脚

- 台基：`primitive box`，顶 +0.45、底 −0.02；主体 + 门廊南延两块（同材质 ⇒ 相接面共面**合法**）；
- 勒脚带：四面临墙薄带（`stone_base`），**通长—内缩成对**（S/N 通长、E/W 缩进），凸出墙面 0.06、嵌入 0.01；
- 腰线以下、勒脚以上**不再加任何贴面**（避免立面碎片化）。

## 5. 屋顶形制（四坡庑殿 = 引擎原生 `roof/hip`）

### 5.1 一条 `roof/hip`（唯一推荐写法）

```json
{"type":"roof","id":"roof_main","roofType":"hip","position":[6.6,10.35,5.1],
 "span":15,"depth":12,"height":3.6,"thickness":0.2,"material":"roof_tile"}
```

- **脊向由"谁更长"决定**：`span > depth ⇒ 正脊 ∥X`；`depth > span ⇒ 正脊 ∥Z`；**脊长恒 = |span − depth|**（本例 15 − 12 = 3.0 ⇒ **正脊半长 1.5**）；
- `span / depth` = 顶层体块外轮廓**四周外放出檐**（本例 13.44 + 2×0.78 = 15.0，**出檐 0.78**，取 0.7–1.0 四周同开）；
- `position` = **檐口平面中心**（必须显式书写）：[中轴 x, **檐口标高** , 进深中 z]；
- 坡度 `α = atan(height / (min(span,depth)/2))` = atan(3.6/6.0) = **30.96°**（欧式板岩屋面 28–40°；中式官帽 25–30° 偏缓，**欧式别墅取 ≥30° 更"陡"**）；
- **`hip` 在矩形平面下天生是"带短正脊的真庑殿"**（`ridgeHalf = |depth − span|/2`）⇒ 一条即可，**禁自绘坡板**（渲染器对 `profile_sweep` 大块实体板兼容不良）；
- **自带底面封口 ⇒ 禁写 `soffit`**。

### 5.2 封檐与正脊

| 构件 | 规则 | 本例 |
|---|---|---|
| 正脊脊盖 | `box`，长 = 脊长 + 0.24；**中心 y = 脊顶 − 0.14**（顶面高出脊顶 0.04 压住坡板 V 口） | 3.24 × 0.36 × 0.36 @ 13.81 |
| 脊端收头 ×2 | 坐落脊盖两端、**超出脊端 0.04**；出脊高度 ≥ 0.15 | 0.30 × 0.42 × 0.36 @ x 5.06 / 8.14 |
| 封檐板 ×4 | `box` 高 0.30、厚 0.06，贴檐口四周（S/N 通长 span、E/W 通长 depth），**外移 0.03 避与屋面端面共面** | `fascia_s/n/w/e` |

### 5.3 老虎窗（两斜板法 + 山墙三棱柱；**后缘必须反解**；**屋面须有出檐**；**屋面下皮贴墙顶、颊墙顶随坡斜切 ⇒ 贴接不穿插**）

**难点**：老虎窗脊线沿 Z 为**水平**，而主坡面沿 Z **上升** ⇒ 若后缘 z 取任意值，山墙脊会**穿出坡面**（读作"浮动三角"）。**硬公式（禁试凑）**：

```
主坡标高函数  f(z) = y3 + ROOF_H · (z − RZS) / RHD          // RZS = CZ − RHD（南檐）
前端墙底      wb   = f(DZ) − 0.06                            // 嵌入坡面 0.06
墙顶          wtop = wb + 1.05                            // 前墙高（含窗）
山墙高        WDH  = 0.60 × WHW        ⇒ 0.57              // 山墙坡角 = 主坡角 30.964°（屋顶与墙体同步）
山墙脊        wridge = wtop + WDH
屋面垂直厚    WVT  = WT / cos α        ⇒ 0.14              // 下皮→上皮（斜板厚 WT = 0.12）
后缘（交线）  DZB = RZS + (wridge + WVT − y3) · RHD / ROOF_H   // 恒等式 f(DZB) = wridge + WVT（**上皮**恰落主坡）

屋面半宽超出墙轴  WOH  = 墙半厚 + EOH        ⇒ 0.26         // EOH = 坡向檐口出檐（越过墙外皮）
斜板长            WSL2 = hypot(WHW, WDH) + WOH / cos α  ⇒ 1.411   // 檐口沿坡加长 = EOH / cos α
屋面石前缘        DZF  = DZ − 墙半厚 − VOH    ⇒ 0.47         // VOH = 前檐 = 0.03（= EMB，联动防共面闪烁）
嵌入量            EMB  = 0.03                                  // 颊墙顶边/山墙斜边对屋面板的不可见插入量（7.0 例外）
颊墙顶斜切         CK   = [(-DWT/2,0),(DWT/2,0),(DWT/2, (wtop−wb)+DWT/2·tanα+EMB),(-DWT/2, (wtop−wb)−DWT/2·tanα+EMB)]
```

**构件组（每樘 8 件）**：前山墙 `wall`（**1.7** 宽 × **1.05** 高，含窗；**沿 X 两端各内缩 `DWT/2 = 0.1`**）+ 西颊 **`profile_sweep`** + 东颊 **`profile_sweep`**（path 沿 **Z** 由 `DZ − DWT/2` 到 **`DZB`**、**顶边随屋面下皮斜切 `CK`**）+ 西坡斜板 `box`（`rotation:[0,0,+α]`，**下皮贴墙顶、含檐口出檐**）+ 东坡斜板 `box`（`rotation:[0,0,−α]`）+ 山墙三棱柱 `profile_sweep`（path 沿 Z、**居中对称**、**斜边 = 屋面下皮**）+ 脊盖 `box`（**坐两坡顶交线 `wridge+WVT`**）+ 窗 `window`（**1.15 × 0.80**，`from[0] = (1.7−1.15)/2 = 0.275` 居中）。

> ★ **正面墙角＝「满长—内缩」配对（禁两墙都按轴线收头）**：颊墙 `profile_sweep` 的 `profile` 宽度（`DWT = 0.2`）是**法向对称外延 ±0.1**，而前山墙 `wall` 的 `from/to` 是**轴线端点、沿 X 不外延**。⇒ 若前山墙取 `x∓WHW`、颊墙又只在 `z ≥ DZ` 起，则**正面外角缺"半墙厚见方"**（墙角"消失"）、且 `z ∈ [DZ, DZ+0.1]` 段两墙**隐藏重叠**。配对写法：**颊墙前伸至前山墙外皮**（`path` 起点 `z = DZ − DWT/2`）、**前山墙沿 X 两端各内缩 `DWT/2`** ⇒ 颊墙内缘 ≡ 前山墙端面（同一平面）⇒ **零缺口、零重叠**。（总则见设计语言 **§0.4 铁律三**）

> ★ **颊墙为何由 `wall` 改 `profile_sweep`**：屋面放大加檐后，若颊墙仍为水平顶的 `wall`，其墙顶（`wtop`）会**高于屋面下皮** ⇒ **墙体从坡面里戳出（BIM 硬碰撞）**。故 ① 屋面一律取「**下皮贴墙顶**」定位（相对"上皮贴墙"整体**抬高一个 `WVT`**）；② 颊墙顶边**随屋面坡度斜切**（`CK` 四边形，外低内高 ±`DWT/2·tanα`）⇒ 墙顶与屋面下皮**零缝、零穿插**。（总则见设计语言 **§0.4 铁律三：贴接不穿插**）

**八条硬判据**：
1. **`f(DZB) = wridge + WVT`**（容差 1e-3）——老虎窗屋面**上皮**恰落主坡等高线 ⇒ **恰好不越坡、不露边**；
2. **±戗脊余量 ≥ 0.30**：后缘 z 处南坡面 x ∈ `[DZB, 2CX − DZB]`（戗脊 45° ⇒ 西戗 x = z、东戗 x = 2CX − z）；**取屋面外缘（含出檐 EOH）**完全落在此区间内。本例 DZB = 3.433 ⇒ 区间 [3.433, 9.767]，外缘 x = 5 ± 1.21 ⇒ [3.79, 6.21] ⇒ 余量 **0.357** ✓；
3. **★ 屋面须有出檐**：坡向水平半跨 = 墙半宽 + 墙半厚 + **EOH**，即斜板**越过墙外皮 EOH 外伸**（本例 **EOH = 0.16**）；同时**前檐 VOH = 0.03 = 嵌入量 EMB**（屋面前缘领先山墙前面一个 EMB ⇒ 颊墙/山墙的**嵌入段前截面全藏于板内**、无共面闪烁；**禁 VOH = 0**——前缘与墙面共面会使嵌入段前截面与之 z-fight；**亦禁大前檐**——原 VOH = 0.12 的悬挑底面在低视角是一整片暗缝，被读作"空心"）。EOH 与 VOH 均须 < 主屋顶出檐 0.78。**禁**屋面紧贴墙轴（零出檐 ⇒ 读作"小帽子"、屋顶显小）；
4. **★ 下皮贴墙顶（贴接）**：屋面**下皮**须过 **檐口轴点 `(脊x ∓ WHW, wtop)`** 与 **山脊 `(脊x, wridge)`**；即斜板 `center = 下皮中点 + 半厚·上法向`：`(脊x ∓ WCX ± WT/2·sinα, wtop + WCY + WT/2·cosα)`（`WCX = (WHW+WOH)/2`、`WCY = (WDH − WOH·tanα)/2`）。**注意是「+」不是「−」**——用「−」即"上皮贴墙"，放大后会穿顶；
5. **★ 禁穿插（硬碰撞）**：在墙**外皮**处（离脊 `WHW + DWT/2`）屋面**下皮**标高 `≥ wtop` ⇒ **颊墙顶不穿出屋面**（容差 2e-3）。本例 `下皮贴墙顶 12.240`、`上皮高出墙顶 0.080` ✓；
6. **★ 正面墙角「满长—内缩」配对（禁墙角消失）**：**颊墙前端 `z = DZ − DWT/2 = 0.5`（= 前山墙外皮）、前山墙沿 X 两端内缩 `DWT/2`** ⇒ 颊墙内缘 `x∓(WHW−DWT/2)` ≡ 前山墙端面（同一平面），**零缺口、零重叠**（本例 X 端 4.15 / 5.85 ✓）；窗 `from[0] = (2·WHW − DWT − 1.15)/2 = 0.275` 居中于内缩后墙长 1.7；
7. **★ 屋顶随墙体同步（联动铁律）**：改老虎窗的宽 / 前墙高 / 出檐，其**颊墙斜切 `CK`**、**山墙三棱柱 profile**、**两坡斜板（长 `WSL2`、旋转 `α`、厚 `WT`）**、**脊盖深 `wzl`**、**窗 `from[0]`** 全部是**派生量**，必须由公式重解，**禁沿用旧数**。本例：宽 1.9 / 高 1.05 / 山墙高 **0.57 = 0.6 × 0.95** ⇒ α = **0.540 rad（30.964° = 主坡角）**、`WSL2 = 1.411`、脊盖 0.30 × 0.16 × **3.053**、窗 0.275 + 1.15。
8. **★ 剖面绕向必须 CW（禁空心）**：颊墙 `CK` 剖面在 `(right, up)` 标架内**必须顺时针**（`CK = [[−DWT/2, 0], [−DWT/2, wtop−wb−DWT/2·tanα+EMB], [DWT/2, wtop−wb+DWT/2·tanα+EMB], [DWT/2, 0]]`，shoelace < 0）；写反（CCW）⇒ 侧面法线**全内向** ⇒ **颊墙渲染成空心管**（端盖已被引擎补偿，故"正面还开着"）。自检 `node 蓝图生成器/check_profile_winding.cjs ../三层欧式别墅.wild` ⇒ 0 错（详见设计语言 §1.4 剖面绕向铁律）。
9. **★ 嵌入量 EMB = 0.03（掠射角发丝缝根除，7.0 例外）**：颊墙顶边、山墙三棱柱斜边与屋面下皮**严格共面**时，掠射视角下共面面片 z-fight/发丝缝 ⇒ 沿两条斜缝读作"两个面没有实体面"。修法 = **wall_stone 构件对 roof_tile 屋面板做 0.03 不可见插入**（同"柱身入柱头 0.04"例外；可见外沿仍以屋面上皮为准）：颊墙顶边两顶点 **+EMB**（保持坡度平行）、山墙棱柱脊 **+0.06**（基角藏于颊墙体内、可见段渐入 ≥0.006、脊仍埋入脊盖）。**前檐 VOH 必须 = EMB 联动**（见判据 3）。判据：颊墙顶边嵌入量恒 = 0.03 ± 1e-3、山墙脊 ∈ (下皮, 上皮)。
   > **排查教训（勿重蹈）**：① **薄板类 `profile_sweep` 的绕向错误在外部视角几乎不可见**——薄板两侧大面平行，绕向翻转后从外侧看到的是"远侧面"，其法线方向与正确近侧面相同 ⇒ 轮廓与明暗不变；**不能用"改绕向"解决薄板观感问题**，须找真实几何诱因（悬挑暗缝 / 共面发丝缝）。② 低视角（低于檐口）看到的屋面**底面暗三角是物理正确的**（任何出檐仰视皆如此），与"缺面/空心"须严格区分——先共面闪烁排查、再谈观感。
   > **放大 / 加檐 / 加高尺寸的连带效应（必须先算后改）**：① 后缘 `DZB = RZS + (wtop + WDH + WVT − y3)·RHD/ROOF_H` 中 `(wtop − wb) = 前墙高`——**窗体越高、后缘越深**；② **加出檐使屋面外缘外伸 EOH** ⇒ 两条都在吃戗脊余量；③ **抬高屋面（下皮贴墙）使上皮再上移 `WVT ≈ 0.14`** ⇒ 后缘又后退。**本次加檐+抬高后把前缘 z 0.8 → 0.6、`DORM_DX` 1.7 → 1.6、EOH 0.18 → 0.16，余量才保住 0.357**（若只改檐不动位置，余量会被吃光）。

### 5.4 烟囱（**靠建筑东/西侧**；坐落坡面时**披水必须随坡**）

- **位置 —— 靠建筑一侧，忌居中**：坐落**西坡面**（x = **3.0** < `CX − RGH` = 5.1、z = 5.1）；`box` **0.7 × 0.7**。**理由**：①正脊实长仅 3.0（= span − depth），居中会把短脊读成"孤岛"；②真烟囱服务于**该侧壁炉**，本就在屋檐一侧，而非屋脊正中。
- **囱底由宿主屋面求解（禁写死）**：屋面标高函数 `surf(x,z) = y3 + (ROOF_H / RHD) · min(z − RZS, RZN − z, x − RXW, RXE − x)`（四坡 = 四张坡面取低，x < CX − RGH 即西坡面）；囱底 `CB = surf(CHX, CHZ) − 1.20`（埋入所在屋面 1.20）。本例 `surf(3.0, 5.1) = 12.69` ⇒ 囱底 **11.49**、囱高 3.36。
- **囱顶判据 —— 高出主脊 ≥ 0.60**（本例 `14.85 − 13.95 = 0.90`）：烟囱不在脊上，判据不是"出脊"而是"**高于屋脊**"（拔风需要）。
- **三段**：囱身（埋入屋面 1.20）+ **披水石板**（1.30 × 0.12 × 1.30，`rotation:[0,0,+β]`、`β = atan(ROOF_H / RHD) = 0.540 rad`、**底皮贴坡面**）+ 压顶（0.82 × 0.14，石材）。
- **★ 坡面烟囱的关键 —— 披水随坡**：坡面沿 x 倾斜（西坡面 `h = y3 + (ROOF_H/RHD)(x − RXW)`）⇒ 水平披水板会在坡上**留楔形缝 / 悬空**；`rotation[2] = +atan(ROOF_H/RHD)`（绕 Z 正角使 +X 端上抬，符号见 §1.4 约定）。**禁**在坡面上放水平披水带。
- **★ 换位置 ⇒ 重解全部派生量（联动铁律）**：`CHS = surf(CHX, CHZ)`、`CB`、`CHP`、披水标高与旋转角**全部由 `(CHX, CHZ)` 与屋面公式派生**——改位置/改坡度后必须重解，**禁**改一个坐标而留旧标高。

## 6. 组件规则（洞口与栏杆）

### 6.1 `from[0]` / `from[1]` 双语义 + 四面墙换算公式（**最易错**）

**语义（引擎源码实证）**：
- `from[0]` = **洞口左边缘**沿墙、从 `wall.from` 端起算的距离（**不是**中心、**不是**世界 X/Z）；
- `from[1]` = 洞口**底部世界 Y**（门 = 本层地面、窗 = 窗台标高）。

**换算（本例墙序，闭式背下；`w` = 洞口宽）**：

| 墙 | 走向 | 起点 | **`from[0]` 公式** |
|---|---|---|---|
| 南 `wall_s` | +X | x = −0.12 | `cx − w/2 + 0.12` |
| 北 `wall_n` | −X | x = **13.32** | `13.32 − cx − w/2` |
| 东 `wall_e` | +Z | z = 0.12 | `cz − w/2 − 0.12` |
| 西 `wall_w` | −Z | z = **10.08** | `10.08 − cz − w/2` |
| 内墙（沿 +X） | +X | x = x₀ | `cx − w/2 − x₀` |
| 内墙（沿 +Z） | +Z | z = z₀ | `cz − w/2 − z₀` |

> **自检**：`from[0] ≥ 0`、`from[0] + w ≤ 墙长`、同墙洞口**不重叠**、净距 ≥ 0.10（同标高段；**异标高段可压缩到 0.10 以下**，但禁重叠）、距墙端 ≥ 0.24。**北墙与西墙是 −X / −Z 走向 ⇒ 公式含"墙长 − 中心 − 半宽"，漏掉镜像项是本类型第一号错误。**

### 6.2 门

| 用途 | 写法 | 尺寸 |
|---|---|---|
| 主入口（拱形双开） | `openingStyle:"arched"` + `doorStyle:"double"`，`frameDepth:0.20` | 1.8 × 2.7 |
| 阳台落地门 | `doorStyle:"double"` + `leafMaterial:"glass"` | 1.6 × 2.4 |
| 室内门 | `single`（缺省），`frameDepth:0.06` | 0.9 × 2.1 |

- **双开必须用 `doorStyle:"double"`**；**禁**拆成 N 件 `single`（每扇自带左右立框 ⇒ 中缝凭空多出 2(N−1) 根竖框）；
- 内门洞口**距内墙 T 型交点 ≥ 0.10**（同墙异标高段可紧贴，本例内门一律落在 z = 2.5 / 7.5，距 z = 5.1 的横墙交点 ≥ 1.95）。

### 6.3 窗

- 窗台高：**落地玻璃 0.30 / 客厅大玻璃 0.90 / 标准窗 0.90**；本例 S1 = 1.35（地面 0.45 + 0.90）、S2 = 4.90、S3 = 7.80；
- 外窗**显式** `frameWidth 0.09` / `frameDepth 0.16`（缺省 0.06 过细）；横竖梃按分格（大玻璃 [2,2]、中央三联 [3,1]）；
- **玻璃一律 `glass`**（`materialClass:"glass"` 全套），**住宅禁用 `glass_curtain`**（读作办公楼）；
- **窗墙比**：别墅主立面 **0.28–0.40**（本例南 0.305）、次立面 0.15–0.22（北 0.178 / 东西 0.187）；**不套用高层板楼 0.35–0.45 口径**（该口径为板楼采光标准）；
- **垂直对位**：同轴位洞口**跨层中心必须对齐**（容差 1e-3）；本例中轴 6.6（主门 / 阳台门 / 三层中央窗）、两翼 2.1 与 11.1（一/二/三层）。**这是"门窗对不齐"痛点的根治判据。**
- **避开内墙 T 接**：东/西立面洞口须避开内墙交点 z = 5.1（本例取 z = 2.6 / 8.0，余量 ≥ 2.5）；北立面须避开 x = 4.2 / 5.4 / 7.8 / 9.0（本例取 2.1 / 6.6 / 11.1，余量 ≥ 0.40）。

### 6.4 栏杆（硬语义⑨）

- **所有室外台阶、坡道、楼梯的两侧临空必须配栏杆**（`railing` 组件：`path` 世界坐标折线 + `height 1.05` + `railLevels [0.5, 1]`）；
- 栏杆须落在**附着体投影面内**（台阶面 / 梯井边），禁悬空于附着体之外；
- **阳台**由 §4.7 宝瓶栏杆围护，**不再写 `railing` 组件**（免重复）；
- `railing` 在部分在线预览编译器中会被静默丢弃 ⇒ **必过真实编译器（flatten）再预览**；需预览时可用 `primitive box` 弦段替代。

## 7. 内外联动规则（外形变更 → 内部构件跟随，硬性七步）

1. **外墙轮廓 / 层高 / 轴网** 变更；
2. 重推**内皮**（南 `z = +0.12`、北 `z = 进深 − 0.12`）；
3. 重推**标高链**（台基顶 → 各层墙顶 → 檐口 → 脊顶）；
4. 重推**内墙端点 + 梯井**（内墙只依附外墙内皮，禁悬空/穿墙/伸到室外）；
5. 重推**门窗 / 内门 `from[0]`**（按 §6.1 公式；**换层/换段宽后所有洞口坐标全部重算**）；
6. 重推**楼板分块 + 楼梯步参数**（公式五b）；
7. 重推**屋顶 `span/depth/position` + 老虎窗 `DZB`（连同其屋面派生量）+ 烟囱 `surf→囱底/囱顶/披水`**；
8. 复跑**自检（§8）→ 独立校验器 → 真实编译器**，三者全绿方可交付。

> **红线**：改外墙**不同步改内墙**（含梯井墙）= 必然产生穿墙/悬空；改层高**不重推楼梯**= 楼梯与楼板差一个步高；改 `span/depth` **不重解 `DZB`** = 老虎窗穿坡；改老虎窗尺寸**不重算其屋面派生量** = 墙大顶小；**老虎窗屋面零出檐** = 读作"小帽子"、屋顶显小；**加出檐不重算戗脊余量（不内移）** = 屋面外缘越戗脊；**放大 / 加高后被覆盖件顶端戳出**（如颊墙穿屋面）= **硬碰撞**，须按 §0.4 铁律三整体重定位（禁削角）。**同一构造在多份蓝图各有拷贝 ⇒ 改动必须全库普查。**（通用律见设计语言 **§0.3 铁律二：联动修改律** + **§0.4 铁律三：组合关系律**）

## 9. 类型总则：体块关系 · 构件清单 · 搭接关系（三张底图）

### 9.1 建筑体块关系（体块语法 = 第一自变量）

**五条体块公理**：
1. **对称中轴体块**：平面以中轴镜像；中跨（4.8）≥ 侧跨（4.2），中跨即"礼仪跨"（门廊 + 阳台 + 山花）；
2. **满铺不逐层内收**：三层轮廓完全相同（区别于新中式退台）；体块读作"竖三段"而非"塔状"；
3. **凸出体量只有两处**：①门廊（z 向凸 1.98）②挑阳台（z 向凸 1.2）；**其余面一律平齐**（立面读作"平面上的雕刻"，不是"堆积体块"）；
4. **体块 → 标高 → 屋顶 推导顺序（禁跳步）**：轴网 ⇒ 段宽 ⇒ 墙环标高 ⇒ 檐口标高 ⇒ 屋顶 `span/depth` ⇒ 正脊标高；
5. **屋顶配重**：屋顶高度 ≈ 檐口标高 × 0.35（本例 3.6 / 10.35 = 0.348）；`ROOF_H < 0.28 × 檐口` ⇒ 读作平顶，`> 0.42` ⇒ 头重脚轻。

**体块原型**：
| 原型 | 体块 | 屋顶脊向 | 判据 |
|---|---|---|---|
| **A 三层满铺（正典范式）** | 三层同轮廓 + 门廊 + 挑阳台 | 脊 ∥X（span 15 > depth 12） | 深 ≥ 9.6、需完整三段式立面 |
| B 二层半阁楼式 | 两层满铺 + 半层 | 脊 ∥X | 用地浅（深 ≤ 9.6）、要"前露台 + 后阁楼" |
| C 短进深（8.4） | 三层，梯井压缩 | 脊 ∥X | 深 < 9.6 仍要三层 ⇒ 梯井 z 段压缩、横墙 z 5.1→4.6 |
