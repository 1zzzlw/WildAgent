## §A ★★ 本轮新增铁律：屋面逐片坐实墙顶（最高优先级）

> **事故**：上一版「二层半·映月台」三片屋顶**一律置于 y=9.75**，而**两翼体块只到 7.35** ⇒ 两翼屋顶**悬空 3.0m**；同时顶层露台四周设**女儿墙（7.35→8.25）**，与坡屋顶**并存在同一标高带** ⇒ 用户读作"既有女儿墙又有庑殿屋顶且屋顶漂浮在半空中"。两份缺陷同源：**收头方式与屋顶座落标高未随体块逐段联动**。

### A1 屋面檐口 = 所坐体块墙顶（偏移 0，逐片核验）

| 屋面 | 所坐体块 | 体块层数 | 墙顶 = 檐口 | 屋脊 |
|---|---|---|---|---|
| `roof_wing_w` | 西翼 X[0, 4.5] | 2 层（0.45→7.35） | **7.35** | 9.05 |
| `roof_wing_e` | 东翼 X[9.3, 13.8] | 2 层 | **7.35** | 9.05 |
| `roof_mid` | 中央 X[4.5, 9.3] | 3 层（0.45→10.35） | **10.35** | 12.05 |

**判据（双通道）**：① `roof.position[1] == 该体块最高墙顶`（严格相等，容差 1e-6）；② **檐口中心正下方必须存在同标高的承托墙**——否则即"无墙可托 = 漂浮"。

**写法**：
```js
hipRoof(tag, x0, x1, z0, z1, h, eaveY)   // eaveY = 所坐墙顶，不再是全局常量
hipRoof("wing_w", -0.72, 4.14, -0.72, 12.12, 1.7, y2)   // 翼坐 y2
hipRoof("mid",     4.14, 9.66, -0.72, 12.12, 1.7, y3)   // 中坐 y3
```
⇒ **禁**把全部屋顶写成同一个 `y3`（一旦体块分层不同，必有一片悬空）。

### A2 三段式体块的收头方式：**庑殿自收头 ⇒ 禁女儿墙、禁伪露台栏板**

- 庑殿屋面（`roof/hip`）**自带底面封口 + 四坡收头**，屋顶本身即"帽"；
- **女儿墙是平屋顶的收头语言**，屋面为坡顶时再设女儿墙 = **同一处两种收头并存** ⇒ 立面读作"重复/矛盾"；
- ⇒ **凡体块盖坡屋顶，该体块即不得设女儿墙**。

#### ★★ A2b 坡顶体块"无上人平面"判据（禁伪露台 · 禁穿屋面栏板）

> **事故**：上一版为"消除女儿墙但不失临空防护"，给两翼顶面又加了**玻璃栏板**（`grail_w/e`，三边环绕）并铺了**露台板**。但**两翼顶面已被翼屋面完全覆盖**（翼屋面檐口外扩 0.72，投影完整包含翼体块顶面）⇒ **翼顶根本不存在可上人平面**。栏板恰好套在檐口环上、**沿坡屋面向上**，渲染读作"**屋顶上一圈护栏**"。

**判据（双通道）**：
1. **覆盖判据**：`体块顶面 ⊆ 该体块屋面投影` ⇒ 该顶面**无上人平面** ⇒ **禁铺露台板**（会与屋面共面/穿插）、**禁设任何栏板**；
2. **位置判据**：任何 `railing` 的 `path` 起点若落在**坡屋面投影范围内**且标高接近檐口 ⇒ 即"穿屋面栏板"，**非法**。

**写法**：
```js
// ✗ 错：给已被坡屋顶覆盖的翼顶加栏板 + 露台板
floor("terr_w", 0, y2, 0, XA, AD, "floor_terrace");
gbRail("grail_w", [[0,0],[XA,0],[XA,11.4],[0,11.4]]);

// ✓ 对：坡顶体块顶面不铺板、不立栏（屋面即收头）
// 本楼唯一护栏 = 室内梯井护栏 rail_l2 / rail_l3
```

- 本楼**无露台**；**唯一临空防护 = 室内楼梯井护栏**（`rail_l2` @4.05 / `rail_l3` @7.35，属室内洞口，与屋面无关）。
- **推论（硬语义⑨的边界）**：**"临空必配护栏"只适用于"存在可上人平面"处**。坡屋面覆盖处**没有平面**，也就**没有临空边**，自然不需要护栏 —— 强行添加反而制造"屋顶护栏"这种不合理构件。

### A3 相邻坡屋面 X 向接缝：**共面贴接**（禁重叠、禁留缝）

三段屋面在同一标高带相接时，X 向必须**端点严格相等**：

| 屋面 | X 区间 | 跨度 |
|---|---|---|
| 西翼 | [−0.72, **4.14**] | 4.86 |
| 中央 | [**4.14**, **9.66**] | 5.52 |
| 东翼 | [**9.66**, 14.52] | 4.86 |

- 段间让量 `ROOF_SEAM = 0.36`（= 出檐的一半）⇒ 翼内侧檐口**退到中央屋面之下**，避免翼屋面压到中段坡面（**上一版翼屋面写到 4.5，与中屋面重叠 0.72 = 非法穿插**）；
- **接缝处两屋面标高不同**（翼檐 7.35 / 中檐 10.35）⇒ 呈"**上下错落**"而非同一平面的发丝缝，不产生 z-fight；
- **中轴镜像校验**：`最西边 + 最东边 == 轴网`（−0.72 + 14.52 = 13.8 ✓）。

### A4 ★★ 门楼柱—屋面三律（禁柱穿透屋面 · 禁柱外露 · 禁屋面后缘悬空）

> **事故**：门楼柱原置于 `PCX ± 1.25`（柱距 2.5），而立面半宽（檐口线）为 `PHW = 1.6` ⇒ 柱**落在坡面下方**（该处屋面下皮 3.392，柱顶 4.05）⇒ **柱穿透屋面 0.658m**；同时屋面檐口端只到 x = 5.351，**柱外缘（5.13）反而露在屋面外**；屋面后缘 z = −0.8、**离南墙 0.8m 悬空**。

**三律（双通道判据）**：

| 律 | 判据 | 本楼实值 |
|---|---|---|
| ① 柱立于**檐口线** | `柱x == PCX ± PHW`（容差 1e-6） | 5.3 / 8.5 |
| ② 柱顶**不穿透**坡屋面 | `柱顶 − 屋面下皮@柱x ≤ 半板厚/cosα` | 3.3 − 3.302 = **−0.002** |
| ③ 屋面**外挑越柱外缘** | `\|柱x−PCX\| + 柱半径 < 屋面半跨 PRHW` | 1.77 < 1.8 ✓ |

**联动闭式**（屋面半跨必须随柱位派生）：

```js
const PHW = PORCH_W/2;               // 檐口线半宽（柱位）
const PEOH = 0.20;                   // 檐口出挑（> 柱半径 0.17，保证覆盖）
const PRHW = PHW + PEOH;             // 屋面半跨
const PRISE = PORCH_HH * PRHW/PHW;   // 脊高（保坡角不变，等比放大）
const PSL   = hypot(PRHW, PRISE);    // 斜板长
const PCOL_H = PORCH_HE − (BASE + 0.3);  // 柱高：柱底=础顶、柱顶=檐口标高
// 屋面进深：后缘抵南墙外皮（嵌入 0.02 防闪面）⇒ 不悬空
const PZF = PORCH_Z − PORCH_D/2 − PEOH;  // 前缘（含出挑）
const PZN = 0 + 0.02;                    // 后缘 = 南墙外皮 + 0.02
```

- **禁**：先定 `PORCH_HH` 脊高再反推屋面半跨 —— 必须**由柱位（檐口线）出发**派生屋面。
- **禁**：屋面进深沿用 `PORCH_D`（柱列进深）—— 柱列进深 ≠ 屋面进深，后者须**向后延伸到墙**。
- **柱顶对齐檐口标高**：`PORCH_HE` 既是檐口标高、也是柱顶标高 ⇒ 柱高 = `PORCH_HE − (台基顶 + 础高)`。

### A5 ★★ 门楼山墙三角（`proof_gable`）尺寸闭式（禁凭"印象"给尺寸）

> **事故**：`proof_gable` 的 `profile` 曾写成 `[[−1,0],[0,0.866],[1,0]]`（底半宽 **1.0**、高 **0.866**）⇒ 比屋面对应的三角空档**窄了 0.6/侧**、矮了 0.08 ⇒ 既**尺寸不对**（用户可见的"大小不对"）、又**两侧露缝**。

**唯一闭式（由屋面几何派生，禁写死）**：

```
底半宽  u   = 檐口线半宽 PHW              // 山墙底边与立面同宽
底边标高 y0 = 檐口线处板下皮
            = PEV + (PRHW − PHW)·tanα − 半板厚/cosα
顶点高  h   = 脊处板下皮 − 底边下皮
            = (PEV + PRISE − 半板厚/cosα) − y0
```

- 记 `tanα = 门廊脊高/门廊半宽`、`PRISE = 门廊脊高 × PRHW/PHW`；
- ⇒ **profile = `[[−u,0],[0,h],[u,0]]`**（CW，`shoelace < 0`）、**path.y = `y0`**、path 沿 z 厚 0.2、**前皮 = 屋面前缘 PHZ**；
- **两腰自然贴合两斜板下皮**（数值实证：三角腰与下皮逐点差 = 0/1mm）；
- 本楼实值：`u = 1.6`、`y0 = 3.302`、`h = 0.951`（顶点 4.253）、profile 宽 **3.2**。

**禁**：直接给 `profile` 写"整数好看值"（如 ±1 / 高 0.9）—— 山墙三角必须由**屋面下皮反解**。
