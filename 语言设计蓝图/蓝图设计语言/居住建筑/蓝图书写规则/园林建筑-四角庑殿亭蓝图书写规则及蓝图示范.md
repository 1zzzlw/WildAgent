# 园林建筑-四角庑殿亭蓝图书写规则及蓝图示范

> 版本 v1.0 · 2026-09-21 · 配套蓝图 `四角庑殿亭.wild`（rev1，14 元素，由 `蓝图生成器/gen_pavilion_hip.cjs` 参数化生成）
> 适用：园林四角亭 / 六角亭（改柱网）/ 方亭一类小式庑殿建筑。继承《WILD蓝图设计语言 v1.2》总则。

## 2. 构件组合规则（自下而上链）

```
台基 → 台阶 → 4 檐柱（柱底=台基顶） → 额枋圈（枋顶=檐口） → 檐口垫板（封 hip 底洞）
→ 庑殿 hip 顶（基面=垫板顶） → 宝顶座（罩顶尖） → 宝顶珠
→ 美人靠 ×3（凳身+斜靠背） → 石桌 + 鼓凳 ×4（亭内居中）
```

1. **台基 + 台阶**：box 台基坐 ±0 以下；前置台阶一级（台基 0.3 = 一踏步），踏步宽 ≥1.8；
2. **檐柱 ×4**：cylinder r0.15，`center y = 台基顶 + CH/2`——按"底面圆心"书写会半截插地；
3. **额枋圈 ×4**：边长 = 柱距 + 2r + 2×半枋厚（3.42），端头互插（同材质，允许实体交叠）；
4. **檐口垫板**（关键，庑殿专属）：引擎 `hip` **只有 4 片坡面、无底面**——从亭内仰视为透空，必须加
   `box [W, 0.1, W]` 垫板封底，兼作挑檐平板（四边各挑出 0.3~0.9）；
5. **庑殿顶**：`roof/hip`，`span = depth = W`，`position = 垫板顶标高处的底面中心`（引擎顶点 y∈[0,h]）；
   小式亭**四坡到顶尖**，无正脊（真庑殿短正脊在大式殿宇表达，亭以宝顶收束）；
6. **宝顶**：座 cylinder 罩住顶尖（座底 = 顶尖 − 0.025 嵌入），珠 sphere `center = 顶尖 + 0.25`
   （sphere position = 球心）；
7. **美人靠 ×3**（除入口面外三边）——**靠背必须镂空格栅，禁止实心板**（传统「靠背栏杆」形制）：
   - 凳身 box（顶 = 台基顶 + 0.42）；
   - 靠背格栅 = **下横档 + 上横档**（`[bL, 0.06, 0.05]`）+ **竖棂条 ×17**（`[0.03, 0.28, 0.04]`，棂距 0.15），
     棂条净高 0.28 = 总高 0.4 − 两横档；栅内透空、栅后透景；
   - 整组（横档+棂条）**随倾角 15° 单轴 rotation 同向旋转**——以底缘中点为原点、坡向单位向量
     `(±sin15, cos15, ±sin15)` 推各构件中心（坡向步进：横档 0.03/0.37、棂条 0.215）；
   - 可选变体：棂条改鹅颈曲条（引擎暂以直棂近似）、端部加鹅颈扶手（下轮扩展）。
8. **石桌凳**：桌 = 腿 cylinder（r0.12×0.64）+ 面 cylinder（r0.45×0.06，顶 = 地面起 0.70）；
   鼓凳 ×4 cylinder（r0.19×0.42，顶 = 地面起 0.42），对角 45° 分布、凳心半径 0.9；
   **人体尺度硬校验**：坐高 0.38~0.46、桌面−凳面高差 0.22~0.34、凳桌净距 ≥0.2。

## 3. 防共面与校验要点

- 垫板顶面 = hip 基面：**搭接接触（法线相反）**，合法不闪面；垫板与台基异材质且标高不同，无共面；
- 生成器内置校验：柱脚坐台基顶 / 坡度 24°~35° 区间 / 宝顶罩尖 / 异材质共面（同面+同法线+面积重叠）；
- 已知豁免：额枋四角同材质互插、台阶与台基同材质搭接——不可见，允许。

## 4. 变体联动

| 变更 | 联动重推 | 依据 |
|---|---|---|
| 柱距 S 变 | 柱位 ±S/2、额枋长、垫板/屋面 W = S+2×出檐、宝顶随顶尖标高 | 本文 §1/§2 |
| 出檐变 | W 与屋面重推（垫板同步）；坡角随 RH/W 复核 24°~35° | 本文 §1 |
| 六角亭 | 柱网改 6 边形分布；屋面仍用 hip（引擎四坡近似，标注假设）或锥坡体系 §3.11 | v1.2 §3.11 |

## 5. 交付自检（本形制 10 条）

1. [ ] 标高链：±0.000 台基顶 → 柱顶/檐口 3.0 → 垫板顶 3.1 → 顶尖 4.5 → 宝顶珠心 4.75
2. [ ] 檐柱 4 根 position = 几何中心，柱底 = 台基顶（无悬浮/插地）
3. [ ] 额枋枋顶 = 柱顶 = 檐口标高；四边闭合
4. [ ] 檐口垫板存在且边长 = 屋面对边 W（封 hip 无底面洞）
5. [ ] hip 顶 position = 垫板顶标高处底面中心；坡度 24°~35°
6. [ ] 宝顶座罩住顶尖（嵌入 ≥0.02），宝顶珠心 = 顶尖 + 0.25
7. [ ] 美人靠三边布置（避让入口面），坐高 0.38~0.46，靠背为**镂空格栅**（每边 2 横档 + ≥15 棂条、棂距 0.15、倾 10°~20° 朝外），无实心靠背板
8. [ ] 石桌高（地面起）0.65~0.75，鼓凳高 0.38~0.46，桌凳高差 0.22~0.34，净距 ≥0.2
9. [ ] 异材质无共面（同面+同法线+面积重叠 = 0）
10. [ ] 紧凑 JSON ≤100KB；editor.revision/generator/params 留痕
