## 4. 逐构件书写规则

### 4.1 塔基、台顶石栏杆与南踏跺（公式十 + 台基栏杆公式）

- `base_main`：单层方台（须弥座简化，已标注）；塔基顶 = 4.2 = 底层墙底；
- **台顶石栏杆（台基必配，v1.5 新增）**——大雁塔"每层门洞凭栏远眺"，台基顶四周必须设栏杆，写法 = **栏板矮墙式 + 望柱**（预算省、无共面）：
  - **栏板**：沿台基顶外沿**内收 0.1** box，高 0.9、厚 0.15，中心标高 = 台基顶 + 0.45；**四角缩进对接（v1.8）**：东西 2 段通长（长 = 台基南北边 − 0.2），北 1 段与南 2 段缩进至东西栏板内侧面（缩进 = 内收 0.1 + 半板厚 0.075 = 0.175；段长微缩 0.015 防舍入重叠）；**南面正中留登塔缺口 GAP = 梯宽 + 2×护栏厚 + 余量 = 4.0**；材质 stone_gray（石作）；
  - **望柱**：截面 0.28×0.28、高 0.45，**立于栏板顶**（柱底 = 栏板顶，禁悬空），每段两端必设、中间按间距 ≈6m 均布（n = round(段长/6)+1，最少 2 根），35 根；**柱位随缩进后跨度均布**（禁用缩进前跨度，否则端柱悬出栏板头）；材质 stone_gray；
  - **禁共面**：栏板内收 0.1 避免与台基侧面/顶面边缘共面；相邻段栏板共用端点处**不重叠**（各段独立计算长度，端点相接）；
- **实体踏跺**：14 步 × 步高 0.3 = 4.2（步高×步数 = 高差，硬语义④）；每级 box 从地面**直砌到踏面顶**（高 = i×0.3，"象眼"填实，禁悬空薄板），步深 0.36、梯宽 3.0；末级顶面 = 4.2 = 塔基顶 ✓；贴塔基南面（z 从基缘向南投影 5.04）；
- **踏跺护栏（v1.6，硬语义⑨"有梯必有栏"）**：与台基栏杆同构（石作）——
  - **随坡栏板**：每侧 1 道 box（0.15 厚 × 0.6 高 × 6.56 长 = √(4.2²+5.04²)），中线在梯边外 0.075（x = cx±1.575）、坡面中点（z = −2.52，y = 2.4）、`rotation[0] = −0.6947 = −atan(4.2/5.04)`——**登高朝 +Z（北）必须用负角**（引擎 +rotX 使 +Z 端下沉，符号约定见设计语言 §1.4）；底边嵌入踏面（中线低于坡线 0.3·cosβ），无悬浮；
  - **望柱**：每侧 3 根（梯段两端 + 中央，t = 0/0.5/1），0.28×0.6×0.28 垂直立放，柱底嵌梯面 0.05（y = 坡线标高 + 0.25），柱顶 ≈ 栏板顶齐平；
  - **rev6 垂带石废弃原因**：斜置光板大壁（0.5×0.6×7.16）+ rotation[0] 误用 +α → 坡向反、南端翘起如"两条奇怪柱状模型"；**凡随坡斜置件先核对 §1.4 rotation 符号约定再落笔**；
- **缺口对位**：栏板南缺口（GAP = 梯宽 + 2×护栏厚 + 余量 ≈ 4.0，cx±2.0）⊃ 踏跺 + 护栏外缘（cx±1.715）——缺口略宽于登道，人可自末级踏面上台再转向，栏杆不拦路。

### 4.2 塔身四墙（满长—内缩配对，公式二）

- 每层半边 h = STORY_B[i]/2；南北墙**满长**：`from = (cx−h, 层底, cz∓h)`、`to = (cx+h, 层顶, cz∓h)`；东西墙**内缩 t/2**：z 向 `cz−h+t/2 → cz+h−t/2`；墙厚 **0.6**；
- 收分：边长 25.5/24.0/22.5/21.0/19.5/18.0/16.5（逐层 −1.5）；上层墙底 = 下层墙顶 = 该层楼板顶。

### 4.3 倚柱与阑额

- **倚柱**：每面 (间数+1) 根——一二层 10、三四层 8、五至七层 6（共 216 根）；沿面均分 `off = −h + (b/(n−1))·k`；box 0.45×(层高−0.45)×0.24，贴墙面外凸 0.15（中心距墙面 0.15）；柱高让出阑额带 0.45，柱顶接阑额底；
- **阑额**：每面 1 道通长 box（长 = 层边长 + 0.9——两端各埋入角柱 0.45，公式八），0.45 高 × 0.18 厚，**顶与墙顶齐平**，外凸 0.12；栌斗简化并入阑额（加大断面表达），如需精细可按 §3.9 斗拱三件套补 216 朵（元件预算 +216，需重新核算 100KB 红线）。

### 4.4 叠涩砖檐（本形制核心之一，§3.11）

每层墙顶之上 4 道：

| 道 | 高 | 外挑（带外缘 − 墙外皮） | y 区间 |
|---|---|---|---|
| 菱角牙子 | 0.15 | 0.45 | 墙顶 → +0.15 |
| 叠涩 1 | 0.3 | 0.75 | +0.15 → +0.45 |
| 叠涩 2 | 0.3 | 1.05 | +0.45 → +0.75 |
| 叠涩 3 | 0.3 | 1.35 | +0.75 → +1.05 |

- 每道 = 4 面围合 box：南北带通长（长 = 2×(墙外皮半距 + 带中心距)），东西带补缺（长 = 南北带长 − 2×带深 0.45）；
- **带内缘藏进墙面或平齐**（菱角牙子内缘 = 墙外皮 − 0.12，其余 ≥ 墙外皮 0.15/0.45/0.75，无共面灰缝）；
- **搭接处（rev13 定版）**：**南北带通长至环带外皮宽**（长 = 2×(outer + 半带深) = 2×outer + 0.45，端头外皮与东西带外皮齐平），东西带**缩进对接**——每端缩进 = **半带深 0.225**（长 = 2×(outer − 带深/2)），端面恰抵南北带**内侧面**：**北带与西带外皮在角部交汇成直角**、零缺口、零共面。**两条教训**：① 缩进量 = 正交构件的**半厚**（半带深/半板厚），不是全厚（v1.4~v1.10 误用整带深遗留 112 处带间缺口，rev12 修正）；② **只对齐端面还不够——通长构件必须延长 2×半厚盖满角部格**，否则外缘角部留 0.225×0.45 台阶缺口（rev12→rev13 定位，用户口径"北向与西向连接起来形成一个直角"）；
- **檐顶四棱台锥坡（rev13 定版）**：每层檐上皮 **1 个 `cylinder segments=4`**——`rotation=[0, π/4, 0]`（引擎 Ry·Rx·Rz 序，rotY 纯水平旋转无俯仰耦合；4 段顶点转至对角线、坡面法向朝四方）；`radiusTop = F×√2`、`radiusBottom = (F+1.8)×√2`（**半径 = 半边×√2 外接圆系数**），`height = 0.8`，底标高 = 带顶 +0.05（内缘标高 = 带顶 +0.85，坡降 0.8 / 坡跑 1.8，α = 23.9°）——四坡面在角部经**角脊线**天然交汇成**直角**，无交叉鳍、无缩进缺口、无贴角补片；锥坡底盖面兼作檐底天花板；顶层（s7）不设，由塔顶攒尖覆盖；
- 方形平面**禁用平滑圆台**（segments ≥16 的旋转体只服务圆形/正多边形平面——§3.11 红线 3）；**segments=4 四棱台是方形锥坡正解**（四棱台是平面拟合体，非旋转体）。

#### 4.4.1 叠檐直角闭合 + 四棱台锥坡——完整书写步骤（rev13 定版，用户确认"交叠处理得很完美"）

对任一层 s（墙外皮半距 F = 层边长/2 + 0.3，层顶 y1）：

1. **定带中心距**：第 ri 道（0=菱角牙子，1..3=叠涩带）`outer = F + out(ri) + 带深/2`，out = 0 / 0.3 / 0.6 / 0.9 逐道外挑；带 y 中心 = y1 + 已堆道高 + 道高/2；
2. **南北带（盖角通长边）**：长 = `2×outer + 带深`（**必须含 2×半带深盖满角部格**），position z = cz ∓ outer，断面 [长, 道高, 带深]；
3. **东西带（缩进对接边）**：长 = `2×(outer − 带深/2)`，position x = cx ± outer——端面恰抵南北带内侧面，**南北带外皮与东西带外皮在四角交汇成直角**（零缺口、零共面）；
4. **四棱台锥坡（每层 1 个）**：`bandTop = y1 + 1.05`；`radiusTop = F×√2`（内半边外接圆）、`radiusBottom = (F+1.8)×√2`（外半边 = 内半边 + 坡跑 1.8）、`height = 0.8`（坡降）、`position = [cx, bandTop + 0.05 + 0.4, cz]`（底面带顶 +0.05）、`segments = 4`、`rotation = [0, π/4, 0]`（四坡面法向朝四方，角部经角脊线交汇成直角）；
5. **瓦材质**：`roof_dark` 中性青灰（rev14 定 [0.44,0.44,0.43]，**R≈G≈B 忌棕黄**），与土黄砖身靠色相区分。

### 4.5 券门 ×28（引擎原生 opening 元素，本形制最易错点）

- **通道**：opening 写在 `geometry.elements[]`（**不是 components**——编译器未注册 opening 编译器，写错通道报"没有注册组合构件类型 opening 的编译器"）；
- **坐标语义**（与墙面组件相反，两条硬规则）：
  - `from[0]` = 洞口**中心**沿墙距离（组件是左边缘）——南北墙 = h、东西墙 = (b−0.6)/2；
  - `from[1]` = **墙底相对高度**（组件是世界标高）——券门落层地面，恒为 0；
- **洞形（rev15 定版，拱券 = 墙上的洞，形状 = 矩形 + 半圆）**：**各层券宽统一 2.25（与一层一致）**——rev13 曾按开间逐层收敛（间宽−0.55），立面上宽窄不一被用户否决；**洞心居中硬口径**：`from[0]` = 墙轴跨一半——S/N 墙轴跨 = B → 写 B/2；**E/W 墙 from 已内收 t/2、轴跨 = B−t → 必须写 (B−t)/2，写混即偏 0.3**；28 洞心穷举 + 渲染衬板包围盒双重复核零偏差；**洞心共竖线**（x=22.8 / z=24.3，收分塔逐层按当层墙轴重算）；**洞顶逼近层檐**——opening 高 = 层高 − 1.8（净高 = 层高 − 1.8 − 1.125），洞顶距檐底净 1.8 留石门楣带；`style:"arched"` 为形制声明；
- **拱肩回填**：半圆外两角用砖色块补回墙体——第 k 道（k=1..N−1，N=4、道高 = 半券宽/4）宽 = `(W − 2√(r² − h²))/2`（r = 半券宽、h = 道中点自拱脚起算），厚 0.64（略出墙 0.02 防共面闪缝）、材质与墙体一致；沿墙偏移 = ±(半券宽 − 宽/2)；半圆弦长 `w(h) = 2√(r² − h²)` **自拱脚向拱顶递减**（rev3 曾颠倒基准，废弃）；宽 <0.05 的残余窄条忽略；
- **石门楣（rev13 凸出墙面）**：横贯拱顶上方（宽 = 券宽 + 0.9×高 0.45×厚 0.3，`rotation[1] = atan2(nx, nz)` 随墙法向旋转，**外皮凸出墙面 0.12、两端嵌入倚柱**——原嵌墙内不可见，v1.12 修正）；底层四面青石门楣为实有形制，上层按同法延续（近似，已标注）；
- **材质**：墙体/回填 `brick_gray` = 泥土色 [0.60, 0.50, 0.37]；洞内衬 `recess_dark` 深色模拟券洞进深。

### 4.6 塔内楼板（可登塔）

- 6 块 `floor`（一至六层顶，第七层顶即塔顶不设）；**板边 = 上层半边 + 半墙厚 0.3**——既被上层墙压住（板边藏进墙厚带，硬语义⑦），又不与下层墙相撞（下层半边 − 0.3 > 上层半边，收分 1.5 > 0.6 ✓）；thickness 0.2，材质 floor_wood。

## 9. 书写与表现经验小结

**书写经验**：
1. **方形塔 ≠ 圆形殿的旋转体思维**——祈年殿屋面靠 cylinder 圆台旋转成形，大雁塔全部靠 box 直角堆叠：叠涩檐是"逐道外挑的水平带"，不是"斜面旋转体"；两类平面各用各的原语，**混用即出椭圆歪坡**；
2. **收分即公式**——塔的一切横向尺寸是"该层半边 h"的函数（倚柱位、叠涩带长、券洞居中距、楼板边），参数表改 STORY_B 一处，全塔联动；
3. **opening 元素与墙面组件是两套坐标语义**——组件 from[0] 左边缘/世界Y，opening 元素 from[0] 中心/墙底相对Y；写错通道或写错语义是本形制两大高频错（已升格 §3.8 与 §9 错误速查）。

**表现经验**（渲染验收怎么判）：
1. 塔身侧影必须是**连续折线**（每层收分 1.5 可读）而非直筒；
2. 每层檐必须是**阶梯状出挑**（菱角牙子 + 3 道叠涩），檐口厚度感来自带深 0.45；
3. 券洞呈**深色内凹**（recess_dark 衬板），石门楣横贯洞顶；
4. 塔刹釉陶件与攒尖顶点衔接、无悬空；踏跺象眼填实、无透空。
