## 2. 坐标与场地约定

- **场地 60×60**；原点 = **场地西南角**（0,0,0），圆心 = 场地中心 **(30, 30, ·)**；
- **±0.000 = 室外地面**（渲染地面 y=0 与之重合——大台建筑铁律，§2.3）；
- **标高链**：台基一层顶 +2.1 → 二层顶 +4.2 → 三层顶 **+6.3 = 殿内地面**；下段柱顶 12.3 → 檐1唇顶 12.7 → **檐1坡顶 14.7** → 中段顶 17.1 → **檐2坡顶 19.1** → 上段顶 21.5 → 檐3唇顶 21.9 → **锥顶 27.7** → 宝顶球心 29.1；
- 方位角：从 +X（东）起算向 +Z（北）旋转，正南 = 270°；
- 全部重要尺寸循 0.3 模数：台基层高 2.1（7M）、柱高 6.0（20M）、中/上段 4.8（16M）、攒顶高 5.4（18M）、台阶步高 1.05（7 半模）。

## 4. 逐构件书写规则

### 4.1 三层圆台基

- 每个 `terrace_t<i>`：`cylinder`，`radiusTop = radiusBottom`（直壁），层高 2.1，**必须写 `segments: 128`**（细分等级判据：边长 2π·30/128 ≈ 1.47m，台基体量大故放宽到边长 ≤1.5m；§3.9 细分等级表）；
- 标高链：t1 0→2.1 → t2 2.1→4.2 → t3 4.2→**6.3（殿内地面）**；半径 **30 / 25 / 20**（每层内收 5.0，留步廊）。

### 4.2 石栏杆三件套（每层 48 组）

- 栏杆圈半径 rr = 层半径 − 0.3；圈上 n=48 等分点为**望柱位**，相邻两柱之间为一段**栏板 + 一段扶手**；
- 第 i 组（p₁、p₂ 为相邻两等分点，mx/mz 为弦线中点，θ = atan2(−Δz, Δx) 弧度）：

| 件 | 尺寸 | 定位 |
|---|---|---|
| 望柱 railP | 0.25 × 0.95 × 0.25 | 中心 = 柱位 p₁，y = 层台面 + 0.475 |
| 栏板 railB | [弦长−0.25] × 0.5 × 0.1 | 中心 = 弦线中点，y = 层台面 + 0.35（+0.1~0.6） |
| 扶手 railH | [弦长−0.05] × 0.12 × 0.2 | 中心 = 弦线中点，y = 层台面 + 0.89（+0.83~0.95） |

- 弦长 = 2·rr·sin(π/48)（rr=29.7 时 **3.885**；n=32 旧值 5.817 已废弃）；栏板缩 0.25 让位于望柱，扶手缩 0.05 搭头；
- 旋转公式（脚本内计算）：`rotation[1] = atan2(−cosθ_m, −sinθ_m)`，θ_m = 弦线中点方位角；
- 三件同材质 stone_white；环首尾相接处天然共点，无需藏入；
- **48 组 × 3 层 × 3 件 = 432 件，必须由生成脚本产出**（§1.5），手写不可行。

### 4.3 御路踏跺 ×5（放射式 · 实体 · 同构护栏，公式十）

**形制**：五条楼梯**均由圆心呈放射状射出**——正面三条（中线方位角互成 15°：255° / 270° / 285°：中轴正面踏跺 s0 + 东西垂手踏跺 s1/s2）+ **东西两侧各一条**（s3 方位角 0° / s4 方位角 180°）；每条为**实体楼梯**（踏步从支承面直砌到踏面顶，"象眼"填实）；两侧设**与台基栏杆同构的护栏三件套**（随坡）；梯段宽 **4.2**（循模，忌过宽）。

- **放射式的几何红利**：中线过圆心 ⇒ 圆台缘对**每一条**楼梯（含东西侧）恒在 **ρ = 30 / 25 / 20**，步深统一 = 5/7 = 0.714，末步顶面恰达台缘（无需按 x 修正台缘）；
- **踏步**：每条 3 梯段 × 7 步 × 步高 0.3；踏步 box 4.2 × h × 0.5714，`rotation[1] = atan2(内向w.x, 内向w.z)`（s0=0、s1/s2=±15°）对齐射线；底 = 支承面 − 0.02（嵌入），顶 = 踏面标高；
  | 梯段 | 支承 | 径向 ρ | 高差 |
  |---|---|---|---|
  | A 落地段 | 地面 0 | 34→30 | 0→2.1 |
  | B 台1面上 | 2.1 | 30→25 | 2.1→4.2 |
  | C 台2面上 | 4.2 | 25→20 | 4.2→6.3 |
- **台阶护栏（与台基栏杆同构三件套）**：每梯段两侧——
  | 件 | 尺寸 | 定位 |
  |---|---|---|
  | 望柱 stairP | 0.25 × 0.95 × 0.25，**垂直** | 梯段两端（足端/顶端），底 = 该端踏面顶；共 5×8 = **40 根**（足端仅首梯段设，防重合） |
  | 栏板 stairB | 0.1 × 0.5 × 坡长 | 随坡，中心 = 鼻线中点 +0.25；共 5×6 = **30 块** |
  | 扶手 stairH | 0.2 × 0.12 × 坡长 | 随坡，中心 = 鼻线中点 +0.79；共 5×6 = **30 块** |
  坡长 = √(run²+2.1²)；先 `rotation[1]` 对齐射线，再 `rotation[0] = −asin(2.1/(坡长·cosβ))` 补偿欧拉顺序（Three.js XYZ 先 Y 后 X）；鼻线中点 y = 支承 + 1.2；
- **穿栏断栏（公式十 3）**：五条放射走廊内（栏杆件方位角与任一楼梯中线夹角 < asin(2.3/自身半径)，全周判定不限南侧）不生成栏杆件；栏杆 432→357 件，断口两端望柱收头；
- 行人自断口上梯，沿射线拾级而上，过台缘即达该层台面。

### 4.4 折面殿身（正十六边形）

- 外接圆 **R = 10.5**；弦长 = 2R·sin(π/16) = **4.0969**；矢高 s = R(1−cos(π/16)) = **0.201 ≤ 0.25**（公式九判据；旧 12 段 s=0.357 折面感明显，已废弃）；
- 第 k 段墙：`from = (R·cos(22.5k−11.25°), 6.3, R·sin(22.5k−11.25°))`，`to = (R·cos(22.5k+11.25°), 12.3, R·sin(22.5k+11.25°))`；墙厚 0.12；材质 pillar_red；
- **墙面中线方位角 = 22.5k**：k=0 东、k=4 北、k=8 西、k=12 南——四正向墙恰为 door 宿主；
- 柱：`base = (R·cos(−11.25°+22.5k), 6.3, R·sin(−11.25°+22.5k))`，高 6.0，r 0.25→0.22，`chinese_wooden`；
- 内核 `body_core`：cylinder r 9.0、6.3→12.3。

### 4.5 隔扇门窗组件（本形制核心）

| 项 | 隔扇门 ×4 | 直棂窗 ×12 |
|---|---|---|
| 宿主 | 四正向墙（中线 0°/90°/180°/270°） | 其余十二面墙 |
| `width × height` | 2.4 × 3.6 | 2.4 × 2.4 |
| `from` | `[0.8484, 6.3, 0]` | `[0.8484, 7.2, 0]` |
| `from[1]` 规则 | **世界标高 = 殿内地面 6.3**（硬语义③） | 殿内地面 + 0.9 = 7.2 |
| `frameWidth / frameDepth` | 0.09 / 0.09 | 0.09 / 0.09 |
| 其它 | `doorStyle:"double"`，frameMaterial gold | `verticalMullions:4`，glassMaterial glass |

- `from[0]` = 弦长/2 − 洞宽/2 = 2.0484 − 1.2 = **0.8484**（公式九居中写法；旧 12 段值 1.518 已废弃）；from[0]+width = 3.248 ≤ 4.0969 ✓；
- **改段数必须重算 from[0]**——门窗不居中是段数变更后最常见回归（§9 错误速查）；
- **必须走 flatten 编译管线**：预览器不展开组件（§1.1 注记②）；flatten 产物 `{primitive:564, wall:16, column:16, roof:1, opening:16}` = 613 元素。

### 4.6 彩画带与中/上段殿身

- 彩画带：环 cylinder，`r = 该段殿身半径 + 0.06`、高 0.6，贴段顶（band_l1 11.7–12.3、band_l2 16.5–17.1、band_l3 20.9–21.5）；
- body_l2：r 8.0、**14.7→17.1**（高 2.4）；body_l3：r 5.5、**19.1→21.5**（高 2.4）——两段殿身夹在檐坡之间，殿身高度循模 2.4（8 半模）。

### 4.7 三重檐（檐唇 + 锥坡，照片指认形制）

每重檐 2 个 primitive cylinder（圆台能力：`radiusTop ≠ radiusBottom`）：

| 重 | 檐唇 eave<i>_lip | 锥坡 eave<i>_slope |
|---|---|---|
| 下檐 1 | r13.0，12.3–12.7 | rB13.0 → rT8.6，12.7–14.7（h2.0，坡度 ≈24°） |
| 中檐 2 | r10.8，17.1–17.5 | rB10.8 → rT6.0，17.5–19.1（h1.6，坡度 ≈18°） |
| 顶檐 3 | r8.4，21.5–21.9 | ——（上接收分圆锥，§4.8） |

- **檐唇** = 直壁薄环，模拟檐口翘边（"直角梯形"的竖直短边）；
- **锥坡** = 圆台斜面（"直角梯形"的斜边），坡度 = atan(高 / (rB−rT))，取 18–25°；
- 锥坡上口半径 = 上层殿身半径 + 0.6（压顶搭接，檐坡上缘扣住殿身）；

### 4.8 圆锥攒尖顶与鎏金宝顶

- `roof_cone`：收分圆锥台 primitive cylinder，rB 8.4（= 顶檐唇半径）→ rT 0.4（= 宝顶座半径），21.9–27.7（h5.8，坡度 ≈36°）；
- 宝顶：金 cylinder（r 0.4、高 0.9，27.7–28.6）+ 金 sphere（r 1.0，球心 29.1，底嵌入座顶）——锥顶半径与宝顶座半径相等，二者自然对接；
- **禁用 dome**：`roofType:"dome"` 是西式半球穹顶（无锥面坡度），中式攒尖一律用圆台收分写法（§3.9）；
- **管线红线**：flatten/编译脚本不得丢弃 `type:"roof"` 元件（历史缺陷，§8 自检 12）；本写法全部用 primitive，无此风险。

### 4.9 屋顶书写与表现经验小结（已泛化至设计语言 §3.11）

**书写经验**（为什么这样写是对的）：
1. **母线思维**：旋转屋面的每一重檐剖面 = "直角梯形"——竖直短边用檐唇直壁环表达、斜边用圆台锥坡表达，两件同半径对接即成完整檐口；沿半径方向逐重内收、沿标高逐重上升，即得 n 重檐；
2. **三个对接零缝隙**：檐唇顶 = 锥坡底（同半径同标高）；锥坡上口 = 上层殿身半径 + 0.6（压顶搭接，檐坡扣住殿身）；锥台顶半径 = 宝顶座半径（金顶座直接落在锥尖）；
3. **坡度即形制**：檐坡 18–25°（下层缓、上层陡）、攒尖锥面 30–40°，全部由"锥坡高 / 半径差"一个比值控制，改坡度只动锥坡高；
4. **形制红线**：屋面禁用平盘、攒尖禁用 dome、圆台只用于圆形/正多边形平面（矩形用 hip/gable）。

**表现经验**（渲染验收怎么判）：
1. 每重檐侧影必须是**斜线**而非水平线——水平线即退化为平盘；
2. 三重檐檐缘半径逐层读得出递减（13.0 / 10.8 / 8.4），层间露出殿身红段与彩画带；
3. 锥面标线（segment 棱）沿径向均匀放射、无扭曲破面；
4. 宝顶金球与锥尖相接、无悬空；屋面底缘与彩画带顶齐平、不穿殿身。

> 以上经验已脱离祈年殿实例，泛化为设计语言 §3.11 的通用体系（单檐亭 / 重檐 / n 重檐 / 庑殿短正脊 / 腰檐门楼 / 西式穹顶的形制泛化表），后续任何屋面形制直接引用，不再重复推导。
