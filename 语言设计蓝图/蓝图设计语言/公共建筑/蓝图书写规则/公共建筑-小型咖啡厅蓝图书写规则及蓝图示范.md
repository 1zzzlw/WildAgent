## 0. 定位与适用范围

- **适用**：城市街角 / 景区 / 社区内的小型独立咖啡厅——两层带夹层、单层通高体块、南向通透玻璃主立面、双坡屋顶、室外木平台、咖啡吧台。建筑面积约 140–200㎡（示范 142.6㎡ 首层 + 夹层部分）。
- **不适用**：连锁旗舰店（大空间多楼层）、带烘焙工坊的复合业态（需另设独立设备分区与排烟井）、历史街区传统木构咖啡（应走传统建筑类配方）。
- **形制取向**：**现代独立小馆**——以「单层通高 + 夹层座位区」的二层剖面替代规矩的两层，主立面整面玻璃对街展示吧台，双坡屋顶取坡面外露的语言（非隐藏式平顶），并用一独立烟囱锚定「咖啡」业态识别。
- **书写顺序**：实心地基 → 台基（勒脚）→ 首层通高墙环 → 夹层板（留洞）+ 楼梯 → 夹层墙（并入墙环）→ 屋面（逐片坐实墙顶）+ 山墙三角 + 封檐板 → 门楼 → 室外木平台 → 烟囱 → 立面开洞（门窗）→ 栏杆 / 灯。
- **变体划分**：§1–§11 为**变体一·坡顶二层小馆**（双坡屋顶 + 夹层 + 门楼）；**§12 为变体二·退台平顶玻璃（Forest 型）**（三级退台 + 屋面即露台 + 外挂折返楼梯 + 顶部玻璃亭与木格栅凉棚）；**§13 为变体三·独栋庭院咖啡厅**（一楼内庭院 + 二楼南/东二面退台 + 二层四坡屋顶 + 木饰面主调）；**§14 为变体四·错位叠盒咖啡厅**（三矩形体块错位叠加 + 交错悬挑 + 退台 + 中庭挑空 + 平顶天窗）；**§15 为变体五·高台观景咖啡厅**（高台基观景平台 + 木饰面 + 落地窗/方格/竖向格栅 + 二层北退台南向观景平台 + 右侧外挂楼梯 + 玻璃护栏）。**读图先定变体**：屋面外露双坡坡面 ⇒ 变体一；平顶逐级退台 ⇒ 变体二；带**内庭院**且二层为**四坡屋顶（庑殿）** ⇒ 变体三；**多矩形体块沿高度错位叠加**、有**交错悬挑**与**中庭挑空** ⇒ 变体四；**整栋坐于较高台基之上**、有**地面层观景平台（玻璃护栏围合）**与**二层北退台南向观景平台**、木饰面外墙 + 格栅立面 + **右侧外挂楼梯** ⇒ 变体五。

## 2. 形制决策链（书写第一步）

1. **定剖面**：先定「单层通高 + 夹层」——通高首层（5.1）+ 悬浮夹层板（厚 0.20）+ 夹层低层（2.1）。**反推**：夹层板顶标高 = 室内地坪顶 + 通高净高 + 板厚 = 0.30 + 3.00 = 3.30；檐口 = 夹层板顶 + 夹层层高 = 3.30 + 2.10 = 5.40。
2. **定体块**：矩形实墙环（13.2×10.8），四道通高外墙一次到顶（Y0 → 檐口 5.40），**不拆首层/夹层两道墙**（拆则夹层墙顶易穿出屋面，见 §10 病例）。
3. **定屋面**：以屋面下皮 = 墙环顶（檐口 5.40）为唯一起算标高 → 半跨 `RW = AZ/2 + 半墙厚 = 5.40 + 0.12 = 5.52` → 脊高 `RISE = RW·tan28° = 2.935` → 正脊 `8.335`。四向出檐统一 0.48（自墙外皮再外挑）。
4. **定夹层**：夹层板 = 4 块瓦片拼装（避开楼梯洞）；夹层洞口（楼梯井）复平面内无板；洞边退至内墙轴线，洞口水平投影须覆盖全部梯跑 + 休息平台。
5. **定楼梯**：两跑一平台（首层地坪顶 0.30 → 夹层板顶 3.30，全高 3.00 ⇒ 半层 1.50 = 10 级 × 0.15）；梯井围合两道内墙。
6. **定立面**：南向两樘大玻璃（底 = 地坪顶 + 0.60 窗台，高 2.90）分主门两侧、各留 0.30 净距；山墙/北墙承夹层窗；西侧临木平台处承侧窗。
7. **定收头**：双坡两斜板 + 脊盖 + 两端山墙三角（顶点 = 正脊下皮）+ 一圈封檐板 + 门楼（双落地方柱 + 三角山花）+ 独立烟囱。

## 3. 坐标、标高与模数（咖啡厅口径）

- **±0.000 = 室外地面**（渲染地面 y=0）；**室内地坪顶 = +0.30**（2 级 × 0.15）= 台基顶 = 首层墙底；整栋坐于实心地基之上（写法：地基顶 +0.30、底 −0.02、四面出挑 0.06，南面兜住外墙外皮与木平台基座）。
- **单标高链**（无住宅类第二链；夹层只是首层通高内的一块板）：

| 标高 | 值 | 含义 |
|---|---|---|
| 室外地面 | 0.000 | 渲染地面 |
| 室内地坪顶 = 台基顶 = 首层墙底 | **0.30** | `Y0` |
| 夹层板顶（= 夹层地板 = 夹层墙底） | **3.30** | `YM` |
| 檐口 = 首层墙顶 = 夹层墙顶（统一墙环顶） | **5.40** | `Y1` |
| 正脊（屋面下皮） | **8.335** | `Y1 + RISE` |
| 囱顶 | **9.535** | 正脊 + 1.20 |

- **统一墙环铁律**：首层墙与夹层墙**合并为同一道通高墙**（Y0 → Y1）。夹层墙不与首层墙分开写（分开 ⇒ 两道墙顶标高不同 ⇒ 低者穿出屋面）。夹层楼板仅作为墙环内部的悬挑板表达。
- 模数：关键尺寸循 **0.3m 模**（轴网 13.2/10.8、层高 5.10/2.10、楼梯步宽 0.30、步高 0.15）；出檐 0.48、板厚 0.20 等构造值不参与模数检查。
- 精度：所有元素 `position/from/to` 三值一律包 `R(v) = Math.round(v×1000)/1000`（**禁 R(v,4)**）；写盘前整份过 `round_all(obj,3)`。

## 4. 构件书写规则

### 4.1 实心地基与台基（勒脚）

- **地基**：`primitive box`，顶 = `Y0`（0.30）、底 = `−0.02`、四面出挑 0.06；**南面须外延到木平台外皮**（`PL_S_OUT = min(ZW, POR_Z0) − 0.05`），否则平台基座露空。材质 = 深色石材（`base_plinth`）。
- **勒脚带（plinthband）**：四面各一条 `primitive box`，循「带体中心三律」——厚 `t = OUT + EMB = 0.06 + 0.02 = 0.08`、中心偏墙皮 `d = (OUT−EMB)/2 = 0.02`；校验 `d + t/2 == OUT`（0.06）、`t/2 − d == EMB`（0.02）。带顶 = 室内地坪顶上方 0.35 内（示范带顶 0.65），**勒脚顶不得高于最低窗台**。

### 4.2 通高墙环（四道外墙，一次到顶）

- 四道 `wall`：`from[1] = Y0`（0.30）、`to[1] = Y1`（5.40）；厚 `TE = 0.24`；**禁写 `height` 字段**。
- **★ 转角 = 端点严格重合 · 引擎斜接**：正交两墙**端点严格重合于同一点**，引擎 `adjustWallJoint()` 判端点距 `< 0.01` + 竖向相交后**各沿其轴向对方外延半厚** ⇒ 外角天然 90° 阳角、零缺口（重叠恒为 `t·h`）。**禁手工写「满长 / 内缩」坐标**——内缩端令端点相距 `h`（远超 0.01）⇒ 配不上 ⇒ 不外延 ⇒ 每角缺口；手工超长端被引擎**再叠加一次** ⇒ 端点落到对方轴线 ⇒ 缺口照旧。**组件联动**：墙两端各外延 `h` ⇒ 挂墙组件 `from[0] = 中心 − 宽/2 + h`。
- 内墙：夹层洞边墙（`wall_bar` 等）厚 `TI = 0.12`；梯井围合墙（`wall_shaft_e` / `wall_shaft_n`）同厚，**围合井道四周，不铺板**。

### 4.3 夹层楼板（四瓦片拼装 + 楼梯洞）

- 夹层板 = `floor` 元素，`from[1] = to[1] = YM`（3.30）= **板顶**，`thickness = 0.20`（板身向下延伸 ⇒ 板底 = 3.10）。
- **4 块瓦片严格划分、凹凸互补**（不重不漏）：

| 瓦片 | X 区间 | Z 区间 |
|---|---|---|
| `slab_a` | 0 → 3.60 | 6.60 → 10.80 |
| `slab_b` | 3.60 → 13.20 | 0 → 3.30 |
| `slab_c` | 3.60 → 8.40 | 3.30 → 10.80 |
| `slab_d` | 8.40 → 13.20 | 3.30 → 10.80 |

- **洞口 = 无板区**：X ∈ [0, 3.60] × Z ∈ [0, 6.60]（西北角），水平投影须覆盖全部梯跑 + 休息平台。**铺满 = 楼梯堵死**。
- 夹层板周边与通高墙环内皮相接（板边 = 墙内皮），板下皮 3.10 = 夹层下净高 4.50 的上界（3.10 − 0.30 ≠ 4.50；净高由**板底**到地坪顶计 ⇒ 通高体块除夹层处外净高 5.10）。

### 4.4 楼梯（两跑一平台）

- `stair` 元素：`from` / `to` + `width` / `stepCount` / `stepDepth` / `stepHeight`；恒等式 `stepHeight × stepCount = 半层高差`（0.15 × 10 = 1.50）。
- 示范：梯跑 1（X 1.325→2.375，Z 3.30→6.30，上行）+ 休息平台（顶 = 1.95）+ 梯跑 2（X 2.375→3.425，Z 0.30→3.30）。
- **所有 from/to 字段逐项过 `R()`**（浮点尾数会被出厂自检拦下）。
- **★ 坡道/台阶/楼梯必配护栏**（硬性语义规则）：临空侧设 `railing`，`height 1.05`、`postSpacing 0.9`、`railLevels [0.5, 1]`。

### 4.5 屋面（双坡两斜板法：斜置 box + 脊盖 + 山墙三角 + 封檐板）

> **★ 屋面属"大面结构"，一律走 `primitive box`（斜置）——禁 `profile_sweep`**（§设计语言 3.6）：引擎 `buildProfileSweep` 把剖面**垂直于 path 扫掠**，小截面沿斜 path 走 ⇒ 生成一根**斜细杆**（读作"从脊到檐支了根棍"），且渲染器对 `profile_sweep` 造的大块实体板存在兼容问题（整片不可见）。**正确写法 = 两片斜置 box 拼双坡**。

**① 斜板（两片 `primitive box`，靠 `rotation` 斜置）**

- 局部轴：`dimensions = [沿脊向 depth(14.4), 板厚 ROOF_TH(0.12), 沿坡斜长 ROOF_SLOPE_L(6.795)]`；`rotation = [±α, 0, 0]`（α = 28° = 0.489 rad，**脊 ∥ X ⇒ 绕 X 旋转**）。
- **旋转符号律**：南坡（−Z 侧）`rotation = [−α, 0, 0]`；北坡（+Z 侧）`rotation = [+α, 0, 0]`。写反 ⇒ 坡向倒转（两坡变"V"字凹口朝上）。
- **中心由"下皮两端点精确命中"反解**（禁先定中心再凑坡度）：
  - 南坡下皮须过 **脊点** `(z = AZ/2 = 5.40, y = YRIDGE = 8.335)` 与 **檐外沿点** `(z = ROOF_Z0 = −0.60, y = Y_EAVE_OUT = 5.145)`；
  - 北坡下皮须过 **脊点** 与 **檐外沿点** `(z = ROOF_Z1 = 11.40, y = Y_EAVE_OUT)`。
  - 局部向量 → 世界：`local Y → (0, cos α, ∓sin α)`、`local Z → (0, −sin α, cos α)`（Euler XYZ，Rx 作用）。
  - 反解结果：`roof_s` 中心 `[6.6, 6.792, 2.372]`、`roof_n` 中心 `[6.6, 6.794, 8.429]`（X 中心 = 轴网中线 + 出檐居中）。
- 板厚 0.12；斜板**水平投影** `ROOF_SLOPE_D = RW + 0.48 = 6.00`；**沿坡斜长** `ROOF_SLOPE_L = ROOF_SLOPE_D / cos28° = 6.795`（**沿坡量取用斜长、不用投影**）。

**② 屋面逐片坐实墙顶（★）**：檐处屋面**下皮**（墙顶线 `z = ∓bi` 处的下皮标高）必须 **== 墙环顶** `Y1`（5.40）。本类型两坡同高，仍须**逐片由 `Y1` 入参派生**（禁多片统一写同一标高——分层不同时必有一片悬空）。檐口正下方须有同标高承托墙。判据：斜板下皮在 `z = −bi`（南）与 `z = AZ + bi`（北）处的标高 `== Y1`（1e-6）。

**③ 脊盖（★ 盖两斜板上皮间的 V 口，遇烟囱分段）**

- 两片斜板在脊线处相交，**上皮之间留一道 V 形凹口** ⇒ 需一条脊盖 box 压顶封口。
- `ridge_cap`：`position[1] = YRIDGE + RIDGE_CAP_H/2`（坐正脊、高出脊线 0.22）、`dimensions = [沿脊长, RIDGE_CAP_H(0.22), RIDGE_CAP_W(0.34)]`、`position[2] = AZ/2`（屋脊线）。
- **遇烟囱必须分段**：烟囱占 X ∈ [`CHIM_X0`(11.20), `CHIM_X1`(12.00)] ⇒ 脊盖断为两段严格**贴接**囱外皮：
  - `ridge_cap_w` X[−0.60, 11.20]（长 11.80，中心 X 5.30）；
  - `ridge_cap_e` X[12.00, 13.80]（长 1.80，中心 X 12.90）。
  - 禁一条通长脊盖横穿烟囱（= 穿插，违铁律三）。

**④ 山墙三角（两片 `profile_sweep`，薄棱柱）**：挤出厚 = 墙厚，与外墙**同轴对齐**（轴线重合）、与墙面共面：

```
path    = [[−bi, Y_ROOF_EAVE(5.40), 0], [bi, 5.40, 0]]     // 沿 X 横穿，厚度 = 2bi = 0.24
profile = [[−AZ/2(−5.40), RISE(2.935)], [0, 0], [−AZ(−10.80), 0]]   // CW 三角，顶点 = 正脊下皮
```

- **★ u 取负的来由**：`path ∥ X` ⇒ 引擎 `createPathFrame` 给 `right = −Z`（源码事实）⇒ 剖面 `u` 分量映射到 **−Z**。故三角顶点须写 `u = −AZ/2`、底边到 `u = −AZ`，世界 Z 才落在 `[0, 10.80]`（顶点 z = 5.40 居屋脊线下）。
  若照直觉写正 u（`[AZ/2, RISE] …`）⇒ 三角整个跑到 **z ∈ [−10.80, 0]**（屋外西南侧），读作"山墙飞了"。
- **必须 CW**（shoelace < 0，点序反转）——CCW ⇒ 侧面法线全内 ⇒ 读作"空心管"。
- 底边 = 檐处屋面下皮（5.40）；顶点高 = `5.40 + RISE = 正脊 8.335`；两斜边贴合两片坡屋面下皮。
- **山墙三角属薄棱柱**——绕向反转视觉无感，不得用"改绕向"治其观感缺陷（薄板反绕向不显）。
- 东面同理：`path = [[AX−bi(13.08), 5.40, 0], [AX+bi(13.32), 5.40, 0]]`，profile 同。

**⑤ 封檐板（四向一圈）**：`wall` 沿檐口线（外墙轴线矩形 ±bi）走环（南/东/北/西各一条），带厚 `BAND_T = 0.08`、顶 = `Y1 − 0.04`、底 = `Y1 − 0.20`，循**带体中心三律**（`d = (OUT−EMB)/2`，外凸 0.06、内嵌 0.02）。端点严格重合 ⇒ 引擎斜切收角。

### 4.6 门楼（双落地方柱 + 过梁 + 棚板 + 三角山花）

- **四段连续搭接（★ 柱类）**：① 柱基础底 = 台基顶（0.30）；② **柱身落于基础顶**（禁悬空）；③ 柱顶入过梁 0.04；④ 过梁上沿 == 棚板下沿。
- 参数：净宽 `POR_W = 3.00`、外挑 `POR_D = 1.70`、净挑高 `POR_CLR = 2.55`、柱截面 `POR_COL = 0.28`、过梁高 `POR_BEAM_H = 0.26`。
- 柱位：`PCX ± POR_W/2`（门楼中线 ± 1.50）。**柱立于檐口线**（禁置坡面下 ⇒ 穿透）。
- 棚板：`primitive box`，顶面约 = 门洞顶 + 过梁 + 板厚；外挑端悬空（自由）。
- **三角山花**：`profile_sweep` 挤出小三角，立面上与棚板前沿齐；属薄棱柱装饰，CW 剖面。

### 4.7 室外木平台（西侧，临空三面栏杆）

- 平台面：`floor`，`from[1]=to[1]=Y0`（台面顶 = 室内地坪顶 0.30），`thickness = 0.20`；平面 X ∈ [`TER_X = ZW_W − TER_D`, `ZW_W`]、Z ∈ [2.40, 9.60]（出挑 2.60）。
- 平台基座：`primitive box`，顶 = 台面下皮（0.10）、底 = 地基底（−0.02），材质同地基。
- **栏杆（硬性）**：临空三面（西/北/南）各一道 `railing` h 1.05，路径内缩 0.05；**贴墙一面不设**。
- 与南侧门楼台阶**错开**（平台移西侧，避门户动线冲突）。

### 4.8 烟囱（东侧独立体）

- **定高律（★）**：囱底 = 坡面下皮（`roofUnderY(z) = YRIDGE − |z − AZ/2|·tanα`）− **1.20**（埋入屋面）；囱顶 = 囱底 + `CHIM_H`（2.40）；**囱顶须高出正脊 ≥ 0.60**（示范 **+1.20**）。禁"先定囱顶再反推囱底"。
- 示范：囱心 z = `AZ/2`（屋脊线上）⇒ 坡面下皮 = 8.335 ⇒ **囱底 7.135**、**囱顶 9.535**。
- **禁居中**：`|CHIM_CX − AX/2| ≥ 1.0`（示范 囱心 X = `AX − 1.60` = 11.60，偏东 5.00）。
- 囱身 `primitive box`（0.80 × 2.40 × 0.80）+ 囱帽（`position[1] = 囱顶 + 0.06`、每边放大 0.16、厚 0.12 ⇒ 帽顶 9.655）。
- 材质：囱身同粉墙、囱帽深灰。
- **与脊盖贴接**：烟囱 X 占位 [11.20, 12.00]，脊盖在此断开为两段（§4.5③）——禁通长脊盖横穿烟囱。

### 4.9 立面开洞（门窗依附三铁律）

- **`from[0]`** = 自墙起点沿墙距离；**`from[1]`** = 洞口底**绝对标高**；**`from[2]` = 0**（法向偏移必须为 0）。
- 南向大玻璃两樘（`window`）：底 = `Y0 + 0.60`（窗台）→ 高 2.90；沿墙起止 `win_facade_w` [1.20, 5.82]、`win_facade_e` [7.62, 12.12]；**与主门各留 ≥0.30 净距**。
- 主门 `door`：中心 X = 6.60、宽 1.20、高 2.20（门洞底 = Y0）；嵌入南墙。
- 夹层窗：东/西山墙 + 北墙各一（宽 1.50 × 高 1.10，中心高按夹层窗台）。
- **同墙洞口净距 ≥0.10**、避同标高段 T 型交点 ≥0.10；**上下层按世界坐标对齐**（反向墙抄 `from` 必错位）。
- 玻璃材质分制：**大玻璃/侧窗用透明玻璃**（`glass`，transmission 0.92）——咖啡厅需室内外视线通透（与商业综合体幕墙用带色反光玻璃相反）。

### 4.10 灯（室内吊灯）

- `light` 组件 5 盏：吧台区 3 盏（沿 X 排布）+ 夹层 2 盏；依附所悬楼板/墙，`from[1]` = 世界 Y。

## 6. 屋面闭式（强制项，禁手写漂亮整数）

```
半跨   RW        = AZ/2 + 半墙厚 = 5.40 + 0.12 = 5.52
脊高   RISE      = RW · tan28° = 2.935
正脊   YRIDGE    = Y1 + RISE   = 8.335
檐下皮 Y_ROOF_EAVE = Y1        = 5.40        （★ 屋面坐实墙顶：z=∓bi 处下皮 == Y1）
檐外皮 Y_EAVE_OUT  = Y1 − 0.48·tan28° = 5.145
斜板投影 ROOF_SLOPE_D = RW + 0.48 = 6.00
斜板斜长 ROOF_SLOPE_L = ROOF_SLOPE_D / cos28° = 6.795
斜板 rotation α     = 28° = 0.489 rad（南坡 [−α,0,0] / 北坡 [+α,0,0]）
X 区间  ROOF_X0 = −0.60 ，ROOF_X1 = 13.80
Z 区间  ROOF_Z0 = −0.60 ，ROOF_Z1 = 11.40    （= 外墙轴线 ∓ 半厚 ∓ 出檐）
山墙三角 profile u = [−AZ/2, 0, −AZ]（★ 取负：path∥X ⇒ right=−Z）
脊盖段 ridge_cap_w X[−0.60, 11.20] / ridge_cap_e X[12.00, 13.80]（避烟囱，严格贴接）
```

**屋面构造闭环断言**：`YRIDGE == Y1 + RISE`（1e-6）；`RISE == RW·tanα`（2e-3）；斜板下皮在 `z=∓bi` 处 `== Y1`（屋面未坐实墙顶即报错）；斜板坡度 `== tanα`（从下皮两端点实测，2e-3）；山墙三角底边 == 檐下皮、顶点 == 正脊（2e-3）；脊盖两段与烟囱外皮公差 `== 0`（贴接）。

## 10. 常见错误速查（咖啡厅）

| 症状 | 根因 | 处方 |
|---|---|---|
| **屋面读作"斜细杆"（从脊到檐支了根棍）** | 屋面写成 `profile_sweep`（小截面沿斜 path 扫掠 ⇒ 扫出一根杆，非平面） | 屋面改**双坡两斜板法**：`primitive box` + `rotation=[±α,0,0]`、dim=[depth, 板厚, 斜长]（§4.5①） |
| **屋面板整片不可见** | 用 `profile_sweep` 造大块实体板（渲染器兼容问题） | 大面结构一律走原生 `box`/`roof`，禁 `profile_sweep`（§4.5 引言） |
| **两坡成"凹口朝上"的 V** | 斜板 `rotation` 符号写反 | 南坡（−Z）`[−α,0,0]`、北坡（+Z）`[+α,0,0]`（§4.5①） |
| **脊线处露一道 V 缝** | 缺脊盖（两斜板上皮间凹口未封） | 加 `ridge_cap` box 压顶；**遇烟囱断为两段**（§4.5③） |
| **脊盖横穿烟囱** | 一条通长脊盖未避烟囱 | 分 `ridge_cap_w`/`ridge_cap_e` 两段，端面严格贴接囱外皮（§4.5③/§4.8） |
| **山墙三角跑到屋外（西南侧）** | `profile` 的 u 照直觉写正（`path∥X ⇒ right=−Z`，u 映射到 −Z） | 三角 u **取负**：`[[−AZ/2,RISE],[0,0],[−AZ,0]]`（§4.5④） |
| **山墙三角读作"空心管"** | `profile` 写成 CCW（要求 CW，shoelace < 0） | 点序反转（薄棱柱反绕向视觉无感，别指望改绕向治缺陷）（§4.5④） |
| 夹层墙顶穿出屋面 | 首层/夹层拆成两道墙，低者墙顶 < 檐口 | 合并为**同一道通高墙环**（Y0→Y1），夹层仅作内嵌悬挑板（§3/§4.2） |
| 屋面某片悬空 | 多片屋面统一写同一标高，未逐片坐实墙顶 | 檐下皮逐片由墙环顶 `Y1` 派生；断言斜板下皮在 `z=∓bi` 处 `== Y1`（§4.5②/§6） |
| 楼梯被堵死 | 夹层板四瓦片划分有重叠覆盖洞口 | 四瓦片凹凸互补、洞口区无板；断言面积守恒（§4.3） |
| 楼梯浮点尾数 | 梯跑 from/to 未过 `R()` | 所有坐标字段逐项 `R()`（3 位）（§4.4） |
| 烟囱居中/过矮 | 囱心居中 或 囱顶未高出正脊 0.60 | `|cx−AX/2| ≥ 1.0`；囱顶 = 正脊 + ≥0.60（§4.8） |
| 南向玻璃与门打架 | 大玻璃未给主门留净距 | 玻璃分两樘，各与主门留 ≥0.30（§4.9） |
| 木平台压住台阶 | 平台未与门户动线错开 | 平台移**西侧**、入户台阶留南侧（§4.7） |
| 勒脚凸出方向反 | 带体中心偏墙皮误写 `OUT` | 中心偏 `d = (OUT−EMB)/2`，校验 `d+t/2==OUT`（§4.1） |
| 大玻璃看不见室内 | 用了带色反光玻璃 | 咖啡厅大玻璃须**透明**（transmission 0.92）（§4.9） |
| 引擎打不开 | 结构位出现全角标点 | 生成器写盘前断言；跑 `check_wild_integrity.cjs`（§7） |

**风格签名（判"Forest 型"第一标准）**：① **三级体量沿对角线逐级后退**（南低北高 + 东低西高）；② **平屋顶即露台**（`floor` 板顶 = 墙顶、板边 = 内皮）；③ **整面黑细框玻璃幕**（南/东向）；④ **西侧通高白墙招牌塔 + 竖长窗**；⑤ **北侧外挂折返楼梯**逐级连通三级露台。五条缺一即读作"普通方盒子"。

### 12.2 形制决策链

1. **定退台谱**：先定三级体量的平面收缩 —— T1 满轴网 10.8×9.0；T2 缩至 X[2.40, 8.40] × Z[2.40, 9.0]；T3 亭缩至 X[2.40, 7.20] × Z[4.20, 9.0]。**每级西界 = 塔东墙轴线 2.40 不变**（塔通高贯通三级）。
2. **定剖面**：层高 3.90 / 3.00 / 2.80；露台1 面 = T1 墙顶 = **4.20**；露台2 面 = T2 墙顶 = **7.20**；亭顶板面 = T3 墙顶 = **10.00**；塔顶板面 = **8.40**（塔在露台2 之上收头，与亭顶错落）。
3. **定屋面**：**不设坡屋面**。每级顶板 = `floor` 元素，`from[1] = to[1] = 该级墙顶`，`thickness = 0.20`（板身向下）⇒ 板顶即露台面、板边自动贴宿主墙内皮。露台面材质 `floor_terrace`（防腐木/户外饰面），亭顶/塔顶材质 `roof_dark`（收头封板）。
4. **定外挂楼梯**：北侧三跑折返 —— 跑1 沿 −X（地面 → 2.10）、平台1、跑2 沿 +X（2.10 → 4.20）、平台2、跑3 沿 −X（4.20 → 7.20）；**恒等式 `stepHeight × stepCount = 升高`**（0.15×14=2.10、0.15×14=2.10、0.15×20=3.00）。跑3 为**纯悬挑梯段**（无落地支撑构件，见 §12.4④）。
5. **定栏板**：露台临空边（未被更高体块围护者）设白色矮墙 h0.90；**邻接更高体块的边不设栏**（被高墙围护）。
6. **定立面**：南/东向整面玻璃（黑细框）；塔南/西/北各一竖长窗；亭两樘对开玻璃窗。
7. **定收头**：顶部玻璃亭（T3）+ 座于亭顶板面的木格栅凉棚（4 柱 2 梁 7 条）+ 露台种植池。

**① 露台板（L 形两片拼装）**：每级露台由「南条 + 东条」两片 `floor` 拼成 L 形（凹凸互补）：

| `deck_r1_s` | 塔内皮 2.28 → 东内皮 10.68 | 南内皮 0.12 → T2 南内皮 2.52 | `floor_terrace` |
| `deck_r1_e` | T2 东内皮 8.28 → 东内皮 10.68 | T2 南内皮 2.52 → 北内皮 8.88 | `floor_terrace` |
| `deck_r2_s` | 塔内皮 2.28 → T2 东内皮 8.28 | T2 南内皮 2.52 → T3 南内皮 4.32 | `floor_terrace` |
| `deck_r2_e` | T3 东内皮 7.08 → T2 东内皮 8.28 | T3 南内皮 4.32 → 北内皮 8.88 | `floor_terrace` |
| `roof_t3` | 亭西内皮 2.52 → 亭东内皮 7.08 | 亭南内皮 4.32 → 北内皮 8.88 | `roof_dark` |
| `roof_tower` | 西内皮 0.12 → 塔东内皮 2.28 | 南内皮 0.12 → 北内皮 8.88 | `roof_dark` |

- **转角交叠口径**：L 形两片在同一露台面转角处**天然交叠一个转角单元**（X × Z = 2.60/1.40 × 0.20）—— 这是**同一块楼板的内部拼缝**，属合法贴接（非构件穿插）。故校验器**允许**该交叠，但要求「板顶严格同高 + 交叠区尺寸 == 转角单元」。**禁把两片写成互相覆盖大半（真穿插）**。

**② 退台墙（端点严格重合 ⇒ 引擎斜接）**：塔墙四道（南/东/西/北西段）通高 `Y0 → TW`；T1 三道（南/东/北东段）`Y0 → Y1`；T2 三道 `Y1 → Y2`；T3 四道 `Y2 → Y3`（西墙为塔东墙上延段 `TW → Y3`，沿同一母线拼合豁免）。**★ 塔墙 T 接 = 满长—内缩配对**：塔东墙 `X=2.40` 为**通长件**（满长）；T2/T3 横墙西端取 **2.52（= 2.40 + 半墙厚，塔东墙外皮）**——横墙端面与塔东墙外皮贴接，转角半步缺口由引擎 `resolveWallJoints` 自动斜接补齐，视觉无缝隙无凸出。
- 塔墙顶（`TW`）与 T3 墙顶（`Y3`）**错落 1.60**（塔在露台2 之上收头），是读图"错落天际线"的来源，**禁拉平**。

**③ 露台栏板（白色矮墙）**：`wall` 元素，`from[1] = 所坐露台面`、`to[1] = 面 + 0.90`、`thickness = 0.12`、同轴（端点严格重合）：`par_r1_s/e/n`、`par_r2_s/e/n`。**邻接更高体块的边不设栏**（如露台1 西缘贴塔、南缘中段贴 T2 ⇒ 只在外露段设栏）。栏板顶须低于上级体块墙顶（露台1 栏顶 5.10 < `Y2` 7.20）。

**④ 外挂折返楼梯（三跑 + 两平台）**：`stair` 元素四参 `width/stepCount/stepDepth/stepHeight` + `from/to`；**恒等式** 0.15×14=2.10、0.15×14=2.10、0.15×20=3.00。折返律：跑1 沿 −X、跑2 沿 +X、跑3 沿 −X；两平台（`landing_1` 顶 2.10、`landing_2` 顶 4.20）与相邻跑端齐平。**顶桥 `bridge_r2`**（顶 = 露台2 面 7.20）北接跑3 顶、南接 T2 北墙顶带。**★ 跑3 为纯悬挑梯段 ⇒ 禁设落地支撑柱**：跑3 两端分别搭在平台2 与顶桥 `bridge_r2` 上，自身即为简支梯段，**不得在其下方立"落地细高杆"**（曾误加 `col_s3_a/b`——0.12 截面、高 5.13/6.20、柱底落地面，在屋面上读作两根无由细杆，属"屋顶奇怪构件"，已删）。**所有 from/to 逐项过 `R()`**。
- **★ 必配护栏**（硬性语义规则）：平台临空边 + 顶桥北缘设 `railing` h1.05；斜跑栏杆为已知简化（见 §12.8）。

**⑤ 顶部玻璃亭 + 木格栅凉棚**：亭 = T3 墙环（四道 `wall` `Y2 → Y3`）+ 亭顶板 `roof_t3`；**凉棚坐亭顶板面** —— 4 柱（`pg_col_*`，柱底 = `Y3` 亭顶面、高 0.60、截面 0.12）+ 2 梁（`pg_beam_*`，梁底 = `Y3 + 0.60`，截面 0.12，**两梁分居亭东西（梁 x = 柱 x）、沿 Z 长 = 亭进深 −0.30**）+ 7 格栅条（`pg_slat_*`）。
- **★ 格栅条跨 X 坐两梁上、沿 Z 排布**（2026-10-11 定案）：条**沿 X 长 == 两梁轴距 + 两端各出梁半径 0.06**（≈ 亭净宽 −0.1）、**条 x 中心 == 两梁 x 中点**；条**沿 Z 等距排布于两柱 z 之间**（间距 = (柱距 − 条厚)/(N−1)），条 z 跨 = 条厚 0.12。
  **★ 禁「沿 X 排布 + 沿 X 跨」**：那会把条甩出亭体——曾致 7 条格栅 X 范围 [0.20, 9.40]（第 1 条压到西塔、第 7 条伸到东侧 T2 屋面上空），**远超 T3 墙投影边界**（用户报"最顶层屋顶超出墙体投影"）。修法 = 条**沿 Z 排布**、**跨 X 坐两梁**。
  **★ 最顶层越界总判据**：亭顶板面（`Y3`）以上所有 `primitive` 的 X/Z 范围须 **∈ T3 亭墙外皮投影** `[T3X0−bi, T3X1+bi] × [T3Z0−bi, AZ+bi]`（生成器断言⑤a + 校验器 J2 双通道）。

**⑥ 立面孔洞（依附三铁律）**：`from[0]` = 自墙起点沿墙距离、`from[1]` = 洞口底**绝对标高**、`from[2] = 0`。**★ 洞口不越父墙竖界**：`from[1] ≥ 墙底`、`from[1] + height ≤ 墙顶`（留 ≥0.15 过梁余量）——T3 亭墙高 2.80 ⇒ 亭窗底 `Y2+0.40`、高 2.00 ⇒ 顶 9.60 ≤ 10.00（**禁写 2.40 高**，会顶破 10.00）。同墙洞口净距 ≥0.10；塔竖窗底 `Y0+1.20`、高 5.60 ⇒ 顶 7.10 ≤ 塔顶 8.40。

### 13.5 四坡屋顶闭式（变体三强制项）

```
檐口  Y2 = Y0 + H1 + H2 = 0.45 + 3.60 + 3.30 = 7.35
正脊  Y2 + RH = 7.35 + 2.40 = 9.75
屋面  span  = L2X1 + 2×EAVE = 10.20 + 1.20 = 11.40
      depth = (AZ − CZ) + 2×EAVE = 7.20 + 1.20 = 8.40
      脊长 = span − depth = 3.00（∥X）
      position = [L2X1/2, Y2, (CZ + AZ)/2] = [5.10, 7.35, 8.40]
坡角  atan(RH / (depth/2)) = atan(2.40 / 4.20) ≈ 29.7°
```

**四坡构造闭环断言**：`Y2 == Y0 + H1 + H2`；`roof.position[1] == Y2`；`roof.height == RH`；`roof.span > roof.depth`（脊 ∥X）；`脊顶 == Y2 + RH`；`ridge_cap 长 == span − depth`（1e-9）。

### 15.5 高台观景闭式（变体五强制项）

```
台基高   YP = 8 × 0.15 = 1.20
层高     H = Y1 − Y0 = Y2 − Y1 = 3.60（恒定）
2F 南退  = B2Z0 − 0 = 3.00
南向观景平台 = 1F ∖ 2F 在 Y1 的外露段 = X[bi, AX−bi] × Z[bi, B2Z0−bi]
观景平台面标高：地面层 = YP；二层 = Y1
玻璃护栏高 = 1.05（两平台一致）；与建筑墙相接处 == 墙外皮
贯通：台基顶 == 首层地坪顶 == 首层墙底 == 地面观景平台面（四点，四点同标高 1e-9）
楼梯：stepHeight × stepCount == YP（8 × 0.15 = 1.20）
```

**高台观景构造闭环断言**：`YP == 8×0.15`；`Y1−Y0 == Y2−Y1 == 3.60`；`B2Z0 == 3.00`；平台板顶 == 所坐墙顶（1e-9）；`deck2_s + slab2 + 2F 南墙脚 == 1F 屋面`（1e-6）；楼梯恒等式（1e-6）；玻璃护栏与墙相接处 == 墙外皮（0.12 / `B2Z0−bi`）。

### 15.8 假设与简化清单（变体五）

### 15.10 常见错误速查（变体五）

| 症状 | 根因 | 处方 |
|---|---|---|
| **台基写成薄地坪板 / 台基顶与首层墙底不符** | 只写 0.2 厚地坪板，未写实心台基 | 台基 = 实心 `primitive box`，**顶 = 首层墙底 = 观景平台面（三合一）**（§15.3） |
