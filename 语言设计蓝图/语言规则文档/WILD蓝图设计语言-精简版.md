# WILD 蓝图设计语言 · 精简版（字段字典）

> 摘自《WILD蓝图设计语言》v1.2，只保留各建筑类型通用的字段规格与硬规则；完整论证与各类型实例见 v1.2 原文及类型规则文档。
> 生成顺序 = 章节顺序：① 场地/坐标 → ② 骨架元素 → ③ 装饰组件 → ④ 材质 → 自检。

## 0. 文件骨架与四铁律

```json
{
  "meta": { "version": "1.1", "type": "building", "name": "建筑名", "style": "modern", "author": "书写者" },
  "geometry": { "elements": [], "components": [] },
  "materials": {}, "behaviors": {}, "editor": { "revision": 1 }
}
```

- 严格 JSON：无注释、无尾逗号；元素 id 全局唯一、禁 `__` 前缀；每次修改 revision +1。
- ★ **铁律零（图片参考任务）**：由参考图片生成蓝图必经三步——**读图提取可判定形制要素（含正脊走向）→ 检索该类型《书写规则》+ 本设计语言配方 → 按设计语言书写**；不可判定项标注或问询；禁跳步、禁凭直觉、禁违引擎硬语义去还原观感；改缺陷只改缺陷、根因回写文档。
- ★ **铁律二（联动修改律）**：改蓝图**任一构件**，必**先列牵连清单**（①被依附侧 / ②派生尺寸侧 / ③同拷贝侧）再动手；依附量一律**由宿主几何与公式重解**（门窗 `from` / 老虎窗 `DZB` / 屋面 `surf(x,z)` / 楼梯步数 / 附件斜板长与旋转角），**禁照抄旧值**；改后重跑三关并**回读盘实测值**比对。完整条文见 v2.0 §0.3。
- ★ **铁律三（组合关系律：贴接不穿插）**：任意两实体（构件 / 组件 / **组件内部构件**）只允许**分离**或**贴接**，**禁体积重叠（= BIM 硬碰撞）**；接触面严格共面、0 缝 0 凸（附 v2.0 §1.4⑩）；唯一例外=异材质为防闪面留**不可见**插入量（柱身入柱头 0.04），**可见外沿必须齐平**。发现穿插**优先整体移动 / 加长 / 加高**使其变"贴接"（如屋面由"上皮贴墙"改"下皮贴墙"⇒抬升 `WVT=t/cosθ`），**禁削角**。**★ 转角完整性「三层总律」**：**一切转角必完整、零缺口、外侧 90° 阳角**——① 构件级（`wall` 端点重合·引擎斜接；`roof`/`floor` 面板不斜接 ⇒ 护板改写 4 段 `wall` 环）② 组件级（组件与宿主/邻组件转角**共用世界点 + 转角柱**；`path` 折点有立杆）③ 组件内部构件级（组件展开出的子几何**不被引擎斜接** ⇒ 同轴折线折点由立杆覆盖、十字/丁字一者通长一者内缩至对方外皮）。典型：放大加檐后**墙顶戳出坡屋面**；**正交墙端点未重合 ⇒ 墙角"消失"**。完整条文见 v2.0 §0.4。
- 三铁律：①每个数字可推导（轴网→层高→墙长→定位），禁止拍数；②引擎硬语义高于建筑直觉；③骨架产几何（elements）、组件产洞口（components），不重复。
- 元素（独立写全几何）：floor / wall / column / beam / stair / roof / primitive / furniture。组件（依附宿主）：door / window / balcony / canopy / railing / ramp / bay_window / cornice / chimney / light。
- 元件数 >300 禁手写 JSON，须参数化脚本生成（参数表单一事实来源 + R() 取整 ≤3 位 + 出厂自检：结构位禁全角标点、禁超 3 位小数）；体积红线 ≤100KB 紧凑 JSON。

## 1. 坐标 · 标高 · 模数

- 单位米；右手系；北=+Z、东=+X；原点=建筑西南角外墙角点；主立面朝南。
- ±0.000 = 首层地坪顶（小台基 ≤0.9）；**台基总高 >0.9 及住宅类：±0.000 = 室外地面**，一切实体最低点 ≥ −0.3（渲染地面 y=0）。住宅类首层室内地坪顶 = +0.45，并须写整块实心地基（顶 +0.45、底 −0.02、四面出挑 0.06）。
- 模数 M=0.3 / 半模 0.15：开间 2.4–6.0、层高 3.0/3.3/3.6（大厅 4.2/4.8）、门洞 0.9×2.1 / 1.2×2.1、窗台 0.9、台阶高 0.15 深 0.3、栏杆 1.05、女儿墙 0.90–1.20、出檐 0.3/0.6/0.9。构造厚度例外：外墙 0.24 / 内墙 0.12 / 楼板 0.20 / 平台 0.15 / 框 0.09。
- 标高谱：**地坪仅一层**（轮廓=一层外轮廓）；层间楼板（N 层共 N−1 组，轮廓=**下层**外轮廓，下层屋顶楼板≡上层地板只写一次）；顶层顶板由 roof 承担不写 floor。板 id：`ground` / `slab_l<n>[_方位]` / `landing_*`。
- 缩尺建筑（≥100m 塔类）：k=1:50，坐标=真实×k，meta.scale 声明 + 回算自检，细小构件按最小可读 0.02m 放大并声明。

## 2. 骨架元素字段（全部必读）

### 2.1 `floor` 水平板
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id | 是 | `"floor"` / 唯一 id |
| from / to | 是 | 矩形对角两端；**Y = 板顶标高**（两者相等，板向下延伸 thickness） |
| thickness | 是 | 地坪/楼板 0.20，平台 0.15 |
| material | 否 | |
| shape / radius | 否 | `"circle"` 圆板用 radius |

### 2.2 `wall` 墙体
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id | 是 | `"wall"` / 唯一 id |
| from / to | 是 | 轴线两端；Y = 墙底 / 墙顶标高 |
| thickness | 是 | 外墙 0.24 / 内墙 0.12 |
| material | 否 | 全楼外墙统一一种材质 |
| curve | 否 | arc / ellipse / catenary，可数组多段 |

- 转角闭环：**端点重合 · 引擎斜接**——四墙端点严格重合于**轴线矩形四角**（如 `[0,0]→[AX,0]→[AX,AY]→[0,AY]→[0,0]`），引擎各向外延对方半厚 ⇒ 外角 90° 阳角。**禁手工"满长—内缩"坐标**（超 0.01 容差 ⇒ 配不上 ⇒ 缺口；且会与引擎外延双重叠加）。
- 墙是洞口宿主；墙起点移动 → 依附组件 from[0] 同步平移。

### 2.3 `column` 柱
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id / base / height | 是 | base = 柱底中心 |
| bottomRadius / topRadius | 是 | 收分用此表达 |
| style | 是 | modern / chinese_wooden / doric / ionic / corinthian（引擎统一渲染截锥体，style 为声明） |
| material | 否 | |

现代柱：≤1000㎡ r0.15，否则 0.20；中式木柱 r≈开间/15–/12（0.15–0.25）；欧式柱径 h/6、h/8、h/10。矩形柱用 primitive box。柱头/柱础等细节用 primitive 叠加。

### 2.4 `beam` 梁
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id / from / to | 是 | from/to = 梁**底**起止 |
| crossSection | 是 | rect / circular / i-beam |
| width / height | 是 | 截面宽/高（圆=直径） |

梁顶与墙顶齐平（from.y = 墙顶 − height）。现代 0.2–0.25×0.3–0.4；额枋 0.18–0.25×0.25–0.4。

### 2.5 `stair` 楼梯
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id / from / to | 是 | from=起步（Y=起步标高）；to=水平到达点 |
| width | 是 | 住宅 1.0–1.2 |
| stepCount / stepDepth / stepHeight | 是 | 三者**必须显式写全**且 stepHeight×stepCount = 目标高差；步深 0.24–0.28、步高 0.15–0.18 |

末步边缘距 to 少一个 stepDepth。双跑 = 两段 stair + 半层平台 + 楼板拆洞。

### 2.6 `roof` 屋顶
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id / roofType | 是 | roofType 六选一（下表） |
| span / depth / height / thickness | 是 | 覆盖总宽 / 覆盖进深（含出檐）/ 屋顶垂直高 / 板厚 |
| position | 是 | **檐口平面中心，必须显式**（漏写=扩张到全楼） |

| roofType | 形制 | 要点 |
|---|---|---|
| flat | 平屋顶 | height ≈0.3 |
| gable | 双坡（硬山/悬山） | 封闭棱柱；硬山 span=墙外皮宽，悬山 +两端各出挑 0.3–0.6；屋脊沿 depth 于 span 中线，屋脊标高=position[1]+height |
| hip | 四坡/庑殿/方攒尖 | 交于顶点无正脊；庑殿正脊用 box 贴顶点补 |
| dome | 西式穹顶 | 仅西式；中式攒尖禁用 |
| chinese_curved | 中式曲面 | 引擎回落为 gable，慎用 |
| chinese_pagoda | 中式重檐 | 加 tiers / tierHeight / eaveOutset / shrinkFactor / baseSpan / baseDepth |

双坡需真实坡面观感 → **两斜板法**：两块斜置 box（dimensions=[斜板长,板厚,depth]，rotation=[0,0,±α]）+ 脊盖 box + 山墙三角实体（**统一 `primitive/profile_sweep` 三棱柱**，见下）。**★ 斜板须越过墙外皮出檐 EOH**（斜板长 = √(HW²+高²) + EOH/cosα）——屋面只到**墙轴**= 贴墙 ⇒ 读作"小帽子"、屋顶显小；**依附大屋面的小屋面（老虎窗 / 门楼 / 披檐）同样须出檐，但其出檐应 < 主屋顶出檐**（主 0.7–1.0、小屋面 0.15–0.25）；**★ 加檐 ⇒ 屋面外缘外伸 ⇒ 须重解受约束余量**（如落在坡上的老虎窗与 **45° 戗脊余量 ≥0.30**），此时不能只加檐，须**一并重解宿主位置**（老虎窗 `x`/`z`）以求回余量（详见 v2.0 §3.6 两斜板法步骤 3）。

山墙三角实体 **统一 `primitive` + `shape:"profile_sweep"` 三棱柱（rev8 定案，废止 rev6/rev7 的 `roof/gable`）**。★★ **语义定性（用户 2026-09-23 原话）**：**三角形墙体 = `wall` 类墙体**（普通墙的三角形态，不是 roof）——只作用于**双坡屋顶**建筑的、**垂直于屋脊线**的两侧端墙；**墙厚 = 屋顶下普通矩形墙体的厚度**；**下沿与下部普通墙对齐**（同轴线、同厚度，|Δ|<0.06）；**上沿刚好与双坡屋顶斜面相接**（`H` 严格 = 屋面高）。用 `primitive` 类型表达纯属引擎能力所限（`wall` 无三角上延实现），**定位须按"端墙延伸段"而非"屋顶构件"**。
★★★ **为什么必须弃用 `roof/gable`（rev8 源码级根因，推翻 rev4–rev7 全部结论）**：`resolver.ts → resolveRoofBoundary()` 对**每一件** `type:"roof"` **无条件**注入 `_gableEnds` —— 判据 `|dx| > |dz|` 挑「**全院墙顶最高的那批沿 X 走向的墙**」，**与"这件 roof 属于哪栋建筑"完全无关**；`buildGableRoof()` 再逐件补三角面。⇒ 12 件 `roof/gable` 山墙**全部被 6 件幽灵端墙劫持**，生成**横跨整院、垂直贯穿沿途每道墙**的三角面（用户报告：「三角形墙体与下部普通墙体垂直交叉」）。**三重致命缺陷**：①归属错 ②位置错（补在 `z=常数` 平面）③垂直交叉。**类型选错 ≠ 参数写错；调 `span`/`rotation` 永远无效。**
**★ 核心不变量：山墙三角面法线 == 屋面屋脊向 == 承载端墙走向轴。**（由 `path` 走向自动保证，无需 `rotation`）
| 屋脊向 | 端墙走向 | 面法线 | **`path`（世界坐标，以端墙轴 ±th/2 对称）** | `profile` | 典型建筑 |
|---|---|---|---|---|---|
| ∥X | 沿 Z | **X** | `[[x_end−th/2, y_base, z_mid], [x_end+th/2, y_base, z_mid]]` | `[[−u,0],[u,0],[0,H]]` | 正房/大门/倒座/垂花门/照壁 |
| ∥Z | 沿 X | **Z** | `[[x_mid, y_base, z_end−th/2], [x_mid, y_base, z_end+th/2]]` | `[[−u,0],[u,0],[0,H]]` | 东西厢房/游廊 |

统一字段（`primitive` + `shape:"profile_sweep"`）：`path` = **沿墙厚方向两点、以端墙轴为中心 ±th/2 对称、世界坐标**；`profile` = 三角形 `[[−u,0],[u,0],[0,H]]`；`u` = **坡度向全跨/2 − 0.02**；`H` = **严格 = 屋面高**；`y_base` = **屋面檐口标高**；`th` = **下部端墙墙厚**；`closedProfile` = `true`（三角扇封端 = 封闭实体）；**禁写 `position`**（二次偏移 → 飞出）、**禁写 `rotation`**（三角面天然 ⊥ 墙厚方向 ⇒ 零旋转、彻底避开 Euler 序陷阱）。
  ⚠️ **与 §2.7 剖面绕向的关系**：上表三角为 **CCW**，其**三条窄侧面**法线内向；但山墙**可见大面是两端三角封盖（端盖）**、引擎已**自动补偿为外向** ⇒ **视觉正确、不会空心**（这就是"颊墙空心而山墙正常"的原因）。**严格合规写法 = CW**：`[[−u,0],[0,H],[u,0]]`（同三角、绕向翻转），可见大面完全相同。
★ **为什么永久弃用 `wall`+`gableTop`**：该三键是 `wild-web` 私有扩展，**分发版引擎（wild-core）的 `wall.ts` 完全未实现** → 三键被**静默忽略**、`buildWall` 只按 `height` 造**矩形墙** ⇒ 山墙读作矩形并高出坡顶（四合院 rev2/rev3 两轮用户报告）。
**★ 相切判据（用户验收标准）**：`H == 屋面高` 且 `u ≈ roofHalf − 0.02` ⇒ 三角斜边 `H·(1−|u|/u)` 与屋面斜边 `roofH·(1−|u|/roofHalf)` 重合（9 点采样 max 偏差 ≤ 0.05）。⚠️ **绝不竖向沉降**防闪面（rev3 曾用 `height−0.04` → 整体下沉、檐口处撕缝、不再相切）；**唯一正确防闪手段 = 水平内缩 0.02**（斜边只产生 0.02 的平行偏移）。
**★ 下沿对齐判据**：`path` **以端墙轴为中心 ±th/2 对称**，`y_base` == 下部墙墙顶（|Δ| ≤ 0.02）；沿墙厚方向两条边与下部墙墙面**同面**，**不得垂直交叉**。
★ **rev5「永久禁用 `profile_sweep` 写山墙」已被 rev8 平反**：引擎 `buildProfileSweep`（`closedProfile` 三角扇封端）与 `buildRoof`（透传 rotation）**均已修复**；`roof/gable` 的幽灵端墙**无法在书写层规避**。
生成器断言十三条（rev8）：①**形态恒为 `primitive/profile_sweep`**；②**全蓝图无 `roof/gable`**；③**无 `position`、无 `rotation`**；④`closedProfile === true`；⑤**`face_ax == roof.ridge`**；⑥`base_ax == roof.base`；⑦`2u == roof.span − 2×GABLE_INSET`；⑧`H == 屋面高`（±0.01）；⑨底面标高 = 檐口标高；⑩`path` 长度 > 0.05；⑪**端墙轴线重合 |Δ|<0.06**；⑫逐点斜边比对 ≤0.05；⑬两件分居两端、对称。禁止静默产出。

### 2.7 `primitive` 附属形体（女儿墙/台阶/台基/脊饰/异形）
| 字段 | 必需 | 说明 |
|---|---|---|
| type / id / shape | 是 | shape ∈ box / sphere / cylinder / profile_sweep |
| position | 是 | **几何中心**（cylinder 按底面圆心写会半截插地）；**profile_sweep 禁写 position/rotation** |
| dimensions | box | [宽,高,深] |
| radius（sphere）/ radiusTop+radiusBottom+height（cylinder） | 对应形状 | cylinder 可加 segments（缺省 32，圆台/檐盘 64） |
| rotation | 否 | **弧度**（全库唯一） |

profile_sweep 参数：path（世界坐标点列）+ profile（[x,y][] 截面）或 radius + segments。斜置杆件首选 profile_sweep 世界路径；回退 cylinder 两角写法 `rotation=[atan2(dz,dy), 0, −asin(dx)]`（禁 `[φ,ψ,0]`——Euler XYZ 下 ψ 对 +Y 轴形体失效）。

> ★★ **profile_sweep 剖面绕向铁律（引擎硬事实）**：侧面法线 = `cross(路径切向, 剖面边)`，端盖由引擎按 `ccw` 自动补偿、**侧面不补偿** ⇒ 绕向写成 CCW ⇒ 侧面法线**全内向** ⇒ **渲染成空心管**（墙/环带等大侧面构件整片消失）。**剖面必须 CW（`shoelace < 0`），与 `path` 走向无关**；**修法 = `profile` 点序反转**。自检 `node 蓝图生成器/check_profile_winding.cjs <file.wild>`。

- **女儿墙 = 墙**：type:"wall"，坐本层墙顶，高 0.90–1.20、厚=墙厚、端点与墙面齐平、只布最外一圈。
- 台阶：box 逐级（高 0.15/深 0.3），大体积室外台阶实体直砌。**★ 朝向铁律**：台阶消化「建筑标高 > 室外地面」的高差 ⇒ **末级（最高）踏面紧贴建筑墙、标高 = 室内地坪顶（门洞底）**，**向远离建筑方向逐级下降**至室外地面（`n×步高 = 室内外高差`）；**反例** = 最高一级在远端 ⇒ 台阶"砌反"、与门洞悬空。
- 平接环件角部：一对通长（长含 2×半厚）、正交一对缩进至对方内侧面（缩进=半厚）；斜置坡板角部用 cylinder segments=4 四棱台锥坡（rotation=[0,π/4,0]，半径=半边×√2）。
- 排序原则：缺口 > 交叉 > 共面。异材质共面错开 ≥0.01 或嵌入 ≥0.03。

### 2.8 `furniture` / `opening`
- furniture：subtype（table/chair/bookshelf/bed/lamp/tile）+ position + dimensions{width,depth,height}。
- opening（引擎原生元素，写在 elements）：字段 parentWall + from + width/height + style（rectangular/arched/gothic/circular）+ material（深色衬板）。**from 语义与组件相反**：`from[0]`=洞心沿墙距（S/N 墙=B/2、E/W 墙=(B−t)/2）、`from[1]`=墙底相对高度（分发版）；wild-web 则 from[0]=左边缘、from[1]=世界标高——写前确认目标引擎。
- 引擎墙体开洞只切矩形通孔；拱形 = 洞切到拱顶（高=净高+洞宽/2）+ 拱肩回填 / 相切拱圈 12 段（拱缘外露处禁阶梯近似）。
- `dense_brick` / `body` 与建筑蓝图无关，禁止使用。

## 3. 装饰组件字段

**通用**：`from = [沿墙距离, 世界Y, 法向偏移]`——沿墙距离 = **洞口左边缘**到墙起点；世界Y：门=本层地面标高、窗=地面+0.9（落地玻璃 0.15–0.3）。width/height = 洞口总尺寸（含框）。组件自动生成框扇玻璃栏杆，**之外禁止补任何几何**。

### 3.1 `door`
parentWall+from（必）、width/height（必，主入口 1.2×2.2 / 内门 0.9×2.1）、frameWidth（显式 0.09）、frameDepth（外门 0.16/内门 0.06）、doorStyle（single/double）、openingStyle（rectangular/arched）、frameMaterial/leafMaterial。

### 3.2 `window`
parentWall+from（必）、width/height（必，标准 1.5×1.5 / 1.8×1.5，大玻璃 3.6–4.0×2.7）、frameWidth（显式 0.09）、frameDepth（0.16）、verticalMullions/horizontalMullions（直棂窗竖 3–5）、frameMaterial/glassMaterial。

### 3.3 其他组件
| 组件 | 必需字段 | 要点 |
|---|---|---|
| balcony | parentWall+from+width+depth+slabThickness | 常用 3.6×1.5；railingHeight 1.1、postSpacing 0.9 |
| canopy | parentWall+from+width+depth+thickness | 宽≈门洞+0.8，棚底高 2.4–2.6，supportCount |
| railing | path（世界坐标折线）+ height | 高 1.05；railLevels/postSpacing；预览编译器不支持，需预览用 primitive box 替代 |
| ramp | from/to+width+thickness | 坡度 ≤1:12；railingSides（both/left/right/none，**左右随路径方向翻转**，路径高→低时 left=外侧） |
| bay_window | 同窗 + projectionDepth | 凸出 0.4–0.6 |
| cornice | parentRoof+path+profile（≥3 截面点） | |
| chimney | parentRoof+position+width/depth/height/wallThickness | 穿出屋面 ≥0.6 |
| light | position+lightType+color/distance/intensity | |

## 4. 材质

每项五件套必填：`baseColor / roughness / metallic / albedo / lightingCondition("D65_noon")`；materials 只放被引用材质；材质 id 与元素 id 是两个命名空间。可见材质 ≤4–6 种；大面积石作降亮度（baseColor≈[0.70,0.69,0.66]、roughness ≥0.9）。

**玻璃分两种，严禁混用**（缺 materialClass 四件会渲染成不透明色块）：

| 材质 | 用途 | 关键参数 |
|---|---|---|
| `glass` 普通窗玻璃 | 家窗、门扇、落地窗 | transmission 0.92、ior 1.5、thickness 0.012、side double |
| `glass_curtain` 幕墙玻璃 | 玻璃幕墙、幕墙球 | **transmission 0**、baseColor 带色、roughness 0.03、metallic 0.70、clearcoat 1 |

- 住宅窗必须透明 glass；幕墙/球幕必须 glass_curtain（室外看不到内部），写成透明玻璃 = 内部构件全外露。
- transmission 0 按不透明处理，无需 opacity。

## 5. 关键公式速查

1. **门窗对齐**：from[0]≥0、from[0]+width ≤ 墙长、同墙不重叠、净距 ≥0.4、距墙端 ≥0.24。
2. **转角端点重合**：见 2.2（引擎斜接）；墙起点移动 → 组件同步平移。
3. **藏带**：板边/拆板缝收进墙厚带；禁边坐标=墙面坐标（例外：楼梯到达边、露台临空边精确对齐并设栏杆）。
4. **楼板拆洞**：梯井投影 = 两跑+平台并集，洞周楼板拆 2–4 块矩形。
5. **双跑楼梯**（层高 3.6）：10 步×0.18=1.8；平台厚 0.15；洞口=两跑+平台并集；到达边=末步边缘。**半层高差步参数必须按层高重推**：步数=半层/步高（取 0.15 或 0.18 能整除者），恒等式 stepHeight×stepCount=半层高差。
6. **体块支承**：上层轮廓 ⊆ 下层顶板范围（悬挑 ≤1.2m）；退台露台净宽 1.5–3.0m 且须升级为露台（floor_terrace+女儿墙）。**改外墙轮廓必须同步改该层全部内墙**（内墙端点=外墙内皮，不得悬空/穿墙）。
7. **板顶=墙顶；女儿墙规则**：见 2.7 女儿墙条。
8. **硬山—悬山**：span=墙外皮宽 → 硬山；span+2×(0.3–0.6) → 悬山。
9. **端头藏柱**：水平构件（坐栏/楣子/拱枋）端头延伸到柱轴线埋入柱身，长度=柱轴距。
10. **圆形建筑**：弦长 c=2R·sin(π/n)，矢高 s=R(1−cos(π/n)) ≤0.25 选 n；门窗居中 from[0]=c/2−w/2；柱立墙段交点；cylinder 部位 segments 按"边长 ≤1m"取 64–128。
11. **高差贯通（台阶/楼梯通用）**：末级顶面=目标平台标高；**★ 入口台阶朝向 = 外低内高（最高一级贴建筑墙、末级踏面 = 门洞底 = 首层墙底；住宅三级 0.15 = 0.45）**；贯通连续禁孤立悬蹬；穿栏处断栏、楼板拆洞；踏步底嵌入支承面 0.02；室外大台阶实体砌筑；**有梯必有栏**（随坡栏板+望柱，登高朝 +Z 用 −α）。
12. **斜置杆件**：首选 profile_sweep（path 世界端点、省略 position/rotation、端头过盈 0.02 且端点藏进实体）；cylinder 回退 `[atan2(dz,dy),0,−asin(dx)]`，必做水平分量方位+内倾方向双校验。
13. **球体**：position=球心；环带半径 r_ring=√(R²−Δy²)，用矩形截面 profile_sweep 空心带（禁实心圆盘；闭合环路点末端重叠 0.06 rad 禁首末重合）；**穿球竖向构件顶端止于壳内**（√(R²−(y_top−yc)²) > R_col+0.005）；小球半径 < 柱圈半径−柱半径。

## 6. 十一条硬语义（速览）

① floor.from[1]=板顶（板顶=下层墙顶=上层墙底）② wall.from/to=轴线，**转角端点严格重合·引擎斜接**（禁手工满长—内缩）③ 组件 from=[左边缘沿墙距, 世界Y, 法向偏移] ④ stepHeight×stepCount=目标高差 ⑤ roof position 显式 ⑥ 组件外禁补几何 ⑦ 板/洞边藏带防灰缝 ⑧ 元素排序不影响渲染 ⑨ **所有坡道/台阶/楼梯必须配护栏**（除用户特殊要求）⑩ **构件搭接律（总则=铁律三）**：相邻构件（上下/左右）**接触面严格共面**（0 缝 0 凸）；唯一例外 = 异材质面接触留**不可见**插入量（柱身入柱头 0.04），可见外沿仍齐平。⑪ **联动修改律**：改任一构件必同步其牵连构件（先列清单、依附量由宿主重解、禁照抄旧数、改后回读盘比对），详见 §0.3。**★ 配套铁律三（组合关系）**：任意两实体只允许**分离/贴接**，**禁体积重叠（硬碰撞）**；穿插一律"整件移动/加长/加高"改成贴接（屋面由"上皮贴墙"改"下皮贴墙"⇒抬升 WVT=t/cosθ），**禁削角**，详见 §0.4。**★ 转角完整性三层**：构件/组件/组件内部构件的一切转角必完整、零缺口、外侧 90° 阳角（详见 §0.4 三层总律）。primitive rotation：正 rotX 使 +Z 端下沉；斜置符号随登高方向取。

## 8. 交付自检（速查）

1. 严格 JSON；id 唯一；version 1.1
2. 地坪仅一层；楼板组数=层数−1、轮廓=下层外轮廓；顶层由 roof 承担
3. floor.from[1]=板顶=上层墙底；同一块板只写一次
4. 外墙**端点重合·引擎斜接**闭环（禁手工满长—内缩）；板/洞边藏带；水平构件端头埋柱
5. 门窗 from[1]=世界标高；外窗 frameWidth 显式 0.09
6. 每跑步高×步数=半层；到达板+门洞反推；临空边有栏杆
7. roof 显式 position/span/depth/height
8. 重要尺寸循 0.3 模数；近似项已标注
9. 组件外无重复几何；无未定义 type
10. 材质五件套齐；玻璃含 materialClass 四件
11. 假设项已标注
12. >300 元件由脚本生成，editor.generator/params 留痕；体积 ≤100KB；结构位无全角标点、无超 3 位小数
13. 屋面有坡度（禁薄平盘）；中式攒尖不用 dome；圆台只用于圆形/正多边形平面
14. 护栏完整性：所有梯/坡道有栏；随坡件 rotation 符号正确
15. minY ≥ −0.3；最低实体不没入渲染地面以下 0.3
16. ★ **联动修改（铁律二）**：本轮每处改动的"牵连清单"（被依附侧 / 派生尺寸侧 / 同拷贝侧）已逐项同步；派生量由宿主几何重解、未沿用旧值；改后已重跑三关并**回读盘实测值**比对
17. ★ **组合关系（铁律三）**：所有交界装配对无体积重叠（贴接合法、穿插非法）；异材质仅留不可见插入量且可见外沿齐平；放大/加高后已复查被覆盖件顶端未戳出（如老虎窗颊墙顶不穿屋面）；判据已入生成器断言 + 独立校验器
18. ★ **转角完整性三层**（v2.0 §0.4 三层总律）：**一切转角必完整、零缺口、外侧 90° 阳角**——① 构件级（`wall` 端点严格重合·引擎斜接，禁手工满长—内缩；`roof`/`floor` 面板不被斜接 ⇒ 边缘护板改写为 4 段 `wall` 环）；② 组件级（组件与宿主/邻组件转角**共用世界点 + 转角柱**，`path` 折点有立杆）；③ 组件内部构件级（组件展开出的子几何不被斜接 ⇒ 同轴折线折点由立杆覆盖、十字/丁字一者通长一者内缩至对方外皮）；判据已入生成器断言 + 独立校验器
19. ★ **profile_sweep 剖面绕向**：逐件`node 蓝图生成器/check_profile_winding.cjs <file>` 0 错（剖面绕向使侧面法线全外向；否则渲染空心管）
20. ★ **上层门防坠落（v2.0 §4.0 第 5 条）**：**除首层外，门外侧无「楼板 + 该向栏板」者禁写门**（门可通行 ⇒ 无板 = 开门即坠落）；门须落在外接露台板正上方（门的水平跨 ⊂ 露台板水平跨），且该向外侧有平行栏板（起本层楼面、高 ≥0.6、覆盖门跨）；该段只可开窗。生成器断言 + 独立校验器各一条
