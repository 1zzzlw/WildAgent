# 门型语义与 WILD 映射

## 门型选择与宿主

门型由用户需求或已批准方案决定。所有 door/window 使用真实 parentWall 与沿墙局部坐标，尺寸根据宿主推导。参数契约维护于 doors-supported.md；具体传统或现代名称不作为新 type、sashType、leafCount 或 parentOpening 字段。
