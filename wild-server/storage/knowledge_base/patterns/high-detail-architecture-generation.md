# 建筑细节的可选策略

## 适用条件

仅用于明确的设计策略比较；普通生成不自动召回。复杂度来自用户要求落实的空间、构造和细节关系，不能仅以体量个数或组件数量定义品质。精密模式意味着更完整地实现方案与更严格地检查，不能自行把单体建筑改成退台或 L 形。

## 选择与解释

根据功能和场地选择体量、立面节奏、入口进深、遮蔽、结构表现及材质层次。只选择有理由的策略，说明它解决什么需求。不要默认“住宅必须上层缩进”“公建必须前置门厅”或“现代建筑必须阳台加凸窗加雨棚”。

## 检查结果

检查已选特征是否落实、轮廓是否保持、构件是否有有效宿主和功能关系。多次生成比较空间组织与形态差异，同时保持用户指定条件一致。相似结果不靠随机挪动坐标或更换颜色掩盖。
