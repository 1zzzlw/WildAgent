# 自由变量（设计选择）

本文件明确哪些内容**不构成约束**，由需求和本次方案自行决定。它存在的目的是防止把设计自由度误当成硬规则。

## 属于设计选择的内容

- 是否采用阳台、退台、对称立面
- 使用什么材料
- 体量比例、入口位置、立面节奏

## 由此得出的两条禁止

- **不得因为检索到某类建筑的资料就自动补上该资料里的构件**——"别墅资料里有阳台"不等于本次方案要有阳台。
- **不得因为开启了某个模式就自动追加固定造型套餐**——精密模式提高的是实现完整性与检查质量，不是体量数量。

## 自由度何时收窄

只在三种情况下收窄，其余一律保持自由：

1. 用户明确提出要求；
2. 违反引擎能力边界；
3. 已被批准方案中已选定的系统要求落实的配套关系（这类关系属 `规则性质/`）。
