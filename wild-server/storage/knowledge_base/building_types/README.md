## 当前拆分

| 子目录 | 内容 |
|---|---|
| `catalog/` | 轻量建筑类型入口：别墅、木屋、凉亭、庭院、塔楼等默认参考 |
| `residential/` | 别墅、普通住宅、宿舍、酒店等居住或类居住建筑 |
| `public/` | 教育、办公、文化、商业、体育、医疗、交通、园林纪念司法等公共建筑 |
| `industrial/` | 单层重工业厂房、工业上楼、仓储建筑 |
| `agricultural/` | 温室、畜禽饲养场、粮仓、农机站 |
