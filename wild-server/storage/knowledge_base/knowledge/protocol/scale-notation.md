# 超尺度建筑的等比例缩尺书写法

适用条件：**用户明确要求等比例缩小版，或真实总高超出常规渲染舒适域**（塔类 >100m 直接书写会导致相机失焦、构件厚度不可读）。普通建筑不使用缩尺。

## 书写步骤

1. **定缩尺系数 k**：常用 1:50（k = 0.02）。模型坐标 = 真实尺寸 × k，一个 k 贯穿全楼。
2. **全部坐标与尺寸统一乘 k**，禁止"主体缩尺、细件不缩"的混写——混写即比例失调。
3. **缩尺声明写入 `meta`**：缩放比、k 值、单位、基准面（±0.000 对应的真实标高）。
4. **真实尺寸链留痕**：总高、特征构件直径、特征标高写进 `meta` 扩展字段，供回算自检对照。
5. **细件可读性放大必须声明**：栏杆、望柱等真实 1.1m 缩后 0.022m 不可读的细件，可放大到可读尺寸，但须在 meta 声明"等效真实尺寸"。
6. **回算自检**：交付前抽 3~5 个特征值（总高、球心标高、柱径）按 `模型值 / k` 回算，与真实尺寸链核对。

## 声明字段

`meta.scale` 与真实尺寸链是 schema 放行的扩展元数据：schema 未封闭 meta 的额外键，校验通过；**渲染引擎不消费**，仅作交付声明与回算依据。

```json
{
  "meta": {
    "version": "1.1",
    "type": "building",
    "name": "电视塔缩尺模型",
    "scale": { "ratio": "1:50", "k": 0.02, "unit": "m", "datum": "室外广场地面" },
    "realSize": { "totalHeight": 468, "mainShaft": 350, "antenna": 118 }
  }
}
```

## 能力边界

- 渲染引擎不读 `meta.scale`，缩尺正确性完全靠书写纪律与回算自检保证。
- 缩尺后最小构件（栏杆、框料）低于约 0.02m 时渲染不可读，按第 5 条声明放大。
- 相机取景范围随模型尺寸缩小，整体构图与光影效果需渲染确认。
- 自由变量：k 值、哪些细件放大、放大倍率——均由本次方案与渲染效果决定，本协议不定值。

## 设计层表态通道（当前生成链）

"直接生成"的建筑链在设计层表态、不产出 meta 扩展字段——**缩尺声明没有设计层通道**。本协议在两条场景生效：ScenePatch 修改链对已有蓝图追加/调整缩尺模型；蓝图直写（导入/外部生成流程）。超尺度建筑直接生成时，编译器按常规尺度派生，若渲染比例失真，走 ScenePatch 链按本文档补缩尺。
