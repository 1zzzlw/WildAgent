# 球体建筑的球幕骨架与斜置杆件

适用条件：**方案点名球体建筑、球形幕墙、斜拉/斜撑杆件**时使用；普通方盒体量不使用。

## 球幕 = 玻璃壳 + 骨架（缺一即失真）

只有玻璃壳是"光球"；骨架四件缺一即被退回：

| 骨架件 | 写法 |
|---|---|
| 经线肋（竖挺） | `profile_sweep` 圆管，path = 大圆子午线取点折线（经度均分），逐点落球面（\|d−R\| ≤ 0.002） |
| 纬线带（横档） | `profile_sweep` 矩形截面闭合环，**半径严格 = √(R² − Δy²)**（Δy = 带心到球心竖距） |
| 观光廊带 | 同纬线带，截面放大 |
| 两极盖板 | 小 `cylinder` 圆盘，置于球心 ±(R−微量)，遮经线肋在极点汇聚的开口端 |

**红线：环带禁实心圆盘**——`cylinder`（radiusTop = radiusBottom）在大直径处等于一张盘，透光壳下读成"球里插了张盘"，必须用矩形截面空心带。

球体一律**球心定位**（`position` = 球心，非底面）。

## 斜置杆件：profile_sweep 世界路径

**任意朝向杆件一律 `profile_sweep` 世界路径（path 两端点，省略 position/rotation）**，不要用 cylinder + rotation：

- 渲染层为 three.js Euler XYZ 序，对 +Y 轴形体 `rotation[1]` 只自转、**方位角被丢弃**——`[φ,ψ,0]` 会让斜杆全部朝 +Z 歪倒，且只查倾角的校验查不出来；
- `profile_sweep` 的 path 是世界坐标，零旋转风险；
- 两端各沿轴外延 0.02 过盈（底入承台、顶入球体）；
- 双校验：与设计夹角偏差 ±0.05°；水平分量内倾且方位角 = 设计值。

```json
{"type":"primitive","id":"brace_0","shape":"profile_sweep","path":[[4.071,0.343,3.618],[3.303,1.877,3.175]],"radius":0.07,"segments":16,"material":"concrete_civic"}
```

## 穿球构件止于壳内

竖向穿球构件（塔柱、单筒体）**顶端必须落在球壳以内**：柱圈半径处的球壳只在 `球心标高 ± √(R² − 柱圈半径²)` 区间存在，柱顶超出即从球面上部穿出。

断言：`√(R_ball² − (构件顶 − 球心)²) > 构件所在半径 + 0.005`（顶端处球壳半径仍大于构件半径，构件被球体完全包裹）。同类：单筒体顶端止于上方舱体底，不穿舱。

## 横梁与多筒束

- 多柱按设计方位角均布；横梁 `primitive box` **长度 = 柱轴距**（端头埋入柱身，不留缝也不共面），`rotation[1] = atan2(−Δz, Δx)` 对齐弦线——绕 Y 单轴旋转对长轴为 X 的 box 有效，不受 Euler 序影响；
- 横梁小球等装饰球：球心落在构件轴线上且球半径 > 构件半径，即完全包裹不外露。

## 检查

- 经线肋逐点贴球面；纬线带半径按 √(R²−Δy²) 严格计算且截面非零厚。
- 穿球断言全过；斜撑夹角/内倾/方位角双校验。
- 球幕材质用带色反光玻璃（见幕墙组装配方"玻璃材质分制"），透明玻璃会内部骨架全外露。
- 缩尺球塔先按缩尺书写法定 k，再按本文书写。

## 设计层表态通道（当前生成链）

- **设计层可表态**：`massing.shape: "circle"`（圆柱塔身）。
- **设计层无通道（能力缺口，只标记不阻断）**：球体量、球幕骨架、profile_sweep 斜撑、穿球构件——当前设计层与编译器均无球体塔型派生规则，"直接生成"不会产出球塔；本文档技法在 ScenePatch 修改链与蓝图直写场景生效（该链直写蓝图 JSON 且会检索到本文档）。
