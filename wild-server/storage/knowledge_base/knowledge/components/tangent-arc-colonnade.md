# 拱券、山花与古典柱廊的相切拱圈法

适用条件：**方案点名拱门窗、拱券、山花、古典柱廊**等形制时使用；普通矩形门窗不使用。

## 拱洞开口

`opening` 元素（`elements[]` 内，`parentWall` 挂墙）原生支持拱形：`style: "arched"` 的开口衬板轮廓即"矩形 + 半圆"。**洞口切到拱顶**：`height = 矩形段高 + 拱半径`。

本引擎 opening 坐标语义：`from[0]` = 开口**左边缘**沿墙距离、`from[1]` = 开口**底部世界 Y**、`from[2]` = 法向偏移。居中写法：`from[0] = 墙轴跨/2 − width/2`（满长—内缩配对的短边墙，轴跨 = 边长 − 墙厚，必须按当层墙轴重算）。

```json
{"type":"opening","id":"arch_door","parentWall":"cella_s","from":[1.5,0.9,0],"width":1.5,"height":2.55,"style":"arched","material":"dark_void"}
```

## 相切拱圈法（石拱圈装饰）

**禁止用阶梯砌块逐级近似拱形**——任何分段数下都呈锯齿轮廓。拱圈装饰段一律相切旋置：

1. 段数 n=12（每段 15°），第 k 段中心角 θₖ = (k+0.5)·15°，自右拱脚越拱顶至左拱脚。
2. 段心位置 = 拱心 + rm·(cosθ, sinθ)，rm = (rIn+rOut)/2。
3. 段尺寸 = [弦长, rOut−rIn, 墙厚+0.06]（两端各出墙 0.03，段外缘嵌入墙身）。
4. **弦长 = 2·rm·sin(π/n) + 0.01**——+0.01 相切搭接消缝，轮廓连续光滑。
5. 旋转 = 绕墙法线单轴转 θₖ：正面墙 `[0,0,θₖ]`、侧墙 `[θₖ,0,0]`。

```json
{"type":"primitive","id":"archivolt_0","shape":"box","position":[4.65,3.615,3.75],"dimensions":[0.484,0.33,0.36],"rotation":[0,0,1.571],"material":"marble_gray"}
```

门扇拱顶：`cylinder` 旋转 90° 使**轴向 = 墙法线**（正圆截面即数学圆滑拱顶），半径 = 拱半径 + 0.01 嵌入洞壁消缝，心 = 拱心。

## 拱肩回填弦长公式

`style: "arched"` 衬板切出拱形后，半圆外两角需用墙体同色块回填。第 k 道（k=1..N−1，道高 = 半券宽/(N−1)）：

- 道宽 = `(W − 2·√(r² − h²)) / 2`，其中 W = 券宽、r = 半券宽、h = 道中点自拱脚起算的高度。
- 弦长 `w(h) = 2·√(r² − h²)` **自拱脚向拱顶递减**——基准颠倒会把最宽行写到拱顶。
- 回填块厚略出墙 0.02 防共面闪缝，材质与墙体一致。

## 山花（pediment）阶梯填充

引擎 gable 端面为薄壳坡面 + 山墙端板，**山花三角形截面有额外形制要求时自建**：

1. 三角形按 4 步均分（步高 = H/4），步宽 = `span·(1 − (y顶 − yRoof)/H)` 留缝 0.05；顶步为脊顶封口块（坡面回算宽在顶点为 0，豁免校验）。
2. 坡檐口线脚沿两坡边斜置：板长 = 坡长 √(hw²+H²)，`rotation = [0,0,±A]`，板外面与水平檐口外面齐平。
3. 山花填充 z 向比水平檐口外面内退 0.05（防共面）。
4. **步宽公式中的 span 是屋面 span（含出檐）**，不是台基宽——写错必穿坡。

## 柱式过盈嵌入

- `column` 元素声明柱式风格；柱径比与收分为自由变量。
- **柱头垫块必写**：每柱顶叠加块，垫块顶 = 额枋底（传力连续硬对位）。
- **接触处一律体积过盈**：柱底低于台基顶 0.02、柱顶高于垫块底 0.04（height = 名义高 + 0.06）——贴合接触在渲染浮点下必露缝，过盈消除。
- 三陇板等凸饰：凸出 0.02、嵌入 0.02（板背面 ≠ 横饰带面）。

## 检查

- 拱圈段逐段按圆公式复算位置与旋角；旋转件天然脱离洞壁切割面，无共面。
- 垫块顶 = 额枋底、檐口顶 = 屋面底缘两处硬对位。
- 洞顶 ≤ 墙顶；居中洞口的世界坐标复核（左右边缘值换算中心后与墙轴对齐）。
- 当前校验器无共面自动检查，防共面尺寸差（0.01~0.05 级）靠书写纪律保证，渲染确认。

## 设计层表态通道（当前生成链）

当前建筑生成链是"设计分块 → 确定性编译"，模型在设计层表态、编译器展开蓝图。本文档技法在两条链路生效方式不同：

- **设计层可表态**：`roof.type: "gable"` 浅坡（山花形制依赖浅坡）；`component_quota.cornice`（檐口/线脚带 1~4 道，覆盖额枋/横饰带层次）；`facades` 各面槽位用 door/window 数量与位置为拱洞占位。
- **设计层无通道（能力缺口，只标记不阻断）**：facade 开口形态闭集只有 `swing/slide/lift/fixed`（开合方式），**没有拱形 `arched`**——设计层无法声明拱洞；拱圈段、拱肩回填、柱头垫块为蓝图层技法，"直接生成"的编译产物不含。
- **生效路径**：对已有蓝图用 ScenePatch 修改链点名"拱形开洞/相切拱圈装饰"（该链直写蓝图 JSON 且会检索到本文档）。
