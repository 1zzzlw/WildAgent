# 双坡屋顶的两斜板法与坡面细节控制

适用条件：**需要精确控制坡面厚度、脊盖、山墙五边形截面等细节，或 `roof` 默认形状不满足形制**时自建坡面；常规双坡优先用 `roofType: "gable"`。注意：本引擎 gable 为薄壳坡面 + 山墙端板 + 檐口，与旧版"实体楔块"观感不同，禁用与否按当前渲染效果判断。

## 两斜板法五步

半跨 `HW = span/2`，坡角 `α = atan(height/HW)`，斜板长 `SL = √(HW² + height²)`：

1. 两块 box，断面 `[SL, 板厚, depth]`，`rotation = [0,0,±α]`（rotation[2] 正角使 +X 端上抬：一坡 +α、另一坡 −α）。
2. 板中心 = 顶面中点沿法线下移半厚：`(脊x ∓ HW/2 ∓ 板厚·sinα, 檐口y + height/2 − 板厚·cosα, 脊z)`。
3. **脊盖** box 压脊：中心 y = 屋脊标高 − 半盖高（盖住脊下 V 口，顶面高出板顶微量）；脊端收头件坐脊盖两端。
4. **山墙五边形填充**用 `profile_sweep`：path = 山墙位置两端点（世界坐标，**省略 position**），截面五边形——上缘平行坡板底面**嵌埋 0.03**、底边坐墙顶。上缘竖向 offset = `板厚/cosα + 0.03`，坡角变更时按此重算。
5. **校验恒等式**：斜板顶面两端点 = (脊x∓HW, 檐口y) 与 (脊x, 檐口y+height)，误差 ≤0.001。

## 封檐板与博风板

- **封檐板**沿两坡檐口边缘：厚小于檐口板、上缘覆板顶、外缘挑出微量，长 = 屋顶 depth。
- **博风板**沿山面两坡边：长 = `√((span/2)² + height²) + 0.01`，`rotation[2] = ±α`，中心 = 坡中点沿法线抬半板高。

## 独立门楼（无承托墙的坡顶）

`roof/gable` 元素的山墙端板依赖承托墙语境；低位独立门楼雨棚无承托墙时，山墙三角**必须自建**阶梯填充（每端 2~3 级 box，宽度按坡板内皮三角逐级内收并留 0.015 防共面间隙），z 向与屋面端面错开 ≥0.01。

**尺度律**：门楼装饰整体 ≤ 主屋顶装饰尺度（小檐口配小装饰），防止头重脚轻。

## 圆柱 position 是几何中心

`primitive cylinder` 的 `position` 是**几何中心**：柱高 h 时 `中心 y = 柱底 + h/2`。按"底面圆心"书写会半截插地、顶部悬空。

## 防共面四条

1. 凸出墙面的构件（门簪等）尾部必须**嵌入墙体 ≥0.03**，尾端面严禁与墙外皮同坐标。
2. 填充/装饰件的端面与屋面板端面**错开 ≥0.01**，顶角与坡板内皮留 ≥0.015。
3. 叠级构件上下级**精确叠合**（共享面法线相反不闪面），禁止 0.01 错缝重叠（同法线共面）。
4. 同材质共面不可见可豁免；异材质共面一律错开。

## 检查

- 当前校验器无共面自动检查：防共面尺寸差靠书写纪律 + 渲染确认。
- 坡角、出檐、脊高为自由变量；坡角变更时两斜板/脊盖/山墙截面/博风板/封檐板按公式联动重算。
- 山墙截面上缘嵌埋坡板、底边坐墙顶两处对位。

## 设计层表态通道（当前生成链）

- **设计层可表态**：`roof.type: "gable"`（双坡）——**`ridge_axis`（x/z）决定山墙朝向**，要"山墙面朝主立面"就让脊垂直于主立面；`overhang` 控制出檐；坡高由编译器按跨度和类型派生。四坡变体用 `"hip"`。
- **设计层无通道**：两斜板/脊盖/山墙五边形截面为蓝图层精细控制技法——引擎 gable 已是薄壳坡面+山墙端板+檐口，常规双坡直接用 `roof.type: "gable"` 即可，仅在渲染确认默认形状不满足形制时走 ScenePatch 修改链自建。
