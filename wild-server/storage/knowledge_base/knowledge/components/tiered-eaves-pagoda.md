# 方形多层塔的叠涩檐与四棱台锥坡

适用条件：**方案点名叠涩檐、多层砖塔、逐层收分塔身**等方形层檐形制时使用。圆形平面不使用（见圆台锥坡体系）。

## 叠涩檐四角直角闭合

每层墙顶之上菱角牙子 + 逐道外挑的叠涩带，每道 = 4 面围合 box。四角闭合五步（对任一层，墙外皮半距 F、第 ri 道外挑 out、带深 d）：

1. **定带中心距**：`outer = F + out + d/2`；带 y 中心 = 层顶 + 已堆道高 + 道高/2。
2. **南北带（盖角通长边）**：长 = `2×outer + d`——**必须含 2×半带深盖满角部格**，只对齐端面会让外缘角部留台阶缺口。
3. **东西带（缩进对接边）**：长 = `2×(outer − d/2)`，端面恰抵南北带内侧面——两带外皮在四角交汇成**直角**，零缺口、零共面。
4. **缩进量 = 正交构件的半厚**（半带深/半板厚），不是全厚——误用整厚会在每角遗留缺口。
5. 带内缘藏进墙面或平齐（各道内缘 ≥ 墙外皮，无共面灰缝）；外挑量与道数为自由变量。

```json
[{"type":"primitive","id":"eave_band_s","shape":"box","position":[22.8,14.7,10.125],"dimensions":[28.8,0.3,0.45],"material":"brick_dark"},
 {"type":"primitive","id":"eave_band_w","shape":"box","position":[8.625,14.7,24.3],"dimensions":[0.45,0.3,27.9],"material":"brick_dark"}]
```

## 四棱台锥坡（层檐盖面）

每层檐上皮用 **1 个 `cylinder` `segments=4`** 盖坡——四棱台是平面拟合体，四坡在角部经角脊线天然交汇成直角；斜置 box 通长交错、缩进对接、45° 盖板三种替代方案均会产生交叉鳍或缺口。

- `rotation = [0, π/4, 0]`：四坡面法向朝四方。
- `radiusTop = F×√2`、`radiusBottom = (F + 坡跑)×√2`——**半径 = 半边 × √2 外接圆系数**。
- `height` = 坡降；底标高 = 带顶 + 微量搭接；坡角由坡降/坡跑控制。
- 底盖面兼作檐底天花板；顶层若被塔顶攒尖覆盖则不设。
- **方形平面禁用平滑圆台**（segments ≥16 的旋转体只服务圆形/正多边形平面，方形上出椭圆歪坡）。

```json
{"type":"primitive","id":"tier_roof_s1","shape":"cylinder","position":[22.8,15.3,24.3],"radiusTop":18.46,"radiusBottom":21.0,"height":0.8,"segments":4,"rotation":[0,0.7854,0],"material":"roof_dark"}
```

## 券洞居中与逐层对位

多层收分塔的拱券门洞：

- **各层券洞规格统一**（同宽同形），立面才读得出节奏；逐层变宽会破坏韵律。
- **洞心共竖线**：各层洞口世界中心对齐塔心轴；满长—内缩配对下，短边墙轴跨 = 边长 − 墙厚，`from[0] = 轴跨/2 − 券宽/2`——写成长边口径即偏移半墙厚。
- **洞顶逼近层檐**：洞高取"层高 − 洞上净空"，净空为门楣带留位。
- 石门楣横贯洞顶上方，**外皮凸出墙面**（嵌墙内不可见），两端嵌入倚柱，`rotation[1] = atan2(法线x, 法线z)` 随墙向旋转。
- 倚柱贴墙面外凸（中心距墙面 = 凸出量），阑额通长且**两端埋入角柱**，顶与墙顶齐平。

## 层间楼板板边藏带

塔内楼板板边 = 上层半边 + 半墙厚——板边藏进上层墙厚带（被上层墙压住），又不与下层墙相撞（收分量 > 墙厚时成立）。板厚与材质自由。

## 检查

- 每层 4 面墙转角共用端点；收分塔逐层按当层半边重算全部派生尺寸（倚柱位、带长、洞口居中距、板边）。
- 叠檐四角外皮齐平 + 端面贴合，数值全查。
- 锥坡 `segments=4` 且 rotation 仅绕 Y π/4；渲染无椭圆歪坡。
- 楼层标高链连续：下层墙顶 = 楼板 = 上层墙底。

## 设计层表态通道（当前生成链）

- **设计层可表态**：`roof.type: "chinese_pagoda"` 或 `"chinese_curved"`；`volumes[]` 逐层收分——每层一个体量项，`width/depth` 随 `start_floor/end_floor` 升高递减（方锥轮廓），体量不得重叠且同层投影覆盖轮廓；`component_quota.cornice`（每层檐口线脚，多层塔取上限 4 或由编译器按层派生）。
- **设计层无通道（能力缺口，只标记不阻断）**：叠涩带逐道外挑、四棱台锥坡（`cylinder segments=4`）、拱肩回填与券洞居中——均为蓝图层技法，编译产物不含；券洞是否出现取决于 facade 槽位是否含 door，拱形需走 ScenePatch 修改链。
