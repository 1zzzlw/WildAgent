# 圆形殿宇的圆台锥坡体系与弦线围合

适用条件：**方案点名圆形殿宇、攒尖顶、重檐、圆形台基、环形栏杆**等旋转面形制时使用。矩形平面不使用（矩形用 gable/hip）。

## 母线思维：檐唇 + 锥坡

旋转屋面的每一重檐剖面 = 直角梯形：**竖直短边用檐唇直壁环、斜边用圆台锥坡**，两件同半径同标高对接即成完整檐口。

| 件 | 写法 | 对接 |
|---|---|---|
| 檐唇 | `cylinder` 直壁薄环（radiusTop = radiusBottom），高约 0.4 | 顶 = 锥坡底（同半径同标高） |
| 锥坡 | `cylinder` 圆台（radiusBottom > radiusTop） | 上口半径 = 上层殿身半径 + 搭接量（檐坡扣住殿身） |

n 重檐 = 沿半径逐重内收、沿标高逐重上升重复 n 次；坡度 = atan(锥坡高 / 半径差)，改坡度只动锥坡高。

以下是 `geometry.elements` 数组中的组合片段（檐唇 + 锥坡两件同半径同标高），不是完整 `.wild` 文件：

```json
[
  {
    "type": "primitive",
    "id": "eave_lip_ring",
    "shape": "cylinder",
    "position": [0.0, 4.2, 0.0],
    "height": 0.4,
    "radius": 3.0,
    "segments": 48,
    "material": "tile"
  },
  {
    "type": "primitive",
    "id": "cone_slope_01",
    "shape": "cylinder",
    "position": [0.0, 4.2, 0.0],
    "height": 1.2,
    "radiusTop": 2.8,
    "radiusBottom": 3.0,
    "segments": 48,
    "material": "tile"
  }
]
```

- 檐唇用单一 `radius`（radiusTop = radiusBottom 的直壁环）；锥坡用 `radiusTop` + `radiusBottom` 成对给出（radiusBottom > radiusTop）。
- 同半径同标高对接：两件底半径与基准标高一致时檐口连续；`segments` 按体量取值，示例 48 仅解释字段。
- `material` 必须引用骨架 `materials` 里已存在的材质名；数值仅解释字段。

**形制红线**：

- 屋面禁用平盘（每重檐侧影必须是斜线，水平线即退化为盘）；
- 中式攒尖禁用 `roofType: "dome"`（dome 是西式半球穹顶，无锥面坡度），一律用收分圆锥台写法；
- 圆台只用于圆形/正多边形平面。

坡度带参考：檐坡 18–25°（下层缓上层陡）、攒尖锥面 30–40°——为形制参考值，非引擎约束。

## 弦线围合石栏杆

圆形台基四周栏杆按弦线围合，每层 n 组（n 为自由变量，常用 32~48），第 i 组：

- 等分点 p₁、p₂ 为相邻望柱位，弦长 = `2·rr·sin(π/n)`（rr = 栏杆圈半径）；
- **望柱**立在等分点（截面小柱）；**栏板**、**扶手**中心 = 弦线中点，长度 = 弦长 − 让位量；
- 旋转 `rotation[1] = atan2(−Δz, Δx)` 对齐弦线（θ 取弦线中点方位角）；
- 望柱高 > 栏板顶 < 扶手顶，三者顶面错层；环首尾相接处天然共点。
- 台阶穿栏处**断栏让位**：栏杆件方位角与楼梯中线夹角小于门槛角的区段不生成，断口两端望柱收头。

以下是 `geometry.components` 数组中的一个片段（圆周上一段弦线），不是完整 `.wild` 文件：

```json
{
  "type": "railing",
  "id": "railing_chord_01",
  "path": [
    [2.82, 0.45, 0.0],
    [2.82, 0.45, 0.8]
  ],
  "height": 0.9,
  "postSpacing": 1.2,
  "postRadius": 0.03,
  "railRadius": 0.02,
  "infillType": "panel",
  "infillThickness": 0.04,
  "material": "stone"
}
```

- 示例为一段弦线 `railing`：`path` 两端即相邻望柱位，`rotation[1] = atan2(−Δz, Δx)` 对齐弦线；栏板/扶手按 `infillType` 展开。
- 沿圆周布置 n 组时逐组复制并按弦线方位旋转 `rotation[1]`；台阶穿栏处整段不生成（断栏让位），断口两端望柱收头。
- 数值仅解释字段，栏杆圈半径、组数 n、望柱/栏板尺寸由本次方案决定。

## 折面圆殿身

圆形殿身用 n 段直墙围合正多边形（n 为自由变量，16~24 常用）：

- 外接圆 R，弦长 = `2R·sin(π/n)`，矢高 s = `R·(1 − cos(π/n))`；
- **矢高判据 s ≤ 0.25**：超出则折面感明显，加段数；
- 第 k 段墙 from/to = 圆周上 `22.5k ∓ 11.25°`（n=16 时）两点，厚度小值；墙面中线方位角 = `360k/n`；
- 组件门窗挂在中线对准目标朝向的直墙上；**改段数必须重算全部 from[0] 与弦长**——段数变更后门窗不居中是最常见回归。

以下是 `geometry.elements` 数组中的一个片段（n=16 的第 1 段直墙），不是完整 `.wild` 文件：

```json
{
  "type": "wall",
  "id": "rotunda_seg_01",
  "from": [2.942, 0.0, 0.585],
  "to": [2.942, 0.0, -0.585],
  "thickness": 0.24,
  "material": "brick"
}
```

- 外接圆 R = 3.0、n = 16 时：弦长 = 2R·sin(π/16) ≈ 1.171，矢高 s ≈ 0.058 ≤ 0.25（判据通过）；示例两端点即 ±11.25° 的圆周点。
- 逐段布置时第 k 段端点按 `22.5k ∓ 11.25°` 重算，墙面中线方位角 = `360k/n`；改段数必须同步重算全部 `from`/`to` 与弦长。
- `thickness` 取小值（示例 0.24）；数值仅解释字段。

## segments 细分判据

旋转体（台基圆柱、锥坡、圆环）的 `segments` 按弦长控制：边长 ≈ `2πr/segments`，台基等大体量放宽到边长 ≤1.5m，近人尺度构件更细。segments 是自由变量，按体量与观感取值。

## 检查

- 檐唇顶 = 锥坡底、锥坡上口压住上层殿身、锥台顶半径 = 宝顶座半径三处对接零缝隙。
- 折面矢高 ≤ 0.25；四正向墙面中线对准目标朝向。
- 渲染无 dome、无平盘；锥面棱沿径向均匀放射无扭曲。
- 栏杆断口与台阶对位，望柱收头无悬空。

## 设计层表态通道（当前生成链）

- **设计层可表态**：`massing.shape: "circle"`（圆形平面/圆台基）；`roof.type: "chinese_curved"`（中式曲线檐）——攒尖/重檐的圆台写法由编译器按中式屋顶类型派生；多体量殿身用 `volumes[]` 表达逐层收径。
- **设计层无通道（能力缺口，只标记不阻断）**：檐唇+锥坡两件式、弦线围合栏杆、折面段数与矢高判据——蓝图层技法，编译产物按引擎中式屋顶内置规则展开；若需精确控制走 ScenePatch 修改链。
