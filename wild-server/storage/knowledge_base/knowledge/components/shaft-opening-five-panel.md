# 高层标准层的井道留洞与层间立面

适用条件：**方案选择多层/高层塔楼并布置竖向交通核心**（楼梯间 + 电梯井）时使用；低层独栋不使用。

## 楼板五块拼装 + 井道留洞

标准层楼板拆 5 块，**竖向交通井道区每层无板**（铺满 = 电梯井与楼梯井堵死）：

| 块 | 覆盖 |
|---|---|
| 南带 | 楼板南缘 → 井道南缘 |
| 井道西侧 | 西墙 → 井道西缘 |
| 前室 | **前室必须有板**（电梯厅区域） |
| 井道东侧 | 井道东缘 → 东墙 |
| 北带 | 井道北缘 → 楼板北缘 |

- 井道无板区 = 楼梯间 + 电梯井的水平投影并集；核心筒剪力墙围合并道，隔墙可省略。
- **上层首层地面 = 下层屋面时只写一次板**：塔楼首层地面由裙房屋面承担，不重复写板。
- 板厚自由；拆板边界优先藏进墙厚带。

## 层间立面：裙墙 + 玻璃带严格无缝

每标准层四向各一对"层间实体裙墙 + 玻璃带"，两者高度之和**严格等于层高**：

- 裙墙：`wall` 元素，`from[1]` = 本层楼面，高 0.8（层间实体封堵的体量表达，构造层不建模）；
- 玻璃带：`primitive box`，厚薄板，高 = 层高 − 裙墙高，**顶面必须 = 本层楼面 + 层高**——留缝即楼层悬浮；
- 裙墙高为常见规范参考值（0.8m），具体按形制需求定。

## 顶部收头对位

- **电梯机房体块必须落在井道区正上方**（平面 = 井道区投影直上）；
- 女儿墙一圈 + 装饰飘板骑女儿墙顶（四面出挑）；
- 女儿墙写法：厚 = 墙厚，底 = 板顶，只布最外一圈，端点与墙面齐平。

## 检查

- 每层井道区无板、前室有板；逐层裙墙 + 玻璃带顶面 = 楼面 + 层高断言。
- 上层外墙全部落在下层楼板/墙体投影内（支承约束）。
- 机房中心 = 井道中心（平面）。
- 疏散楼梯、电梯数量等规范要求为领域参考，不在本知识库执行范围。

## 设计层表态通道（当前生成链）

- **设计层可表态**：`circulation.vertical_strategy` 选择竖向交通策略（含核心筒+楼梯的电梯派生规则）——井道留洞由电梯派生规则与编译器确定性接管，无需逐块声明；裙房+塔楼双体量用 `volumes[]`（塔楼 `start_floor` = 裙房层数，两套层高体系分体量表达）；整片玻璃立面通过 plan 层 `curtain_wall: true` 声明（配合幕墙组装配方）。
- **设计层无通道**：五块拼板拆分、裙墙+玻璃带的逐层无缝断言由编译器按体量与层高确定性派生，模型不写逐块楼板。
