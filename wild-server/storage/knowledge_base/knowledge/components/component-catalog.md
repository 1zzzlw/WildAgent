# 构件参考目录

由 scripts/kb/update_component_catalog.py 从构件注册表及知识小节元数据生成。
修改示例后重新生成此文件；运行时提示词读取同一批元数据，目录不占用构件 RAG 的 top_k。

构件参考目录（非白名单）：用于统一命名和查找已有资料；目录外的新构件仍可设计和实现。
已有示例是实现起点，形态、尺寸和材料由当前图纸决定；experimental 示例需要核对能力限制。
