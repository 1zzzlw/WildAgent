# 多层体块咬合与水平板分层纪律

适用条件：**方案为多层体块咬合建筑（退台、翼体、露台）**时使用；单一体量不涉及退台条款。

## 体块构成四律

1. **轮廓错落律**：相邻两层实体外轮廓至少一处退让或悬挑，禁止逐层完全重合的"叠方盒"。悬挑量自由（建议声明上限）。
2. **支承约束律**：缩进/悬挑的上层墙体必须有同轮廓的下层楼板/墙体托底——自上而下检查：顶层轮廓 ⊆ 下层楼板 ⊆ …… ⊆ 首层。
3. **露台升格律**：上层退让暴露的下层屋面**必须升格为露台**——露台面（独立 floor 板）+ 女儿墙 + 至少一樘可达门窗；禁止留裸楼板。
4. **翼体收头律**：L 形/T 形平面中，翼体尽端设满长女儿墙或高墙压边，与主体墙外皮精确对齐，不留缺口。

## 水平板四类术语（各司其职）

| 名称 | 定义 | 顶面标高 | 轮廓算法 | 数量 |
|---|---|---|---|---|
| 地坪 | 首层落地板 | ±0.000 = 一层墙底 | = 一层整个外轮廓 | 全楼恒 1 组 |
| 楼板 | 某层屋顶板，兼上层地板 | 上层墙底 | **= 下层整个外轮廓**（不是上层） | N 层建筑 N−1 组 |
| 露台面 | 楼板暴露在上层轮廓外的部分 | 同该层楼板 | 楼板分块，**并集仍 = 下层外轮廓** | 随退台 |
| 休息平台 | 双跑楼梯半层高转台板 | 半层高 | 梯井旁矩形 | 每层 1 块 |

- 顶层顶板由屋面系统承担，**顶层不另写 floor**（屋面与楼板重叠是高频错）。
- 引擎语义：`floor` 的 `from[1]` 为板底、`thickness` 向上延伸；板顶 = 板底 + thickness，应与"下层墙顶 = 上层墙底"平面对齐（字段级语义以 blueprint-skeleton 与 component-parameters 为准）。
- 禁止：每层另写地坪；层间楼板缩成上层更小轮廓；用全楼外包大矩形多铺楼外板。

## 楼板边缘藏带律

楼板 `from/to` 取**外墙中线包络**，板边藏进墙厚带内不可见；**严禁板边与外墙皮齐平**——板 Y 向与上下层墙体必然重叠，外皮齐平产生全周长共面灰缝。

## 闭环外墙转角（满长—内缩配对）

- 一向墙满外皮长（压角），另一向墙两端各内缩一厚度，转角处两墙共用端点；
- 墙起点确定后**依附构件 from[0] 相对此起点计量**，墙起点改变时全部组件 from[0] 同步平移（漏移 = 门窗整体偏移半墙厚）；
- 自检：转角处两墙实体并集完整覆盖角柱区，无缺口无重叠错缝。

## 女儿墙规则

- **只布当层屋顶/露台板最外边缘一圈**；中间分界、室内板边、阳台禁写；
- 写法同 `wall`：厚 = 墙厚，高 0.9–1.2，底 = 板顶，**端点与墙面齐平（禁嵌入墙身）**；
- 最外一圈上有常规墙继续升高 → 该边不写女儿墙。

## 内外联动（外形变更 → 内部跟随）

外轮廓/体块变更后沿链重推：①标高链 → ②楼板重分（轮廓 = 下层外轮廓）→ ③内墙端点 = 外墙内皮重算 → ④门窗/洞口平移 → ⑤楼梯步参数与梯井洞重推 → ⑥外饰带体避让重查 → ⑦全量自检。**禁止只动外部**。

## 检查

- 逐层轮廓包含关系（支承）；退台处有露台三件套；翼体收头无缺口。
- 楼板并集 = 下层外轮廓；板边藏带；顶层无 floor。
- 楼梯每跑 `stepHeight × stepCount` = 该跑升高，两跑之和 = 层高；梯井洞 = 两跑 + 平台水平投影。
- 当前校验器不判定共面：藏带律与转角配对靠书写纪律 + 渲染确认。

## 设计层表态通道（当前生成链）

本文档多数规则在当前生成链**直接以设计层字段生效**：

- **轮廓错落律**：`volumes[]` 相邻体量至少一处退让或悬挑（width/depth/x/z 错动），禁止逐层完全重合；缩进侧必须满足支承约束（编译器校验体量投影与支承）。
- **露台升格律**：上层退让暴露的屋面由编译器按体量关系派生露台；可达门窗靠 facade 槽位在对应立面布置 door。
- **女儿墙/水平板分层**：板顶 = 上层墙底由编译器确定性保证；顶层不写楼板由编译器处理——模型只需给对 `volumes` 与 `roof`。
- `component_quota.balcony/railing/canopy` 可配额（balcony 二层以上生效）。
- **设计层无通道**：楼梯拆板边界与藏带细节、到达边栏杆由编译器按交通策略派生；模型在 `circulation.vertical_strategy` 上表态即可。

## 蓝图层产物示例

设计层主通道由 `volumes[]` + `roof` 表达；需要**精确控制拆板边界、藏带与边栏杆**时走 ScenePatch 修改链，对应产物是 `floor` 元素（`geometry.elements`）与 `railing` / `balcony` 组件（`geometry.components`）。以下片段不是完整 `.wild` 文件：

楼板按**外墙中线包络**（板边藏进墙厚带）：

```json
{
  "type": "floor",
  "id": "floor_l2",
  "from": [0.0, 3.2, 0.0],
  "to": [12.0, 3.2, 8.0],
  "thickness": 0.2,
  "material": "concrete"
}
```

- `from[1]` 为板底、`thickness` 向上延伸：示例板顶 = 3.4 = 上层墙底；`to[1]` 与 `from[1]` 同标高。
- 板边不与外墙皮齐平：`from` / `to` 取外墙中线包络，外皮齐平产生全周长共面灰缝（藏带律）。

上层退让后下层屋面升格为露台，露台板 + 边栏杆（升格三件套中女儿墙由编译器派生，蓝图层不另写）：

```json
{
  "type": "floor",
  "id": "terrace_l2",
  "from": [12.0, 3.2, 0.0],
  "to": [14.0, 3.2, 8.0],
  "thickness": 0.2,
  "material": "concrete"
}
```

```json
{
  "type": "railing",
  "id": "railing_terrace_01",
  "path": [
    [12.0, 3.4, 0.0],
    [14.0, 3.4, 0.0]
  ],
  "height": 1.1,
  "postSpacing": 1.0,
  "postRadius": 0.03,
  "railRadius": 0.02,
  "infillType": "panel",
  "infillThickness": 0.04,
  "material": "metal"
}
```

`component_quota.balcony` 对应蓝图层 `balcony` 组件（二层以上生效）：

```json
{
  "type": "balcony",
  "id": "balcony_l2_01",
  "parentWall": "wall_south_l2",
  "from": [4.0, 3.4, 0.0],
  "width": 2.4,
  "depth": 1.2,
  "slabThickness": 0.16,
  "railingHeight": 1.1,
  "postSpacing": 1.0,
  "material": "concrete",
  "railingMaterial": "metal"
}
```

- 露台/阳台 `from[1]` 取对应楼层板顶标高（示例 3.4 = 板底 3.2 + thickness 0.2）；数值仅解释字段。
- 女儿墙蓝图层没有独立 `height` 字段，墙高由编译器按屋顶/露台关系派生——不要在 `wall` 上发明高度字段。
