# 10 月 10 日优化：自由设计图纸，按标记尝试实现

日期：2026-10-10，更新至 10 月 12 日。状态：代码已改造，保存回复的实现回放与当前引擎渲染已完成；真实模型新生成与完整服务验收尚未完成。

本文件按用户后续明确的目标重新整理，替代此前“先按模板编译，再补细节”的方案。历史诊断和阶段结果保留在 `执行记录`（已归档），当前实现以本文及执行记录的后续章节为准。

## 1. 当前职责与链路

```text
architecture：一次形成完整图纸
    ↓
material_plan：解析材料
    ↓
design_review：展示图纸，确认或修改
    ↓
plan：从图纸标记展开任务，准备空 WILD 容器
    ↓
execute / replanner：落实标记，保留实际实体与尝试证据
    ↓
compile：统一装配、完整检查；整体问题回到原任务
    ↓
final_validate：完整通过才交付 .wild
```

`intent`、`massing`、`structure`、`facade`、`roof`、`components` 只保留为局部修订的字段归属，不再是首次设计的六个模型任务。首次 architecture 一次输出完整方案，只有 JSON 格式或图纸自身矛盾才要求修订。

architecture 可以描述新屋型、新构件、材料、空间布局和关系。设计字段支持扩展，构件 type/form 不按引擎类型白名单拒绝。保留的图纸检查是基本数据一致性：稳定 ID、正尺寸、楼层与体量范围、立面数组长度等；不在这里证明当前程序已经能实现设计。

`design_review` 直接读取同一份图纸展示逐层平面、立面示意和构件标记，不先生成模板建筑。当前示意图主要展示体量轮廓和标记；自定义房间与曲面描述会进入 plan，预览还不能完整绘制所有扩展造型，也不是施工图验收。

## 2. plan 如何落实图纸

每个标记有稳定 ID、原始设计、宿主与依赖。主体任务负责墙、板与结构；楼梯交通、门窗、屋顶及显式附属件成为后续任务。立面与显式构件按位置及构件族对应，单个显式实例不会吞掉同墙全部标记；明确阳台接管同位置的概略阳台，保留该开间的窗。

一个图纸标记可以对应多个 WILD 元素。plan 从空容器开始，由模型编写实际 `geometry.elements/components`、材料和资产定义；不再只填写已经编译好的模板中的 detail_fields。原生类型不足时，可以用 primitive 或其他有效元素组合形态。

每个条目按以下流程实现：

1. 先检索当前构件的知识、构造和 JSON 示例。
2. 缺少必要形态资料时才检索网络；已有原生形态或明确图纸几何时直接利用模型知识。
3. 结合当前标记、实际宿主、参考资料和相关 WILD 字段生成。
4. 校验失败只修失败标记与实体，保留已通过的实体，最多两次局部修订。

成功便停止后续调用；修订复用已检索资料，不为每个检索阶段再调用模型。主体单独执行，其他依赖已落定的条目每批最多三项并发，各自保留思考。知识库或网络无结果、不可用时会记录原因，仍继续模型实现。参考内容作为数据传入，不作为修改用户要求的指令。网络查询仍使用 Bing RSS；先前真实请求经常返回无关内容，不能把接入搜索当作可靠图纸检索已完成。

每次局部结果检查标准 JSON、WILD Schema、尺寸、必填字段、引用和开口坐标。模型负责构件形态与构造组合；已确定的直墙门窗安装位置由程序统一换算，保持尺寸和组内分格，并记录转换前后值。architecture 不需要先迎合模板参数。

相连矩形体量的同向共面外墙，自动立面在重叠区域只派发一份默认布局，优先沿较长墙展开，等长时按体量 ID 稳定对应。明确构件实例保持原设计。同构造墙的实体装配只保留一份重叠段及全部外露段；门窗可沿原图纸换算到裁分后的真实宿主，安装范围不满足时仍要求修订。当前标记投影版本为 `drawing-projection/8`，旧缓存不能继续使用重复标记。

## 3. 完整装配失败与舍弃

局部通过还要经过完整装配检查。整体问题回到对应原任务，仅提交失败标记的实际片段与反馈，允许一次装配修订。尝试进度按标记保存，批次里成功的其他构件保留。

宿主重做时，依附它的旧实体同时移除并重新落实，防止无效引用阻止新宿主通过局部检查。所有尝试耗尽后，舍弃失败构件并清理其依赖与引用；再对剩余建筑完整检查。

原设计不被删改。交付报告单列落实与舍弃记录，包含真实实体 ID、来源、模型输出、检查错误和原因。没有尝试记录不能声明“已经舍弃”；主体失败或剩余文件无效时，生成明确失败，不提供最终文件，也不再转入另一套旧 callback 修复循环。

每个标记最多一次生成、两次局部修订与一次装配修订。主体自身失败时立即停止附属件生成。模型调用与迭代上限按标记数计算；审核恢复时按实际标记数计算图步骤。原有连续两轮无进展规则不再提前打断建筑的必需尝试。

几何有效与设计准确度分别记录：组合构件的外观、空间用途和建筑审美仍需渲染及人工确认，不能从生成数量或流程完成推断已经满足。
