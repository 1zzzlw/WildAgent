# 项目版本固定

日期：2026-10-13。

未上线阶段，普通修复和优化不递增版本。当前功能、字段、建筑能力和已有修复保留；版本标记恢复各自首版。只有用户明确要求发布或迁移时才调整版本。

| Core、Web、Server 软件包 | `0.1.0` |
| WILD 蓝图 | `1.0` |

| 知识配置、集合新建标签 | `1` |
| 知识检索修订标签 | `rules-v1` |

前后端默认蓝图、模型上下文、WILD Schema 和活动知识文档已同步。DesignDocument 的导出 Schema 从当前契约重新生成，现有自由设计、物件和构件字段继续保留。

删除了 WILD `1.0 → 1.1` 的自动升版函数，以及按旧图纸版本把整面 `empty` 改成 `open` 的迁移逻辑。历史 WILD `1.1`、图纸 `design/1.1`～`design/1.3` 仍可读取，只归一化版本标记，不改写立面语义；未知版本继续由契约拒绝。历史 trace、建筑文件和按日期记录的文档不批量改写。

场景、图纸和 plan 的 `revision` 是编辑次序，撤销与补丁冲突判断仍依赖它。第三方依赖、LangGraph `astream_events(version="v2")`、GLSL 语言版本与 Chroma 向量兼容签名算法继续遵循现有契约。旧向量签名没有被改写，也没有删除集合重建。

没有新增版本管理框架、开关或生成节点。校验缓存继续核对产物指纹和批准设计；渲染比较继续绑定源码与配置摘要。开发代码修改后应重启对应服务、刷新前端，再进行新的生成测试。
