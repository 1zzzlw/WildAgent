# 全构件拖拽与渲染优化

日期：2026-10-13。

## 修改原因与使用方式

旧视口只给单个、显式设置 `draggable:true` 的组合构件显示移动控件。Agent 直接生成的 `geometry.elements` 墙、柱、楼板等虽然能选中，却不能拖动；渲染合批中的实例也没有单独移动的预览处理。

现在在**编辑模式**中，从场景树或三维视口选择源构件，拖动三轴控件即可移动。当前可渲染的原生元素和组合构件默认均可移动；组合构件显式设置 `draggable:false` 时仍保留锁定。Ctrl/Shift 多选沿用原有选择操作，可以一起移动。组合构件生成的多个网格仍作为同一个源构件编辑。

位移通过现有 ScenePatch 写回 Blueprint，接入原有校验、重建和撤销重做。导出 `.wild` 后重新打开会保留位置。无效移动恢复原位置并显示失败原因。

## 具体修复

| 位置 | 修改与原因 |
| --- | --- |
| `wild-web/src/wild/componentDrag.ts` | 统一源元素与组合构件的平移。墙、楼板、梁、楼梯修改端点；柱修改 base；其他形状修改自身位置或路径。无显式位置的屋顶复用已有定位解析，避免移动时跳回原点。 |
| `wild-web/src/components/viewport/CanvasViewport.vue` | 选择不再限于构件库对象；普通网格和 InstancedMesh 的选中实例均可预览位移，松手提交一次修改。 |
| `wild-web/src/components/panels/PropertyPanel.vue` | 组合构件的拖动开关默认值与视口一致。 |
| `wild-core/src/primitive/index.ts` | 删除旧的瓦片网格合并分支。它会丢失源 ID，并遗漏旋转；相同几何继续由现有渲染实例化合批，保留逐实例身份。 |
| `wild-core/src/primitive/geometry/column.ts` | 原柱面法线只按圆柱径向计算，忽略已有收分、柱槽与倾斜。改为由柱面的两个切向推导法线，并缓存重复顶点结果；尺寸、形状和分段数量不变。 |
| `wild-web/src/renderer/materialFeatures/` | PBR 天气层原来混用模型与视图空间法线；默认材质的 flatShading 分支遗漏实例变换。均复用 Three.js 已计算的 transformedNormal 还原世界法线，并更新 shader 缓存版本。 |

移动墙时，依附门窗的沿墙距离与法向进退保持不变，世界 Y 标高随墙移动。墙和门窗同时选中时也只移动一次。这是宿主坐标关系的编辑处理，不加入建筑类型、构件 ID 或特定建筑坐标规则。

## 已完成验证

- `npm run build`：通过；保留原有包体积警告。
- `node scripts/check-component-compiler.mjs`：通过；包含源墙柱移动、宿主门窗联动、显式锁定、序列化重载及各类型坐标字段检查。
- `node scripts/check-wild-core.mjs`：14 份样例通过；新增柱面法线与瓦片源 ID、旋转保留检查。
- `node scripts/check-rendering-pipeline.mjs`：通过。
- 独立 Edge 中使用实际殿宇文件验证鼠标拖拽：合批中的单根柱子移动，其他柱不变；墙垂直移动时门标高跟随；门可独立移动；工具栏撤销、重做有效。
- 工具栏导出文件实际下载落盘，重新打开后 `geometry` 与导出前完全一致。
- 实际将门拖出宿主墙水平范围：修改被拒绝、原位置恢复，界面显示具体越界原因。
- 真实 WebGL 检查默认/PBR 材质的普通与实例网格、平滑与平面着色、非均匀缩放和两个相机位置：8 组检查均无 shader 错误；法线像素误差不超过 0.004，两个相机位置结果一致。默认材质平面实例的误差从约 0.298 降至约 0.002。
- 同一原始 `.wild`、相同灯光与相机的四视角对照渲染：编译和重建错误为零，柱槽明暗更清楚。验证使用保存的文件，没有调用模型重新设计建筑。

## 本地证据与边界

证据目录：`wild-server/storage/sessions/diagnostics/editor-drag-render-20261013/`。

- `verification.json`：交互和 WebGL 数值证据。
- `ui-interaction-results.json`：拖动、联动、撤销与重载结果。
- `exports/`：实际从浏览器导出的文件。
- `before-render/`、`final-render/`：四视角图片及输入 hash、渲染配置和源码摘要。
- `*-final.log`：检查与构建日志。

本次完善编辑与渲染链路，未改变 architecture、plan、RAG 或生成提示词。移动操作保持几何编辑的现有校验边界，不等于重新审批建筑功能关系；不同模型重新生成建筑的稳定性仍需单独测试。展示模式及线框查看沿用原有交互限制，无法生成有效网格的实验类型也不会因此获得渲染能力。
