# 听澜合院 · 新中式别墅

## 用户要求与执行方式

用户要求创建多个精致的 WILD 建筑，依次给出名称；本轮先创建新中式别墅。效果至少达到 `docs/10月20日优化/汀院别墅-Codex.wild`，全部创建过程按类别保存至 `docs/10月22日`。

本次由当前对话中的 Codex 设计并编写确定性 Python 生成脚本，输出严格 JSON 的 WILD 1.1。使用当前 Core 校验和 Chromium/WebGL 真实渲染，不调用项目配置的聊天模型，不声称运行完整 LangGraph。只新增当前日期目录的文件，不修改应用源码或旧建筑。

## 方案

建筑命名为“听澜合院”。20 米宽的两层主楼位于北侧，西侧单层茶室、东侧单层书斋与院墙形成非对称合院。庭院由月洞门进入，沿池侧石径到达首层门厅，北侧内楼梯连接二层卧室和院向木栏露廊。

- 场地：约 26 × 23 米；主楼轴线 20 × 7 米，室内首层顶面 0.50 米，二层顶面 4.05 米，主楼墙顶 7.35 米。
- 体量：两层主楼、西侧较长单层茶室翼、东侧较短单层书斋翼；三组灰瓦四坡屋面，屋面高低有序，中央庭院露天。
- 屋面：原生 `hip` 实体薄壳，另加沿坡向的瓦垄、横向瓦缝、正脊、斜脊、檐板与檐下木构；避免只有一块无细节的灰色屋面。
- 立面：暖白灰泥、青灰石勒脚、深木色窗框和格栅、低反射玻璃；洞口由真实 `door/window` 组件裁墙，墙面装饰避开门窗。
- 庭院：有实体圆环的月洞门、浅水池与池底、池岸压顶、石径、景石、修剪树、小灌木、竹丛、枯山水和夜间灯体。
- 室内：起居、餐厨、茶室、书房、卧室、卫浴和两跑楼梯；放置沙发、茶几、餐桌椅、厨房、床、床柜、书架及柜体，保留通行空间。
- 二层露廊：楼板、真实支承柱、木金属栏杆与竖向格栅；梯井明确留洞并配护栏。

## 验收口径

1. JSON Schema、ID、材质和宿主引用有效；当前 Core 解析、组件编译和网格重建没有错误，所有网格与包围盒为有限数。
2. 门窗在宿主范围内且不重叠；楼梯两跑连平台，楼板留井口，上下落点有承接。
3. 原项目脚本对参考和新作使用同一份相机规则、光照、尺寸和引擎源摘要出图，检查正面、侧面、俯视、透视。
4. 额外查看剖切，确认室内不是空壳；保留初稿与修订，不用提高亮度或后期效果代替建筑细化。
5. “更优秀”是审美判断。交付提供逐项实图比较和作者复核，不将网格数或零错误当作审美证明。
