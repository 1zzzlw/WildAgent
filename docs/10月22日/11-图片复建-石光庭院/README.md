# 林庭石光馆 · 图片复建

正式文件：[林庭石光馆.wild](林庭石光馆.wild)

右高左低的体量、两层各四组高窗、右侧两扇竖窗、木饰单层翼、玻璃露台、屋顶绿化、四片方锥天窗和六级宽阶。

推定地块32×32米，层高3.75米。参考没有标尺，背面、室内和隐蔽交通由本次设计补齐；这些推定已与图片可见事实分开记录。
