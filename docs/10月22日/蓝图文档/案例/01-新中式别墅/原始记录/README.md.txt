# 听澜合院 · 新中式别墅

正式文件：[听澜合院-新中式别墅.wild](听澜合院-新中式别墅.wild)。

![真实引擎透视图](05-效果图/perspective.png)

两层主楼与高低错落的单层茶室、书斋形成合院，包含灰瓦四坡顶、逐道瓦垄、月洞门、木格栅、池院、二层露廊、两跑楼梯以及餐厨、起居和卧室家具。由本次 Codex 重新设计，未复制参考建筑。

最终为 r3：1,165 个基础元素、62 个组合构件、26 种材质；当前 Schema 与原项目 18 项校验零错误、零警告。真实 Chromium 渲染得到 1,534 个网格，编译错误、重建错误、未映射材质均为 0。正式外观和两份剖切共 12 张图已出图，作者已查看四视外观及两幅剖切俯视。

与汀院采用完全一致的引擎摘要、浏览器、相机、灯光及 1280×960 出图设置。作者判断屋面构造、入口、廊道和中式风格层次更细致；建筑风格不同，审美是否达到你的预期以实图为准。零错误只证明对应自动检查，不包含施工、结构安全及完整导航验证。

复现：在项目根目录使用 `wild-server/.venv/Scripts/python.exe` 运行作者脚本，再运行公共 `校验蓝图.py`、项目 `validate-generated.mjs` 与 `render-baseline.mjs`。完整精确命令保存在 `03-过程记录/命令记录`。重放到同一目录会覆盖同名产物，请先另存旧版本。
