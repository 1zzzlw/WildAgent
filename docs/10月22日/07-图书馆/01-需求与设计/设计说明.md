# 知序图书馆

中央开敞庭院贯通两层，环绕布置书架与阅览席；前庭台阶和细柱雨棚形成公共入口。

地块：32×32米，含庭院与入口；主体边界[-12, -8, 12, 12]。共2层，层高4.2米，首层完成面0.4米。

- 入口咨询与新书展示
- 首层开放书架与阅览席
- 二层安静阅览
- 贯通庭院
- 双跑楼梯

精细化内容：石材分缝与勒脚、入口悬挑雨棚及承托、赤陶遮阳片、庭院环廊栏杆、书架书脊与阅览家具、可保存中文招牌、真实灯光。

招牌正面朝向街道（世界−Z），文字存于label.text。灯罩的emissive负责可见亮面，lightSource负责照亮周围。

这是本次独立设计，未读取或复用旧三层别墅设计。作者编译不使用Agent、RAG或模型API；结构验证和审美验收分开记录。
