# 邻里优选超市

正式文件：[打开 邻里优选超市.wild](邻里优选超市.wild)

地块 **16×16米**，包括入口、庭院和景观；主体退进地块边界。连续招牌、双面分区货架、商品、生鲜、冷藏柜、收银、后场与推车。

主招牌文字为“邻里优选超市”，直接保存在 `geometry.elements[].label.text` 中，朝向世界−Z。共有5个自制灯罩使用 `lightSource`，能照亮周围；不只是材质自发光。正式文件有574个基础元素、7个组合构件，数量只用于核对文件，不充当精细度评价。
