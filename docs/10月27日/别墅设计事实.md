# 岚石光庭：原创别墅设计事实

本方案按当前 WILD 参数化能力原创生成，不复制既有别墅，不以 GLB 或内嵌网格替代建筑。采用两层 L 形体量，北侧生活主翼与西侧卧室翼围合东南水庭，以洞石立面、暖白抹面、胡桃木遮阳与通透窗墙形成层次。

- 用地约 30×27m；北侧主翼 17×7m，西侧翼 6×7m；东南侧泳池和木平台。
- 首层完成面 Y=0.32m，二层 Y=3.72m，层高 3.40m；楼板厚 0.30m，主要墙厚 0.24m。
- 首层为起居、餐厨、入口及客卧；二层为主卧、书房和临水露台。楼梯与电梯双交通，电梯井贯通二层楼板。
- 电梯入口朝 +Z；轿厢宽深 1.8m、高 2.55m；中心 X=-6.2、Z=-4.45；层门宿主墙 Z=-3.47m，各层按钮与入口分开。上层楼板留出井道和楼梯洞口。
- 楼梯净宽 1.10m，20 级，每级 0.17m，水平踏步深 0.28m；从首层后厅通至二层走廊，不以视觉线条代替可走踏步。
- 吊扇放在首层起居室，开关位于北侧厨房端部可达墙面，距地约 1.1m；面向 +Z，与电梯按钮分别管理。
- 材质按库中真实配方使用：石灰抹面、清水混凝土、洞石、浅石砖、陶土砖、橡木、胡桃木、石英石、亚麻、拉丝金属、清透/磨砂玻璃；泳池另设水材质。
- 尺度细节包含门窗洞口与框、阳台玻璃栏杆、遮阳格栅、屋檐分层、室内家具与厨房台面、照明灯体、台阶、花池与池壁。木纹与板缝保持米制尺寸。
- 出图使用正式 Three.js 管线的精细质量，日景、夜景、室内、材质近景和交通交互分别留证。俯视剖切图须明确记录隐藏对象；外景和室内正式视角不靠删墙取景。

“引擎最大限度”在本交付中指充分使用现有可运行的参数材质、物理玻璃、各向异性金属、阴影、环境反射、GTAO、水面反射与细节构造，不宣称离线路径追踪或建筑写实效果的理论上限。渲染后按实际截图调整，并记录未达到的边界。
