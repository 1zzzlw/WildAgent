# 使用与复现

## 直接使用

1. 启动项目后，导入同目录的 `岚石光庭-交互材质别墅.wild`。
2. 在视口中选择“精细”质量、白天或夜晚，可查看木纹、石材、玻璃、织物、灯光和水面反射。
3. 电梯位于北侧核心筒，世界坐标约 X=-6.2、Z=-4.45，入口朝 +Z。点击层门旁按钮呼梯；进入后点击轿内 `1` / `2` 选层，`◀▶` 开门，`▶◀` 关门。编辑 / 展示视图可直接左键点设备按钮；人物漫游中瞄准按钮后右键操作。
4. 起居室吊扇开关位于北侧厨房端部墙面，约 `[7.7,1.45,-6.85]`。点击按关闭、低速、高速循环。电机中心约 `[3.1,2.91,-2.25]`。
5. 在“材质”面板点击内置预设；有选中构件时应用到适配部位。属性面板可以选择机身、扇叶、轿厢、门板、地板等不同部位的材质。保存后完整配方随 `.wild` 存储。

电梯 `initialFloor` 使用 0 起始序号，位置 Y 是初始停靠层完成面；轿厢高 / 宽 / 深是几何尺寸。独立蓝图使用电梯时必须为行程设置真实井道与上层楼板洞口。`landingWalls` 按楼层顺序列出入口墙；当前入口墙沿 X 轴，Z 为 `position.z + dimensions.depth / 2 + 0.08`。

## 作者输入

设计依据是[别墅设计事实](./别墅设计事实.md)。在仓库根目录运行：

```bat
node docs/10月27日/生成岚石光庭.mjs
```

该脚本只写同目录的交付 `.wild`，不调用模型、不读取 `.env`、不删除原项目文件。

## 复现验证

在 `wild-core` 执行：

```bat
node node_modules/typescript/bin/tsc --noEmit -p tsconfig.json
```

在 `wild-web` 逐条执行：

```bat
npm run build
node scripts/geometry-regression.mjs
node scripts/check-opening-interactions.mjs
node scripts/check-mechanisms.mjs
node scripts/validate-showcase-villa.mjs
```

浏览器检查使用本机 Chromium 和独立临时浏览器配置，不连接用户的浏览器会话。启动 `wild-web/scripts/serve-editor-smoke.mjs` 后，使用 5178 测试服务：

```bat
node scripts/material-mechanism-smoke.mjs
node scripts/ride-physics-smoke.mjs
node scripts/render-showcase-villa.mjs
```

完整编辑器验收还需在 `wild-server` 启动 `.venv\Scripts\python.exe scripts\ci\editor_smoke_server.py`，它使用独立临时存储、禁用 RAG 与追踪，不发起模型请求。然后在 `wild-web` 运行：

```bat
node scripts/viewport-mechanism-smoke.mjs
```

后端局部检查在 `wild-server` 运行：

```bat
.venv\Scripts\python.exe -m pytest scripts/ci/test_surface_presets.py scripts/ci/test_dynamic_components.py scripts/ci/test_asset_storage.py -q
```

本机若 Node/Python 启动缺失系统目录环境，可先在同一命令窗口设置 `SystemRoot=C:\Windows` 和 `WINDIR=C:\Windows`；这属于测试进程环境，无需修改项目 `.env`。
