## 本次引擎改动

- 水面视锥剔除与静态捕获缓存；运动捕获上限30次/秒，截图强制更新；可见水仍动画，离屏水不再单独维持帧循环。
- 局部灯按照射球筛选；逐灯阴影失效，增量更新保留贴图，移动灯和几何编辑刷新；局部灯选择变化不再顺带重算主方向光。
- 太阳阴影按光空间矩形拟合，保留长影和高瘦建筑深度覆盖；切档更新贴图及按纹素计算的normalBias。
- 关闭/静止的风扇和电梯不再逐帧重写全部成员变换。编辑器与离线均只有精细档捕获水面场景反射，均衡档保留环境反射。

同条件静止夜景绘制调用中位1152→690，约减少40%；移动相机仍为1152。实际耗时以[原始优化前](验证/性能优化前.json)、[最终优化后](验证/性能优化后.json)和[比较](验证/性能比较.json)为准。绘制调用不是FPS，本机结果不能代表所有建筑和设备。

## 复现

仓库根目录执行作者脚本，仅重放这三项已设计作品：

```text
node docs/10月27日/渲染性能光影与三种别墅/生成三种别墅.mjs
node docs/10月27日/渲染性能光影与三种别墅/运行最终检查.mjs
```

真实浏览器检查先在wild-web执行node scripts/serve-editor-smoke.mjs（5178）；完整编辑器检查另需wild-server/.venv/Scripts/python.exe scripts/ci/editor_smoke_server.py，它使用临时存储，不调用模型。在wild-web执行：

```text
node scripts/render-performance-smoke.mjs
node scripts/render-optimization-smoke.mjs
node scripts/render-three-villas.mjs
node scripts/viewport-villa-performance-smoke.mjs
node scripts/viewport-mechanism-smoke.mjs ../docs/10月27日/渲染性能光影与三种别墅/验证
```

生成和渲染只是项目内验证，没有运行LangGraph/RAG或远程模型。仍无真实全局光照、彩色透射阴影、光线追踪、工程结构/法规认证或新三案全空间人物行走证明。基础家具、植被与部分微纹理仍是参数化近似，用户对风格和画质的评价不由测试替代。
