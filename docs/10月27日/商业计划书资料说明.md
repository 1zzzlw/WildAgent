# 商业计划书 Vue 页面与工作台主题

## 最终交付

用户最终选择只维护 Vue。已删除独立 HTML 计划书、HTML 导出脚本和中间 HTML/CSS/DOM 脚本，原项目根目录介绍文件保留。

- [BusinessPlanDocument.vue](../../wild-web/src/features/business-plan/BusinessPlanDocument.vue)：纯 Vue 单文件组件，包含模板、响应式试算、作品循环、大图对话框、目录与样式。没有 v-html、iframe 或外部 HTML 模板。
- [BusinessPlanView.vue](../../wild-web/src/views/BusinessPlanView.vue)：计划书路由页面。
- [路由](../../wild-web/src/router/index.ts)：/ 为建筑工作台；/business-plan 为计划书，支持直接打开与刷新。
- [WorkbenchView.vue](../../wild-web/src/views/WorkbenchView.vue)：从原 App 移出的工作台，通过 KeepAlive 保留场景与画布；计划书显示时停止视口循环，返回后恢复。
- [themeStore.ts](../../wild-web/src/stores/themeStore.ts) 与 [style.css](../../wild-web/src/style.css)：亮暗主题与 Element Plus 配色。默认亮色，本地保存选择。暗色采用原工作台底色与表面色；亮色使用米白、深绿与低饱和橙。

工作台顶部及访客入口提供计划书入口，计划书右上角回到主页。公开页面移除了版本、日期、取材来源、仓库路径和文档引用；定价、试算和增长目标仍标为建议或假设。

计划书直接复用工作台的 studio 主题变量与全局 color-scheme，不再固定为浅色。正文、导航、卡片、表格、输入框、强调区域和图片弹窗跟随主页选择；独立刷新同样读取已有主题偏好，不增加第二份主题状态。

## 产品定位

以项目 README、根目录介绍、蓝图语言和用户补充为写作依据，网页不展示内部取材信息。强调成熟智能体可以依据文档、规范与示例编写丰富的小体积 WILD 蓝图；自研参数化几何、编译校验与基于 Three.js 的渲染编辑工作台承接资产。自研 Agent 同步开发，资源有限，目前复杂创作效果和成熟度仍落后于成熟智能体。

没有把显示库全部声称为自研，也没有把本轮截图声称为新完成的 Agent 全链路生成、客户交付或用户验收。

根据 README 与根目录项目介绍进一步补充了蓝图保存的建筑语义、参数化轻量表达、Core/Vue/Three.js 的职责、DesignDocument/Blueprint/ScenePatch 三份契约，以及局部修改示例。应用与路线增加方案交流、设计学习、场景内容、按需检索、预算控制、失败草稿保留、表现层独立迭代和外部服务接入，并区分风格、材质、光影与世界包的现有基础和规划中的产品化工作。

依据根目录项目介绍的“能力边界与发展规划”补充四档自研 Agent 目标范围（minimal、simple、standard、detailed），明确区分蓝图表达、引擎重建与自动生成稳定性。自动房间布局、场地语义规划、专业二维平剖面交付，以及任意有机造型和扫描级细节均列出当前边界，没有把早期文档中的稳定性描述当作本轮实测结论。

发展规划细化为光影扩展包、材质扩展包、扩展制作页面、世界导入与效果预览、建筑编辑增强、生成稳定性收敛六项；每项分别写出现有基础和仍需完成的交付、验收工作。

## 手机与电脑布局

电脑端保留侧边目录、表格对照与双列建筑作品；640 像素及以下采用横向章节目录、单列作品和带字段标题的条目卡片，避免长表格需要左右拖动。所有表格单元格保留对应列名；原表头仍保留在辅助技术可读取的结构中。图片继续按原始比例展示，可点击放大。

页面作为独立路由占满视口并自行滚动，修复长页跳转时外层窗口一起滚动、导致顶部导航离开屏幕的问题。手机端返回主页按钮与章节目录在深处阅读时保持可见。亮暗配色继续使用主页共享主题变量。

本轮在真实 Chromium/WebGL 中，使用项目 Core、材质、光影与后期模块读取既有 WILD 重新渲染。没有生成图片替代渲染，没有隐藏墙体或屋顶。

1. [首批渲染清单](./商业计划书素材/render-manifest.json)：8 个既有项目，共 28 张新截图。

3. [工作台截图清单](./商业计划书素材/workbench-manifest.json)：独立浏览器真实导入岚石光庭，拍摄场景树和材质面板。
