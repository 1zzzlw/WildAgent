# PBR 素材导入操作说明

## 1. 进入导入界面

1. 启动 WILD 前端和服务端，并打开一个蓝图场景。
2. 在右侧面板选择“素材”。
3. 进入“PBR 素材入库”。

## 2. 填写素材信息

- 素材名称：使用能说明颜色、材质和用途的名称，例如“新中式深灰屋面陶瓦”。
- 材质 ID：使用不重复的英文名称，例如 `roof_tile_dark_gray`。
- 授权信息：填写 `CC0`、`User supplied` 或素材实际授权方式。
- 材质类别：选择石材、混凝土、砖、木材、金属、抹灰、瓷砖等正确类别。
- 检索标签：使用英文并用逗号分隔，例如 `dark_gray, clay_tile, new_chinese, seamless`。
- 推荐角色：填写下表中的准确英文角色，多个角色用逗号分隔。

| 推荐角色 | 用途 |
| --- | --- |
| `facade_primary` | 建筑外墙主材 |
| `structure` | 柱、梁等结构构件 |
| `floor` | 楼板、台阶和地面铺装 |
| `frame` | 门窗框、金属框架 |
| `door` | 门扇 |
| `roof` | 屋面 |
| `ground` | 室外地面 |
| `accent` | 装饰和点缀材质 |

## 3. 填写物理参数

- 粗糙度：非金属材质通常为 `0.5–0.9`，数值越大越粗糙。
- 金属度：石材、木材、抹灰通常为 `0`；金属通常为 `0.5–1.0`。
- 真实宽度和高度：填写整张纹理实际覆盖的米数，用于保持砖瓦、木纹等比例正确。
- UV 横向/纵向重复：不确定时保留 `1`。
- 法线强度：不确定时保留 `1`。

## 4. 上传纹理图片

`Base Color` 必须上传，其他贴图可选：

- Base Color：表面颜色，不应带有明显光照和阴影。
- Normal：表面凹凸细节。
- Roughness：粗糙度分布。
- Metalness：金属区域分布。
- Ambient Occlusion：缝隙和接触区域的遮蔽效果。

图片支持 PNG、JPEG 和 WebP。建议同一套贴图分辨率一致，并可无缝平铺。当前不支持 Height 或 Displacement 高度贴图。

## 5. 完成导入

1. 如需立即应用到某个构件，先在场景中选中该构件，并勾选“入库后绑定到当前选中构件”。
2. 点击“入库并写入场景”。
3. 在下方“本地资产”列表中确认素材已经出现。
4. 重新生成建筑时，材质规划节点会根据名称、类别、标签和推荐角色自动选择合适的 PBR 资产。

## 6. 推荐示例

| 素材 | 类别 | 推荐角色 | 标签示例 |
| --- | --- | --- | --- |
| 白色细砂抹灰 | `plaster` | `facade_primary` | `white, stucco, new_chinese, seamless` |
| 深灰陶瓦 | `tile` | `roof` | `dark_gray, clay_tile, roof, new_chinese` |
| 深色喷涂金属 | `metal` | `frame, accent` | `charcoal, powder_coated, metal` |
| 深色木门 | `wood` | `door, accent` | `dark_wood, door, new_chinese` |
| 灰色石材铺装 | `stone` | `floor, ground` | `gray_stone, paving, seamless` |

## 7. 常见问题

- 显示“匹配 0 个”：通常是素材名称过于简单，或没有填写类别、英文标签和推荐角色。
- 推荐角色报错：只能填写本说明列出的英文角色，注意不要使用中文或空格。
- 重新上传后信息没有变化：完全相同的纹理会按内容哈希去重，并返回已有资产记录。
- 玻璃没有匹配贴图：这是正常现象；玻璃使用透射率、折射率等程序化物理材质，不使用 PBR 图片资产。
