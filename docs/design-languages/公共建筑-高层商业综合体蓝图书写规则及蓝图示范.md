# 公共建筑 · 高层商业综合体蓝图书写规则及蓝图示范

> 版本 v1.0 ｜ 2026-09-23 ｜ 生成器 `gen_commercial_complex.cjs` ｜ 独立校验 `verify_commercial_complex.cjs`（24 项）
> 蓝图示范：`高层商业综合体.wild`（496 元素 / 13 组件 / 60.9KB / minY=−0.020，三级体检 + 独立校验双通过）
> 上位规范：《WILD蓝图设计语言》v1.2；本文档为其「公共建筑类」第一条类型配方，与住宅类规则并列。

## 0. 定位与适用范围

- **适用**：底层商业裙房 + 高层办公/酒店玻璃幕墙塔楼的城市综合体（含裙房商业、办公塔楼、单塔或子母塔）。不适用：纯商业步行街（无塔楼）、超高层 (>100m 需另设避难层/停机坪)。
- **双子结构**：综合体 = 「裙房 podium（集中商业大空间）+ 塔楼 tower（标准层重复堆叠）」两个子结构拼装；塔楼整体坐落在裙房屋面之上，两套层高体系独立。
- **书写顺序**：场地地基 → 裙房（自下而上）→ 裙房屋面（= 塔楼首层楼面，井道留洞）→ 塔楼标准层循环 → 顶部收头。

## 1. 形制总表（先定高度，再定平面）

| 维度 | 推荐值 | 规范/依据 |
|---|---|---|

| 塔楼标准层层高 | 3.9m（办公 3.6–4.5 区间取中） | 办公标准层 3.6–4.5m |

| 核心筒占比 | 20–25%（本示范 21.4%），集中式 | 核心筒系数 20–25% |
| 柱网 | 裙房 9.0×9.0；塔楼边柱距核心筒 11–13m | 8.4×8.4 或 10.8×10.8 / 12×12 亦可 |
| 总高 | 示范 93.75m（一类高层 <100m，免设停机坪） | >100m 加避难层、停机坪 |

| 幕墙占比 | 塔楼立面玻璃 ≥60–70%，反射率 <30% | 玻璃反射率宜 <30% |

**防火分区速查（GB50016）**：高层主体 1500㎡（设自喷 ×2=3000）；裙房与主体间设防火墙时按单多层 2500㎡（×2=5000）；商店营业厅设自喷+报警+不燃装修 ≤4000㎡；**设明火餐饮的防火分区降为 3000㎡**；中庭上下连通面积叠加计算。

## 2. 形制决策链（书写第一步）

1. **定总高**：≤100m 走一类高层；>100m 每15m 设避难层（蓝图须加避难层楼板+外窗）。
2. **定标准层**：面积取 ~1400㎡；核心筒 = 面积×20–25%，集中式布置（楼梯间+电梯井+前室一次排开）；反推柱网与外框进深 8–12m。
3. **定登高面**：选塔楼一个长边作消防登高面 → **该侧裙房进深 ≤4m**（硬约束，先于裙房平面确定）；场地 ≥20×10m（>50m 建筑）、距建筑 5–10m、坡度 ≤3%，对应范围设直通室外楼梯。
4. **定裙房**：层数 2–4；首层沿登高面以外布置主入口（大堂直通室外）；柱网 9×9 大空间。
5. **定立面**：三段式配比 → 塔楼「层间裙墙 0.8 + 玻璃带」的竖向节奏 → 顶部收头（女儿墙+机房+飘板）。

## 3. 坐标、标高与模数（综合体口径）

- ±0.000 = 室外地面（渲染地面 y=0）；首层室内地坪顶 = **+0.45**（3 级台阶×0.15），与住宅类口径一致；整栋坐于实心地基之上（写法同住宅 §4.9：顶 +0.45、底 −0.02、四面出挑 0.06）。
- **双标高链**：裙房链 `Y1=0.45 → Y2=5.85 → Y3=11.25 → YP=15.75`；塔楼链 `yT(n)=YP+(n−1)×3.9`，`yT(1)=YP`（塔楼首层地面 = 裙房屋面，**不重复写板**，由裙房屋面 4 块拼板承担）。
- **井道自 YP 起贯通**：塔楼核心筒井道区（楼梯间+电梯井）从 YP 向上每层无板；YP 以下裙房层满铺板属正常（核心筒墙体自 YP 起才存在）。
- 模数：关键尺寸循 0.3m 模；**层间裙墙 0.8m 是规范强制值，不参与模数检查**。
- 塔楼平面：示范 42×30（x 6–48，z 4–34）——z=4 即「登高面侧裙房进深 4m」的落地；其余三侧裙房外露 6m。

## 4. 构件书写规则

### 4.1 塔楼幕墙（本类型第一特征，逐层配方）

每标准层四向各一对「裙墙 + 玻璃带」，**0.8 + 3.1 = 3.9 严格无缝**：

- 层间实体裙墙：`wall` 元素，厚 0.2，`from[1]=yT(n)`，高 0.8（JGJ102/GB50016 3.0.8.3 层间封堵：每层楼板外沿实体裙墙 ≥0.8m（设自喷），内衬镀锌钢板承托+岩棉——封堵构造不建模，裙墙体块即其承重表达）。
- 玻璃带：`primitive box`，厚 0.1，高 3.1，中心 `yT(n)+0.8+1.55`，顶面必须 = `yT(n)+3.9`（自检断言：幕墙不得留缝，留缝 = 楼层悬浮）。
- **材质分制（红线）**：幕墙玻璃 `gc` = `materialClass:"clearcoat" + clearcoat:1 + transmission:0 + 带色 baseColor + 低 roughness + 中高 metallic` → 带色反光、看不到内部；**严禁用透明 `gl`（transmission 0.92）写幕墙**，否则塔楼内部核心筒全外露。橱窗/门扇才用透明玻璃。
- 同一幕墙单元不宜跨防火分区（≤3000㎡/单元区段）；开启扇 ≤15%、上悬 ≤30°——蓝图以救援窗口金属框示意开启扇，不逐扇建模。
- 幕墙单元下无窗间墙（室内侧）应设护窗栏杆；玻璃反射率 <30% 记入 meta.note。

### 4.2 塔楼楼板（五块拼装 + 井道留洞）

标准层板拆 5 块：`slA`（南带，至井道南缘 z=22）/ `slB`（井道西侧 x6–12）/ `slC`（前室 x25.2–30，**前室必须有板**）/ `slD`（核心筒东侧 x30–48）/ `slE`（北带 z27–34）。井道无板区 = 楼梯间 x12–16.8 + 电梯井 x16.8–25.2（共 x12–25.2 × z22–27）。**铺满 = 电梯井与楼梯井堵死**。厚度 0.15（金属复合楼板抽象）。

### 4.3 塔楼核心筒（六墙职责的公建简化）

每层 4 道剪力墙（`cw/ce` 东西 + `cs/cn` 南北，厚 0.24）围合 18×15=270㎡；内部楼梯间/电梯井/前室以「井道无板区 + 楼梯构件」表达，隔墙省略。**2 部疏散楼梯**为 >18 层硬要求，蓝图抽象为 1 部双跑（占位井道），在 `editor.params.tower.stairs` 声明；3 台电梯（≥1 台消防电梯）同此声明。

### 4.4 裙房立面（商业语言，与塔楼区分）

- 首层：实墙 + 橱窗组件（4.5×3.6、竖梃 2 横梃 1、透明玻璃）+ 主入口双开门（3.0×3.0）+ 雨棚（9.0 宽双柱）；实墙材质 = 基座石材。
- 二三层：实体裙墙（1.5 / 1.2）+ 玻璃带（3.9 / 3.3），高度各层内**严格无缝**（1.5+3.9=5.4；1.2+3.3=4.5）。
- 柱网 9.0×9.0、方柱 0.6×0.6，自下层板底直通上层板底（`primitive box`，高 = 层高−0.2）。

### 4.5 顶部（三段式收头）

女儿墙一圈（1.2，铝板材质与裙墙同）→ 电梯机房体块（**必须落在井道区正上方** x12–25.2 × z22–27，高 2.4）→ 装饰飘板（四面出挑 0.4，骑女儿墙顶）。总高 <100m 不设停机坪；>100m 须补避难层与停机坪。

### 4.6 台阶 / 坡道 / 地基

与住宅类 §4.8/§4.9 完全同口径：台阶每级自室外地面直砌、栏板只设临空侧；坡道贴墙（路径 z = 墙皮 − width/2）、1:12、`railingSides:"left"`（路径高→低时 left=外侧）；地基实心 box 顶 +0.45 / 底 −0.02 / 出挑 0.06，南面兜住外墙外皮。公共建筑主入口台阶加宽（示范 6.0m）。

## 6. 参数化生成（强制项）

- 单一真源 `gen_commercial_complex.cjs`：`P` 参数表（POD/TWR/CORE/SHAFT/ST/SPAN/RESC…）+ 标高函数 `yT(n)` + 标准层 `for` 循环；禁逐层手写。
- 派生值一律包 `R()`（取整 3 位，**禁 R(v,4)**）；楼梯等直推元素的所有坐标字段（from/to）必须逐项过 `R()`——本次 rev1 即被出厂自检拦下 `st114.from[1]=66.44999999999999`（`Y1+13×3.9` 的浮点尾数，仅第 14 层触发）。
- **出厂自检**（写盘前）：结构位禁全角标点 + 禁超 3 位小数（断言代码见 v1.2 §1.5 第 7 条）。
- **双通道校验**：内部自检 12 组 + `verify_commercial_complex.cjs` 独立重读 .wild 24 项 + `check_wild_integrity.cjs` 三级体检。

## 7. 假设与简化清单

- 中庭未建模（真实项目若设中庭，连通面积叠加计防火分区）；明火餐饮未分区（设则该分区 3000㎡）。
- 幕墙竖梃 1.5m 分格由材质抽象，未逐根建模；幕墙开启扇以救援窗口示意（规范：每防火分区 ≥2、间距 ≤20m、净 ≥1.0、下沿 ≤1.2；蓝图每 3 层 × 3 樘示意）。
- 核心筒 2 部疏散梯抽象 1 部双跑；3 台电梯轿厢/导轨不建模；办公标准层隔墙不展开（大空间抽象）；裙房内商铺隔墙/卫生间/机电用房不展开。
- 消防登高场地（≥20×10m、距建筑 5–10m）位于红线外，不建模；裙房与塔楼间防火墙构造以体量断开表达。

## 10. 常见错误速查（综合体）

| 症状 | 根因 | 处方 |
|---|---|---|
| 塔楼内部核心筒外露 | 幕墙用了透明玻璃 | 幕墙必须 `gc`（transmission 0 + clearcoat），透明 `gl` 只给橱窗/门 |
| 幕墙层间横向缝隙 | 玻璃带顶 ≠ 层高 | 断言 0.8+3.1=3.9；玻璃带顶面 = 楼面+层高 |
| 电梯/楼梯井被堵 | 井道区铺满板 | 五块拼板，井道区（x12–25.2×z22–27）每层无板；前室必须有板 |
| 塔楼首层板重复/缺失 | yT(1)=YP 又写一块板 | 塔楼首层地面由裙房屋面 4 块拼板承担，n≥2 才写 slA–slE |
| 登高面不合规 | 登高侧裙房进深 >4m | 先定登高面再定裙房；塔楼该侧面 z = 裙房边 −4 |
| 某单层楼梯悬空/浮点尾数 | 楼梯坐标未过 R() | 楼梯直推元素 from/to 全字段过 R()；靠出厂自检拦截（st114 案例） |
| 机房漂移 | 未落在井道正上方 | 机房 = 井道区平面直上；断言中心 = 井道中心 |
| 引擎打不开 | 结构位全角标点 | 跑 `check_wild_integrity.cjs`；生成器写盘前断言 |
