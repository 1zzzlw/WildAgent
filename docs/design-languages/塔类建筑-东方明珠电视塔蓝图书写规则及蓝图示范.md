> 版本 v1.2 ｜ 2026-09-23 ｜ 配套生成器 `蓝图生成器/gen_pearl_tower.cjs` ｜ 示范 `东方明珠电视塔.wild`（**rev3，126 元素 / 38.6KB**）
> 依据《WILD蓝图设计语言 v1.2》**§2.6 等比例缩放书写法** / **§3.12 塔类建筑配方** / §3.7 primitive / §5 材质 / §6 公式十一（斜置杆件）、公式十二（球体与球面环带）。
> **v1.1 修订（用户验收反馈第二波：球体是金属框架+玻璃幕墙、比例不均衡、两根斜撑方向错误）**：
> ① **球幕骨架化**——下球/上球/太空舱由"光球"改为「玻璃球壳 + 金属框架」：经线肋 12/12/6 道（profile_sweep 圆管，逐点贴球面）+ 纬线带 ±35°/±65°（矩形截面空心带，半径严格 = √(R²−Δy²)）+ 观光廊宽带（90m / 263m）+ 两极盖板；**废弃实心圆盘环带**（透光球壳下会看成"球里插了张盘"）。
> ② **斜撑方向错误根因定案**——渲染层 `mesh.rotation.set()` = three.js Euler **XYZ 序（R = Rx·Ry·Rz）**，对 +Y 轴形体 `rotation[1]` 只自转、**方位角被丢弃**，故旧写法 `[φ, ψ, 0]` 使三根斜撑全部朝 +Z 歪倒（用户所见"两根方向错误"）。**改为 `profile_sweep` 世界路径**（零旋转、方向绝对正确），并新增"水平分量必须内倾 + 方位角 = 设计值"双校验。
> ③ **比例均衡**——柱圈半径 15m→**18m**（直径 30m→**36m**，三筒束更壮、与 Ø50/45m 球体关系更协调）；斜撑底半径按 60° 硬约束重推 = 18 + 75/tan60° = **61.3m**。
> **v1.2 修订（用户验收反馈第三波：幕墙玻璃材质 ≠ 窗玻璃、三柱贯穿上球）**：
> ① **幕墙玻璃材质分制**——`glass_curtain`（**带色反光玻璃**：`transmission` 0、带色 baseColor、低粗糙度 + `clearcoat` 1）替代原透明玻璃（transmission 0.86）→ **从外面看不到球体内部**；与普通透明窗玻璃 `glass`（§5，transmission 0.92）严格区分。
> ② **三柱贯穿上球修复**——柱圈半径 18m 处，上球（R22.5、心 272.5m）球壳只存在于 **272.5 ± √(22.5²−18²) = 259 / 286m**；旧柱顶 **294m > 286m** → 三柱从上球**上部穿出球面**（用户所见"三根柱子贯穿第二个圆球"）。**改法：柱顶收到 284m（壳内留 2m 过盈）**，并新增断言「柱顶处球壳半径 > 柱圈半径 + 0.005」。
> ③ **单筒体止于太空舱底**——旧单筒体 288→350m 穿过太空舱（舱 334–350m）→ 改为 **290→334m**（止于舱底），舱体承接天线（350m 起）。
> **v1.2 调色（rev3.1，用户反馈第四波：玻璃偏蓝一点、反光再大一点）**：幕墙玻璃 `glass_curtain` baseColor `[0.48,0.53,0.58]` → **`[0.40,0.50,0.62]`（偏蓝）**、`roughness` 0.06 → **0.03**、`metallic` 0.50 → **0.70**（反射更锐更亮）。
> **v1.2 下球放大（rev3.2，用户反馈第五波：下球须比上球直径略大）**：下球真实 Ø50 与上球 Ø45 只差 11%，缩尺下读不出"下大上小" → 下球**风格化放大至 Ø52**（+4%，§2.6 第 5 条声明）；上球保持真实 Ø45 不动；新增硬规则断言「**下球直径 > 上球直径**」。
> **v1.2 副斜撑（rev3.3，用户反馈第六波：三根斜杆应各有一根小斜杆支撑）**：每根主斜撑配一根**副斜撑**——Ø4m（真实尺寸未公开，假设声明）、与主斜撑**同方位角平面**，自塔座面（半径 52m，主斜撑底 61.3m 的内侧）斜升至**主斜撑轴线 48m** 处（约 75°，比主斜撑更陡，读作"内撑"）；48m 恰在半腰球（Ø12m@55.5m）下方，端点距球心 7.7m > 球半径 6m → **不穿球**。
> **本次为设计语言补入的新构件/规则（v1.2 原缺）**：①球体建筑写法（球心定位/球幕材质/穿球构件/小球防遮挡）②**球体幕墙骨架（经线肋 + 纬线带 + 极盖）**③斜置杆件两点定位（profile_sweep 首选 / cylinder 两角回退）④多筒束（n 柱 + 横梁联结）⑤天线桅杆（收分多段 + 航空障碍色带）⑥球面环带（观光廊）⑦塔座环形台阶栏杆 ⑧等比例缩放书写法（超尺度建筑）。

## 1. 形制特征（先读懂再写）

设计构思 = 白居易《琵琶行》"**大珠小珠落玉盘**"——11 个大小球体沿塔身错落，串在带斜撑的巨型空间框架上。塔类建筑六要素，缺一即失神：

1. **多层退台塔座 + 中央大堂筒**：塔座 Ø158.4m 三层逐层内收；中心 Ø60m、2 层高（18m）大堂筒，顶面 = 塔座顶面；外围为商场，一层外围 15m 宽地下环形车库（缩尺模型从略）。
2. **环形登塔台阶 + 扶手栏杆**：塔座四周环形台阶 3 级，逐级半径内收、**末级顶面 = 塔座顶面**；台阶外缘一圈栏杆（望柱 + 扶手环）——**硬语义⑨：台阶必配护栏**。
3. **三筒束主干**：3 根 Ø9m 空心擎天柱沿平面正三角形均布（柱圈 **R18m，直径 36m**），柱间以**横梁**（真实 6m 高）多道联结——塔身不是单筒，是"筒束 + 巨型框架"，也是全塔最不可替换的结构语言。
4. **斜撑 + 副斜撑**：3 根 Ø7m 斜柱与地面成 **60°**，自塔座平台斜升，顶端撑住下球体与柱束（真实支撑标高 93m）；**每根主斜撑内侧另有一根 Ø4m 副斜撑**（自塔座面内撑至主斜撑 48m 腰部，约 75° 更陡）——斜撑让塔体在立面读作"A"形三角 + 内撑，是东方明珠区别于所有圆筒电视塔的识别特征。
5. **悬挂球体（11 珠，金属框架 + 玻璃幕墙）**：下球 Ø50m（心 93m）／上球 Ø45m（心 272.5m）／太空舱 Ø16m（心 342m）呈"下大上小"串联；5 个小球 Ø12m 由横梁联结组成，另 3 个小球挂于斜撑半腰；球体表面为**金属框架分格的玻璃幕墙**——经线竖挺 + 纬线横档 + 观光廊带，不是光球；幕墙玻璃是**带色反光玻璃**（`glass_curtain`：室外看不到内部）——**不是普通透明窗玻璃**。
6. **上部单筒体 + 天线桅杆**：三柱与球体之上收为混凝土单筒体，顶端 350m 接钢天线桅杆（长 118m），桅杆分段收分、**红白航空障碍色带交替**，细针尖收头，塔顶总高 468m。

## 4. 构件组合规则（自下而上链）

```
广场盘（顶 +0.005 防与引擎地面共面）
→ 环形登塔台阶 ×3 级（末级顶 = 塔座顶 0.36）+ 望柱 ×24 + 扶手环 ×1
→ 塔座三层（r 1.584 / 1.4 / 1.3，逐层内收）+ 中央大堂筒（r 0.6，顶 = 塔座顶）+ 筒顶线脚环
→ 三根擎天柱（column 元素，柱底嵌塔座 0.02、柱顶 5.88 藏于中球内并与单筒体底过盈）
→ 三根斜撑（**profile_sweep 世界路径**，60° 硬约束，两端各过盈 0.02）+ 承台 ×3 + 斜撑半腰小球 ×3
→ 5 道横梁 ×3 根（端头埋入柱身 = 柱轴距）+ 横梁小球 ×5
→ 三大球体（玻璃壳）**+ 幕墙骨架**（经线肋 12/12/6 + 纬线带 ±35°/±65° + 观光廊带 + 极盖 ×2/球）
→ 混凝土单筒体（收分圆台）
→ 天线桅杆 5 段（红白交替）+ 针尖
```

### 4.1 多筒束（三柱 + 横梁）

- 3 根柱用 `column` 元素（`style:"modern"`，rB 0.09 → rT 0.08 收分）；平面按正三角形均布，**方位角 90° / 210° / 330°**（一柱朝北、两柱朝南偏东西——正立面读作"两柱张开夹一柱"）；
- **柱圈直径 36m（R0.36）**：真实柱距未公开；取值为使 Ø45/50m 球体恰好包裹柱束、柱束在立面上有足够视觉重量（**rev2 由 15m 调大——原值使柱束过细、与球体比例失衡**）；
- 柱长含**两端过盈**：柱底 = 塔座顶 − 0.02、**柱顶 5.68（= 284m）**；
- **★柱顶标高硬约束（rev3 用户反馈主修项：三根柱子贯穿了上球）**：柱不在球心正上方（在柱圈 18m 处），而**球壳沿竖向是收口的**——柱圈半径处的上球（R22.5m、心 272.5m）球壳只存在于 `272.5 ± √(22.5²−18²) = 259 / 286m`。**柱顶必须 ≤ 286m**（留过盈取 **284m**），否则柱子会从球体上部**穿出球面**（rev2 写 294m > 286m → 三柱扎穿上球，被用户退回）；
- **生成器断言**：`√(R_ball² − (柱顶−球心)²) > 柱圈半径 + 0.005`（即柱顶处球壳半径仍大于柱圈半径，柱被球体完全包裹）；
- 横梁 = `primitive box`，**长度 = 柱轴距**（两端各埋入柱身，公式八），`rotation[1] = atan2(−Δz, Δx)` 对齐弦线（**绕 Y 单轴旋转 = 对长轴为 X 的 box 有效**，不受 Euler 序影响）；断面 = [柱轴距, 真实梁高 ×k, 真实梁宽 ×k]（本例 0.12 × 0.04）。

### 4.2 球体玻璃幕墙（球壳 + 金属框架，§6 公式十二）

球幕 = **玻璃球壳 + 骨架**，二者缺一即失真（rev1 只有玻璃壳 → "光球"，被用户退回）。骨架四件：

| 骨架件 | 写法 | rev2 取值 |
|---|---|---|
| **经线肋（竖挺）** | `profile_sweep` 圆截面管，path = 大圆子午线 19 点折线（球面上取点，经度均分） | 下球 12 道 / 上球 12 道 / 太空舱 6 道；管半径 0.005（真实竖挺 ≈0.25m）；逐点必须落在球面 ±0.002 |
| **纬线带（横档）** | `profile_sweep` 矩形截面闭合环（u = 径向、v = 竖向），路点 θ ∈ [0, 2π+0.06] | 纬度 ±35° / ±65° 各一道；截面 [0.012, 0.012]（真实 0.6m × 0.6m）；半径严格 = √(R²−Δy²) |
| **观光廊带** | 同上，截面放大 | 下球 90m（室外廊）、上球 263m（主观光层）；截面 [0.032, 0.048]（真实 1.6m × 2.4m） |
| **两极盖板** | 小 `cylinder` 圆盘（`radiusTop = radiusBottom = capR`） | **r = 0.08**（真实极点开口 ≈4m 半径）、h 0.012，置于球心 ±(R−0.004)、遮经线肋在极点汇聚处的开口端 |

- 球体一律 **球心定位**（`position` = 球心，非底面）；
- **★球幕材质 = `glass_curtain` 带色反光玻璃（rev3 用户反馈主修项 / rev3.1 调色）**：`transmission: 0`、**偏蓝** baseColor `[0.40,0.50,0.62]`、`roughness 0.03`、`metallic 0.70`、`clearcoat 1.0`、`clearcoatRoughness 0.02`——**从外面看不到内部**，且**偏蓝 + 强反光**（rev3.1 按用户"玻璃偏蓝一点、反光再大一点"调整）；**区别于普通透明窗玻璃 `glass`**（§5，`transmission 0.92`）。幕墙玻璃写成透明玻璃 → 内部柱/肋/楼板全部外露（用户退回）；
- **穿球关系不做布尔**：柱与斜撑穿球而过（引擎无布尔）；因幕墙为**带色反光玻璃**（室外不可见内部）+ **柱顶止于壳内**（§4.1），故内部不外露；柱顶/斜撑顶插入球内 ≥0.02（缩尺）；
- **小球防遮挡**：柱束间小球 r 0.12 < 柱圈 0.36 − 柱半径 0.09 ✓（柱圈加大后余量更足）；
- **斜撑半腰球包裹斜撑**：球 r 0.12 > 斜撑 r 0.07，球心落在斜撑轴线上 → 斜撑完全藏于球内；
- **红线：环带禁实心圆盘**——`cylinder`（rTop=rBottom）在大直径处等于一张盘；若幕墙改透光或相机入内，即读成"球里插了张圆盘"（rev1 缺陷），必须用矩形截面空心带。

### 4.3 斜撑（profile_sweep 世界路径，§6 公式十一写法 A）

```
P0 = 塔座面（半径 61.3m = 18 + 75/tan60°，标高 18m）
P1 = 柱圈处（半径 18m，标高 93m，落于下球体内）
path = [P0 沿轴外延 0.02, P1 沿轴外延 0.02]      // 两端各过盈 0.02
shape:"profile_sweep"，radius 0.07，segments 16，省略 position/rotation
```

- **为什么不用 cylinder + rotation**：渲染层 `mesh.rotation.set()` = three.js Euler **XYZ 序（R = Rx·Ry·Rz）**，对 +Y 轴形体 `rotation[1]` 只自转、**方位角被丢弃** → `[φ, ψ, 0]` 会让三根斜撑全部朝 +Z 歪倒（**用户所见"两根方向错误"的真因**，且旧校验只查倾角查不出来）。`profile_sweep` 的 path 是世界坐标，**零旋转风险**；
- 斜撑**方位与三柱错开 60°**（柱 90/210/330，斜撑 30/150/270）——正南（270°）一根正对主入口，正立面读作"人"字；
- **60° 硬约束反推底半径**：底半径 = 柱圈半径 + (93−18)/tan60° = 18 + 43.3 = **61.3m**（柱圈由 15m 调到 18m 后同步重推，角度不漂移）；
- 底端加**承台**（cylinder r = 0.13、h 0.10，顶面与塔座顶齐平）；
- **双校验（rev2 新增，防事故重演）**：① 与地面夹角 = 60° ± 0.05°；② **水平分量必须内倾**（`(P1−P0)·(P0−塔心) < 0`）且**方位角 = 设计值**（30/150/270°，±0.6°）；
- **★副斜撑（rev3.3 用户反馈项：每根斜杆应各有一根小斜杆支撑，每根主斜撑一根）**：
  - 断面 **Ø4m**（真实尺寸未公开 → **假设声明**，§7）；`profile_sweep` 世界路径（同主斜撑，禁 rotation）；
  - **与主斜撑同方位角平面**（同一 az）——立面读作"A 形 + 内撑"；
  - **底**：塔座面（y = 18m，沿轴嵌 0.02），半径 **52m**——在主斜撑底（61.3m）**内侧**，与之错开 9.3m，且不碰主斜撑承台（承台外缘 54.8m）；
  - **顶**：落在**主斜撑轴线 48m** 处（r = 18 + (93−48)/tan60° = **44m**），沿轴过盈 0.02 插入主斜撑身；与地面约 **75°**——**比主斜撑（60°）更陡**，读作"内撑"；
  - **不穿半腰球（硬约束）**：48m 在半腰球（Ø12m@55.5m，球底 49.5m）下方，顶端距球心 7.7m > 球半径 6m → **副斜撑顶标高必须 ≤ 半腰球底标高**。

### 4.4 天线桅杆

- 5 段收分（r 0.07 → 0.008 模型），**段间搭接 0.01**（相邻段 rT = 下段 rB，连续收分，消接触缝）；

## 5. 过盈 / 防共面硬规则（塔类特有）

1. **柱底嵌塔座 0.02**；**柱顶止于上球壳内**（§4.1，不再求"与单筒体过盈"）；**单筒体底嵌上球壳、顶止于太空舱底**（§4.6）——所有"贴合接触"必用体积过盈，**所有"穿球"必止于壳内**；
2. **斜撑两端各嵌 0.02**（底入承台/塔座、顶入下球体）；
3. **横梁端头埋入柱身**（长 = 柱轴距，公式八）——端头既不外露留缝也不与柱面共面；
4. **桅杆段间搭接 0.01**，与球体、单筒体的交接同样过盈；
5. **广场盘顶面 +0.005**——避免与渲染引擎固定地面（y=0）共面闪烁；
6. **球壳与环带不相交共面**（球面为曲面，环带为圆台侧面，交线天然非共面）；
7. 塔座各层、台阶各级同材质交叠 → 共面校验豁免（生成器已实现）；
8. 最低点 ≥ −0.3（渲染地面固定 y=0，任何构件不得下沉超过 0.3）；
9. **★穿球构件止于壳内**——竖向穿球构件（塔柱、单筒体）顶端必须落在球壳以内（即柱圈半径处的球壳标高区间内）；断言 `√(R_ball² − (构件顶−球心)²) > 构件所在半径 + 0.005`（生成器已内置）。
