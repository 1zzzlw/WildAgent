# 传统住宅-新中式别墅蓝图书写规则及蓝图示范

> **版本**：v1.0 ｜ **依据**：《WILD蓝图设计语言 v1.2》（下称"总协议"） ｜ **实例**：`三层新中式别墅.wild`（rev3，78 元素 + 38 组件，由 `蓝图生成器/gen_villa_xzs.cjs` 参数化生成）
> **定位**：实例级书写规则字典——在总协议通用规则之上，给出新中式住宅的全部专项规则、公式与实值。与总协议冲突处以总协议为准。
> **核心抽象**：①双坡屋顶 = **两块斜置楼板经屋脊线组合 + 脊盖 + 山墙 gable 三棱柱填充**（坡面用斜板防实体楔块观感，山墙用封闭三棱柱防透空）；②内外联动 = **外部形体是自变量，内部构件是因变量**——外轮廓/标高/洞口任何变更，内墙、楼梯、门窗必须按 §6 联动链重算。

## 2. 坐标与标高体系

- 原点 = 首层轴网西南角；外墙满长—内缩（南墙 x ∈ [−0.12, 12.72]，外墙皮 ±0.12）；
- 标高链：台基顶 0 = L1 墙底 → L1 顶 3.6 → L2 顶 6.9 → L3 顶 9.9 → 檐口 9.9 → 屋脊 12.6；
- **任何外形变更后，先重推此标高链，再重推一切构件**（§6 联动链）。

## 3. 主体骨架规则（继承总协议，列专属要点）

1. 外墙四面满长—内缩闭环；内墙端点 = 外墙内皮（东西向内墙按层分段时端点仍落内皮，Y = 本层墙底→墙顶，**禁止写成同 Y 平板墙**）；
2. 地坪仅 1 块；层间楼板轮廓 = 下层外轮廓；梯井拆洞补板（L1→L2 洞 z [4.50, 8.34]，L2→L3 洞 z [4.50, 8.58]——洞深 = 步深×步数 + 0.24）；
3. 双跑楼梯：L1→L2 高差 3.6 = 2×10 步×0.18；L2→L3 高差 3.3 = **2×11 步×0.15**（半层 1.65 非标准步高整数倍，禁止照抄 10×0.18）；B 跑在 A 跑正上方反向，到达边 = 梯井洞南缘；
4. 梯井临空边 `railing` 组件 L 形围合（path 沿洞东缘 + 北缘，高 1.05）；
5. 露台：floor_terrace 板（板边藏进 L3 东墙厚度带）+ 女儿墙（type wall，厚 = 墙厚，高 0.9，满长—内缩，端头抵 L3 山墙外皮）。

## 4. 外立面装饰构件组合规则（新中式专属）

### 4.1 青砖勒脚（材质 brick_dark）

- 高 **h ≤ 0.3 且 ≤ 最低窗台标高**（实例窗台 0.3 → 勒脚 h = 0.3，顶面与窗台齐平；**勒脚高于窗台会遮挡窗洞下缘**）；
- 截面：厚 0.07，凸出墙面 0.06、嵌入 0.01（消共面）；
- 转角：南北带**通长至环带外皮宽**（长 = 东西外皮距 = 12.96），东西带**缩进对接**（长 = 11.02）；
- **避让门窗**：穿越门洞分段（实例南墙分 2 段，段端距洞边 0.03）；
- 实值：`plinth_s1 [4.845,0.15,−0.145] 10.05×0.3×0.07`｜`plinth_n [6.3,0.15,10.955] 12.96×0.3×0.07`｜`plinth_w [−0.145,0.15,5.4] 0.07×0.3×11.02`。

### 4.2 深灰腰线（材质 roof_dark，与瓦同色勾边）

- 位置 = 层高处（y = 3.6 / 6.9），高 0.12，中心 y = 层高 + 0.06；
- 截面规则与勒脚相同（厚 0.07、凸 0.06 嵌 0.01、南北通长东西缩进）；
- **禁止跨越任何门窗洞口**——布置前核对全部洞口 Y 范围（实例层高恰落在上下层窗之间的空白带）。

### 4.3 入口门廊（柱础 + 圆柱 + 小双坡顶）

- **柱础**：box 0.4×0.3×0.4 落地（中心 y = −0.15），顶面 = ±0.000；
- **圆柱**：primitive cylinder r 0.15，**position 是几何中心**——`中心 y = 柱底 + h/2`（实例 [9.3, **1.5**, −1.5]，h 3.0 → span 0~3.0，下坐柱础顶、上入檐口板 0.1 嵌接）。**按"底面圆心"书写会半截插地、顶部悬空**；
- **门楼顶**：`roof/gable` 坡屋顶元素（跨 = 门洞 + 2×0.9，檐口 = 柱顶，脊垂直于主立面，山面朝向观者）。**必须显式补山墙体块**：渲染器的 gable 是构造式坡屋顶（两坡板+封檐+脊盖），其山墙三角仅运行时从「最高承托墙」自动注入——门楼是低位独立雨棚、无承托墙，自动注入失效 → 蓝图层加**两端山墙阶梯填充**：每端 3 级 box（厚 0.24），宽度按**坡板内皮三角**逐级内收并留 0.015 防共面间隙（`w(y) = 2·(脊高−板厚/cosα−y)/tanα`，实例 1.98/1.14/0.30，顶区由加高正脊盖罩住）；z 向与屋面端面**错开 0.01**（南端 z = −1.79~−1.55、北端 z = −0.25~−0.01），底面抬 0.01 防与屋面底共面。
- **防共面硬规则（门楼区教训，rev8 全量修正）**：①凸出墙面的构件（门簪等）尾部必须**嵌入墙体 ≥0.03**，尾端面严禁与墙外皮同坐标；②填充/装饰件的端面与屋面板端面**错开 ≥0.01**，顶角与坡板内皮留 ≥0.015；③叠级构件上下级**精确叠合**（共享面法线相反，不闪面），禁止 0.01 错缝重叠（同法线共面）；④同材质共面不可见可豁免，异材质共面一律错开。生成器已内置共面校验（同面+同法线+面积重叠即报错）。
- **门楼装饰组合（屋顶形式不变、只做减法式增饰）**——无装饰的门楼顶是单调的素坡顶，必须配齐：

| 件 | 构件 | 截面/材质 | 定位规则 | 实值（rev5） |
|---|---|---|---|---|
| 1 | 正脊盖 `porch_ridge` | box 0.26×0.14，roof_dark | 压脊：中心 y = 脊标高 + 0.03（下缘嵌入脊尖 0.04），长 = depth + 0.1（两端各挑 0.05） | `[10.5, 3.63, −0.9] 0.26×0.14×1.9` |
| 2-3 | 脊端收头（吻）×2 | box 0.26×0.2×0.08，roof_dark | 坐正脊盖两端外挑处，中心 y = 脊盖顶 + 0.02 | `[10.5, 3.72, ∓1.87/0.07]` |
| 4-5 | 博风板 ×2 | box [L, 0.12, 0.05]，roof_dark | 沿山面两坡边：L = √((span/2)²+height²) + 0.01，rotation[2] = ±α（α=atan(height/(span/2))，西坡 +α），中心 = 坡中点沿法线抬半板高，z = 山面外皮 − 0.05 | `[9.6/11.4, 3.36, −1.85] 1.9×0.12×0.05 rot ±0.322` |
| 6 | 悬鱼 `porch_xuanyu` | box 0.1×0.28×0.05，wood_grille | 山尖正下方悬垂：顶 = 脊标高 − 0.04 | `[10.5, 3.42, −1.86]` |
| 7-8 | 封檐板 ×2 | box 0.06×0.14×(depth+0.1)，roof_dark | 沿两坡檐口边缘：外缘挑出 0.03，上缘覆板顶 | `[8.68/12.32, 2.97, −0.9]` |

- **尺度红线**：门楼装饰整体 ≤ 主屋顶装饰尺度（正脊盖 0.26 < 主脊盖 0.34，吻 0.2 < 鸱吻 0.5）——小檐口配小装饰，防止头重脚轻；
- **门簪 ×2**（`doorpin_l/r`）：门楣上成对短圆柱（传统固定门框构件，新中式简化写法）——cylinder r 0.09、h 0.12，**axis 转 Z**（`rotation = [π/2, 0, 0]`，单轴旋转各引擎语义一致），突出墙面 0.09、尾部嵌入墙体 0.03（center z = 墙外皮 − 0.03，防尾面与墙外皮共面）、y = 门洞顶 + 0.1、内缩洞边 0.18；实值 `[10.08/10.92, 2.3, −0.15]`；
- **联动**：门楼跨/坡/脊标高变更时，装饰与填充按上表定位规则全部重推（见 §6）。

### 4.4 木格栅（材质 wood_grille）

- 贴墙面：厚 0.12，中心 z = 墙外皮 − 0.06（外皮 −0.12 → 格栅 z = −0.18，凸出 0.06）；
- **起止标高避让带体**：底 ≥ 勒脚顶（0.6），L2 格栅底 ≥ 腰线顶（3.72）；顶 ≤ 檐口；
- 对称布置于门/大窗两侧，净距 0.15；实值：`grille_l [9.6,1.65,−0.18] 0.3×2.1×0.12`。

### 4.5 女儿墙压顶（深灰）

- 高 0.06，宽 = 女儿墙厚 + 0.12（两侧各挑 0.03），中心 y = 女儿墙顶 + 0.03；三面围合随女儿墙分段。

### 4.6 封檐板（深灰）

- 沿坡屋顶两檐口边缘：厚 0.06（外缘超出檐口 0.03）、高 0.3（上缘覆板顶）、长 = 屋顶 depth；
- 实值：`fascia_w [−0.75, 9.85, 5.4] 0.06×0.3×11.4`（檐口 x = −0.72，板中心再外移 0.03）。

## 5. 双坡屋顶·两斜板法（本形制核心规则）

引擎 `gable` 是封闭棱柱（两坡面+两端山面+底面），主体屋顶观感为实体楔块，**禁用**；改用两块斜置楼板经屋脊线组合：

| 步 | 规则 | 实值（rev3） |
|---|---|---|
| 1 | 半跨 `HW = span/2`，坡角 `α = atan(height/HW)`，斜板长 `SL = √(HW²+height²)` | HW 4.92，α 0.502 rad（28.7°），SL 5.612 |
| 2 | 两块 box `[SL, 0.2, depth]`，`rotation = [0,0,±α]`（**rotation[2] 正角使 +X 端上抬**：西坡 +α / 东坡 −α） | `slab_w rot [0,0,0.502]`｜`slab_e rot [0,0,−0.502]` |
| 3 | 板中心 = 顶面中点沿法线下移半厚：`(脊x ∓ HW/2 ± 0.1·sinα, 檐口y + height/2 − 0.1·cosα, 脊z)` | `slab_w [1.788, 11.162, 5.4]`｜`slab_e [6.612, 11.162, 5.4]` |
| 4 | **脊盖** box `[0.34, 0.5, depth]`，中心 y = 屋脊标高 − 0.23（盖住脊下 V 口，顶面高出板顶 0.02）；鸱吻坐脊盖顶（中心 y = 脊盖顶 + 0.25） | `ridge [4.2, 12.37, 5.4]`｜鸱吻 y 12.87 |
| 5 | **山墙五边形填充**：`profile_sweep`，path = 墙厚两端点（世界坐标，**省略 position**），截面 = 五边形，上缘平行坡板底面**嵌埋 0.03**、底边坐墙顶 | 见下示范 |

**校验恒等式**：斜板顶面两端点 = (脊x∓HW, 檐口y) 与 (脊x, 檐口y+height)（误差 ≤0.001）。

## 6. 内外联动规则（外形变更 → 内部构件跟随，硬性）

**原则：外部形体是自变量，内部构件是因变量。任何外形修改必须沿以下联动链顺序重推，禁止只动外部：**

```
外轮廓/体块变更 → ①标高链重推 → ②楼板重分（轮廓=下层外轮廓） → ③内墙端点重算
→ ④门窗/洞口连带平移 → ⑤楼梯步参数与梯井洞重推 → ⑥外饰带体避让重查 → ⑦全量自检
```

| 外部变更 | 必须联动的内部构件 | 依据 |
|---|---|---|
| 外墙轮廓（退台/凸出/平移） | 内墙端点=外墙内皮重算；依附组件 from[0] 平移；门窗重定位 | 总协议公式六b |
| 层高/标高变更 | 楼梯步数×步高重推（半层=高差/2，步高取 0.15/0.18 能整除者）；梯井洞重算；楼板拆洞重分；洞口 from[1] 全部重推 | 公式五b / 硬语义①③ |
| 屋顶坡角/出檐变更 | 山墙三棱柱 span/height 随坡重推（height = 屋面高−0.04）；脊盖/鸱吻标高随屋脊 | 本文 §5 |
| 门楼顶跨/坡/脊标高变更 | 两坡板（roof/gable 元素）随坡重推；山墙阶梯填充 3 级宽度按坡板内皮三角重推（防共面间隙 0.015）；装饰构件按 §4.3 定位规则全部重推（脊盖长=depth+0.1、博风板长=√((span/2)²+height²)+0.01、吻/悬鱼/封檐板随脊与檐口、门簪随门洞顶与洞边） | 本文 §4.3 |
| 台基/±0.000 变更 | 全部标高链 + 台阶 + 柱础重推 | 总协议 §2.3 |
| 立面开洞增删 | 勒脚分段重查（段端距洞边 0.03）；腰线不跨洞重查；格栅避让重查 | 本文 §4.1/4.2/4.4 |
| 退台位置变更 | 露台板 + 女儿墙 + 压顶 + 对应层楼板轮廓同步 | 总协议 §2.4 |

## 7. 交付自检（本形制专属 10 条）

1. [ ] 标高链完整：台基顶 → 各层 → 檐口 → 屋脊逐级可推导
2. [ ] 内墙 Y = 本层墙底→墙顶（无平板墙）；端点 = 外墙内皮
3. [ ] 楼梯 stepHeight×stepCount = 半层高差（层高不同步数不同）；梯井洞深 = 步深×步数 + 0.24
4. [ ] 双坡屋顶为两斜板 + 脊盖 + 山墙五边形（禁用引擎 gable 表达主体屋顶）；斜板顶面端点校验通过
5. [ ] 山墙截面上缘嵌埋坡板 0.03；profile_sweep 无 position 字段
6. [ ] 圆柱 position = 几何中心（span = 柱底~柱顶，与柱础/檐口嵌接）
7. [ ] 勒脚顶 ≤ 最低窗台；南墙分段避让门洞；段端距洞边 0.03
8. [ ] 腰线不跨越任何洞口；格栅起止避开勒脚/腰线带体；门楼装饰构件配齐（正脊盖/脊头/博风板/悬鱼/封檐板/门簪）且尺度 ≤ 主屋顶装饰
9. [ ] 外形变更后联动链（§6）七步全部重推并自检
10. [ ] 紧凑 JSON ≤100KB；editor.revision 递增 + generator/params 留痕
