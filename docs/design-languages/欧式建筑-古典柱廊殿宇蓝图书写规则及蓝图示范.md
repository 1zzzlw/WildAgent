## 1. 形制特征（先读懂再写）

古典神庙式（peripteral temple）七要素，缺一即失真：

1. **三层踏步台基 crepidoma**：三级实体板逐层内收 0.3（四面皆可登踏），层高 0.3，顶面 = ±0.000 = 首层地坪。
2. **围廊柱网 peristyle**：柱沿外圈矩形布置（角柱共享），柱距 1.5 循模；多立克柱径比 h/6，柱身收分 rB→rT。
3. **柱头垫块 abacus**：引擎柱无柱头 → 每柱顶叠 0.66×0.12×0.66 垫块，**垫块顶 = 额枋底**（传力连续）。
4. **三段横梁檐部 entablature**：额枋 architrave 0.3 + 横饰带 frieze 0.3（三陇板 triglyph 凸出 0.02/嵌入 0.02）+ 檐口 cornice 0.24（加深 0.15 出挑），四面闭合。
5. **殿身 cella**：内收一圈的实墙（厚 0.3、高比柱身高 0.6），山墙面开拱门、侧面开拱窗。
6. **浅坡双坡顶 + 山花 pediment**：坡 ≈15°（古典山花必须浅坡，禁用 25°+），悬山出檐；山花 = 檐口之上的三角形端面。
7. **拱门 + 朱红拱形门扇 + 石拱圈/门楣凸出**：拱券按 §3.3「洞口切到拱顶 + 相切拱圈法」书写——禁用阶梯砌块近似（凹凸不平）。

→ 山花阶梯填充 ×2 端 ×4 步 + 坡檐口线脚 ×4（rotation [0,0,±A]）

### 3.1 山花（pediment）书写法（本类型核心难点）

引擎 gable 端面在 wild-web 是构造式坡屋顶、无山墙体块（§3.6 引擎差异），**山花必须自建**：

1. **阶梯填充**：三角形按 4 步均分（步高 = H/4），步宽 = `span·(1 − (y顶 − yRoof)/H)` 留缝 0.05；**顶步 0.30 宽为脊顶封口块**（坡面回算宽在顶点为 0，豁免校验）。
2. **坡檐口线脚 raking cornice**：沿两坡边斜置板（长 = 坡长 √(hw²+H²)），rotation = [0,0,±A]，板外面与水平檐口外面**齐平**（前山花 = 屋面底缘 z 侧的檐口面）。
3. 山花填充 z 向比水平檐口外面**内退 0.05**（读作凹龛，兼防共面）。
4. 步宽公式中的 span 是**屋面 span（含出檐）**，不是台基宽——写错必穿坡（生成器内置复验）。

### 3.2 柱式书写法（v1.1 过盈规则）

- 用 `column` 元素（style 声明 doric/ionic/corinthian，引擎渲染截锥体，柱头细节用 primitive 叠加）；
- 柱径比：doric h/6、ionic h/8、corinthian h/10；收分 rB→rT ≈ 0.8×rB；
- **柱头垫块必写**：高度 0.12，顶 = 额枋底（硬对位校验）；
- **接触处一律过盈嵌入（v1.1 硬规则）**：柱底低于台基顶 0.02、柱顶高于垫块底 0.04（height = 名义高 + 0.06）——柱/垫块/额枋是"贴合接触"，渲染浮点误差即露缝，必须用体积过盈消除；
- 柱底 = 台基顶（多立克无柱础，直接坐台）。

### 3.3 拱门/拱窗书写法（v1.5 圆滑拱圈法；from[0]/from[1] 双语义见 §3.8）

1. `opening` 切拱形通孔：高度 = rect + r（洞口切到拱顶）；
2. **`from[0]/from[1]` 按 wild-web 语义书写**：`from[0]` = 开口**左边缘**沿墙距离（门 1.5、窗 0.6/5.4）、`from[1]` = 底部**世界标高**（门 0.9、窗 1.8）——写中心值门洞错位半宽、写相对值洞口陷入地基（分发版 wild-core 为中心/相对语义，交付时注明引擎）；
3. **窗衬板材质 = 透明玻璃** glass_pane（materialClass "glass" / transmission 0.92 / side double）——引擎衬板按 opening 材质渲染，写 dark_void 即黑窗；门洞保持 dark_void（朱红门扇 + 拱洞进深暗龛）；
4. **石拱圈 archivolt = 相切拱圈法（禁阶梯砌块）**：n=12 段（每段 15°），第 k 段中心角 θₖ = (k+0.5)·15°（0→π 自右拱脚越顶至左拱脚；侧墙 −90°→+90°），段心位 = 拱心 + rm·(cosθ, sinθ)，rm = (rIn+rOut)/2；段尺寸 = [弦长, rOut−rIn, 墙厚+0.06]，**弦长 = 2·rm·sin(π/n) + 0.01**（相切搭接）；旋转 = 绕墙法线单轴转 θₖ（正面墙 [0,0,θ]、侧墙 [θ,0,0]）——轮廓为连续光滑半圆；
5. **竖框 ×2**：中心压洞边（跨压切割面防共面），高 = 洞底→拱脚步线（rect），底=洞底、顶=拱脚；
6. **门扇 = 矩形段 + 旋转圆柱拱顶**：矩形段顶至拱心（1.46×1.76×0.08 内缩 0.02），拱顶 = cylinder（rTop=rBottom=r+0.01，height=0.08，**rotation 绕水平轴 90° 使轴向=墙法线**，心=拱心）——正圆截面即数学圆滑拱顶，r+0.01 嵌入洞壁/拱圈消缝；朱红漆高对比材质；
7. 门楣（压顶石条）位于拱圈外顶之上：宽跨拱圈外径 +0.04、厚 0.3、出墙 0.06。

## 4. 防共面硬规则（欧式特有，v1.1 补强 / v1.5 更新）

1. **拱圈段为旋置件天然脱离洞壁切割面**（绕法线单轴旋转）：段外缘嵌墙身——rOut 压入实墙区，段厚 = 墙厚+0.06（两端各出 0.03）；
2. **门扇四边内缩 0.02、圆柱拱顶 r+0.01 嵌入洞壁**（r−0.01 则露 0.02 暗缝环，r+0.02 则穿出拱圈）；
3. 三陇板凸 0.02 嵌 0.02（板背面 ≠ 横饰带面）；
4. 柱头垫块与额枋**同材质**（marble_cream），交叠由校验豁免——对位靠数值硬校验 + 柱身过盈嵌入；
5. 山花填充内退 0.05 ≠ 檐口外面；坡檐口板/拱圈段为旋转件天然豁免；
6. 竖框中心压洞边（内缘盖切割面 0.07），竖框面 ≠ 洞壁面；
7. **殿身墙顶 = 屋面底缘**（墙顶面与屋面底面贴合，消除看穿空隙）；
8. 大台阶三级实体自地面直砌（级间同材质交叠豁免）。
