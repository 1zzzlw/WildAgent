## 1. 类型定义与特征

### 1.1 类型学界定

现代简约别墅是低层（1–3 层）独栋居住建筑，以**几何纯粹的体量、简洁屋面（平顶为主，双坡为变体）、大面玻璃与实墙的虚实对比、克制的色彩**为标志。与相近类型的区分：

| 对比类型 | 区别要点 |
|---|---|
| 坡顶小住宅（通用协议 F1） | 本类型**以平顶 + 女儿墙为原型**；双坡仅作 §7.4 变体（山墙朝主立面，无中式举架曲线） |
| 中式宅院（F2/F3） | 无坡瓦、无柱廊；木色仅作点缀不做结构表达 |
| 玻璃幕墙公建（F5） | 玻璃是**开洞窗**（宿主墙 + window 组件），不做整片幕墙 |
| 多层公寓（F6） | 层数 ≤3、体量错落而非规则柱网重复 |

### 1.2 五大类型特征（生成时的"气质校验"）

1. **体量语汇——错动的盒子**：2–3 个几何纯粹的体块咬合，禁止每层同轮廓的"叠方盒"。惯用手法：底层满铺基座、上层退让出露台、翼体延伸、局部悬挑（≤1.2m）。
2. **虚实对比**：每个主要立面同时存在"实"（白墙）与"虚"（大玻璃），虚实比约 6:4～7:3；南向（主立面）虚面最大。
3. **材质体系——三色律**：全楼外墙**统一一种材质**（默认暖白），配深灰金属框与木色点缀；全楼可见材质 ≤4 种；**严禁各层异色**。
4. **开口逻辑——水平长窗 + 四分格**：窗以水平向为主（宽 ≥1.5m），统一 `frameWidth 0.09` 深灰框 + 四分格/竖梃；同一立面同轴同型号。
5. **屋面即第五立面**：平顶时退台处全部升格为可到达露台（floor_terrace + 女儿墙 + 可达门窗）；双坡时山墙三角面作为主立面构图要素，坡下空间不设露台。

### 1.3 默认设计参数表 P（未指定时全部采用，并向用户标注假设）

| 参数 | 默认值 | 参数 | 默认值 |
|---|---|---|---|
| 层数 | 3 | 外墙厚 / 内墙厚 | 0.24 / 0.12 |
| 轴网开间 | 5.0 × 3 跨（总长 15） | 地坪厚 / 楼板厚 | 0.20 / 0.20（休息平台 0.15） |
| 轴网进深 | 5.0 × 2 跨（总深 10） | 女儿墙 | **高 0.90–1.20 / 厚=墙厚 0.24**；对齐墙边；底=板顶 |
| 层高 | L1 3.6 / 上层 3.0 | 楼梯 | 双跑，梯宽 1.2，步高 0.15–0.18，步深 0.24 |
| 主入口 | 南面，1.2×2.2 单扇 + 雨棚 + 两级台阶 | 阳台 | 南向 ×2（上层卧室），3.6×1.5 |

**板的级配（与层数联动，见 §5.4）**：N 层 → **1 组地坪（仅一层，轮廓=一层外轮廓）+ N−1 组层间楼板（每组并集=下层外轮廓，板顶=上层地板）**；顶层顶板由屋面系统承担，不另写楼板。

### 1.4 类型文字描述（智能体可直接引用的"标准话术"）

**总体描述（代参数版）**：

这是一栋[层数]层的现代简约风格独栋别墅，平面呈[轴网总长]米 × [轴网总深]米的矩形基座，总建筑面积约[Σ层面积]平方米。建筑整体由[2–3]个几何纯粹的体块咬合而成：首层作为完整基座满铺场地，二层向西收拢为[主块尺寸]的主体、向东伸出[翼体尺寸]的翼体，顶层再度收为[顶层尺寸]，两次退让在东侧和东北角分别造就了高出室外[标高1]米与[标高2]米的屋顶露台，使建筑剖面呈清晰的阶梯状退台。立面以暖白色涂料实墙为底，穿插深灰色金属框的水平长窗与整面落地玻璃，虚实相间；[平屋顶以深灰色女儿墙收边 / 双坡屋顶以深灰屋面覆盖，山墙三角面正对南向主立面]，与白墙形成两色对比，木色仅在门扇与室内地板处作点缀。入口位于南面中央，两级混凝土台阶与深灰雨棚界定了谦和而明确的进门序列。

**气质描述（固定话术）**：

建筑的语言是克制的：没有线脚、没有装饰构件，全部表现力来自体量本身的错落、玻璃与实墙的比例关系，以及三种颜色（暖白、深灰、木色）之间的克制搭配。水平向的长窗强化了低层建筑的舒展感，露台把"屋顶"变成可居住的第五立面，楼梯间借助外墙高窗获得垂直贯通的自然光——白天整栋建筑像一组被阳光切割的白色盒子，夜晚室内灯光则透过分格玻璃透出安静的网格。

### 1.5 基本形式特征描述（分维度）

**① 体量特征**：由 2–3 个长方体盒子错动咬合，几何纯粹、边角锐利；禁止曲线与装饰性体块。层间至少一处退让或悬挑，形成"基座—主体—退台"三段式剖面；悬挑 ≤1.2m，悬挑下方即灰空间或入口。

**② 立面特征**：构图逻辑是**实墙与玻璃的面积对比**（约 6:4～7:3），每个主立面同时有"实"与"虚"。窗全部为矩形水平窗，以 1.5–1.8m 标准窗为基本单元、4m 级横向大玻璃为客厅主角色；深灰细框四分格或竖梃，窗台统一 0.9m（客厅大玻璃 0.3m），同轴同型号逐层对位。上层卧室常带 1.5m 出深的南向阳台，栏板为细金属杆。

**③ 屋面特征**：平顶 + **0.90–1.20m 女儿墙（厚=墙厚，对齐墙边）** 为原型，退台暴露屋面全部升格为露台；**双坡变体**（§7.4）山墙三角面朝主立面，坡角 25°–35°，无中式举架曲线。屋面不是覆盖物而是构图与活动面。**无墙的屋顶/露台边缘必须做女儿墙**（通用硬性）。

**④ 材质与色彩特征**：三色律——暖白涂料（主调，≥70% 可见面积）、深灰金属（框料/栏杆/压顶）、木色（门扇/室内地板点缀）；全部哑光，无镜面高反射；玻璃为淡蓝透明（transmission 0.92）。

**⑤ 比例与尺度特征**：开间 4–5m、层高 3.0–3.6m，窗高普遍 ≥1.5m，建筑总高（3 层）≈10m——总体**横向舒展**；南立面窗带与实墙交替周期约 5m，与轴网同构。

**⑥ 入口与序列特征**：主入口位于南面轴线附近，雨棚 + 两级台阶构成过渡空间；L1 公共区（客厅/餐厨）居南向采光面，上层私密区（卧室），动静分层、洁污分区。

**⑦ 竖向交通特征**：双跑楼梯藏于角部楼梯间（默认西北角），借外墙高窗采光，梯井垂直贯通——楼梯间在外立面上表现为一列上下对位的竖向窗带，是唯一暴露"垂直性"的元素，与水平长窗形成方向对比。

**⑧ 场地关系特征**：建筑贴平场地，±0.000 抬高 0.15–0.45m 以两级台阶消化；不设院墙时以 L1 满铺体量的檐下阴影定义边界；露台朝东南开口取日照。

## 3. 引擎关键语义速查（完整版见书写说明 §1.4）

> 以下 5 条是**设计决策时必须提前预判**的引擎行为；字段级写法与模板一律查书写说明。

| # | 语义 | 对设计决策的影响 |
|---|---|---|
| ① | `floor.from[1]` = **板顶**，板向下延伸 | **板顶 = 下层墙顶 = 上层墙底（与墙体顶面同一平面）**；「下层屋顶楼板≡上层地板」只写一次；地坪仅一层 |
| ② | 墙 `from/to` 为**轴线中线**，厚度法向对称 | 外轮廓尺寸按**轴网**定，不要按外皮定 |
| ③ | 门窗构件 `from` = [左边缘沿墙距离, **世界 Y**, 0] | 上层构件坐标含累计层高（L2 门写 3.6 起） |
| ④ | 楼梯升高 = `stepHeight × stepCount`（与 from/to 的 Y 无关） | **层高必须先定**，步数×步高 = 半层高 |
| ⑤ | 屋顶**必须显式定位**（position），否则会被扩展到全楼包围盒 | 多体块建筑：屋顶只盖顶部体块，露台不设屋顶 |

**摆放顺序提示**：元素在 JSON 中的排列顺序不影响渲染，但建议按"楼板 → 墙 → 楼梯 → 屋顶 → primitives → components"书写以便自检。

## 4. 体块构成规则（防"叠方盒"——本类型的灵魂）

### 4.1 轮廓错落律
相邻两层实体外轮廓**至少一处退让或悬挑**，禁止完全重合。推荐三段式：**L1 满铺基座 → L2 主体 + 翼体 → L3 主体 + 露台**。

### 4.2 支承约束律
缩进/悬挑的上层墙体必须有同轮廓的下层楼板托底。生成时**自上而下检查**：L3 轮廓 ⊆ L2 楼板，L2 轮廓 ⊆ L1 楼板（→ 书写说明 §5.6）。悬挑 ≤1.2m 且在设计说明中显式声明。

### 4.3 露台升格律
上层退让暴露的下层屋面**必须升格为露台**：floor_terrace 面 + 女儿墙 + 至少一樘可达门窗。禁止留裸楼板。

### 4.4 翼体收头律
L 形/T 形平面中，翼体尽端设满长女儿墙或高墙压边，与主体墙外皮精确对齐，不留缺口。

### 4.5 两个已验证体块（可直接套用）

**实例 A（三层平顶，轴网 15×10）**：

| 层 | 轮廓 | 说明 |
|---|---|---|
| L1 | 15×10 满铺 | 完整基座，客厅大玻璃朝南 |
| L2 | L 形：主块 10×10（X 0–10）+ 东翼体 5×6.5（X 10–15, Z 0–6.5） | 主块正好托住 L3；东北角退让 |
| L2 露台 | 5×3.5（X 10–15 × Z 6.5–10） | L1 屋面升格，+3.8m |
| L3 | 10×10（X 0–10） | 书房 + 主卧 |
| L3 露台 | 5×6.5（X 10–15 × Z 0–6.5） | 坐在翼体屋顶上，+6.8m |

**实例 B（两层双坡，轴网 11×9）**：

| 层 | 轮廓 | 说明 |
|---|---|---|
| L1 | 11×9 满铺 | 基座 3.6m 层高 |

## 5. 平面与轴网规则

### 5.1 轴网
南立面沿 X 展开；开间默认 5.0×3 跨、进深 5.0×2 跨（实例 B 为 5.0×2 跨 × 4.5×2 跨）。门窗、隔墙、楼梯**全部以轴线定位**，立面每个开口都能追溯到轴网。

### 5.2 房间表（范例，可按需求改）

| 层 | 功能 |
|---|---|
| L1 | 客厅（南向开敞，大玻璃）、餐厨（侧翼）、玄关（南中）、楼梯间（角部） |
| L2 | 卧室 ×2（带南阳台）、家庭厅/书房（中部）、露台可达房间 |
| L3（三层时） | 书房（南）、主卧（北），开门通露台 |

### 5.3 隔墙
内墙 0.12；位置避让北立面窗洞（隔墙端头不得落在窗洞内）；每樘内门 0.9×2.1。

### 5.4 水平板分层：地坪、楼板、露台面、休息平台

**术语定义（本类型的水平板只有四类，各司其职）**：

| 名称 | 定义 | 顶面标高 | 归属 | 轮廓算法 | 数量规律 |
|---|---|---|---|---|---|
| **地坪** | 首层落地板（slab-on-grade） | ±0.000 = 一层墙底 | **仅一层** | **= 一层整个外建筑轮廓**（带厚度；非矩形可拼块） | **全楼恒 1 组** |
| **楼板** | 某层的**屋顶楼板**，同时是上一层的**地板** | 上一层地面 = 上一层墙底 | **下层**（它封顶的那一层） | **= 下层整个外建筑轮廓**（不是上层轮廓） | N 层建筑 **N−1 组** |
| **露台面** | 楼板**暴露在上层轮廓外**的部分（其上无墙体） | 同该层楼板 | 该层楼板 | 楼板分块/分材质；**并集仍=下层外轮廓** | 随退台 |
| **休息平台** | 双跑楼梯半层高处的转台板 | 半层高 | — | 梯井旁矩形 | 每层 1 块 |
| **屋面** | 顶层顶板 | 顶层墙顶 | roof 构件 | **= 顶层外轮廓 + 挑檐**；顶层不写 floor | 1 |

**核心理解——同一块板有两个身份，轮廓取下层**：

```
地坪 ground（仅一层）         轮廓 = 一层外建筑轮廓
一层屋顶楼板 ≡ 二层地板       轮廓 = 一层外轮廓（不是二层！）
二层屋顶楼板 ≡ 三层地板       轮廓 = 二层外轮廓（不是三层！）
顶层顶板 = 屋面 roof          轮廓 = 顶层外轮廓 + 挑檐（不另写 floor）

首层地面 ≠ 楼板，叫「地坪」；其下没有楼层，是落地板。
因此"一层地板"只指地坪；凡说"某层楼板"，指该层顶部、轮廓=该层外轮廓的那块板。
```

**平面构成**：每组层间楼板**并集 = 下层外轮廓**；室内（上层投影下）可用 `floor_wood`，暴露部分用 `floor_terrace` 分块——**分块不改变轮廓算法**。楼梯间拆板留洞后，剩余并集仍须托住上层全部墙底。

**开洞**：楼梯间拆板留洞；拆板边界优先藏入墙厚带（→ 书写说明 §5.5）。

**禁止**：二层/三层另写地坪；层间楼板缩成上层更小轮廓；用全楼外包大矩形多铺楼外板；顶层再写 floor 与屋面重叠。

**命名约定（蓝图 id）**：`ground` / `ground_<凸出>` / `slab_l<上层号>[_in|_sw|_s|_e…]` / `terrace_*`（仅材质分块）/ `landing_*`。

**修改联动**：改第 k 层外墙轮廓 → 重算以该层为下层的楼板（及一层时的 ground）；退台暴露分块随之增减。

## 6. 立面规则（虚实对比的算术）

### 6.1 门窗对齐公式

```
沿墙距离 s = 起点累加 + 开间内偏移        （一律以轴线对称布置）
from[0] = s − width/2                    （= 洞口左边缘，相对墙起点）
from[1] = 本层地面世界Y（门）/ 地面Y+0.9（窗台）
```
硬校验：同墙开口不重叠；`from[1]+height ≤ 墙顶`；相邻开口净距 ≥0.4；距墙端 ≥0.24。
**墙起点 = 外皮角**（因满长—内缩写墙，§6.4）：南墙起点 X=−0.12、北墙起点 X=轴长+0.12（反向书写）、东墙起点 Z=0.12、西墙起点 Z=进深−0.12——依附构件 `from[0]` 一律相对此起点计量。

### 6.2 门窗尺寸表（现代简约默认）

| 类型 | 宽×高 | 底标高 | 分格 | 用途 |
|---|---|---|---|---|
| 客厅大玻璃 | 3.6–4.0×2.7 | +0.3 | 竖梃×2–3 | L1 南 |
| 横向书房窗 | 3.0×1.8 | +0.9 | 竖梃×2 | 顶层南 |
| 标准窗 | 1.5×1.5 / 1.8×1.5 | +0.9 | 四分格（1×1） | 全楼统一 |
| 主入口门 | 1.2×2.2 | ±0.000 | single | 南中 |
| 内门 / 楼梯间门 | 0.9×2.1 | 本层地面 | — | 全楼 |
| 露台门 | 1.0×2.1 | 本层地面 | — | 通露台 |

安装规格（`frameWidth 0.09`、外门窗 `frameDepth 0.16`、内门 `0.06`、`glassDepth 0.012`）→ 书写说明 §4.0。

### 6.3 立面韵律律
同一立面同轴同型号（尺寸、窗台、分格全同），逐层上下对位；北立面为服务面，可统一 1.5×1.5@0.9 四分格；楼梯间开窗占北墙轴线位并逐层对位。

### 6.4 闭环外墙转角（满长—内缩配对）

- **南北墙满外皮长**：`from[0]=−0.12`、`to[0]=轴长+0.12`（压角）；**东西墙两端内缩一厚度**：`from[2]=0.12`、`to[2]=进深−0.12`；
- 墙起点改变后**依附构件 from[0] 同步平移**（漏移 = 门窗整体偏 0.12）；
- 自检：转角处两墙实体并集完整覆盖 0.24×0.24 角柱区。

### 6.5 楼板边缘藏带律
楼板 from/to 取**外墙中线包络**，板边藏进墙厚带不可见；**严禁板边与外墙皮齐平**（±0.12）——会产生全周长共面灰缝。

## 7. 屋面、露台与附属

### 7.1 平屋顶（原型）
`roofType:"flat"`，`span/depth` = 覆盖范围包围盒 + 出檐，`position` = **顶层墙顶中心**（屋面与墙顶共面），`height` 按构造。**多体块必然分块设屋顶**；露台区域不设屋顶。

### 7.2 女儿墙（硬性 · 只布一圈 · 端点齐平）

**本质**：女儿墙是在**原有墙体顶上**再加的一段矮墙，书写同 `wall`，仅高度与材质不同。

| 参数 | 规则 |
|---|---|
| **位置** | **只**在当层屋顶/露台板的**最外边缘轮廓**（一圈） |
| **中间** | **禁止**：同层露台共边、退台内凹分界、室内板边 |
| type | **`wall`**；通长段 from/to 与下层外墙一致 |
| 厚/高 | 厚=墙厚；高 **0.90–1.20** |
| 底 | = 本层墙顶 = 板顶/屋面 |
| **端点** | 与墙面**齐平**（外皮/内皮）；**禁止嵌入墙身** |

最外一圈上若有常规墙继续升高 → 该边不写女儿墙。禁止 primitive box；禁止中间线段；阳台不写女儿墙。

### 7.3 台阶（门口）
无台阶类型，primitive box 叠加：每级高 0.15、深 0.4–0.6，宽 ≈ 门洞总宽 + 0.6。

### 7.4 双坡屋顶变体（G1 实测语义）
- **引擎语义**：屋脊**沿 Z（进深方向）**，山墙三角面朝南北（±Z），坡面朝东西降落；`buildGable` 输出封闭棱柱（`thickness` 不参与）。要"山墙朝主立面"，让体块长边沿 Z；
- **定位**：`position` 必须显式写（引擎扩张陷阱，§3 语义⑤）；`depth` = 体块进深（山墙与墙外皮贴合），`span` = 体块宽度 + 2×0.4（东西出檐）；`height` = 1/4–1/3 × span（范例 span 9.8 取 2.6，坡角 ≈28°）；屋脊标高 = position[1] + height；
- **与露台关系**：坡屋顶覆盖的体块上方不设露台；相邻退台仍按 §4.3 升格，坡檐可悬于露台上方形成半遮蔽。

## 8. 竖向交通（双跑楼梯间）

### 8.1 布局
楼梯间占角部，**借两面外墙采光**，另两面以 0.12 内墙围合；每层一樘 0.9×2.1 楼梯间门；门洞必须落在**到达板**范围内。完整数组配方（含拆板与栏杆）→ 书写说明 §5.5。

### 8.2 双跑构成（每层四件套）

| 构件 | 实例 A（15×10，层高 3.6/3.0） | 实例 B（11×9，层高 3.6） |
|---|---|---|
| 上行第一跑 | from (1.2, 0, 9.4) → to (3.6, 1.8, 9.4)，宽 1.2，10×0.18 | from (0.72, 0, 2.34) → to (0.72, 1.8, 4.74)，10×0.18 |

- 每跑 `stepHeight × stepCount` = 半层高；两跑之和 = 层高；

## 12. 修改协议（对话式增量修改）

### 12.1 话术映射
| 用户说 | 设计层动作 | 书写层动作 |
|---|---|---|
| "把窗改大" | 查立面韵律是否破坏 | 改 width/height，重算 from[0] 保中心 |
| "南墙加窗" | 检查槽位与韵律（§6.3） | add window，查同墙无重叠 |
| "加一层" | 复查体块规则（§4） | 全构件 Y 平移 + 新墙/板/楼梯延伸 |
| "要个露台" | 上层退让 + 升格（§4.3） | 加 floor_terrace + 女儿墙 + 门 |
| "改成坡屋顶" | 按 §7.4 定山墙朝向与坡高 | 改 roofType/span/depth/height/position |
| "东墙没门窗" | — | 先查洞口-框对齐（书写说明 §8.1），多为墙角/引擎角度问题 |
| "外墙退让/改轮廓" | 体块与房间随外墙变 | **外墙 + 该层全部内墙 + 依附组件**一起改 |

### 12.1b 外墙轮廓修改 → 内墙联动（硬性）

改任一层外墙（退让、凸出、共线）时：

1. **必须同步改该层全部内墙**（含梯井），禁止只动外墙+门窗/阳台；
2. 内墙只依附外墙；端点=外墙**内皮**（南 z=zc+th/2，北 z=zc−th/2，西 x=xc+th/2，东 x=xc−th/2）；
3. 端点不得超出外墙内皮区间；不得悬空、穿墙、伸到室外；
4. 组件 from 随父墙/父内墙重算；
5. 重推：外墙轮廓 → 内皮 → 内墙端点 → 组件 from → 自检。

### 12.2 修改门禁
每次修改后三级校验归零（书写说明 §8.1）；**同文件修改必须串行**；改外墙必过 §12.1b。

### 12.3 修改闭环 SOP（三交付）
1. 修蓝图 + 校验；2. 部署预览确认；3. **问题→根因→规则写回对应层文档**（设计问题回本文，书写/引擎问题回书写说明）。缺一不可。

## 14. 设计层自检清单

> 书写级自检（JSON 格式、字段、坐标、材质）→ 书写说明 §9（13 项）。本清单只列**设计层**必须自检的项：

1. [ ] **体块**：相邻层轮廓错落；L3 ⊆ L2 ⊆ L1 支承；悬挑 ≤1.2m
2. [ ] **水平板分层**：**地坪仅一层**；**层间楼板并集=下层外轮廓**；**板顶=下层墙顶=上层墙底（与墙体顶面同一平面）**；顶层无 floor
3. [ ] **露台/女儿墙**：退让暴露屋面已升格；**无墙的屋顶/露台边缘均有女儿墙**（厚=墙厚，高 0.9–1.2，对齐墙边，底=板顶）；阳台未重复设
4. [ ] **轴网一致性**：立面每个开口、每道隔墙都能追溯到轴网
5. [ ] **内墙联动**：改外墙后该层内墙已同步；端点=外墙内皮；无悬空/无超出外墙
6. [ ] **立面韵律**：同立面同轴同型号逐层对位；主立面虚实比 6:4～7:3
7. [ ] **材质三色律**：全楼外墙单一材质；可见材质 ≤4 种
8. [ ] **竖向交通**：双跑构成完整（两跑+平台+洞口+围合+门+栏杆）；层高与步数×步高吻合

## 15. 常见问题速查（设计层）

| 现象 | 设计层成因 | 规则 |
|---|---|---|
| 建筑像"叠方盒"，立面单调 | 每层同轮廓 | §4.1 |
| 把"一层楼板"和"二层地板"写成两块板 | 未理解板的双身份 | §5.4 |
| 首层地面误当楼板标高往上叠 | 地坪与楼板混淆 | §5.4 |
| 顶层多写一块楼板 / 屋面与楼板重叠 | 顶层顶板应由屋面承担 | §5.4、§7.1 |
| 三层颜色不一 | 各层材质未统一 | §10 |
| 立面杂乱、无韵律 | 同立面混用不同型号窗 | §6.3 |
| 上层墙体悬空/露台无支承 | 未自上而下检查轮廓包含关系 | §4.2 |
| 退台处留裸楼板 | 未升格为露台 | §4.3 |
| 楼梯与层高对不上 | 层高晚定或步数×步高 ≠ 半层高 | §8.3 |
| 露台无法到达 | 未设可达门窗 | §4.3 |

> 引擎/书写类问题（地板与墙分离、墙角缺口、共面灰缝、有洞无门窗、屋顶被扩张、门窗偏移、预览卡顿等 12 项）→ **书写说明 §10 错误速查**。
