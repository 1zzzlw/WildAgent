## 一、日常运维命令

### 1.1 查看服务状态

```bash
docker ps --filter "name=wild-" --format "table {{.Names}}\t{{.Image}}\t{{.Status}}\t{{.Ports}}"
```

### 1.2 查看日志

```bash
# 后端实时日志
docker logs -f --tail=100 wild-server

# 前端实时日志
docker logs -f --tail=100 wild-web
```

### 1.3 检查容器环境变量

```bash
docker exec wild-server env | sort
```

## 二、修改 .env 后更新后端

> ⚠️ **关键**：修改 `/opt/wild-agent/.env` 后，**不能**用 `docker restart`，必须**删除旧容器再重建**。

### 2.1 完整重建命令

```bash
# Step 1: 删除旧容器（数据在 volume 挂载里，不会丢失）
docker rm -f wild-server

# Step 2: 重建容器（重新读取 .env）
docker run -d \
  --name wild-server \
  --restart unless-stopped \
  --network wild-net \
  -p 8000:8000 \
  -v /opt/wild-agent/storage/scenes:/app/storage/scenes \
  -v /opt/wild-agent/storage/sessions:/app/storage/sessions \
  -v /opt/wild-agent/storage/chroma:/app/storage/chroma \
  -v /opt/wild-agent/storage/geoip:/app/storage/geoip:ro \
  --env-file /opt/wild-agent/.env \
  -e PRESENCE__GEOIP_DB=/app/storage/geoip/GeoLite2-City.mmdb \
  wild-agent/wild-server:latest

# Step 3: 验证 .env 是否生效
docker exec wild-server env | grep -E "CHAT__|EMBEDDING__|RERANK__|RAG__"

# Step 4: 确认服务正常
docker logs --tail=30 wild-server
```

### 2.2 快速验证清单

```bash
# 容器是否在运行
docker ps | grep wild-server

# 端口是否监听
curl -s http://localhost:8000/docs -o /dev/null -w "%{http_code}\n"

# 最近日志有无报错
docker logs --tail=50 wild-server 2>&1 | grep -iE "error|traceback|exception"
```

## 四、完全重新部署（前后端一起）

```bash
# 1. 确保网络存在
docker network inspect wild-net >/dev/null 2>&1 || docker network create wild-net

# 2. 删除旧容器
docker rm -f wild-server wild-web 2>/dev/null; true

# 3. 确保数据目录存在
mkdir -p /opt/wild-agent/storage/{scenes,sessions,chroma,geoip}

# 4. 启动后端
docker run -d \
  --name wild-server \
  --restart unless-stopped \
  --network wild-net \
  -p 8000:8000 \
  -v /opt/wild-agent/storage/scenes:/app/storage/scenes \
  -v /opt/wild-agent/storage/sessions:/app/storage/sessions \
  -v /opt/wild-agent/storage/chroma:/app/storage/chroma \
  -v /opt/wild-agent/storage/geoip:/app/storage/geoip:ro \
  --env-file /opt/wild-agent/.env \
  -e PRESENCE__GEOIP_DB=/app/storage/geoip/GeoLite2-City.mmdb \
  wild-agent/wild-server:latest

# 5. 启动前端
docker run -d \
  --name wild-web \
  --restart unless-stopped \
  --network wild-net \
  -p 80:80 \
  wild-agent/wild-web:latest

# 6. 等待启动
sleep 5

# 7. 验证
docker ps --filter "name=wild-"
docker logs --tail=20 wild-server
```

## 五、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 改 `.env` 后不生效 | 用了 `docker restart` 而非重建 | 执行 **第二章** 重建命令 |
| `Missing credentials` | 启动时没带 `--env-file` | 重建容器并加上 `--env-file` |
| `hash fallback embedding` 警告 | `EMBEDDING__API_KEY` 未设置或无效 | 检查 `.env` 中 Embedding 配置 |
| 容器启动后立刻退出 | 环境变量缺失导致 Python 报错 | `docker logs wild-server` 查看错误 |
| 前端 502/无法访问 | `wild-net` 网络或后端未就绪 | 确认两个容器都在运行且在同一网络 |
