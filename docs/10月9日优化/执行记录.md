## O1：坐标与设计事实

状态：实现完成待验收。

- `app/design/coordinates.py`、`contracts.py`：体量 `x/z` 明确为世界平面起点，支持平移和负坐标；`width/depth` 为体量跨度。`massing.width/depth` 是总体包络的尺寸控制上限，没有隐含世界原点边界。实际包络由 volumes 计算，投影和决策摘要分别展示实际尺寸与控制值。
- `generation/architecture/planning.py`、`design_workflow.py`：显式体量不再被夹取、丢弃或自动延伸楼层。包络越界、楼层缺口等返回字段冲突，交给设计块修订。缺省体量仍走原有确定性派生。
- `compiler/compile.py`、`generation/architecture/facade.py`：单体屋顶与墙体读取同一体量起点、跨度和承托层；单体和逐体量屋顶统一保留 0—2m 出檐契约，零出檐不再被改为非零。完整上下叠置的体量可生成顶部屋面；不再用一块整体包围盒屋顶冒充不支持的多体量组合。
- `wild-core/types.ts`、`schema.json`、`src/primitive/geometry/roof.ts`、`expander.ts`、`compiler/components/attachedToSurface.ts`：gable 屋脊方向落实到网格、法线、附着面和附属件；后端 `storage/knowledge_base/schema.json` 同步可选 `ridgeAxis` 字段。

本次观测的 `x=10,z=7.5,width=20,depth=15` 按新契约是一个整体平移的 20×15m 体量，不能自行猜成中心输入，也不能裁成 10×7.5m。只有明确声明或可计算的契约冲突才拒绝；模型是否想表达中心仍是未知，不伪称已识别其意图。20×15m 是 Agent 的采用决定，不冒充用户硬要求。

已知表达边界：上层部分覆盖下层时，当前还不能无损表达剩余局部屋面，返回 `roof_partial_coverage`；多体量非分段屋型返回 `roof_layout_unsupported`。独立相邻体量支持 flat/gable/hip，不宣称任意退台、穹顶组合已完成。审核允许查看草稿，但已知编译 error 禁止直接确认。

## O2：产物与校验证据

状态：实现完成待验收。

- `services/agent_service.py`：`run_validation_pipeline(auto_fix=False)` 不执行修复，也不把未执行的 fix 计为通过。显式修复路径完成后全量复查当前内容。
- `agent/validation/candidate.py::evaluate_candidate`：共享只读入口；检查结构与 ID、几何、设计清单、审核开口、批准实体/材质、批准设计编译错误、既有警告上限，并计算最终实体履约。履约未知项单独报告，不变为几何错误。
- `compiler/pipeline_defects.py`：通过共享入口检查实际原产物，不再把自动修好副本后的零错误归给原产物。
- `validation/diagnostics.py`、`workflow.py`：快照记录 Blueprint 指纹、设计 hash/revision、设计清单指纹与 validator 版本；最终节点独立运行完整验收，不复用合并或 callback 的旧通过结论。
- `services/agent_delivery.py`、`api/ws_agent.py`：交付开关处理完实际材质内容后重新验收。生产提交必须携带快照；指纹、版本、状态、校验结果、设计版本或履约产物指纹不一致就拒绝落盘。错误计数参数不能覆盖结果中的真实错误。
- `agent/vision/workflow.py`：离线修订的几何评估也改为只读，不以修好的副本代替原候选。

证据对应：编译诊断 → 原始编译 Blueprint；callback before/after → 各自副本与同一设计上下文；final_validate → 当前合并产物；delivery → 交付开关处理后实际落盘内容。最后一次内容变化必须重新形成证据。
