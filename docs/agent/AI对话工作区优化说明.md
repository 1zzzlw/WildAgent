# AI 对话工作区优化说明

## 1. 为什么不再只使用底部对话框

WildAgent 的 AI 面板不只是聊天窗口，还会同时展示执行计划、节点过程、平面审核、建筑风格审核、校验日志和修复结果。固定的底部半屏适合短对话，但在建筑生成任务中会产生三个问题：

1. 可见高度不足，长计划和节点日志需要反复滚动；
2. 用户难以一边观察三维建筑，一边核对 Agent 当前步骤；
3. 对话、审核和错误混在同一条时间线里，定位失败节点很慢。

因此，当前前端把原来的 `BottomPanel` 升级为 `AIWorkspace`。聊天数据和 WebSocket 连接仍只有一份，切换布局不会创建第二个会话，也不会中断正在运行的生成任务。

## 2. 三种工作区模式

| 模式 | 适用场景 | 页面行为 |
|---|---|---|
| 底部 | 简短提问、快速修改 | AI 工作区位于三维视口下方，可拖动上边缘调整高度 |
| 侧栏 | 生成建筑、对照结果 | AI 工作区位于编辑器右侧，可拖动左边缘调整宽度，三维视口保持可见 |
| 专注 | 阅读长计划、审核和错误 | AI 工作区占据顶部工具栏以下的全部区域，三维编辑区暂时隐藏 |

工作区标题栏中的“底部、侧栏、专注”可以随时切换。专注模式按 `Esc` 会回到进入专注模式之前的布局。

窗口宽度小于 900px 时，侧栏没有足够空间同时展示三维视口和对话内容，因此会自动进入专注模式。

为了优先保证三维视口可用，侧栏模式在中等宽度窗口中会临时隐藏辅助面板：1500px 以下隐藏右侧属性面板，1100px 以下再隐藏左侧场景面板。这里只是布局层隐藏，用户原来的面板开关状态不会丢失；退出侧栏模式后会自动恢复。

## 3. 尺寸调整和保存位置

- 底部模式最小高度为 180px，最大高度根据当前浏览器高度动态计算，不再写死为 600px；
- 侧栏模式宽度范围为 360～900px，同时会为主编辑区保留基本空间；
- 关闭、刷新或重新打开页面后，会恢复上一次的显示状态、模式、高度和宽度。

布局偏好保存在浏览器 `localStorage` 的 `wild_ai_workspace_layout_v1` 中。它只影响当前浏览器用户，不会修改前端部署目录、后端配置或服务端 `.env` 文件。

## 4. 长内容应该怎么看

AI 工作区在会话列表下方增加了内容导航：

- `全部`：消息和执行过程都显示；
- `对话`：只看用户与 AI 的消息；
- `执行`：只看 Agent 执行记录；
- `待审核`：只看正在等待用户确认的计划、平面或风格；
- `错误`：只看执行失败、节点失败或校验失败的任务。

右侧的“跳转节点”会列出当前重要任务的执行节点。失败节点带 `!`，正在运行的节点带 `→`。选择节点后会自动展开对应任务和节点，并滚动到该位置。

“定位：当前任务/待审核任务/失败任务”用于快速回到最应该处理的一次执行。优先级为：

```text
等待审核 → 执行失败 → 正在运行 → 最近一次任务
```

执行卡片仍采用渐进展开方式：完成的任务默认折叠，正在运行和等待审核的任务默认展开，避免所有历史日志同时占满页面。

## 5. 代码结构

| 文件 | 作用 |
|---|---|
| `wild-web/src/App.vue` | 使用 CSS Grid 在底部、右侧和专注区域之间切换布局 |
| `wild-web/src/components/layout/AIWorkspace.vue` | 工作区标题栏、模式切换、拖拽尺寸、Esc 返回和窄屏处理 |
| `wild-web/src/stores/uiStore.ts` | 保存工作区模式、尺寸和显示状态，并写入 localStorage |
| `wild-web/src/components/panels/AIChatPanel.vue` | 内容筛选、重要任务定位和执行节点跳转 |
| `wild-web/src/components/panels/AgentExecutionPanel.vue` | 为每个执行节点提供稳定的页面定位点 |

原来的 `BottomPanel.vue` 已删除，因为它只能表达一种固定的底部布局。

## 6. 人工验收步骤

启动前端后依次检查：

1. 在底部模式拖动上边缘，确认三维视口随高度变化重新适配；
2. 切换侧栏模式，拖动左边缘，确认聊天内容和三维视口均未溢出；
3. 切换专注模式，确认 AI 内容占满可用区域，并能按 `Esc` 返回；
4. 刷新页面，确认显示模式和尺寸保持不变；
5. 对包含执行节点的历史会话切换五种筛选，确认内容类型正确；
6. 选择“跳转节点”，确认任务卡片和目标节点自动展开；
7. 点击顶部“隐藏 AI”再重新显示，确认当前会话和运行状态没有丢失。

代码级检查命令：

```powershell
cd E:\AgentProject\WildAgent\wild-web
npm run build
```

该命令会先运行 `vue-tsc` 类型检查，再执行 Vite 生产构建。
