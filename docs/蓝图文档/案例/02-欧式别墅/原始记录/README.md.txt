# 玫庭庄园 · 欧式别墅

正式文件：[玫庭庄园-欧式别墅.wild](玫庭庄园-欧式别墅.wild)。

![真实引擎透视图](05-效果图/perspective.png)

两层法式古典别墅，包含爱奥尼石柱门廊、拱形双门、铁艺露台及法式小阳台、石窗套、百叶、角石、齿饰、瓦垄坡屋面、三个老虎窗、双烟囱、玻璃花房、喷泉与玫瑰前庭。室内有起居、餐厨、书房、两间卧室、浴室和双跑楼梯，配有实际家具。

最终为 r2：1,286 个基础元素、62 个组合构件、25 种材质。Schema 通过；Core 组件编译、网格重建零错误、零警告，真实 Chromium 输出 1,726 个网格，未映射材质为 0。正式四视图和两份剖切共 12 张图，已查看四视外观和两层剖切俯视。

完整项目流水线 18 项中，17 项无错误，1 项 `validate_roof_coverage` 保留错误报告，零警告：当前全图检查器把小老虎窗解释为退台，并使用 18×11 米主楼作为其承托范围。没有删除老虎窗或修改校验器来制造通过。按真实承托组调用同一个屋面检查器，并独立计算包含墙厚的包络，主楼、花房和三个老虎窗共五组均通过；这份局部复核不等于全图流水线通过。详情、原字段与复现命令见流程日志和原始 JSON。

与汀院使用完全相同的当前引擎摘要、浏览器、相机规则、光照和图片尺寸。作者判断立面、门廊、屋顶、铁艺和庭园细节已达到参考的细化深度；审美请结合真实截图判断。房屋不含施工、结构安全与完整导航证明。

复现：在项目根目录，使用项目 Python 运行作者脚本；脚本导入 `../00-公共脚本/构件作者工具.py`，该工具只含本轮原语函数，没有历史别墅方案参数。随后运行公共校验、屋面复核、项目 `validate-generated.mjs` 和 `render-baseline.mjs`。完整命令及退出码见 `03-过程记录/命令记录`，其中完整项目校验的退出码 1 是明确保留的老虎窗误判。
