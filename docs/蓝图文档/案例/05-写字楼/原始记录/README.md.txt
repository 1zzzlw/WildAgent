六层、3.9m 层高，前五层 24×17m，顶层向南和东退台。包含接待等候、成组工位、会议室、茶水区、两跑楼梯、电梯井与层门、露台、格棚、设备屋面及光伏板。玻璃、浅石边框和金属遮阳竖片均由真实几何/材质表达。

811 个基础构件、135 个组合构件、22 种材质。Schema 与后端完整流水线通过，错误步骤 0、警告步骤 0；真实重建 2531 个网格，编译/重建错误 0、缺失材质 0。最终网格数量以渲染清单为准，不作为审美评分。

额外复核了五块上层楼板的完整面积、梯井/电梯井开口、十跑楼梯与平台的接续、130 个踏面位置的楼板净空、电梯六层停靠及露台西端回折栏杆。首层、标准层、六层的查看副本只删除遮挡构件，未移动或重造保留几何。

电梯是当前引擎内置简化轿厢/导轨模型；本次没有把它扩展成完整电梯设备或建筑内漫游仿真。成果用于建筑表现，未经结构、消防、无障碍和施工审查。
