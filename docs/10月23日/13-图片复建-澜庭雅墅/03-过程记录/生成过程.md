# 澜庭雅墅的实际创作过程

1. 读取当前主语言/屋顶、开口、楼梯、灯与材质契约；从用户第一图辨认奶白线脚、中央退进、分段四坡屋面、二层栏杆和一层浅拱门廊。
2. 先保存设计输入。参考平面可读宽13.5米、深约13米；后部/楼梯/房间按住宅用途补全。没有调用项目Agent、RAG或模型API。
3. 用Python标准库作者脚本展开墙板、真实开洞组件、两个楼层、楼板梯井和家具；屋瓦纵垄/横缝由四坡高程公式派生。WILD中只有参数，渲染时才生成网格。
4. 首次实际出图因柱帽radiusTop=0被Schema拒绝；错误稿单独保留，按正半径契约将柱帽顶改为0.015米，原始错误和命令见命令记录。
5. 看首轮正面/透视后，补浅拱实体拱肩、门廊椅、棕榈盆栽、室内真实灯与分层檐口；将横向瓦缝按约0.3米坡进深细化。
6. 标准四视图展示全地块；参考近景仅调整相机距离/角度，保留完整建筑与源文件。两种相机分别出清单，不能当相同条件比较。

## 局限

第一图的平面文字不完整，内部为合理补全，未声称逐房测绘。当前原语绿植和透射玻璃与参考照片有可见差距。室内布置存在但没有完整可达性/碰撞检查；前端UI测试仍由用户负责。

7. 根据空间程序补两层卫浴与西侧房间横向分隔。最终设计修订号2，场地事实明确为22×28米（另含2米道路）；最终近景方位145°、极角74°，不改变建筑数据。最终hash见生成统计与出图清单。
