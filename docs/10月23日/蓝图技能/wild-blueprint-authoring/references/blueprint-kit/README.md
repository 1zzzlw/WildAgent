# WILD 蓝图创作包 v3.0

这套资料用于让AI根据需求独立设计并输出完整WILD，覆盖住宅、亭廊、办公、公共建筑和商铺等当前几何可表达的类型。它提炼了11栋当日作品与汀院质量参照的经验，保留可自由设计的空间，也明确格式、计算与实际引擎边界。

2026-10-23已参考用户提供的v2.0作补充：增加依赖联动、精度、重复立面、圆形/分段建筑和门廊装配检查，纠正与现引擎冲突的规则。版本名称仍为v3.0，详见 [采纳说明](03-v2.0参考采纳说明.md)。

同日渲染修订已同步多边形楼板/真实孔洞、显式扫掠端盖、米制平面材质UV、局部灯预算与共享展示出图。新几何字段属于前端/Core扩展，后端设计/校验链未修改；经旧链路时仍用兼容拆板。历史案例与已有实图保留原样，新能力以当前源码和新验证结果为准。

同日关系修订补充源构件身份、统一宿主引用和坐标语义，更新完整Core快照；编辑支持与限制见主语言§8.8。没有新增GLB实例、风扇运动或通用组织树语法。

项目坚持极小文件表达精细建筑，不采用GLB/GLTF模型资产路线；后续丰富度通过参数化几何、紧凑装配复用与声明式行为提升。尚未实现的机制不能提前写进正式WILD。

同日界面与材质修订新增石英石/木板参数表面，并将水面显示策略固定，见主语言§6/§7.3；源码快照已同步。本轮由用户负责测试，未运行构建、测试或渲染，历史验证报告不代表新增实现已验收。

**只想把一个文档发给大模型：直接发送 [WILD蓝图设计语言-v3.0.md](WILD蓝图设计语言-v3.0.md)。** 文末有启动提示词，正文含字段、装配方法、差异化原则、自检和完整JSON例子。不必附项目源码或安装工具。

## 本包没有隐藏的“万能建筑生成器”

设计由读取语言的AI完成；包内新写的Python脚本只检查文件或展开一个教学例子。原项目Core负责确定性编译与网格重建，Three.js/Chromium负责显示。它们不会根据“欧式别墅”四个字自动规划建筑。

本批大部分作品由当前对话中的Codex做设计、作者脚本展开、原项目检查和真实看图修订，没有运行项目LangGraph/RAG或模型API。完整后端/Agent、编辑器界面、模型配置、数据库、密钥与依赖缓存均不包含在本包。来源和边界公开，不把这些能力隐含为任意AI的首次生成保证。

## 最短使用示范

给模型附上主语言后发送：

> 生成一座24×20米地块的两层现代别墅，三卧、书房、餐厨、家庭起居，有院子不要泳池，招牌“松间居”。自主设计体量、平面、交通、屋面、材料和构造细节，避免照搬文档教学例子。只输出完整自足WILD JSON。

将输出保存为UTF-8的`松间居.wild`，导入WildAgent查看。要进一步核验则按工具说明执行。语法成功、几何可重建、空间完整和画面满意分别确认；任何一种都不能替代其他项。
