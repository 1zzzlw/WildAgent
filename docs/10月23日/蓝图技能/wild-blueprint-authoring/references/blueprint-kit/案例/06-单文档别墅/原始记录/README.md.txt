两层现代石木住宅：两层主楼与单层起居翼组成 L 形庭院，翼部上方是可到达露台。包括庭院起居、餐厨、书房、两间卧室、两处卫浴、阅读区和连续两跑梯。细部有基座、窗台/窗套、层间边带、木格栅、女儿墙与压顶、玻璃防护、露台木平台和格棚。

本次唯一作者资料为 `docs/Wild蓝图设计语言.md`，磁盘版本 1.2。作者脚本从零编写，只使用 Python 标准库；未导入其他建筑文件、历史生成脚本、共用构件作者工具、图片、知识库或项目提示词。项目的 Schema、后端流水线和真实渲染器只用于生成后的验收/显示；没有运行 Agent 或 RAG。当前对话已有历史上下文，因此这不是新模型的独立盲测，也不是一次无修订生成的演示。

最终为 r2：372 个基础元素、41 个组合构件、24 种材质，72703 字节，真实重建 780 个网格。Schema、后端只读全流水线与引擎编译/重建均通过，错误 0、警告 0、缺失材质映射 0；确定性重放与正式文件指纹相同。

首层查看副本移除了二层楼板，后端因此提示上行楼梯终点没有承托；两个去顶副本均提示没有完整顶盖。这些原始报告保留，是副本删除遮挡层后的状态；不将其写为完整建筑验收通过。两副本 Schema 与真实编译/重建通过，保留几何逐项与正式文件相同。正式建筑的对应完整关系已通过校验。

这是建筑表现模型；本次没有进行结构、消防、机电、施工、人员导航或门窗逐帧交互专项验收。图片来自真实项目渲染，不是 AI 效果图或外部建模替代图。
