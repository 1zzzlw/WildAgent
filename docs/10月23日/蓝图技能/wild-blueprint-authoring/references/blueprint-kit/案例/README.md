保留问题：玫庭的老虎窗和听雨水榭的木构屋面有全图后端识别误判及范围明确的复核；知序图书馆保留原语承托识别提示；澄屿保留前端露台覆盖提示；Forest Cafe保留露天护墙/连接识别提示。原始JSON随记录带走，不能把这些例子统一描述为后端全图零错误零警告。

学习每栋如何组织用途、空间、构造与细部即可，勿把所有参数和布局变成固定模板。
