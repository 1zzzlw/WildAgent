## 设计事实与过程

本例为本次语言整理新建的语法样本，不计入原十二例。先在本文主语言及作者脚本中确定一层6×4.8m茶室、12×10m场地、前方到达与两级阶、四面墙和独立屋面，再输出完整WILD。

场地完成面+0.06m，台基顶+0.32m，室内/门廊完成面+0.36m，墙顶/屋面底+3.22m，屋面厚0.18m。前墙朝较小Z，门居中，两侧窗有窗台和上口；屋檐边和四边压条独立建模。文字牌局部+Z经Y轴180°转向正面，写“听风茶室”。室内有桌椅、后侧小柜台和一份真实光源。它不包含卫生间/完整商用运营功能，不标为完整咖啡馆。

生成顺序：`展开最小茶室.py` → 原始Schema/引用/尺寸检查 → 复制核心资料到独立临时目录 → 安装随包依赖 → 包内Core检查 → 包内真实WebGL四视图。主语言里的完整例子从同份WILD同步，避免两份数字漂移。

已实际查看正面和透视图：门廊/两级阶接续、左右窗和屋檐可见，招牌文字可读；室内家具透过玻璃部分可见。侧面和俯视也已出图，查看范围以验证说明为准。未进行去顶室内、夜景照明和逐帧开门专项验收；不能据此声明这些专项通过。

26个基础元素、6个组合构件、7种材质；重建76网格，Core编译/重建诊断0，材质缺失0。教学例展示契约闭合，**不作为本批丰富建筑的质量上限或后续方案默认模板**。更丰富类型表达看案例与创作复盘。
