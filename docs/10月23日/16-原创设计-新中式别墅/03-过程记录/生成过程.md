## 01 项目扫描

- 阅读项目 `README.md`、当前 `WILD蓝图设计语言-v3.0.md`，确认文件 `meta.version` 仍写 `"1.1"`。
- 阅读 `wild-core/schema.json` 与 `types.ts`，核对墙、楼板、屋顶、楼梯、原语、门窗/栏杆/灯组件、材质与 `lightSource` 的必填字段和枚举。
- 阅读 Core 的 `roof.ts`、`floor.ts`、`wall.ts`、`stair.ts`、`compiler/components/attachedToWall.ts`、窗/门/栏杆/灯编译器，确认坡面公式、板底锚点、沿墙 `from`、门窗深度校验和栏杆路径语义。
- 阅读前端 `materialAdapter.ts`、`waterSurfaceMaterial.ts`、`waterReflectionRuntime.ts`，确认玻璃 `transmission`、水面识别（`ior≈1.333` 或 `water` 名称）、动态波纹与反射条件。

- 查看听澜合院、云汀合院、栖庭等既有新中式方案，只用于能力与差异化对照，没有复制其平面、体量、坐标或材料组合。
- 初始 `git status` 显示用户已有未提交修改；本轮只在 `docs/10月23日/16-原创设计-新中式别墅/` 下新增文件。

## 02 设计事实与实现路线

- 场地 30×24 m，南向到达；东侧两层主宅、西侧单层茶室、南侧门屋，中间南北长水院与木廊桥。
- 先写 `设计输入.json`，再写只依赖 Python 标准库的确定性作者脚本；重复瓦垄、椽、栏杆、家具和植栽由脚本展开，正式 WILD 自足，不依赖脚本或外部资产。
- 院墙用实体 box 而不是 wall，避免项目校验流水线把 30×24 m 院墙误判为低层退台承托；主宅、茶室、门屋三块屋顶分别由自身墙顶承托。
- 主要楼板采用矩形拆板，梯井、双高挑空和池口均真实留空；门屋用原生矩形洞口，其余门窗用组合构件真实裁墙。

## 04 r2 设计修订

看图后确认首稿水院被两侧屋面夹成暗缝、南立面缺少檐下层次、院墙过于整片。r2 做实质修订：

- 水池从 Z 0.2–8.4 南延到 Z -6.0–8.4，形成从门屋可见的长水院；加跨水汀步与西岸石凳。
- 照壁移到西侧 `X -9.4–-4.6, Z -7.2–-6.8`，不再压住水院南端。
- 主宅南侧加三柱檐廊（X 8.6–14.5），茶室南侧加两柱木格棚（X -6.9–-2.7）。
- 主宅南立面窗改为 4.3 / 7.2 / 12.0 m 三开间对齐；门额放大。
- 院墙增加木格漏窗，增加东侧竹丛、花灌木、池面补植、池边地被；檐廊/入口雨棚补瓦垄，茶室/门屋补脊端饰。
- r2 结果：1,356 个基础构件、40 个组合构件、37 种材质、219,306 bytes；Core 1,675 网格；静态/项目流水线均 0；白天四视图 0 错误。

## 05 r3 视觉收口

第二轮看图后继续处理水色、侧山墙、院墙高度和门额照明：

- 水面基色与衰减距离调亮，池底改为浅石色；池内加 3 个真实发光点。
- 南院墙从 2.20 m 降到 1.85 m，东西北院墙保持 2.20 m；南墙漏窗同步降低。
- 主宅山墙圆窗加大并外移，两侧山墙加木格屏；主脊加端饰。
- 门额加洗墙灯，门屋两侧加壁灯；茶室东门旁加壁灯。
- 檐廊/入口雨棚补瓦垄细节；庭院红叶树减为少量，增加浅绿/白花灌木与竹丛。
- r3 结果：1,397 个基础构件、40 个组合构件、37 种材质、225,507 bytes；Core 1,716 网格；静态/项目流水线均 0；白天与黄昏各 4 视图均 0 错误。

## 06 剖切查看

- 公共 `制作剖切.py` 依赖 `构件分层.json`，且上层家具阈值是 Y>4；本建筑有多处 3.5–4.0 m 的上层构件，因此写了本建筑专用的 `06-剖切查看/制作本建筑剖切.py`。
- 脚本先生成 1,437 个源 ID 的分层记录，再复制两份 WILD：
  - 一层：删除 roof / roof_detail / wall_upper / floor_upper / facade_upper / gate，以及 Y≥3.5 的上层家具；删除 698 个遮挡件，保留 716 构件/23 组件。
  - 二层：删除 roof / roof_detail / gate；删除 510 个，保留 887 构件/40 组件。
- 两份副本的静态检查与 Core 重建均 0 错误；分别渲染四视图。剖切来源 JSON 记录源 hash、副本 hash、删除 ID、分层和保留数量。
