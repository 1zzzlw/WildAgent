## 5. 边界

- 自动检查通过不等于结构承载、消防、节能、无障碍或法规合规。
- 前端交互、编辑器内拖拽、相机与 UI 测试由用户执行；本轮没有运行完整 Vue 编辑器或后端 Agent 生成链。
- 剖切副本只删除遮挡，缺屋面/缺上层板属于查看设置，不是正式 WILD 的缺陷。
- 审美是否达到预期以实图为准；零错误只证明对应自动检查通过。
