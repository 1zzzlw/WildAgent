# 砚溪别院 · 新中式别墅

## 1. 主命题

“东宅西亭，一水连院”。场地 30×24 m，东侧两层主宅、西侧单层茶室并列，中间留出从门屋一直延伸到前院的南北长水院；木廊桥与跨水汀步把两侧体量与户外交通连接起来。南侧门屋、照壁和主宅三柱檐廊组成“门—院—水—桥—宅”的到达序列。

本稿与既有合院方案不同：不把主楼放在北侧再用两翼围合，而是让两座体量隔着水院并置，靠桥和汀步组织生活。设计目标是把“新中式”落在院落、檐下、木格栅、瓦垄与材料的真实构造上，而不是只换名称或颜色。

## 2. 场地与体量

- 场地 X -12–18、Z -10–14，南侧（-Z）为到达面；南院墙 1.85 m，东西北院墙 2.20 m，南低北高。
- 主宅 X 2.5–14.5、Z -2–10，两层；首层完成面 +0.30，二层 +3.70，二层墙顶 +6.90；主屋顶双坡，脊沿 X，檐口 +6.90，脊高 +8.80。
- 茶室 X -7.5–-1.5、Z 2.0–9.5，单层，墙顶 +3.60；屋顶双坡、脊沿 Z，脊高 +4.65；东侧出檐覆盖木檐廊，三根木柱落在檐廊上。
- 门屋 X 5–9、Z -10–-8.6，墙顶 +3.20；前后墙各开 2.2×2.4 m 洞口，形成短门道；屋顶双坡、脊沿 X。
- 水院 X -0.6–1.9、Z -6.0–8.4，池底 -0.55，水面 -0.08；南段 Z=-3.6 设五块跨水汀步。
- 木廊桥 X -0.85–2.6、Z 3.5–4.9，桥面 +0.34，两侧木栏杆；连接主宅西墙门与茶室东墙门。
- 照壁 X -9.4–-4.6、Z -7.2–-6.8，高 2.3 m；主宅南侧三柱檐廊 X 8.6–14.5、Z -3.8–-2.0；茶室南侧两柱木格棚 X -6.9–-2.7、Z 0.4–1.9。

## 3. 空间组织

首层：南门进入门厅，向东展开为双高起居；北侧为餐厨，厨房沿北墙布置操作台与石英石岛台；西侧为客卧套房，内含独立客卫；西北角为两跑楼梯厅；跨过廊桥进入茶室，茶室北端设备茶间。

二层：楼梯井到达西侧梯厅；西南为卧室 3，西侧梯厅连接家庭厅；中南为卧室 2，中北为公卫；东侧整跨为主卧套房，含主卫与衣帽区；东南角保留双高起居挑空，沿 X=10.2 与 Z=2.0 设栏杆，可从二层俯看首层起居与南向庭院。

## 4. 交通与楼梯

- 两跑楼梯位于西北角：第一跑 X=3.3、Z 6.6→9.0；中间平台顶 +2.00；第二跑 X=4.5、Z 9.0→6.6；每跑 10 级，步高 0.17 m、步深 0.24 m，梯宽 1.0 m。
- 二层梯井 X 2.5–5.4、Z 6.9–10.0；上口用实体平台与拆板留空，梯段与平台全宽承接。
- 主宅西墙门与茶室东墙门通过廊桥连接；桥面与两侧檐廊保留 4 cm 高差，作为门槛感。
- 南侧跨水汀步与门屋、主宅入口、茶室南格棚共同形成多条户外路径。

## 5. 立面、屋面与构造

- 主宅南立面按 4.3 / 7.2 / 12.0 m 三开间对齐：首层为客卧窗、双开玻璃门、起居通高窗；二层为卧室窗、家庭厅窗、东南 3.8×3.0 m 双高玻璃。
- 主宅东立面有起居/餐厨窗、主卧窗与主卫高窗，上部加竖木格栅；西立面有廊桥门、客卧窗与卧室窗；北立面为厨房高窗、卧室窗与主卫小窗。
- 茶室东立面正对廊桥：1.0×2.3 m 玻璃门、两侧落地窗，三根 `chinese_wooden` 木柱承托出檐；南侧木格棚与长凳形成半室外茶座；西/北面为长窗和高窗。
- 三块双坡屋面分别由主宅二层墙、茶室墙、门屋墙承托。瓦垄、横向瓦缝、正脊、脊端饰、封檐板、博风板、檐下椽与斗拱均从各自坡面派生；主宅山墙加圆窗，两侧山墙加木格屏。
- 院墙用石材基座、暖白墙身、瓦顶压顶，并加木格漏窗；门屋用石门套、抱鼓石、开启木门与“砚溪别院”门额，主宅门额“砚溪”，照壁题“澄怀”，茶室题“听松”。

## 6. 水、绿化与光

水院按“池口—池底—池壁—压顶—水面”的真实关系建模；水面低于压顶 0.18 m，池底为浅石色，南段设汀步，池面点缀睡莲与锦鲤。水面使用 `water` 材质，`ior=1.333`，透射与吸收参数按浅水调整。

绿化分三层：前院以造型松、红枫和景石建立到达识别；西侧竹院沿墙布置竹丛与地被；北后园为碎石、苔藓、石灯与长凳。院墙内侧有漏窗、花灌木和低矮地被，避免整片白墙。

照明分真实光源与发光面：门屋门额洗墙灯、门侧壁灯、池底灯、主宅檐廊壁灯、茶室东门壁灯、餐吊灯、起居吊灯、厨房岛台灯、主卧吊灯和园路地灯使用 `lightSource`；檐下灯带、池底灯罩和灯笼纸面使用 `emissive` 材质。
