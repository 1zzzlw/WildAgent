# 独立创作：棕影水院

## 任务和边界

用户要求：扫描项目信息，随机选择一种别墅，创建可渲染 WILD；生成时不得使用创建蓝图 skill；完成后更新项目中的该 skill；完整过程保存到本目录。

本次生成阶段不读取、不调用、不复制 `wild-blueprint-authoring` 目录及其脚本、参考资料。依据当前项目公开文档与实际 Core/renderer 源码自行设计。仅在成品通过检查并查看真实渲染后，进入 skill 更新阶段。

不修改业务源代码，不覆盖历史建筑，不调用模型 API、RAG、LangGraph，不提交 Git。作者脚本只展开本方案；当前项目 Core 执行组件编译与网格重建。

## 执行顺序与验收

1. 扫描当前契约和工具：核对 DesignDocument、WILD Schema、材料/门窗/屋面实现、真实渲染入口。
2. 保存设计输入：使用当前 `DesignDocument` Pydantic 类型验证；明确场地、体量、房间、开口和标高。
3. 展开 WILD：作者脚本读设计文件生成；执行原始 Schema、引用、开口界限、几何关系检查以及当前 Core 编译/重建。
4. 真实渲染：用项目 Chromium/WebGL 路线生成展示四视图、夜景和剖切图；实际查看图片，保留修订记录和输入 hash。
5. 成品完成后更新项目蓝图 skill：只提炼已验证的可复用经验，保存修改前副本、差异、校验与打包指纹。
