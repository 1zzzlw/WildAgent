# 棕影水院：现代热带别墅

风格从四项候选随机选出；平面、尺度和构造为本次原创，未调用创建蓝图 skill，未读取旧三层现代别墅设计模板。

## 空间和尺度

场地外缘 X=−14～14、Z=−10～12，入口朝 −Z。主体为 U 形：西翼 X=−11～−5、Z=−5～7；东翼 X=5～11、Z=−5～7；后厅 X=−5～5、Z=3～7。三体量在后厅左右直接连通，不在共享界面重复建墙。

西翼前段起居、中段餐厅、后段开放厨房；东翼两间独立卧室、1.4m 净宽走廊、后侧书桌区与共用卫浴。中央庭院10×8m，泳池4×4m，院内铺地在两翼深檐下连续。前庭三级浅踏步到达露台，绕池进入后厅，可分往客餐厨或卧室走廊。

单层是本方案的空间选择。没有虚构二层、楼梯或阁楼；坡顶下是完整天花。

## 标高与构造

| 对象 | 米制标高/范围 |
| --- | --- |
| 场地顶 | 0.00 |
| 露台顶 | 0.16 |
| 室内完成面 | 0.18 |
| 墙顶/檐底板底 | 3.50 |
| 檐底板顶 | 3.57 |
| 坡顶檐面 | 3.75；厚0.18，最低3.57 |
| 坡顶脊顶 | 5.25 |
| 后厅平顶 | 底3.50、顶3.70 |
| 池底顶/水面 | −1.12 / 0.04 |

两翼屋面各8×14m，包含1m轴线出檐；木檐底板、深色封边、檐下柱及柱脚形成可见收口。立面以暖白灰泥、深色框、窄幅木格栅和石材基座组成。窗与门使用真实宿主开口，门采用显式开合配置；家具、灯体、植物均由当前支持的原语表达，无外部资产。

泳池开口贯穿场地与露台，池底、池壁、水体和压边分别建模；透明水面不能覆盖完整地板充当泳池。景观叶冠也纳入场地外缘复查。

## 设计文件与生成边界

`DesignDocument.json` 通过当前 `app.design.contracts.DesignDocument`。标准字段记录体量、风格、材料与屋面意图；`decisions.authoring` 承载本次作者脚本消费的精确墙、房间、开口和标高。该扩展不是后端通用字段能力声明，Pydantic 通过不等于后端 Agent 已执行这些布局。

本次路线为：保存设计 → 专用 Python 展开 → 原始 Schema/空间检查 → 当前 Core 组件编译与网格重建 → 项目 Chromium 展示渲染。没有运行 `compile_document`、LangGraph、RAG 或模型 API。

棕榈为简化形体，厨房、洁具和家具为概念表达；静态图不证明门窗动画、完整编辑器交互、结构安全或施工可用性。
