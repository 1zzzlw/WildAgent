| 版本 | 内容 | 实际流程 |
| --- | --- | --- |
| [V1-优化前手工基线](V1-优化前手工基线/README.md) | 栖庭原设计、WILD、编译记录、真实截图，文件原样归档 | Codex 手工设计与专用实现器；没有运行 plan / execute 节点 |
| [V2-优化后Agent生成](V2-优化后Agent生成/README.md) | 已实际调用；设计阶段失败，用户已要求停止测试 | 实际到达 classifier → architecture；尚未执行 plan，未产生新 WILD |

| [V4-Codex设计与项目计划流程](V4-Codex设计与项目计划流程/README.md) | 已生成栖庭 V4 WILD、校验记录、四视角与剖切渲染 | Codex 编写设计及生成处理器；真实运行 plan → execute / replanner → compile → final_validate；项目模型调用为 0 |

当前后续改动见 [Agent 参数计算收敛优化](Agent参数计算收敛优化/README.md)：减少模型填写派生参数，删除重复提示与修订注入，接入受支持构件的程序实现；本轮未运行测试或重新生成建筑。

V2 及用户最近两次测试暴露的问题与后续修复见 [设计节点失败诊断与修复](设计节点失败诊断与修复.md)。后续已完成 V3 定向回归与重新生成；V3 仍在设计阶段失败。V4 按用户要求使用 Codex 自身设计与实现能力完成，具体执行边界见版本记录。

V1 归档文件附 SHA-256 清单。脚本保留原始字节与原相对路径写法，作为历史证据；目录搬迁后旧脚本的 ROOT 路径不适合直接复跑，且当前契约已变化。V2 使用独立调用入口，不修改 V1 来适配新版。

V1 / V2 的作者和执行方式不同，这次比较可以观察完整 Agent 的实际效果，不能单凭两张图将差异全部归因于源码优化。
