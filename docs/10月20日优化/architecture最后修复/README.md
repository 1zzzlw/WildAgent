# architecture 本轮修复与真实模型测试

**当前结论：两轮真实生成均失败，本轮修复没有达到“稳定生成合格图纸”的目标。** 离线回归通过不能代替真实生成成功。

本轮只修改设计图纸与 architecture；经用户授权，运行离线回归并调用项目当前配置的大模型。没有接入下游编译与渲染。

## 实际测试

模型为项目配置的 **qwen3.8-flash**，思考开启，预算沿用项目的 4096；没有换模型、增加节点或提高单次 architecture 的三次调用上限。

第一轮用了 3 次模型调用，耗时约 242 秒，28474 tokens。第二轮改用实体 ID 修订，用了 3 次，约 180 秒，26795 tokens。共 6 次真实模型调用、55269 tokens；没有接受的 design.json。两轮失败记录全部保留。

## 两轮实际暴露的问题

第一轮首稿：一层路线穿墙时没对准门、二层路线穿梯井。修订模型调整了门和路线，但数错部分开口下标，最终还剩一条路线与主卧门洞错位。按 ID 修订解决的是定位可靠性，没有证明模型的布局判断已经可靠。

第二轮首稿：porch 的 south=0、north=-0.6，违反具名边界顺序。Pydantic 因这处错误拒绝整份输入，后续关系校验没有执行；模型最后一轮正确修改了 /components/porch/rect。之后才暴露出 13 处门窗缺少框/扇材质角色、1 对开口重叠及 4 条路线冲突。

这轮是**校验反馈分层中断**：附属构件一个字段错误，遮住了本来可以独立发现的主体问题。加上计算占用一次模型调用，整图只有一次修订机会，所以无法在固定预算内修完。原有“整图一次设计＋一次修订”的假设没有得到实测支持。

记录只证明边界、楼梯推导、默认编号和局部定位机制的具体行为；不能从两个失败样本声称生成成功率提高。下一步应先让独立错误能在同轮反馈，再用冻结坏稿验证完整修订，而不是继续逐条追加提示词或增加调用次数。本轮到此保留结果，没有继续扩展规则或反复抽样直到偶然通过。

## 用户补充 trace：01a158aa

用户随后提供的 Studio trace 也失败，确实使用 design-facts/2、楼梯预计算及按 ID 修订。原稿已经报告 21 条问题，最后一轮只调整楼面/屋面及屋顶，最终剩 4 条：门洞超过墙长 0.1 m、卫生间墙穿楼梯、一层及二层路线与门洞不符。这次不能仅归因于“独立错误没有同轮反馈”：三类未修错误在第一次检查中已经明确报告；二层墙恢复有效后又检查出了二层路线冲突。

首稿 levels 只有 GF=0、L1=3.2，main.top=L1，却在 L1 布置卧室。一个屋面标高缺失引出多条墙高/宿主错误。反馈“顶部房间需有可使用的平屋面”又引导模型把 gable 改成 flat；离线对照证实，只添加 RF=6 并将 main.top 指向 RF，保留原 gable/rise=2，仍能得到相同的最终 4 条错误，不需要更换屋顶造型。

本次只读分析和已有首稿离线检查，没有继续修改业务源码或新增模型调用。完整输入、修订及对照结果见 [07-用户trace诊断](07-用户trace01a158aa-诊断.json)。

## 本轮找到的原因与改动

| 原问题 | 原因与处理 |
| --- | --- |
| site 写成 [0,0,20,15] | 四数字语义易与起点/宽深混淆。rect/site 改成 west/east/south/north 具名边界，不猜测旧数组含义 |
| 楼梯宽度不够、布局后才发现放不下 | 先提供 calculate_stair；楼梯输入改为连接、尺度及 origin，程序推导占地，不再同时让模型填写互相冲突的矩形 |
| 重新提交时缺屋顶 id、无关实体变化 | 缺省屋顶编号由程序生成；修改用局部操作，程序保留其余内容，删除整稿 ID/楼层锁定及重复墙豁免分支 |
| 模型自填 9 级后被锁死 | 无用户级数要求时省略 steps_each，程序计算；明确填写但步高超限仍报错 |
| 修订改到了别的门 | 第一次真实调用证实模型数错数组序号。现在必须按实体 ID 修订；报告提供 edit_paths，并附相关门洞实际值 |
| 相接体量共墙的单个开口仍被另一侧判堵 | 使用世界坐标投影识别共墙开口，不要求两侧重复开门；独立内墙不被自动合并 |
| 错位开口可能被误判可通行 | 回归发现本轮新增共墙投影代码的局部变量覆盖了所需通行区间；已修复，并保留负例检查 |

门挂错楼层、墙穿楼梯、路线穿墙/洞口仍属于需要协调的设计错误，程序继续拒绝，不裁小门、不挪墙、不降低净距制造通过。声明跨层使用空间却删掉全部楼梯也会被拒绝。

## 结论边界

通过只表示当前字段与已覆盖关系检查通过，不能证明建筑美观、房间分区完整、全部房间可达、楼梯全程净高或构造已实现。L 梯实际转向和到达板、共墙两侧重复开口的完整合并检查仍未覆盖。
