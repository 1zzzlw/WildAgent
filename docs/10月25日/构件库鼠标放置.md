# 构件库鼠标预览与放置

构件库原先点击即添加到默认坐标，附墙构件取第一面墙，檐口取第一座屋顶。现在选择构件只进入放置状态：鼠标在视口内移动显示半透明预览，左键单击确认，Esc或右键取消。确认一次后退出放置，新增构件被选中，可通过原有属性面板编辑和历史记录撤销。

## 行为

- 普通构件通过射线落到模型表面；没有命中模型时使用当前场地的水平面。原构件的造型尺寸、招牌高度、灯泡离地高度等默认参数保留。
- 门、窗、雨棚、阳台与凸窗使用鼠标命中的直线墙，沿墙移动并限制在可用边界内；门底对齐宿主墙底。无有效墙或墙太小时显示提示，点击不写入。
- 檐口显示在鼠标命中的屋顶边界；兼容当前引擎推导位置的旧屋顶。
- 鼠标离开视口隐藏预览，重新进入继续；拖动超过5px不当作确认点击。切换文档、进入人物漫游/展示/线条模式会取消待放置对象。
- 预览为临时几何，不写蓝图、不增加revision或撤销历史。确认时用预览参数创建一次ScenePatch。
- 命中点由视口显示坐标转换回蓝图坐标；新增改变模型居中范围时同步移动相机和观察目标，使确认前后落点保持在同一屏幕位置。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `wild-web/src/components/panels/BlockLibrary.vue` | 选择待放置类型、选中样式及使用提示 |
| `wild-web/src/stores/blockPlacementStore.ts` | 面板与视口共享待放置选择，生成稳定源ID |
| `wild-web/src/wild/blockPlacement.ts` | 从原有默认构件参数构造指定落点的蓝图操作，计算墙面局部坐标 |
| `wild-web/src/renderer/blockPlacementPreview.ts` | 编译临时构件、生成半透明预览、复用几何并释放资源 |
| `wild-web/src/components/viewport/CanvasViewport.vue` | 射线命中、预览更新、确认/取消、显示坐标转换及生命周期 |
| `wild-web/scripts/block-placement-smoke.mjs` | Chromium真实输入事件回归 |

预览保留宿主与墙体推导上下文，过滤掉上下文网格，只显示新构件。同一选择/宿主内的移动仅改预览变换，不随每次鼠标移动重建整栋建筑。门窗预览使用半透明叠加，避免被确认前尚未开洞的墙遮住。

## 已执行验证

1. `node node_modules/vue-tsc/bin/vue-tsc.js -b --pretty false`：通过。
2. `node node_modules/vite/bin/vite.js build`：通过；输出有超过600KB的分块提示。最初`npm run build`包装命令在当前环境退出1且无诊断，随后直接执行其类型检查和Vite两步均退出0。
3. `node scripts/block-placement-smoke.mjs`：通过。覆盖空场景、鼠标移动、表面高度、偏离原点的场景、全部17种库条目、鼠标指定第二面墙/第二座屋顶、未显式定位的旧屋顶、预览/落盘参数及几何包络一致性、撤销、无效宿主、取消、离开视口、拖动保护和文档切换。招牌正式显示额外添加2mm文字贴面，实体预览包络比较对此单独保留2.1mm容差。
4. `node scripts/viewport-interactions-smoke.mjs`：通过。原有选择、双击移动轴、基础/组合构件拖动、撤销、多选、展示模式、空白点击和紧凑窗口布局回归通过。
5. `git diff --check`：通过。

浏览器回归使用原项目`serve-editor-smoke.mjs`与`editor_smoke_server.py`，后端数据位于独立临时目录；没有调用模型生成。无浏览器运行时/Shader错误。实际查看了门窗半透明预览截图，本次截图位于本地忽略目录`docs-dev/2026-10-25-block-placement`。
