# P3：约束归一化与默认规则

状态：未实施。前置：P2。目标：归一化纠正输入格式，设计改变可见且可追溯。

## 可直接使用的提示词

```text
请实施 WildAgent 建筑生成优化 P3。读取 docs/10月7日优化/03-Agent执行总约束.md，并核对共享解析入口。

重点审计 generation/architecture/planning.py、profile.py、facade.py，compiler/compile.py，utils/blueprint_normalizer.py，设计收敛和修复流程。

任务 A：分类现有规则
对会改变体量、屋顶、门窗尺寸、围护和材质的规则列出：输入字段、规则来源、触发条件、修改结果、是否改变设计语义。
分类为：协议规范化 / 可确定的几何派生 / 缺失值默认 / 设计语义变更。不要因为规则是确定性的就自动归入“物理必要”。

任务 B：实现最小变更记录
1. 利用现有 diagnostics/defaulted/defects 结构，必要时补字段，不创建另一套审计平台。
2. 对重要变化记录 path、before、after、reason/rule、来源类别和是否改变语义。
3. 能区分用户明确值、模型设计值、程序派生和默认值；用户来源无法准确识别时标 unknown，不假称用户指定。
4. 只有顶层 raw_plan 为 None 才 used_fallback 的旧判断不足以揭示局部回退，补充局部默认/丢弃证据。

任务 C：修正处理边界
1. 合法显式值保留；缺失值才使用默认。
2. 显式非法值给出具体字段问题，进入现有有界设计修订；修订失败可产生明确降级，但不能隐藏变化。
3. roof 数组等不支持输入不得默默换成另一屋顶类型。可无损迁移则迁移，不能无损表达则报协议问题。
4. 同层体量重叠不能简单视为“模型设计无意义”；先判断能否等价分解。非等价推移、删减、整案回退必须标记设计变化。
5. 设计说明不能继续宣称已经消失的退台、平屋顶等。优先从最终决策生成事实摘要，非结构化理由保留时标记是否仍适用。
6. 批准前允许有界修订；批准后自动修复只能保持设计语义，改变批准设计遵循原有确认流程。
7. 不通过取消几何校验或把阻断错误降为 warning 来让样本成功。

测试：缺失值/合法显式值/非法值分别覆盖；局部 fallback 有证据；归一化重复执行不继续改变方案；有效设计前后语义一致；批准设计的语义变化被识别。
不要在本阶段扩大尺寸自由度的全部 Schema，P5 负责新增表达。现有表达不足的值如实标明，不能伪装支持。
交付一份规则分类表、变化记录样例及对应回归。测试覆盖通性，不以历史别墅 ID 为分支。
验收：合法显式决策经过归一化与编译保持语义；每个默认、丢弃或语义改写都有字段级证据；批准后的设计不能无记录地变化。运行未完成时不得标记本阶段验收通过。
```
