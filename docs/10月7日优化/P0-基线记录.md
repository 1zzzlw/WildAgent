## 数据契约地图

| 字段 | 生产者 | 实际消费者 | 覆盖风险 / 验收 |
|---|---|---|---|
| architecture_plan | architecture.workflow、convergence、review_outcome | compile_node、构件检索、plan | 分块过滤、归一化、审核往返 |
| design_document | design.resolver、material_workflow、review | repository、审核、SVG、交付 | build_design_document 未传 components |
| resolved_design | resolve_design、repository.save | 审核预览、meta.designHash | 与实际 facade 槽位另算尺寸 |
| design_brief | compile/facade 或 skeleton | 构件提示词、merge conform、final_validate | 末端吸附可能覆盖实例形态；主要验收槽位与配额 |
| components | 设计实例（不同于 Blueprint 组件） | compiler._compile_from_instances | 分块只收 quota；文档双向转换丢失 |
| material_plan | material_workflow | document、compile、merge | 无资产跳过模型；引用检查不等于意图验收 |
| compile_report | compile_node | plan 缺口摘要、执行上下文 | 缺陷报告不等于逐条需求验收 |
| final_blueprint | validation.workflow | agent_delivery | complete 由最终错误列表决定，不含视觉验收 |

节点返回的是局部更新；组件映射通过 reducer 合并。未返回某字段不等于字段丢失。进入 State、进入提示词、影响输出是三个不同层级。
