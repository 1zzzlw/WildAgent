# 建筑描述 · 热带现代主义白色泳池别墅

> **输入**：用户提供的一张照片（无原始设计图、无平面图）。
> **本文的定位**：「图片 → 蓝图」链条里唯一的中间依据。先定建筑语言，再定尺寸，最后落到 WILD 类型。
> **注意**：本文不写"引擎能做什么"，只写"这栋房子是什么"。能力映射见 §4。

## 1. 读图

照片从泳池边斜看建筑正面（拍摄点在泳池一侧偏左，视角约 30°，略仰）。

### 1.1 决定风格的四条特征

| # | 特征 | 照片依据 |
|---|---|---|
| 1 | **纯白体量、无装饰线脚** | 所有墙面一片白，阴阳角利落；没有檐口线、窗套、勒脚、分格缝 |
| 2 | **平屋顶、薄檐口** | 屋顶就是一块薄板，板边约 20~30 cm，四周有少量出挑；无坡屋面、无女儿墙砌高 |
| 3 | **一层近乎整面落地玻璃** | 朝泳池这一面，一层从地面到楼板几乎全被玻璃占满，深色（近黑）细框，可透视到室内餐桌与座椅 |
| 4 | **深色木格栅是唯一的暖色插入** | 左侧门廊的顶棚是深棕木格栅；二层阳台扶手同为深棕木 |

四条合起来 = **热带现代主义（Tropical Modernism）**：
**白墙当画布 + 玻璃做通透 + 木材点温度 + 平屋面板收头。**

### 1.2 体量：四个盒子，靠高低差造型

这栋房子不靠装饰取胜，靠体量错落。可拆成 4 块：

| 体量 | 位置（相对主体，+X 向右、+Z 朝泳池） | 层数 | 说明 |
|---|---|---|---|
| **A 主体** | 居中偏右 | 2 层 | 最大的一块，屋面最低 |
| **B 门廊体量** | 贴主体左前方（−X、−Z 角） | 2 层通高 | **顶面高于主屋面**；一层架空，仅一根方柱落地；顶棚为深色木格栅 |
| **C 内退块** | 主体右侧后方 | 2 层 | 二层墙面往里退，形成一片阴影凹口 + 一扇窗，破掉大平面的单调 |
| **D 顶部高块** | 左后方 | — | 冒出的白色竖向体（楼梯间/设备井一类功能体），是全屋最高点 |

> 关键观察：**B 的顶面比 A 高、D 又比 B 高**，三级台阶式升起，视线被引向左侧。
> 这是整张图里最容易被忽略、但删掉就"变成普通白盒子"的关系。

### 1.3 细部

- **门廊（B 的一层）**：一根白色方柱落在画面左前，上方悬挑出整块楼板；楼板底面封深色木格栅。地面无台阶，直接与泳池平台平接。
- **悬挑阳台（A 的二层，朝泳池面中部）**：白色实体悬挑板（板侧看得到厚度），栏板为玻璃，扶手为深棕细木条。阳台后方是通高玻璃门。
- **二层实墙**：阳台左右两侧都是白墙，右侧墙上有一扇方形窗（凹进、无窗套）。
- **一层玻璃幕墙的构型**：竖向细框把玻璃切成若干宽扇；框为深色。底部**没有明显窗台墙**——玻璃直接落到接近地面（这是"看不到勒脚"的原因）。
- **泳池平台**：浅色石材，与建筑同标高，中间只差一条收边线。

### 1.4 场地与画面

- **泳池**：紧贴建筑正面，深蓝色马赛克池底，池沿为浅色石材；画面里能看到池内蓝色分层次（浅水区/深水区）。
- **池边家具**：两张木质躺椅，靠建筑右侧。
- **植被**：右侧一棵高大椰棕，左下角一丛小棕榈，池边低矮灌木。
- **周边**：右侧有浅色围墙与相邻建筑的白色体量（同小区）。
- **天空**：晴朗，蓝天 + 白云。**光照判断：正午偏后的硬光**，阴影短、对比强，白墙亮部接近过曝、暗面偏冷灰。

## 2. 尺寸推定

照片没有比例尺，按热带度假别墅的常规做法推定（全部为**设计取值**，不是测量值）：

| 部位 | 取值 | 推定理由 |
|---|---|---|
| 主体平面 | **12.0 × 9.0 m** | 一层能容纳客厅+餐厨+一跑楼梯，符合画面上玻璃幕墙开间数 |
| 一层层高 | **3.30 m** | 玻璃幕墙显得比常规层高更高，取整 |
| 二层层高 | **3.20 m** | 常规住宅层高 |
| 二层墙顶（= 主屋面标高） | **6.80 m** | 3.30 + 3.20 + 楼板 0.30 |
| 楼板厚 | **0.30 m**（二层）/ 0.20 m（地面） | 悬挑板在照片里看得到厚度 |
| 主屋面 | 厚 **0.24 m**，四周出挑 **0.60 m** | 薄檐口 |
| B 门廊体量 | 平面 **5.4 × 3.0 m**，顶面 **7.60 m** | 顶面明显高于主屋面 |
| B 一层架空高度 | **3.30 m**（与一层同高），方柱 **0.40 × 0.40 m** | 柱在照片里接近方形、偏细 |
| D 顶部高块 | 平面 **2.4 × 2.4 m**，顶面 **9.60 m** | 全屋最高点 |
| 悬挑阳台 | 宽 **4.20 m**、挑出 **1.80 m**、栏板高 **1.10 m** | 玻璃栏板 + 木扶手 |
| 一层幕墙 | 高 **3.00 m**，分 **4 扇**，竖向细框 **0.06 m** | 玻璃近乎落地 |
| 泳池 | **12.0 × 4.0 m**，池底 **−1.50 m** | 前景横跨画面 |

## 4. 落到 WILD 类型（映射表）

| 建筑要素 | WILD 类型 | 关键注意 |
|---|---|---|
| 各层楼板、地面板 | `floor` | 地面板写 `from[1]=-0.2, thickness=0.2` → 板顶正好 0.0 |
| 主体两面外墙 / 内退块墙 | `wall` | 墙角两面墙**共用完全相同的端点坐标**（容差 0.01 m） |
| **主平屋面** | `roof` + `roofType: "flat"` | `position[1]` **必须等于承托墙顶**（6.80）；`span/depth` = 覆盖范围 + 出檐 |
| **B 门廊体量屋面** | `roof` + `flat` | `position[1]` = B 的墙顶 7.60，**它高于主屋面是故意的，不是悬空** |
| **D 顶部高块屋面** | `roof` + `flat` | `position[1]` = 9.60 |
| 一层落地玻璃幕墙 | `wall` + `window`（幕墙方案 A） | 4 扇并排，`frameWidth` 细、`glassDepth` 薄；底标高贴近楼板面（无窗台墙） |
| 二层落地玻璃门（阳台后） | `door` 或 `window` | 走 `parentWall` |
| 二层方形窗 | `window` | 凹进感靠 `frameDepth` 表达 |
| **门廊顶（悬挑板 + 木格栅底）** | `canopy` | ⚠️ `from[1]` 是**板中心**（不是板底/板顶） |
| **门廊方柱** | `column` + `style: "modern"` | `base` + `height`；`bottomRadius`/`topRadius` 取方形等效 |
| **悬挑阳台（含玻璃栏板 + 木扶手）** | `balcony` | ⚠️ `from[1]` 是**板顶**（板向下增厚）；`railingMaterial` 给玻璃材质 |
| 泳池池体 | `floor`（池底 / 池沿）+ `primitive`（池壁） | WILD **没有 pool 类型**，用组合表达 |

## 5. 照片里有、但这版蓝图**先不做**的（待迭代）

按重要性排序，**这些是下一轮的输入，不是遗漏**：

1. **室内**——照片能透视到餐桌椅，本版只做外壳（`furniture` 类型可以加）
2. **椰棕/灌木等植被**——需要植被系统，非 WILD 原生
3. **水的折射与马赛克分层**——材质系统能否表达水面待测
4. **围墙与相邻建筑**——场地尺度问题，先只做主体
5. **池平台铺装分缝**——细部，优先级最低

## 6. 验收口径

渲染出来后，按这个顺序看（从上往下，前一条不过就不用看后面的）：

1. **体量关系对不对**：B 比 A 高、D 比 B 高，三个盒子错落可辨
2. **白墙 + 深框玻璃**的对比在不在
3. **平屋顶薄檐口**有没有出挑、板边是不是白的
4. **悬挑阳台**是否真的挑出去、玻璃栏板是否通透
5. **门廊**：方柱落没落地、顶棚是不是深木色
6. **一层幕墙**是否近乎落地、分了几扇

> 分诊原则（用户定）：**渲染出来不对时，先判是蓝图的问题还是引擎的问题。**
> 判据：拿同一份蓝图跑 `check_blueprint_render.mjs`（真实编译重建 + 逐元素世界 AABB）。
> - 数据就错（悬空、穿透、坐标越界）→ **蓝图问题**
> - 数据对但视觉不对（材质、光影、法线、剔除）→ **引擎问题**
